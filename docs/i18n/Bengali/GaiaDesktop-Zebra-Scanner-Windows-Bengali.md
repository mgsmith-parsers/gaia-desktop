# Zebra স্ক্যানার সেটআপ — Windows-এর জন্য GAIA Desktop

কীভাবে একটি Zebra বারকোড স্ক্যানার ইনস্টল ও কনফিগার করবেন, যাতে GAIA Desktop সরাসরি সেটি থেকে
GS1 বারকোড পড়তে পারে: প্রতিটি স্ক্যান বিশ্লেষণ করে ইতিহাসে যোগ হয়, AIM Code ID উপসর্গ ও প্রতিটি
FNC1 বিভাজক অক্ষত থাকে। মূল নথি:
[GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md)।

GAIA Desktop তৈরি ও পরীক্ষা করা হয়েছে USB-তে যুক্ত একটি **Zebra DS8108** হাতে-ধরা ইমেজার দিয়ে।
ধাপগুলো Zebra-র Scanner SDK যে কোনো Zebra 2D স্ক্যানার সমর্থন করে তার সবগুলোর ক্ষেত্রেই খাটে;
নির্দিষ্ট মডেলের সেটআপ বারকোড ও মেনুর নাম পাওয়া যায় তার নিজস্ব Quick Reference Guide বা
Product Reference Guide-এ।

> **শুধু Windows।** Zebra-র স্ক্যানার ড্রাইভার শুধু Windows-এর জন্যই আছে, তাই macOS বা Linux-এ
> GAIA Desktop কোনো স্ক্যানার নিয়ন্ত্রণ তৈরি করে না। অ্যাপের বাকি সবকিছু সব প্ল্যাটফর্মে চলে।

## 1. যা যা লাগবে

| | |
|---|---|
| **স্ক্যানার** | একটি Zebra 2D স্ক্যানার, তার USB কেবলসহ — দেখুন [সমর্থিত Zebra 2D স্ক্যানার](#12-সমর্থিত-zebra-2d-স্ক্যানার) |
| **কম্পিউটার** | Windows 10 বা 11, 64-বিট |
| **Java** | Java 21 বা নতুনতর, **64-বিট** |
| **Zebra Scanner SDK for Windows** | **64-বিট**, Zebra-র সহায়তা সাইট থেকে — এটি ড্রাইভার এবং GAIA Desktop যে JavaPOS পরিষেবাগুলো ব্যবহার করে সেগুলো দেয় |
| **Zebra 123Scan** | Zebra-র বিনামূল্যের কনফিগারেশন ইউটিলিটি, Zebra-র সহায়তা সাইট থেকে — স্ক্যানারের ফার্মওয়্যার আপডেট ও সেটিং যাচাইয়ের জন্য |
| **GAIA Desktop** | `gaia-desktop-1.0.0-win.zip` |
| **ঐচ্ছিক** | স্ক্যানারের **Product Reference Guide** (PRG), যাতে সেটআপ বারকোডগুলো থাকে |

অংশগুলো কীভাবে মেলে:

```
Zebra scanner ──USB──► Zebra CoreScanner driver ──► Zebra JavaPOS services ──► GAIA Desktop
                       (installed by the SDK)        (in the SDK's JPOS\bin)    (run.bat puts them on
                                                                                 the class path)
```

GAIA Desktop নিজেই JavaPOS API এবং স্ক্যানারের নাম দেওয়া কনফিগারেশন (`jpos.xml`, `gaia-desktop.jar`-এর
ভেতরে) বহন করে। বাকিটা দেয় Zebra SDK: যে ড্রাইভার স্ক্যানারের সঙ্গে কথা বলে, আর Zebra-র সেই পরিষেবা
ক্লাসগুলো যেগুলো JavaPOS ও সেই ড্রাইভারের মাঝে থাকে।

## 2. Java ইনস্টল করুন

GAIA Desktop-এর **Java 21 বা নতুনতর** লাগে, এবং সেটি অবশ্যই **64-বিট** বিল্ড হতে হবে, যাতে 64-বিট
Zebra ড্রাইভারের সঙ্গে মেলে।

1. Windows x64-এর জন্য একটি Java 21 JDK বা JRE ইনস্টল করুন — যেমন adoptium.net থেকে
   Eclipse Temurin। ইনস্টলার `JAVA_HOME` সেট করার প্রস্তাব দিলে তাকে করতে দিন।
2. Command Prompt-এ যাচাই করুন:

   ```
   java -version
   ```

   প্রথম লাইনে সংস্করণ 21 বা পরবর্তী দেখাতে হবে; 64-বিট Java `64-Bit Server VM`-ও ছাপে।

`run.bat` এই ক্রমে Java খোঁজে: `run.bat`-এর পাশে একটি `jdk*` ফোল্ডার, তারপর `JAVA_HOME`, তারপর
`PATH`-এ থাকা `java`। 21-এর চেয়ে পুরোনো কিছু হলে বার্তা দিয়ে সেটি প্রত্যাখ্যান করে।

## 3. Zebra Scanner SDK ইনস্টল করুন

1. Zebra-র সহায়তা সাইট থেকে **Zebra Scanner SDK for Windows (64-bit)** ডাউনলোড করুন।
2. ইনস্টলার চালান। উপাদান বেছে নেওয়ার বিকল্প দিলে নিশ্চিত করুন যে **JPOS** (JavaPOS) উপাদানটি
   অন্তর্ভুক্ত আছে।
3. ডিফল্ট ইনস্টল অবস্থানই রাখুন। GAIA Desktop SDK-র JavaPOS অংশটি এখানে খোঁজে:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   এবং আশা করে যে Zebra-র পরিষেবা jar-গুলো (`JposServiceScanner.jar`, `JposServiceJniScanner.jar`, …)
   ও নেটিভ লাইব্রেরিগুলো (`CSJPOSScanner64.dll`, …) তার `bin\` ফোল্ডারে আছে। SDK অন্য কোথাও
   ইনস্টল করা থাকলে [ZEBRA_HOME](#zebra_home) দেখুন।
4. ইনস্টলের পর **Windows রিস্টার্ট করুন**। SDK-র CoreScanner ড্রাইভার পটভূমিতে চলে এবং GAIA Desktop
   স্ক্যানারে পৌঁছানোর আগে সেটি চালু থাকা দরকার; রিস্টার্ট করাই তা নিশ্চিত করার সবচেয়ে সহজ উপায়।

## 4. 123Scan ইনস্টল করুন

123Scan হলো Zebra-র স্ক্যানার কনফিগার করার বিনামূল্যের ইউটিলিটি। পরের ধাপে এটি দিয়ে স্ক্যানারের
ফার্মওয়্যার আপডেট করা হয়, এবং পরে স্ক্যানারের সেটিং যাচাই ও বদলানোর সবচেয়ে সহজ উপায়ও এটিই।

1. Zebra-র সহায়তা সাইট থেকে **123Scan** ডাউনলোড করে ইনস্টলার চালান।
2. Zebra স্ক্যানারটি লাগিয়ে 123Scan চালু করুন। এটি স্ক্যানারটি খুঁজে পেয়ে তার মডেল, সিরিয়াল নম্বর ও
   বর্তমান ফার্মওয়্যার সংস্করণ দেখানোর কথা। না দেখালে, এগোনোর আগে অন্য USB পোর্ট বা কেবল চেষ্টা
   করুন — যে স্ক্যানার 123Scan দেখতে পায় না, GAIA Desktop-ও তা দেখবে না।

## 5. Zebra স্ক্যানারের ফার্মওয়্যার আপডেট করুন

কনফিগার করার আগে স্ক্যানারের ফার্মওয়্যার সর্বশেষ সংস্করণে নিয়ে আসুন। ফার্মওয়্যার আপডেট ডিকোডিংয়ের
সমস্যা সারায় এবং স্ক্যানারকে SDK-র ইনস্টল করা Zebra ড্রাইভারের সঙ্গে সামঞ্জস্যপূর্ণ রাখে।

1. **GAIA Desktop** এবং স্ক্যানার ব্যবহার করতে পারে এমন অন্য যে কোনো প্রোগ্রাম বন্ধ করুন: আপডেটের
   সময় 123Scan-এর স্ক্যানারটি একা নিজের কাছে দরকার।
2. স্ক্যানার যুক্ত থাকা অবস্থায় 123Scan-এ তার ফার্মওয়্যার আপডেটের বিকল্প বেছে নিন। 123Scan
   স্ক্যানারের ফার্মওয়্যার Zebra-র প্রকাশিত সর্বশেষটির সঙ্গে তুলনা করে এবং ডাউনলোড ও ইনস্টলের প্রস্তাব
   দেয়। কম্পিউটারে ইন্টারনেট না থাকলে Zebra-র সাইটে স্ক্যানারের সহায়তা পাতা থেকে তার ফার্মওয়্যার
   ডাউনলোড করে ফাইলটি 123Scan-এ লোড করুন।
3. আপডেট শুরু করুন এবং **123Scan শেষ হওয়ার খবর না দেওয়া পর্যন্ত স্ক্যানার লাগিয়ে রাখুন**। এতে
   কয়েক মিনিট লাগে; শেষে স্ক্যানার রিস্টার্ট হয়। মাঝপথে খুলে ফেললে সেটি অকেজো হয়ে যেতে পারে।
4. যাচাই করুন যে 123Scan এখন নতুন ফার্মওয়্যার সংস্করণ দেখাচ্ছে।

আপডেট কিছু সেটিং ডিফল্টে ফিরিয়ে দিতে পারে, সে কারণেই স্ক্যানার পরের দুই ধাপে, ফার্মওয়্যারের পরে,
কনফিগার করা হয়।

## 6. Zebra স্ক্যানারের USB মোড ঠিক করুন

এই ধাপটিই সবচেয়ে বেশি বাদ পড়ে। **বাক্স থেকে বেরোনো Zebra স্ক্যানার একটি USB কিবোর্ড** (USB HID
Keyboard মোড): যেখানে ফোকাস আছে সেখানে সে প্রতিটি বারকোড "টাইপ" করে। সেই মোডে GAIA Desktop-এর
*স্ক্যানার সংযুক্ত করুন* তাকে খুঁজে পায় না, আর টেক্সট ফিল্ডে টাইপ হওয়া সবকিছু তার FNC1 বিভাজক হারায়,
যাতে একটি GS1 উপাদান স্ট্রিংয়ের অর্থ বদলে যায়।

স্ক্যানারটিকে এমন মোডে নিন যার সঙ্গে Zebra ড্রাইভার সরাসরি কথা বলে:

| স্ক্যানারের USB মোড | GAIA Desktop-এ ডিভাইসের নাম | টীকা |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld`, অথবা `ZebraAllScanners` | প্রস্তাবিত |
| SNAPI (ইমেজিংসহ বা ছাড়া) | `ZebraScannerSNAPI`, অথবা `ZebraAllScanners` | Zebra-র নিজস্ব USB প্রোটোকল; এটিও চলে |
| IBM Table-top USB | `ZebraUSBTableTop`, অথবা `ZebraAllScanners` | টেবিল-টপ স্ক্যানারের জন্য |
| USB OPOS (Hand-held) | `ZebraUSBOPOS`, অথবা `ZebraAllScanners` | |
| USB HID Keyboard (কারখানার ডিফল্ট) | — | **সংযুক্ত হবে না** |

`ZebraAllScanners`, GAIA Desktop-এর ডিফল্ট ডিভাইস নাম, যে কোনো সমর্থিত মোডে থাকা স্ক্যানার গ্রহণ
করে, তাই মোড ঠিক হয়ে গেলে ডিফল্টটি সাধারণত এমনিতেই কাজ করে।

মোড বদলাতে, হয়:

- স্ক্যানারের Quick Reference Guide বা Product Reference Guide-এ (USB Host Types / USB Device Type
  অংশ) মোডটির — যেমন *IBM Hand-held USB* — **সেটআপ বারকোড স্ক্যান করুন**; স্ক্যানার বিপ করে
  নিশ্চিত করে। অথবা
- **123Scan ব্যবহার করুন** ([ধাপ 4](#4-123scan-ইনস্টল-করুন)): স্ক্যানার যুক্ত করুন, তার কনফিগারেশন
  খুলুন, আর USB হোস্টের ধরন সেট করুন।

মোড বদলানোর পর Windows স্ক্যানারটিকে অন্য ধরনের ডিভাইস হিসেবে আবার শনাক্ত করে; সংযুক্ত করার আগে
কয়েক সেকেন্ড অপেক্ষা করুন।

পরে স্ক্যানারকে কিবোর্ড মোডে ফেরাতে — অন্য সফটওয়্যারের সঙ্গে ব্যবহারের জন্য — *USB Keyboard (HID)*
সেটআপ বারকোড স্ক্যান করুন, অথবা কারখানার ডিফল্ট সেটিং ফিরিয়ে আনুন।

## 7. GS1-এর জন্য Zebra স্ক্যানার কনফিগার করুন

স্ক্যানার যখন জানায় সে কোন ধরনের বারকোড পড়েছে, তখন GAIA Desktop সবচেয়ে ভালো বিশ্লেষণ করে।

### AIM Code ID পাঠান

Product Reference Guide-এর (User Preferences) সেটআপ বারকোড দিয়ে বা 123Scan-এ **Transmit Code ID
Character**-কে **AIM Code ID Character**-এ সেট করুন। তখন প্রতিটি স্ক্যান তার সিম্বলজি শনাক্তকারী
দিয়ে শুরু হয় — GS1-128-এর জন্য `]C1`, GS1 DataMatrix-এর জন্য `]d2`, GS1 QR Code-এর জন্য `]Q3`,
GS1 DataBar-এর জন্য `]e0` — যা দিয়ে GAIA Desktop ডেটা বাহকের নাম বলে এবং তার নিয়ম প্রয়োগ করে।

এটি ছাড়াও GAIA Desktop উপাদান স্ট্রিং বিশ্লেষণ করে এবং সিম্বলজি স্ক্যান থেকেই নেয়, কিন্তু রিপোর্টে
দেখানোর মতো কোনো AIM Code ID থাকে না, আর EAN-13-এর মতো সাধারণ বারকোডকে GS1 উপাদান স্ট্রিং থেকে
আলাদা করা কঠিন হয়।

### সিম্বলজি যাচাই করুন

নিশ্চিত করুন যে আপনি যে বারকোড ধরনগুলো নিয়ে কাজ করেন সেগুলো **সক্রিয়**: সাধারণত GS1-128,
GS1 DataMatrix, GS1 DataBar, GS1 QR Code ও EAN/UPC। Zebra-র 2D স্ক্যানারে এগুলোর বেশিরভাগ ডিফল্টভাবে
চালু থাকে; 123Scan বর্তমান সেটিং দেখায়, আর Product Reference Guide-এ প্রতিটি সক্রিয় করার বারকোড আছে।

### Zebra-র GS1 বিশ্লেষণ সুবিধাগুলো বন্ধ রাখুন

নতুন ফার্মওয়্যার এমন GS1 সুবিধা যোগ করে যা স্ক্যানারেই কাজ করে — **Label Parse+**, **GS1
Digital Link** ও **GS1 Retail POS parsing**। এগুলো **বন্ধ** রাখুন, যেভাবে স্ক্যানার আসে: এগুলো
স্ক্যানারের পাঠানো ডেটার রূপ বদলায় বা ছোট করে, অথচ GAIA Desktop-এর বিশ্লেষণ ও যাচাইয়ের জন্য কাঁচা
ডেটা দরকার। প্রতিটি কী করে, তা দেখুন [সমর্থিত Zebra 2D স্ক্যানার](#12-সমর্থিত-zebra-2d-স্ক্যানার)-এ।

### উপসর্গ ও প্রত্যয় বন্ধ রাখুন

স্ক্যানারের আউটপুটে কোনো উপসর্গ, প্রত্যয় বা Enter কী যোগ করবেন না। GAIA Desktop প্রতিটি স্ক্যান
JavaPOS-এর মাধ্যমে একটি সম্পূর্ণ বার্তা হিসেবে পায় এবং এগুলোর কোনোটিরই দরকার নেই; বাড়তি অক্ষর
উপাদান স্ট্রিংয়ে ঢুকে পড়বে।

## 8. GAIA Desktop ইনস্টল ও চালু করুন

1. `gaia-desktop-1.0.0-win.zip` আনজিপ করুন, যেমন `C:\Tools\`-এ। এতে একটি ফোল্ডার থাকে:

   ```
   gaia-desktop-1.0.0-win\
   ├── docs\
   │   └── GaiaDesktop-Zebra-Scanner-Windows.md      this guide
   ├── gaia-desktop.jar
   ├── lib\
   ├── readme.html                                   index of every guide
   └── run.bat
   ```

2. স্ক্যানার লাগান।
3. **`run.bat`**-এ ডাবল-ক্লিক করুন। অ্যাপের পাশে একটি কনসোল উইন্ডো খোলে এবং খোলাই থাকে: স্ক্যানারের
   অবস্থা ও JavaPOS ত্রুটি সেখানে জানানো হয়।
4. কনসোলের প্রথম লাইন পড়ুন। এতে বলা থাকে `run.bat` কী খুঁজে পেয়েছে:

   ```
   run.bat: Java 21.0.8 from JAVA_HOME; JavaFX from lib\; JavaPOS from lib\; Zebra services from C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   এটি **`Zebra services from none (Zebra Scanner SDK not installed)`** দিয়ে শেষ হলে SDK তার ডিফল্ট
   অবস্থানে পাওয়া যায়নি — সেটি ইনস্টল করুন ([ধাপ 3](#3-zebra-scanner-sdk-ইনস্টল-করুন)) অথবা
   [ZEBRA_HOME](#zebra_home) সেট করুন। অ্যাপ তবু চালু হয়, কিন্তু স্ক্যানার সংযুক্ত হতে পারে না।

## 9. স্ক্যানার সংযুক্ত করুন

1. টুলবারে **ডিভাইস নির্বাচক** GAIA Desktop-এর জানা স্ক্যানারের নামগুলো দেখায়। এটি
   **`ZebraAllScanners`**-এ রেখে দিন, অথবা [ধাপ 6](#6-zebra-স্ক্যানারের-usb-মোড-ঠিক-করুন)-এর সারণি থেকে
   স্ক্যানারের USB মোডের নামটি বেছে নিন।
2. **স্ক্যানার সংযুক্ত করুন**-এ ক্লিক করুন, অথবা **Ctrl+K** চাপুন (এটি **স্ক্যানার** মেনুতেও আছে)।
3. স্ট্যাটাস বার বদলে **`স্ক্যানার: ZebraAllScanners`** (বা আপনার বেছে নেওয়া নাম) হয়, এবং অবস্থার
   লাইন জানায় *স্ক্যানার সংযুক্ত — ZebraAllScanners*। বোতামে এখন লেখা থাকে **স্ক্যানার বিচ্ছিন্ন করুন**।
4. একটি GS1 বারকোড স্ক্যান করুন। এটি ক্যাপচার ইতিহাসের শীর্ষে দেখা যায় এবং তার রিপোর্ট খোলে। AIM
   Code ID চালু থাকলে রিপোর্ট ডেটা বাহকের নাম বলে — *GS1-128*, *GS1 DataMatrix* — এবং উপাদান স্ট্রিং
   প্রতিটি FNC1 বিভাজক রেখে দেয়।

ডিভাইস নির্বাচক প্রতিবার চালানোর মাঝে আপনার পছন্দ মনে রাখে। আপনি বিচ্ছিন্ন না করা বা অ্যাপ বন্ধ না
করা পর্যন্ত স্ক্যানার সংযুক্ত থাকে। **নির্মাণ** ও **সংযোজন** মোডেও স্ক্যান কাজ করে: সংযোজনে প্রতিটি
স্ক্যান যুক্ত করা বারকোডগুলোর একটি হয়ে যায়।

GAIA Desktop যতক্ষণ স্ক্যানার ধরে রাখে, অন্য প্রোগ্রাম সেটি ব্যবহার করতে পারে না, উল্টোটাও সত্যি:
সংযুক্ত করার আগে 123Scan এবং অন্য যে কোনো পয়েন্ট-অব-সেল বা স্ক্যানার সফটওয়্যার বন্ধ করুন।

## 10. কনফিগারেশন সহায়িকা

### ডিভাইসের নাম

ডিভাইস নির্বাচক ভরা হয় `gaia-desktop.jar`-এ থাকা `jpos.xml` থেকে। তার স্ক্যানার এন্ট্রিগুলো:

| ডিভাইসের নাম | স্ক্যানারের ধরন | কীসের সঙ্গে ব্যবহার |
|---|---|---|
| `ZebraAllScanners` | যে কোনো | **ডিফল্ট।** যে কোনো সমর্থিত USB মোড |
| `ZebraAllScanners114` | যে কোনো | একই পরিষেবার JavaPOS 1.14 সংস্করণ |
| `ZebraUSBHandHeld` | IBM Hand-held USB | IBM Hand-held USB মোডে থাকা স্ক্যানার |
| `ZebraUSBTableTop` | IBM Table-top USB | টেবিল-টপ মোড |
| `ZebraUSBOPOS` | USB OPOS | USB OPOS মোড |
| `ZebraScannerSNAPI` | SNAPI | SNAPI মোড |
| `ZebraScannerUSB` | যে কোনো USB | যে কোনো USB মোড |
| `ZebraScannerSerialSSI` | সিরিয়াল SSI | সিরিয়াল কেবলের স্ক্যানার (USB নয়) |
| `ZebraScannerSerialNIXMODB` | সিরিয়াল NIXMODB | সিরিয়াল কেবলের স্ক্যানার |
| `ZebraVDI` | VDI | ভার্চুয়াল ডেস্কটপে পাঠানো স্ক্যানার |

### ZEBRA_HOME

Zebra SDK ডিফল্ট ছাড়া অন্য কোথাও ইনস্টল করা থাকলে `run.bat` চালুর আগে `ZEBRA_HOME`-কে তার `JPOS`
ফোল্ডারে সেট করুন — যেমন তার পাশে রাখা একটি ছোট ব্যাচ ফাইলে:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

তখন `run.bat` Zebra-র পরিষেবা jar-গুলো `%ZEBRA_HOME%bin` থেকে নেয় এবং Zebra DLL-এর জন্য সেই
ফোল্ডারটি `PATH`-এ যোগ করে।

### আপনার নিজস্ব jpos.xml

কোনো ডিভাইস নাম যোগ করতে বা কোনো এন্ট্রির সেটিং বদলাতে `gaia-desktop.jar` থেকে `jpos.xml` কপি করে
বের করুন (এটি একটি zip; যে কোনো আনজিপ টুল এটি খোলে), কপিটি সম্পাদনা করুন, এবং GAIA Desktop-কে
সেদিকে নির্দেশ করুন:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

তখন ডিভাইস নির্বাচক সেই ফাইলের স্ক্যানারগুলো দেখায়। একাধিক Zebra স্ক্যানার যুক্ত থাকলে কোনো এন্ট্রিকে
তার `ScannerModel` বা `SerialNumber` বৈশিষ্ট্য দিয়ে সেগুলোর একটির সঙ্গে বাঁধা যায়, যেমন
`ZebraAllScanners` এন্ট্রিতে।

### অন্যান্য বিকল্প

| সেটিং | কীভাবে |
|---|---|
| অ্যাপের ভাষা | `run.bat --language=FR` (শুধু এবারের জন্য), অথবা বিকল্প প্যানেল |
| অতিরিক্ত Java বিকল্প | `run.bat`-এর আগে `set GAIA_DESKTOP_OPTS=…` |
| সঙ্গে রাখা Java | `run.bat`-এর পাশে একটি `jdk-21…` ফোল্ডার রাখুন; এটি `JAVA_HOME`-এর আগে ব্যবহৃত হয় |

## 11. সমস্যা সমাধান

ত্রুটি দেখা যায় সংযুক্ত করার সময় একটি ডায়ালগে, কনসোল উইন্ডোতে, এবং লগ ফাইল
`logs\gaia-desktop.log`-এ, যা সেই ফোল্ডারে থাকে যেখান থেকে `run.bat` চালু হয়েছে (`run.bat`-এ
ডাবল-ক্লিক করলে সেটি GAIA Desktop ফোল্ডার)। লগে বর্গবন্ধনীর ভেতরের সংখ্যাটি JavaPOS ত্রুটি কোড।

| যা দেখছেন | সম্ভাব্য কারণ | কী করবেন |
|---|---|---|
| কোনো *স্ক্যানার সংযুক্ত করুন* বোতাম নেই | Windows-এ চলছে না | স্ক্যানিং শুধু Windows-এ |
| 123Scan স্ক্যানার খুঁজে পায় না | কেবল, USB পোর্ট, অথবা স্ক্যানারটি অন্য প্রোগ্রাম ধরে রেখেছে | অন্য কেবল বা পোর্ট চেষ্টা করুন; GAIA Desktop ও অন্যান্য স্ক্যানার সফটওয়্যার বন্ধ করুন। যে স্ক্যানার 123Scan দেখে না, GAIA Desktop-ও তা দেখবে না |
| কনসোল: `Zebra services from none (Zebra Scanner SDK not installed)` | SDK তার ডিফল্ট অবস্থানে নেই | 64-বিট SDK ইনস্টল করুন ([ধাপ 3](#3-zebra-scanner-sdk-ইনস্টল-করুন)), অথবা [ZEBRA_HOME](#zebra_home) সেট করুন |
| ত্রুটি **104**: *Could not connect to service with logicalName = …: …SymScannerSvc112Factory* | Zebra-র পরিষেবা jar পাওয়া যায়নি | ওপরের মতো — কনসোলের `Zebra services from` লাইনটি দেখুন |
| ত্রুটি **109**: *Service does not exist in loaded JCL registry* | ডিভাইসের নাম স্ক্যানার কনফিগারেশনে নেই, অথবা SDK-র `javaPOS114.jar` class path-এ ঢুকে গেছে | ডিভাইস নির্বাচক থেকে একটি নাম বেছে নিন; `javaPOS114.jar` যোগ করবেন না; নিজস্ব `jpos.xml` ব্যবহার করলে দেখুন নামটি তাতে আছে কি না |
| ত্রুটি **107** (হার্ডওয়্যার নেই), অথবা স্ক্যানার লাগানো থাকলেও সংযোগ ব্যর্থ | স্ক্যানার এখনো USB কিবোর্ড মোডে, অথবা CoreScanner ড্রাইভার চলছে না | USB মোড ঠিক করুন ([ধাপ 6](#6-zebra-স্ক্যানারের-usb-মোড-ঠিক-করুন)); SDK ইনস্টলের পর Windows রিস্টার্ট করুন; অন্য USB পোর্ট চেষ্টা করুন |
| সংযুক্ত করার সময় ত্রুটি **112** (সময় শেষ) বা **102** (দখলে) | অন্য একটি প্রোগ্রাম স্ক্যানার ধরে রেখেছে | 123Scan ও অন্য যে কোনো স্ক্যানার বা পয়েন্ট-অব-সেল সফটওয়্যার বন্ধ করে আবার সংযুক্ত করুন |
| কনসোলে `UnsatisfiedLinkError` … `CSJPOSScanner64` | Zebra DLL লোড হচ্ছে না — প্রায়ই 64-বিট Java-র সঙ্গে 32-বিট SDK | 64-বিট SDK ইনস্টল করুন; দেখুন `java -version` 64-বিট VM দেখায় কি না |
| স্ক্যান ক্যাপচার হিসেবে না এসে ইনপুট বারে টাইপ হয়ে যায় | স্ক্যানার USB কিবোর্ড মোডে আছে | USB মোড ঠিক করুন ([ধাপ 6](#6-zebra-স্ক্যানারের-usb-মোড-ঠিক-করুন)) |
| সংযুক্ত, কিন্তু স্ক্যান আসে না | স্ক্যানারের মোডের জন্য ভুল ডিভাইস নাম, অথবা সংযুক্ত অবস্থায় স্ক্যানার আবার লাগানো হয়েছে | বিচ্ছিন্ন করুন, `ZebraAllScanners` বেছে নিন, আবার সংযুক্ত করুন |
| রিপোর্টে AIM Code ID / ডেটা বাহক দেখায় না | AIM Code ID পাঠানো বন্ধ | *Transmit Code ID Character → AIM Code ID* চালু করুন ([ধাপ 7](#7-gs1-এর-জন্য-zebra-স্ক্যানার-কনফিগার-করুন)) |
| উপাদান স্ট্রিংয়ে বিভাজক নেই, অথবা AI-গুলো একসঙ্গে মিশে গেছে | কিবোর্ড মোডে স্ক্যান করা, অথবা `{GS}` ছাড়া হাতে টাইপ করা | JavaPOS USB মোড ব্যবহার করুন; টাইপ করার সময় `{GS}` বোতাম দিয়ে বিভাজক বসান |
| কোনো একটি বারকোড ধরন কখনো পড়া হয় না | সেই সিম্বলজি স্ক্যানারে নিষ্ক্রিয় | সেটি সক্রিয় করুন ([ধাপ 7](#7-gs1-এর-জন্য-zebra-স্ক্যানার-কনফিগার-করুন)) |

সমস্যা থেকে গেলে কনসোলের `run.bat:` লাইন, ত্রুটি ডায়ালগের লেখা এবং `logs\gaia-desktop.log` একসঙ্গে
রাখুন: মিলিয়ে এগুলো দেখায় কোন Java, কোন Zebra পরিষেবা ও কোন ডিভাইস নাম ব্যবহার হয়েছিল, এবং ঠিক
কোথায় সংযোগ ব্যর্থ হয়েছে।

## 12. সমর্থিত Zebra 2D স্ক্যানার

GAIA Desktop-এর এমন স্ক্যানার লাগে যা GS1 ডেটা যে বারকোডে ছাপা হয় সেগুলো পড়তে পারে — GS1-128,
GS1 DataBar, EAN/UPC, এবং বেশিরভাগ কাজের জন্য 2D কোড: **GS1 DataMatrix** ও **GS1 QR Code**, যাতে
সাধারণত **GS1 Digital Link** URI-ও ছাপা হয়। অর্থাৎ একটি Zebra **2D ইমেজার**: রৈখিক (1D) স্ক্যানার
DataMatrix বা QR কোড একেবারেই পড়তে পারে না।

স্ক্যানারকে নিজে GS1 Application Identifiers বা Digital Link বুঝতে হয় না।
**GAIA Desktop দুটোই বিশ্লেষণ করে**: স্ক্যানার যেভাবে পড়েছে স্ক্যানটি সেভাবেই নেয় — AIM Code ID,
FNC1 বিভাজক, সবকিছুসহ — এবং নিজেই সেটিকে AI-তে ভাগ করে, অথবা Digital Link URI-কে তার AI-তে রূপান্তর
করে।

### পরীক্ষিত

| স্ক্যানার | ধরন | অবস্থা |
|---|---|---|
| **DS8108** | তারযুক্ত হাতে-ধরা 2D ইমেজার | GAIA Desktop-এর সঙ্গে **তৈরি ও পরীক্ষিত** |

### চলবে বলে আশা করা হয়

এগুলো Zebra-র 2D ইমেজার, যেগুলো DS8108-এর মতোই Zebra-র Scanner SDK ও JavaPOS পরিষেবা দিয়ে চলে।
GAIA Desktop-এর সঙ্গে এগুলো **পরীক্ষা করা হয়নি**; প্রতিটিকে এই নির্দেশিকা অনুযায়ী সেট করুন, সেটআপ
বারকোডের জন্য তার নিজস্ব Quick Reference Guide বা Product Reference Guide ব্যবহার করে।

| পরিবার | মডেল (উদাহরণ) |
|---|---|
| DS81x8 | DS8108 (তারযুক্ত), DS8178 (তারবিহীন) |
| DS22x8 | DS2208 (তারযুক্ত), DS2278 (তারবিহীন) — সাধারণ কাজের |
| DS36x8 | DS3608 (তারযুক্ত), DS3678 (তারবিহীন) — মজবুত, KD ও XR সংস্করণসহ |
| DS46x8 | DS4608 (তারযুক্ত), DS4678 (তারবিহীন) |
| DS9308 / DS9908 | প্রেজেন্টেশন ও হ্যান্ডস-ফ্রি স্ক্যানার |
| MP7000 / MP7200 | বহুতলীয় বায়োপটিক স্ক্যানার ও স্ক্যানার-দাঁড়িপাল্লা |
| CS6080 | তারবিহীন সহচর স্ক্যানার |

তারবিহীন স্ক্যানার তার ক্রেডলের সঙ্গে কথা বলে, আর কম্পিউটারে লাগে ক্রেডলটিই: ক্রেডলটি USB দিয়ে
যুক্ত করুন এবং জোড়াটিকে একটি স্ক্যানার হিসেবে ধরুন। অন্য Zebra পরিবারের স্ক্যানারও চলতে পারে, যদি
Zebra-র Scanner SDK সেগুলোকে [ধাপ 6](#6-zebra-স্ক্যানারের-usb-মোড-ঠিক-করুন)-এর কোনো USB মোডে সমর্থন করে।

### Zebra স্ক্যানারে চলা GS1 সুবিধা

বারকোড পড়া ছাড়াও কিছু Zebra 2D ইমেজার স্ক্যানারেই GS1 ডেটা প্রক্রিয়া করতে পারে, যা 123Scan দিয়ে
কনফিগার করা হয়:

| সুবিধা | এটি কী করে | GAIA Desktop-এর জন্য |
|---|---|---|
| **Label Parse+** | স্ক্যানারেই একটি GS1 লেবেলের AI বিশ্লেষণ করে নতুন রূপে ফিল্ড পাঠায় | **বন্ধ রাখুন** — তখন GAIA Desktop আর AI, FNC1 বিভাজক ও AIM Code ID দেখতে পাবে না |
| **GS1 Digital Link** | 1D EAN/UPC ও 2D Digital Link কোড দুটোই থাকা খুচরা পণ্যের জন্য: কোনটি পাঠাবে তা বেছে নেয় | **বন্ধ রাখুন** (ডিফল্ট) |
| **GS1 Retail POS parsing** | Digital Link URI বা উপাদান স্ট্রিং সিনট্যাক্সে থাকা 2D খুচরা বারকোড পড়ে | **বন্ধ রাখুন** |

**GS1 Digital Link** সেটিংয়ের তিনটি মোড আছে। **Mode 1 — GTIN only**, সক্রিয় করার পর যে মোডে এটি শুরু
হয়, শুধু GTIN পাঠায়, সেটি যে বারকোড থেকেই আসুক, তাই Digital Link-এর ব্যাচ, মেয়াদোত্তীর্ণের তারিখ বা
সিরিয়াল নম্বর কখনো GAIA Desktop-এ পৌঁছায় না। **Mode 2 — Prioritize 2D** অগ্রাধিকারের সময়সীমার
(ডিফল্টে 200 ms) মধ্যে 2D কোড দেখা গেলে সেটি পাঠায়, নইলে 1D। **Mode 3 — Corroborate 1D and 2D GTINs
Match** 1D পাঠায়, এবং GTIN মিললে 2D-ও। অন্য সফটওয়্যারের জন্য সেটিংটি চালু রাখতেই হলে Mode 1 নয়,
Mode 2 ব্যবহার করুন। DS8108-এ এগুলো হলো প্যারামিটার 2373 (চালু/বন্ধ), 2374 (মোড) ও 2491 (সময়সীমা)।

এই সুবিধাগুলো ব্যবহারে **123Scan সংস্করণ 6 বা নতুনতর** এবং এগুলো থাকা ফার্মওয়্যার লাগে। Zebra এপ্রিল
2025 থেকে ফার্মওয়্যার আপডেটের মাধ্যমে GS1 Digital Link সমর্থন যোগ করছে; নিচের তারিখগুলো একজন Zebra
পুনর্বিক্রেতার কাছ থেকে নেওয়া, তাই প্রতিটি মডেলের ফার্মওয়্যার রিলিজ নোট দেখে নিন:

| মডেল পরিবার | GS1 Digital Link ফার্মওয়্যার প্রকাশ |
|---|---|
| DS81x8 | 16 এপ্রিল 2025 |
| MP7000 | 21 এপ্রিল 2025 |
| DS9908 | 6 জুন 2025 |
| SP72 / SM72 | 11 জুলাই 2025 |
| DS46x8 | 28 জুলাই 2025 |
| MP7200 (Rev-C), DS5502 | 30 জুলাই 2025 |
| DS9308 | 29 আগস্ট 2025 |
| DS22x8, DS1000 | 5 সেপ্টেম্বর 2025 (শুধু এশিয়া-প্রশান্ত মহাসাগরীয় অঞ্চল) |
| DS36x8 (KD ও XR সহ), MS47 | 30 সেপ্টেম্বর 2025 |
| PL5000, SE4107 | 15 অক্টোবর 2025 |
| CS6080 | 31 ডিসেম্বর 2025 |

GAIA Desktop-এ GS1 Digital Link কোড পড়তে এই সুবিধাগুলোর কোনোটিই দরকার নেই: এগুলো বন্ধ থাকলে
বর্তমান ফার্মওয়্যারের একটি Zebra 2D স্ক্যানার Digital Link QR কোড অন্য যে কোনো কোডের মতোই পড়ে, আর
GAIA Desktop URI-টিকে তার AI-তে রূপান্তর করে।
