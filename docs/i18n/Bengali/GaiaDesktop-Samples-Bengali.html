GAIA Desktop নমুনা

প্রতিটি GS1 ডেটা বাহকের জন্য একটি করে বারকোড, এবং সংযোজনের জন্য একটি প্রচলিত লেবেল। Zebra স্ক্যানার দিয়ে সরাসরি স্ক্রিন থেকে এগুলো স্ক্যান করুন, অথবা একটি উপাদান স্ট্রিং GAIA Desktop-এর ইনপুট বারে কপি করুন।

প্রতিটি উপাদান স্ট্রিং তার AIM Code ID দিয়ে শুরু হয়, যা GAIA-কে জানায় স্ক্যানটি কোন ডেটা বাহক থেকে এসেছে। {GS} বলতে FNC1 বোঝায়, যা পরিবর্তনশীল দৈর্ঘ্যের AI-এর পরের বিভাজক; ইনপুট বার এটিকে আসল অক্ষরে রূপান্তর করে। বারকোডের ছবিগুলো আঁকে TEC-IT-এর অনলাইন বারকোড জেনারেটর, তাই এই পৃষ্ঠা খুললে নমুনা ডেটা সেখানে পাঠানো হয়। বেশি ব্যবহারের সময় বারকোডের বদলে অনুরোধ-সীমার একটি বিজ্ঞপ্তি দেখাতে পারে; পরে আবার লোড করুন।

বিশ্লেষণ

বিশ্লেষণ মোডে প্রতিটি স্ক্যান বা পেস্ট তার Application Identifier-গুলোতে ভাগ করে পড়া হয়।

সংযোজন

একটি প্রচলিত লজিস্টিকস লেবেল তার ডেটা কয়েকটি GS1-128 বারকোডে রাখে। সংযোজন মোডে এগুলোর সর্বোচ্চ তিনটি স্ক্যান করুন, আর GAIA Desktop তাদের AI-গুলোকে একটি GS1 DataMatrix যে একক উপাদান স্ট্রিং বহন করত তাতে যুক্ত করে, এবং পুরোটা একসঙ্গে যাচাই করে। এই তিনটি ক্রমানুসারে স্ক্যান করুন:
