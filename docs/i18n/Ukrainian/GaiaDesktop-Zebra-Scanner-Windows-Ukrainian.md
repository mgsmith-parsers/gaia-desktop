# Налаштування сканера Zebra — GAIA Desktop для Windows

Як установити й налаштувати сканер штрихкодів Zebra, щоб GAIA Desktop читав штрихкоди GS1
безпосередньо з нього: кожне сканування розбирається й додається до історії, з префіксом
AIM Code ID і кожним роздільником FNC1 без змін. Оригінальний документ:
[GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md).

GAIA Desktop створено й перевірено з ручним 2D-сканером **Zebra DS8108**, підключеним через USB.
Ці кроки підходять для будь-якого 2D-сканера Zebra, який підтримує Scanner SDK від Zebra;
штрихкоди налаштування й назви меню для конкретної моделі наведено в її власному Quick Reference
Guide або Product Reference Guide.

> **Лише Windows.** Драйвери сканерів Zebra існують тільки для Windows, тож у macOS і Linux
> GAIA Desktop не створює елементів керування сканером. Усе інше в застосунку працює на будь-якій
> платформі.

## 1. Що потрібно

| | |
|---|---|
| **Сканер** | 2D-сканер Zebra з USB-кабелем — див. [Підтримувані 2D-сканери Zebra](#12-підтримувані-2d-сканери-zebra) |
| **Комп'ютер** | Windows 10 або 11, 64-розрядна |
| **Java** | Java 21 або новіша, **64-розрядна** |
| **Zebra Scanner SDK for Windows** | **64-розрядний**, із сайту підтримки Zebra — містить драйвер і служби JavaPOS, якими користується GAIA Desktop |
| **Zebra 123Scan** | Безкоштовна утиліта налаштування від Zebra, із сайту підтримки Zebra — для оновлення мікропрограми сканера й перевірки його параметрів |
| **GAIA Desktop** | `gaia-desktop-1.0.0-win.zip` |
| **Необов'язково** | **Product Reference Guide** (PRG) сканера, де зібрано штрихкоди налаштування |

Як усе поєднується:

```
Zebra scanner ──USB──► Zebra CoreScanner driver ──► Zebra JavaPOS services ──► GAIA Desktop
                       (installed by the SDK)        (in the SDK's JPOS\bin)    (run.bat puts them on
                                                                                 the class path)
```

GAIA Desktop сам містить JavaPOS API і конфігурацію, що називає сканер (`jpos.xml`, усередині
`gaia-desktop.jar`). Решту дає Zebra SDK: драйвер, що спілкується зі сканером, і класи служб Zebra,
які стоять між JavaPOS і цим драйвером.

## 2. Встановлення Java

GAIA Desktop потребує **Java 21 або новішої**, і це має бути **64-розрядна** збірка, щоб
відповідати 64-розрядним драйверам Zebra.

1. Установіть Java 21 JDK або JRE для Windows x64 — наприклад, Eclipse Temurin з
   adoptium.net. Дозвольте інсталятору задати `JAVA_HOME`, якщо він це пропонує.
2. Перевірте в командному рядку:

   ```
   java -version
   ```

   Перший рядок має показати версію 21 або новішу; 64-розрядна Java також виводить `64-Bit Server VM`.

`run.bat` шукає Java в такому порядку: тека `jdk*` поруч із `run.bat`, потім `JAVA_HOME`, потім
`java` у `PATH`. Усе, що старше за 21, він відхиляє з відповідним повідомленням.

---

## 3. Встановлення Zebra Scanner SDK

1. Завантажте **Zebra Scanner SDK for Windows (64-bit)** із сайту підтримки Zebra.
2. Запустіть інсталятор. Якщо він пропонує вибір компонентів, переконайтеся, що компонент
   **JPOS** (JavaPOS) вибрано.
3. Залиште типове місце встановлення. GAIA Desktop шукає JavaPOS-частину SDK тут:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   і очікує jar-файли служб Zebra (`JposServiceScanner.jar`, `JposServiceJniScanner.jar`, …)
   та нативні бібліотеки (`CSJPOSScanner64.dll`, …) у її теці `bin\`. Якщо SDK встановлено
   деінде, див. [ZEBRA_HOME](#zebra_home).
4. Після встановлення **перезапустіть Windows**. Драйвер CoreScanner із SDK працює у фоновому
   режимі й має бути запущений, перш ніж GAIA Desktop зможе дістатися до сканера; перезапуск —
   найпростіший спосіб у цьому переконатися.

## 4. Встановлення 123Scan

123Scan — безкоштовна утиліта Zebra для налаштування її сканерів. На наступному кроці нею
оновлюють мікропрограму сканера, і це найпростіший спосіб перевіряти й змінювати параметри
сканера згодом.

1. Завантажте **123Scan** із сайту підтримки Zebra й запустіть інсталятор.
2. Підключіть сканер Zebra й запустіть 123Scan. Утиліта має знайти сканер і показати його модель,
   серійний номер і поточну версію мікропрограми. Якщо цього не сталося, спробуйте інший USB-порт
   або кабель, перш ніж іти далі — GAIA Desktop не побачить сканер, якого не бачить 123Scan.

## 5. Оновлення мікропрограми сканера Zebra

Оновіть мікропрограму сканера до останньої версії, перш ніж його налаштовувати. Оновлення
мікропрограми виправляють проблеми з декодуванням і тримають сканер в узгодженні з драйвером
Zebra, установленим разом із SDK.

1. Закрийте **GAIA Desktop** і будь-яку іншу програму, яка може використовувати сканер: під час
   оновлення 123Scan потрібен сканер у винятковому користуванні.
2. У 123Scan, коли сканер підключено, виберіть його функцію оновлення мікропрограми. 123Scan
   порівнює мікропрограму сканера з останньою, яку публікує Zebra, і пропонує завантажити й
   установити її. Якщо комп'ютер не має доступу до інтернету, завантажте мікропрограму сканера
   з його сторінки підтримки на сайті Zebra й завантажте файл у 123Scan.
3. Запустіть оновлення й **не від'єднуйте сканер, доки 123Scan не повідомить про завершення**.
   Це триває кілька хвилин; наприкінці сканер перезапуститься. Якщо від'єднати його посередині,
   він може стати непридатним до роботи.
4. Перевірте, що 123Scan тепер показує нову версію мікропрограми.

Оновлення може повернути деякі параметри до типових значень, тому сканер налаштовують на двох
наступних кроках, уже після мікропрограми.

## 6. Налаштування режиму USB сканера Zebra

Цей крок пропускають найчастіше. **Із заводу сканер Zebra працює як USB-клавіатура** (режим USB
HID Keyboard): він «друкує» кожен штрихкод туди, де стоїть фокус. У цьому режимі
*Підключити сканер* у GAIA Desktop не може його знайти, а все, що надруковано в текстове поле,
втрачає роздільники FNC1, і від цього змінюється зміст рядка елементів GS1.

Перемкніть сканер у режим, з яким драйвер Zebra працює напряму:

| Режим USB сканера | Назва пристрою в GAIA Desktop | Примітки |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld` або `ZebraAllScanners` | Рекомендовано |
| SNAPI (з передаванням зображень або без) | `ZebraScannerSNAPI` або `ZebraAllScanners` | Власний USB-протокол Zebra; теж працює |
| IBM Table-top USB | `ZebraUSBTableTop` або `ZebraAllScanners` | Призначено для настільних сканерів |
| USB OPOS (Hand-held) | `ZebraUSBOPOS` або `ZebraAllScanners` | |
| USB HID Keyboard (заводське значення) | — | **Не підключиться** |

`ZebraAllScanners`, типова назва пристрою в GAIA Desktop, приймає сканер у будь-якому з
підтримуваних режимів, тож щойно режим задано, типове значення зазвичай просто працює.

Щоб змінити режим, можна:

- **відсканувати штрихкод налаштування** для режиму — скажімо, *IBM Hand-held USB* — у Quick
  Reference Guide або Product Reference Guide сканера (розділ USB Host Types / USB Device Type);
  сканер підтвердить звуковим сигналом. Або
- **скористатися 123Scan** ([крок 4](#4-встановлення-123scan)): підключіть сканер, відкрийте його
  конфігурацію й задайте тип USB-хоста.

Після зміни режиму Windows заново виявляє сканер як пристрій іншого типу; зачекайте кілька
секунд, перш ніж підключатися.

Щоб згодом повернути сканер у режим клавіатури — для роботи з іншими програмами, — відскануйте
штрихкод налаштування *USB Keyboard (HID)* або відновіть його заводські параметри.

## 7. Налаштування сканера Zebra для GS1

GAIA Desktop розбирає найкраще, коли сканер повідомляє, який тип штрихкоду він прочитав.

### Передавання AIM Code ID

Задайте **Transmit Code ID Character** значення **AIM Code ID Character** за допомогою штрихкоду
налаштування в Product Reference Guide (User Preferences) або в 123Scan. Тоді кожне сканування
починається з ідентифікатора символіки — `]C1` для GS1-128, `]d2` для GS1 DataMatrix, `]Q3` для
GS1 QR Code, `]e0` для GS1 DataBar, — за яким GAIA Desktop називає носій даних і застосовує
правила для нього.

Без нього GAIA Desktop усе одно розбирає рядок елементів і визначає символіку із самого
сканування, але звіту нема чого показати як AIM Code ID, а звичайний штрихкод, наприклад EAN-13,
важче відрізнити від рядка елементів GS1.

### Перевірка символік

Переконайтеся, що потрібні вам типи штрихкодів **увімкнено**: зазвичай це GS1-128, GS1 DataMatrix,
GS1 DataBar, GS1 QR Code і EAN/UPC. На 2D-сканерах Zebra більшість із них увімкнено за
замовчуванням; 123Scan показує поточні параметри, а в Product Reference Guide є штрихкод для
ввімкнення кожної.

### Вимкніть функції GS1-розбору Zebra

Новіша мікропрограма додає функції GS1, що працюють на самому сканері, — **Label Parse+**, **GS1
Digital Link** і **GS1 Retail POS parsing**. Залиште їх **вимкненими**, як сканер і постачається:
вони переформатовують або скорочують те, що надсилає сканер, а GAIA Desktop потрібні сирі дані,
щоб їх розібрати й перевірити. Що робить кожна з них, див. у розділі
[Підтримувані 2D-сканери Zebra](#12-підтримувані-2d-сканери-zebra).

### Без префіксів і суфіксів

Не додавайте до виводу сканера префікс, суфікс чи клавішу Enter. GAIA Desktop отримує кожне
сканування як завершене повідомлення через JavaPOS і не потребує жодного з них; зайві символи
потрапили б у рядок елементів.

## 8. Встановлення й запуск GAIA Desktop

1. Розпакуйте `gaia-desktop-1.0.0-win.zip`, наприклад у `C:\Tools\`. Архів містить одну теку:

   ```
   gaia-desktop-1.0.0-win\
   ├── docs\
   │   └── GaiaDesktop-Zebra-Scanner-Windows.md      this guide
   ├── gaia-desktop.jar
   ├── lib\
   ├── readme.html                                   index of every guide
   └── run.bat
   ```

2. Підключіть сканер.
3. Двічі клацніть **`run.bat`**. Поруч із застосунком відкриється вікно консолі й залишиться
   відкритим: там з'являються стан сканера й помилки JavaPOS.
4. Прочитайте перший рядок у консолі. Він повідомляє, що знайшов `run.bat`:

   ```
   run.bat: Java 21.0.8 from JAVA_HOME; JavaFX from lib\; JavaPOS from lib\; Zebra services from C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   Якщо він закінчується на **`Zebra services from none (Zebra Scanner SDK not installed)`**, SDK
   не знайдено в типовому місці — установіть його ([крок 3](#3-встановлення-zebra-scanner-sdk))
   або задайте [ZEBRA_HOME](#zebra_home). Застосунок однаково запуститься, але сканер не зможе
   підключитися.

## 9. Підключення сканера

1. На панелі інструментів **список пристроїв** показує назви сканерів, відомі GAIA Desktop.
   Залиште **`ZebraAllScanners`** або виберіть назву для режиму USB сканера з таблиці на
   [кроці 6](#6-налаштування-режиму-usb-сканера-zebra).
2. Натисніть **Підключити сканер** або **Ctrl+K** (також у меню **Сканер**).
3. Рядок стану зміниться на **`сканер: ZebraAllScanners`** (або вибрану вами назву), а рядок
   повідомлень покаже *Сканер підключено — ZebraAllScanners*. Кнопка тепер називається
   **Відключити сканер**.
4. Відскануйте штрихкод GS1. Він з'явиться вгорі історії записів, і відкриється його звіт. Коли
   AIM Code ID увімкнено, звіт називає носій даних — *GS1-128*, *GS1 DataMatrix*, — а рядок
   елементів зберігає кожен роздільник FNC1.

Список пристроїв запам'ятовує ваш вибір між запусками. Сканер лишається підключеним, доки ви
його не відключите або не закриєте застосунок. Сканування також працює в режимах **Побудова** і
**Об'єднання**: в Об'єднанні кожне сканування стає одним зі штрихкодів, що об'єднуються.

Поки GAIA Desktop тримає сканер, інші програми не можуть ним користуватися, і навпаки: перед
підключенням закрийте 123Scan і будь-яке інше POS-програмне забезпечення чи програму для сканера.

## 10. Довідник з налаштувань

### Назви пристроїв

Список пристроїв заповнюється з `jpos.xml`, вбудованого в `gaia-desktop.jar`. Записи сканерів
у ньому:

| Назва пристрою | Тип сканера | Для чого |
|---|---|---|
| `ZebraAllScanners` | будь-який | **Типова.** Будь-який підтримуваний режим USB |
| `ZebraAllScanners114` | будь-який | Версія тієї самої служби для JavaPOS 1.14 |
| `ZebraUSBHandHeld` | IBM Hand-held USB | Сканер у режимі IBM Hand-held USB |
| `ZebraUSBTableTop` | IBM Table-top USB | Режим Table-top |
| `ZebraUSBOPOS` | USB OPOS | Режим USB OPOS |
| `ZebraScannerSNAPI` | SNAPI | Режим SNAPI |
| `ZebraScannerUSB` | будь-який USB | Будь-який режим USB |
| `ZebraScannerSerialSSI` | послідовний SSI | Сканери з послідовним кабелем (не USB) |
| `ZebraScannerSerialNIXMODB` | послідовний NIXMODB | Сканери з послідовним кабелем |
| `ZebraVDI` | VDI | Сканери, передані у віртуальний робочий стіл |

### ZEBRA_HOME

Якщо Zebra SDK встановлено не в типове місце, задайте `ZEBRA_HOME` як шлях до його теки `JPOS`
перед запуском `run.bat` — наприклад, у невеликому пакетному файлі поруч із ним:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

Тоді `run.bat` бере jar-файли служб Zebra з `%ZEBRA_HOME%bin` і додає цю теку до `PATH` для
DLL Zebra.

### Власний jpos.xml

Щоб додати назву пристрою або змінити параметри запису, скопіюйте `jpos.xml` з
`gaia-desktop.jar` (це zip-архів, його відкриває будь-який розпаковувач), відредагуйте копію й
укажіть її GAIA Desktop:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

Тоді список пристроїв показує сканери з цього файлу. Якщо підключено кілька сканерів Zebra, запис
можна прив'язати до одного з них через його властивість `ScannerModel` або `SerialNumber`, як у
записі `ZebraAllScanners`.

### Інші параметри

| Параметр | Як задати |
|---|---|
| Мова застосунку | `run.bat --language=FR` (лише для цього запуску) або панель параметрів |
| Додаткові параметри Java | `set GAIA_DESKTOP_OPTS=…` перед `run.bat` |
| Вбудована Java | покладіть теку `jdk-21…` поруч із `run.bat`; вона має перевагу над `JAVA_HOME` |

## 11. Усунення несправностей

Помилки з'являються в діалоговому вікні під час підключення, у вікні консолі та в журналі
`logs\gaia-desktop.log` у теці, з якої запущено `run.bat` (тека GAIA Desktop, якщо `run.bat`
запущено подвійним клацанням). Число у квадратних дужках у журналі — код помилки JavaPOS.

| Що ви бачите | Імовірна причина | Що робити |
|---|---|---|
| Немає кнопки *Підключити сканер* | Застосунок працює не у Windows | Сканування доступне лише у Windows |
| 123Scan не знаходить сканер | Кабель, USB-порт, або сканер зайнято іншою програмою | Спробуйте інший кабель чи порт; закрийте GAIA Desktop та інші програми для сканера. GAIA Desktop не побачить сканер, якого не бачить 123Scan |
| Консоль: `Zebra services from none (Zebra Scanner SDK not installed)` | SDK немає в типовому місці | Установіть 64-розрядний SDK ([крок 3](#3-встановлення-zebra-scanner-sdk)) або задайте [ZEBRA_HOME](#zebra_home) |
| Помилка **104**: *Could not connect to service with logicalName = …: …SymScannerSvc112Factory* | Не знайдено jar-файли служб Zebra | Як вище — перевірте рядок `Zebra services from` у консолі |
| Помилка **109**: *Service does not exist in loaded JCL registry* | Назви пристрою немає в конфігурації сканера, або `javaPOS114.jar` із SDK потрапив у class path | Виберіть назву зі списку пристроїв; не додавайте `javaPOS114.jar`; якщо ви використовуєте власний `jpos.xml`, перевірте, що назва в ньому є |
| Помилка **107** (немає обладнання), або підключення не вдається, хоча сканер під'єднано | Сканер досі в режимі USB-клавіатури, або драйвер CoreScanner не запущено | Задайте режим USB ([крок 6](#6-налаштування-режиму-usb-сканера-zebra)); перезапустіть Windows після встановлення SDK; спробуйте інший USB-порт |
| Помилка **112** (тайм-аут) або **102** (зайнято) під час підключення | Сканер тримає інша програма | Закрийте 123Scan і будь-яку іншу програму для сканера чи POS, потім підключіться знову |
| `UnsatisfiedLinkError` … `CSJPOSScanner64` у консолі | Не вдається завантажити DLL Zebra — часто це 32-розрядний SDK із 64-розрядною Java | Установіть 64-розрядний SDK; перевірте, що `java -version` показує 64-розрядну VM |
| Сканування друкуються в поле введення замість надходити як записи | Сканер у режимі USB-клавіатури | Задайте режим USB ([крок 6](#6-налаштування-режиму-usb-сканера-zebra)) |
| Підключено, але сканування не надходять | Неправильна назва пристрою для режиму сканера, або сканер перепідключили під час з'єднання | Відключіться, виберіть `ZebraAllScanners`, підключіться знову |
| Звіт не показує AIM Code ID / носій даних | Передавання AIM Code ID вимкнено | Увімкніть *Transmit Code ID Character → AIM Code ID* ([крок 7](#7-налаштування-сканера-zebra-для-gs1)) |
| У рядку елементів бракує роздільників, або AI злилися | Сканування в режимі клавіатури, або введення вручну без `{GS}` | Використовуйте режим USB для JavaPOS; під час введення вставляйте роздільники кнопкою `{GS}` |
| Якийсь тип штрихкоду ніколи не читається | Цю символіку вимкнено на сканері | Увімкніть її ([крок 7](#7-налаштування-сканера-zebra-для-gs1)) |

Якщо проблема не зникає, збережіть разом рядок `run.bat:` з консолі, текст діалогу помилки й
`logs\gaia-desktop.log`: разом вони показують, яку Java, які служби Zebra й яку назву пристрою
було використано і де саме з'єднання зазнало невдачі.

## 12. Підтримувані 2D-сканери Zebra

GAIA Desktop потребує сканера, здатного читати штрихкоди, якими друкують дані GS1, — GS1-128,
GS1 DataBar, EAN/UPC і, для більшості завдань, 2D-коди: **GS1 DataMatrix** і **GS1 QR Code**,
яким зазвичай друкують і URI **GS1 Digital Link**. Отже, потрібен **2D-сканер-імейджер** Zebra:
лінійний (1D) сканер узагалі не може читати коди DataMatrix чи QR.

Сам сканер не мусить розуміти GS1 Application Identifiers чи Digital Link.
**GAIA Desktop розбирає і те, і інше**: він бере сканування таким, яким його прочитав сканер, —
з AIM Code ID, роздільниками FNC1 і всім іншим — і сам ділить його на AI або перетворює URI
Digital Link на його AI.

### Перевірено

| Сканер | Тип | Стан |
|---|---|---|
| **DS8108** | Дротовий ручний 2D-імейджер | **Створено й перевірено** з GAIA Desktop |

### Мають працювати

Це 2D-імейджери Zebra, якими, як і DS8108, керують через Scanner SDK і служби JavaPOS від Zebra.
Їх **не перевіряли** з GAIA Desktop; налаштуйте кожен за цим посібником, беручи штрихкоди
налаштування з його власного Quick Reference Guide або Product Reference Guide.

| Родина | Моделі (приклади) |
|---|---|
| DS81x8 | DS8108 (дротовий), DS8178 (бездротовий) |
| DS22x8 | DS2208 (дротовий), DS2278 (бездротовий) — загального призначення |
| DS36x8 | DS3608 (дротовий), DS3678 (бездротовий) — захищені, зокрема варіанти KD і XR |
| DS46x8 | DS4608 (дротовий), DS4678 (бездротовий) |
| DS9308 / DS9908 | Презентаційні сканери й сканери для роботи без рук |
| MP7000 / MP7200 | Багатоплощинні біоптичні сканери й сканери-ваги |
| CS6080 | Бездротовий компактний сканер-компаньйон |

Бездротовий сканер спілкується зі своєю підставкою, і саме підставка під'єднується до
комп'ютера: підключіть підставку через USB і вважайте пару одним сканером. Сканери інших родин
Zebra теж можуть працювати, якщо Scanner SDK від Zebra підтримує їх в одному з режимів USB з
[кроку 6](#6-налаштування-режиму-usb-сканера-zebra).

### Функції GS1 на самому сканері Zebra

Окремо від читання штрихкодів деякі 2D-імейджери Zebra вміють обробляти дані GS1 на самому
сканері; це налаштовують через 123Scan:

| Функція | Що вона робить | Для GAIA Desktop |
|---|---|---|
| **Label Parse+** | Розбирає AI етикетки GS1 на сканері й надсилає переформатовані поля | **Залиште вимкненою** — GAIA Desktop більше не бачитиме AI, роздільників FNC1 і AIM Code ID |
| **GS1 Digital Link** | Для роздрібних товарів, позначених і 1D-кодом EAN/UPC, і 2D-кодом Digital Link: вибирає, що надіслати | **Залиште вимкненою** (типово) |
| **GS1 Retail POS parsing** | Читає роздрібні 2D-штрихкоди в синтаксисі URI Digital Link або рядка елементів | **Залиште вимкненою** |

Параметр **GS1 Digital Link** має три режими. **Mode 1 — GTIN only**, режим, з якого він
починає після ввімкнення, надсилає лише GTIN, хоч би з якого штрихкоду той походив, тож партія,
термін придатності чи серійний номер із Digital Link ніколи не дійдуть до GAIA Desktop.
**Mode 2 — Prioritize 2D** надсилає 2D-код, якщо його видно в межах тайм-ауту пріоритизації
(типово 200 мс), інакше — 1D. **Mode 3 — Corroborate 1D and 2D GTINs Match** надсилає 1D, а також
2D, коли його GTIN збігається. Якщо параметр мусить бути ввімкнений для іншої програми,
використовуйте Mode 2, а не Mode 1. На DS8108 це параметри 2373 (увімк./вимк.), 2374 (режим) і
2491 (тайм-аут).

Щоб користуватися цими функціями, потрібен **123Scan версії 6 або новішої** й мікропрограма, що
їх містить. Zebra додає підтримку GS1 Digital Link оновленнями мікропрограми з квітня 2025 року;
наведені нижче дати взято від реселера Zebra, тож перевіряйте примітки до випуску мікропрограми
кожної моделі:

| Родина моделей | Вихід мікропрограми з GS1 Digital Link |
|---|---|
| DS81x8 | 16 квітня 2025 |
| MP7000 | 21 квітня 2025 |
| DS9908 | 6 червня 2025 |
| SP72 / SM72 | 11 липня 2025 |
| DS46x8 | 28 липня 2025 |
| MP7200 (Rev-C), DS5502 | 30 липня 2025 |
| DS9308 | 29 серпня 2025 |
| DS22x8, DS1000 | 5 вересня 2025 (лише Азійсько-Тихоокеанський регіон) |
| DS36x8 (зокрема KD і XR), MS47 | 30 вересня 2025 |
| PL5000, SE4107 | 15 жовтня 2025 |
| CS6080 | 31 грудня 2025 |

Жодна з цих функцій не потрібна, щоб читати коди GS1 Digital Link у GAIA Desktop: коли їх
вимкнено, 2D-сканер Zebra з актуальною мікропрограмою читає QR-код Digital Link, як і будь-який
інший, а GAIA Desktop перетворює URI на його AI.

«GS1 Digital Link Parameters» і розділ Data Parsing; Zebra, *123Scan release notes*;
Barcode Factory, *Upgrade Zebra Scanners for GS1 Digital Link* (дати мікропрограм).
