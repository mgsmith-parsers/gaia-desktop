## Що це таке

GAIA Desktop робить із даними GS1 дві речі:

- **Розбирає** — наберіть, вставте, відкрийте або відскануйте рядок елементів GS1 чи URI
  Digital Link і прочитайте результат як повний звіт: що означає кожен ідентифікатор
  застосування (AI), що в ньому не так і чому;
- **Будує** — складає пари «AI / значення» в рядок елементів або в URI Digital Link.

Усе, що застосунок знає про GS1 — кожне означення AI, кожне правило перевірки, кожне
повідомлення про помилку і кожен локалізований опис — походить із рушія GAIA, що лежить в
основі. Застосунок не додає власних правил: він приймає рівно те, що приймає рушій.

## Запуск

```bash
java -jar gaia-desktop.jar
```

JAR-файлові потрібен каталог `lib/`, що постачається поруч із ним, — тримайте їх разом, інакше
застосунок не запуститься. (Можна зібрати й один самодостатній JAR-файл; див.
[посібник розробника](../../GaiaDesktop-Developer.md#packaging).)

Потрібна встановлена **Java 21 або новіша**. Збірка прив’язана до однієї операційної системи та
однієї архітектури процесора — використовуйте JAR-файл, зібраний для вашого комп’ютера.

Щоб відкрити застосунок певною мовою, не змінюючи збережену мову:

```bash
java -jar gaia-desktop.jar --language=FR
```

Значенням може бути код каталогу (`FR`, `PCM`, `ARZ`), повна назва (`FRENCH`, `WU-CHINESE`) або
мовний тег (`fr`, `zh-HK` для кантонської, `ar-EG` для єгипетської арабської) — регістр не має
значення. Указівка діє лише для цього запуску: збережена мова лишається недоторканою, тож
ярлик, зроблений для колеги, не змінить мову, якою відкривається ваша власна копія. Вибір мови
*всередині* застосунку — це вже справжній вибір, і він зберігається як завжди. Значення, яке не
позначає жодної мови, ігнорується із записом у консолі: застосунок відкриється збереженою
мовою, а не відмовиться запускатися.

Під час запуску консоль друкує рядок із версією застосунку, датою збирання та версією рушія.
Саме його варто наводити в повідомленні про помилку.

```
│ status …                                     scanner: off  [About] │
└────────────────────────────────────────────────────────────────────┘
```

> Схема зберігає англійські підписи, як і всі блоки коду в цій документації. На екрані ви
> побачите *Розбір* / *Побудова*, *Записи*, *Зберегти звіт*, *Параметри*, *сканер: вимк.* та
> *Про програму*.

**У macOS і Linux рядка зі сканером на цій схемі немає** — ані перемикача, ані вибору пристрою
на панелі інструментів, немає меню *Сканер*, немає *сканер: вимк.* у рядку стану. Див.
[Сканування](#сканування).

Перемикач **Розбір ⇄ Побудова** змінює лише смугу під панеллю інструментів та елементи
керування захопленням. Історія, звіт, панель параметрів і дії експорту служать обом режимам,
адже вдала побудова просто стає ще одним записом.

Панель параметрів **під час першого запуску закрита**. Режим, видимість панелі, тема й останній
використаний сканер запам’ятовуються між запусками.

## Режим «Розбір»

### Поле введення і токен {GS}

Поле приймає рядок елементів, URI GS1 Digital Link або необроблені дані сканування разом із
префіксом AIM Code ID (`]d2…`). <kbd>Enter</kbd> запускає розбір.

AI змінної довжини розділяються символом **FNC1** — невидимим керівним символом `0x1D`.
Текстове поле не може його зберігати: він буде мовчки прибраний, і `01…` + FNC1 + `10LOT`
надійде як `01…10LOT` — рядок елементів з іншим змістом.

Тому застосунок показує роздільник як видимий токен **`{GS}`** і перетворює його назад дорогою
до аналізатора:

- **кнопка `{GS}`** вставляє токен там, де стоїть курсор;
- **вставляння** справжніх символів-роздільників — з клавіатури, з контекстного меню чи
  перетягуванням — автоматично перетворює їх на `{GS}`, тож нічого не втрачається;
- токен записується так само, як його записує звіт, тож значення, скопійоване зі звіту, можна
  вставити назад без змін.

Запис, звіт і збережена історія містять **справжній** роздільник. Токен — це лише те, що ви
бачите й набираєте.

### Сканування

> **Лише Windows.** Zebra постачає драйвери сканера тільки для Windows, тож у macOS і Linux
> застосунок узагалі не створює елементів керування сканером — немає перемикача *Підключити
> сканер*, немає вибору пристрою, немає меню *Сканер*, немає стану сканера в рядку стану. Нічого
> не «пригашено», бо немає ні налаштування, ні пристрою, які могли б це ввімкнути. Усе інше,
> включно з відкриванням файлу зі збереженими сканами, працює скрізь.

*Підключити сканер* відкриває пристрій, указаний у списку; `ZebraAllScanners` — типове значення,
що підходить для більшості моделей. Кожне сканування розбирається й автоматично додається до
історії.

Дані сканера читаються побайтово, тож префікс AIM Code ID і кожен роздільник FNC1 доходять до
аналізатора точно такими, якими їх надіслав сканер.

У режимі «Побудова» елементи керування сканером сховані, але підключений сканер працює й далі:
*Сканер → Підключити / Відключити* (<kbd>⌘K</kbd>) досі його перемикає, рядок стану досі про
нього повідомляє, а скан, що надійшов при відкритому редакторі, все одно буде записаний.

Якщо пристрій не підключається, див. [Усунення несправностей](#усунення-несправностей).

### Відкривання файлу

*Файл → Відкрити текстовий файл…* розбирає **кожен непорожній рядок як окремий запис** — це
швидкий спосіб опрацювати партію сканів, яку вам надіслали. Файл читається побайтово, тож
справжні роздільники в ньому зберігаються.

### Історія записів

Найновіші згори. У кожному рядку — крапка «чинний / нечинний», однорядковий підсумок, а також
час запису, джерело та кількість AI. Дата з’являється лише в записах попередніх днів; у
сьогоднішніх рядках показано тільки час.

Підсумок — це **URI Digital Link** для Digital Link і **HRI** в решті випадків: для рядка
елементів `(01)09506000134352 (17)261231` читається краще, ніж
`01095060001343521726123110…`.

Клацніть запис правою кнопкою, щоб скопіювати його введення або HRI, повернути його в поле
введення, відкрити в редакторі, вилучити чи очистити історію.

## Режим «Побудова»

### Редактор AI

Таблиця пар «AI / значення». Наберіть код AI або виберіть із **усіх AI, які знає рушій**, у
списку *Додати AI…*; стовпці **Назва**, **Формат** і **Опис** заповнюються під час набору
вибраною мовою. Список не запропонує AI, який побудова відхилила б.

У кінці таблиці завжди лишається **один порожній рядок**: наберіть у ньому щось — і з’явиться
наступний, тож рядкові з кількома AI ніколи не потрібна команда *Додати рядок*.

Редагування поводиться так, як і має поводитися таблиця: <kbd>Enter</kbd>, <kbd>Tab</kbd>,
<kbd>Shift</kbd>+<kbd>Tab</kbd> і клацання поза коміркою **зберігають** набране;
<kbd>Esc</kbd> відкидає. <kbd>Tab</kbd> переходить від AI до Значення й далі до наступного
рядка, оминаючи стовпці, які не можна редагувати.

### Що редактор відхиляє

| | Що відбувається |
|---|---|
| AI, якого рушій не розпізнає | Рядок червоніє просто під час набору; побудову відхилено з поясненням |
| Той самий AI вдруге, зі списку | Не додається — повідомлення називає його, а рядок, де він уже є, стає виділеним |
| Той самий AI вдруге, набраний вручну | Позначено обидва рядки; побудову відхилено з помилкою `GE-S004` |
| Нема чого будувати | Повідомлення; жодного запису не створено |

В одному рядку елементів AI може траплятися лише раз — тому список відмовляє одразу, а не
дозволяє взятися за заздалегідь приречену побудову.

### Рядок елементів чи Digital Link

**Побудувати рядок елементів** з’єднує рядки, вставляючи роздільник FNC1 всюди, де цього вимагає
стандарт. **Побудувати Digital Link** видає URI; розгорніть *Ціль Digital Link*, щоб скерувати
його на власний резолвер замість канонічного `id.gs1.org`:

| Поле | Дія | Порожнє значення |
|---|---|---|
| Домен | Вузол резолвера, напр. `example.com` | `id.gs1.org` |
| Префікс шляху | Відрізок перед шляхом AI, напр. `/products` | без префікса |

За **успіху** результат поводиться точно як скан: його розбирають, додають до історії,
показують як звіт і зберігають. Побудова перевіряє себе, розбираючи власний вивід, тож усе, що
вона повертає, є завідомо коректним.

За **невдачі** нічого не записується. Причина лишається під кнопками побудови — по рядку на
кожну проблему, у кожному вказано помилку, відповідний AI та власне пояснення рушія:

```
GE-C003  (01)  Check digit validation failed for AI (01) value ''09506000134350''
```

> Подвоєні лапки в цьому повідомленні походять із каталогу помилок рушія, а не з цього
> застосунку.

### Редагування наявного запису

Клацання правою кнопкою на записі → **Побудова** завантажує його AI до редактора. Змініть
значення, побудуйте знову — і результат з’явиться як новий запис, а початковий лишиться
недоторканим.

## Звіт

Вибраний запис показується як повний звіт: смуга висновку, рядок елементів, розкладений на
підписану «стрічку», метадані розбору, по картці на кожен AI з його тлумаченнями, а також
помилки та попередження з підказками, як їх усунути.

Для **Digital Link** кожна картка AI несе ще й свою структурну роль — **первинний ключ**,
**кваліфікатор ключа** або **атрибут даних** — позначену кольором у тому порядку, в якому вони
йдуть в URI. Ролі показуються лише для Digital Link: у звичайному рядку елементів AI не має
позиції в URI, яку можна було б описати.

Звіт відповідає вибраним вами мові та темі.

### Експорт

| | |
|---|---|
| **Зберегти звіт → Як HTML…** (<kbd>⌘S</kbd>) | Записує саме те, що на екрані: один самодостатній файл, який відкривається в будь-якому браузері |
| **Зберегти звіт → Як PDF…** (<kbd>⌘P</kbd>) | Друкує звіт через системне вікно друку — виберіть там призначення PDF |

PDF проходить через вікно друку, бо саме там вибирають призначення й ім’я файлу: у macOS —
**PDF ▾ → Зберегти як PDF**, у Windows — **Microsoft Print to PDF**, у Linux — **Друк у файл**.
Сторінки розбиваються належним чином, а текст лишається виділюваним.

Друк і PDF завжди використовують світлу палітру, навіть коли застосунок у темній темі, і
зберігають кольорові позначки AI та смугу висновку.

Якщо на комп’ютері не налаштовано ні принтера, ні призначення PDF, застосунок повідомить про це
й скерує до експорту в HTML, який друкується з будь-якого браузера.

## Параметри аналізу

Панель праворуч збирає всі параметри рушія. Зміна будь-якого з них **одразу перерозбирає
вибраний запис**, тож панель також дає змогу спитати «а як цей ввід виглядав би з такими
налаштуваннями?», а не лише впливає на наступне сканування.

| Параметр | Значення |
|---|---|
| Режим аналізу | `SYNTAX`, `CONTENT`, `DATA_CARRIER`, `INTERPRETATION` — наскільки глибоко вести розбір |
| Мова | 35 каталогів повідомлень |
| Порядок | `LITTLE` (дд/мм/рррр), `MIDDLE` (мм/дд/рррр), `BIG` (рррр/мм/дд) |
| Роздільник | `SLASH`, `HYPHEN`, `PERIOD` |
| Місяць | `TWO_DIGIT` (12), `THREE_LETTER` (DEC) |
| Рік | `FOUR_DIGIT` (2026), `TWO_DIGIT` (26) |
| Пропустити перевірку «requires» | Більше не відхиляє AI, у якого бракує обов’язкового супутника (`GE-S005`) |
| Пропустити перевірку «excludes» | Більше не відхиляє поєднання AI, які забороняє стандарт (`GE-S006`) |

*Скинути до типових* унизу панелі повертає власні типові значення рушія.

### Перший запуск

Поки нічого не збережено, застосунок бере налаштування з **регіональних параметрів вашого
комп’ютера**, а не з типових значень рушія:

- **мова** береться з локалі системи, з поверненням до англійської, якщо каталогу для неї
  немає;
- **параметри дати** зчитуються з короткого формату дати вашої локалі: порядок складників,
  роздільник і те, чи скорочуються місяць та рік.

> **Примітка.** Тому локаль, що записує короткі дати з дворічним записом року, і тут почне з
> двох цифр: це збігається з рештою системи, але відрізняється від типового значення рушія, де
> рік чотирицифровий. Змініть його в панелі — і вибір збережеться.

## Мови

Вибір мови змінює **весь застосунок** — меню, кнопки, редактор, панель параметрів, рядок стану
та звіт, — а не лише повідомлення про помилки. Мови, що пишуться справа наліво, розвертають
вікно та звіт.

Доступні всі 35 мов, із двома рівнями охоплення:

| | Охоплення |
|---|---|
| Звіти розбору й усі повідомлення про помилки рушія | **усі 35 мов** |
| Меню, кнопки та підписи самого застосунку | **усі 35 мов** |

Мови, що пишуться справа наліво — арабська, єгипетська арабська, перська та урду — розвертають
вікно та звіт від самого моменту відкриття застосунку.

Мова запам’ятовується між запусками. Щоб відкрити іншою мовою лише один раз, див.
[`--language`](#запуск).

Дещо навмисно лишається без перекладу в усіх мовах: короткі назви полів поруч із «сирими»
значеннями (`format`, `position`, `raw`, `len` …) — це ідентифікатори, а не слова; назви
прикладів і символік — це терміни GS1 та галузі; і один довгий абзац зі стандарту, де
половинчастий переклад ввів би в оману.

## Що запам’ятовується

Два файли в каталозі `.gaia-desktop` усередині вашого домашнього каталогу:

| Файл | Містить |
|---|---|
| `options.properties` | Усі параметри аналізу, тему, ознаку відкритої панелі параметрів, останній використаний сканер і режим, у якому лишили вікно |
| `captures.tsv` | Історію записів, найновіші згори, не більше 500 позицій |

Параметри записуються щоразу, коли ви щось змінюєте; історія — щоразу, коли вона змінюється.
Обидва файли перезаписуються під час виходу.

Вилучення будь-якого з файлів скидає лише цю частину й нічого більше — їх тримають окремо, щоб
пошкоджена історія не коштувала вам налаштувань. Файл, зіпсований ручним редагуванням, теж не є
катастрофою: кожне налаштування повертається до свого типового значення окремо, тож один хибний
рядок коштує лише цього рядка.

Історія зберігає ввід, а не результат розбору. Під час завантаження його розбирають наново — це
означає, що відновлений запис відображає параметри, чинні **зараз**, а не ті, що діяли на мить
запису.

## Усунення несправностей

| Ознака | Причина та розв’язання |
|---|---|
| Застосунок не запускається або повідомляє `NoClassDefFoundError` | Каталог `lib/` має лежати поруч із JAR-файлом. Тримайте їх разом або скористайтеся самодостатньою збіркою |
| *«Unsupported JavaFX configuration…»* у консолі під час запуску | Очікувано й нешкідливо — бібліотека лише зазначає, як її було завантажено. Застосунок працює нормально |
| Вставлений роздільник наче зникає | Так і задумано: його переписано у видимий токен `{GS}`, а аналізатор усе одно отримує справжній символ. Див. [токен {GS}](#поле-введення-і-токен-gs) |
| Немає кнопки *Підключити сканер* | Ви працюєте в macOS або Linux, де драйверів сканера не існує. Див. [Сканування](#сканування) |
| Сканер не підключається | Перевірте, чи логічна назва у списку відповідає вашій моделі, чи сканер під’єднано і чи не тримає його інший застосунок |
| Експорт у PDF повідомляє про відсутність призначення | На комп’ютері не налаштовано ні принтера, ні призначення PDF. Додайте його або експортуйте в HTML і надрукуйте з браузера |
| Пункт меню показує щось на кшталт `act.hri` | Бракує підпису — повідомте про це, будь ласка; це вада збірки, а не налаштування |

## Обмеження

- **Сканування працює лише у Windows**, бо драйвери існують тільки там.
- **PDF проходить через вікно друку**, а не через вікно збереження.
- **Цілі Digital Link приймають домен і префікс шляху**, але не додаткові параметри запиту й не
  фрагмент.
- **AI може траплятися лише раз** у рядку елементів — це правило GS1, а не обмеження застосунку.
