GAIA Desktop کے نمونے

ہر GS1 ڈیٹا کیریئر کے لیے ایک بارکوڈ، اور یکجا کے لیے ایک روایتی لیبل۔ انہیں Zebra اسکینر سے براہِ راست اسکرین سے اسکین کریں، یا کسی عنصر سٹرنگ کو GAIA Desktop کی ان پٹ بار میں کاپی کریں۔

ہر عنصر سٹرنگ اپنے AIM Code ID سے شروع ہوتی ہے، جو GAIA کو بتاتا ہے کہ اسکین کس ڈیٹا کیریئر سے آیا ہے۔ {GS} سے مراد FNC1 ہے، یعنی متغیر لمبائی والے AI کے بعد آنے والا فاصل؛ ان پٹ بار اسے اصل حرف میں بدل دیتی ہے۔ بارکوڈ کی تصاویر TEC-IT کا آن لائن بارکوڈ جنریٹر بناتا ہے، اس لیے یہ صفحہ کھولنے سے نمونہ ڈیٹا اسے بھیجا جاتا ہے۔ زیادہ استعمال کے وقت وہ بارکوڈ کی جگہ درخواستوں کی حد کا نوٹس دکھا سکتا ہے؛ بعد میں دوبارہ لوڈ کریں۔

تجزیہ

تجزیہ موڈ میں ہر اسکین یا چسپاں کیا گیا متن اس کے Application Identifiers میں تقسیم کیا جاتا ہے۔

یکجا

ایک روایتی لاجسٹکس لیبل اپنا ڈیٹا کئی GS1-128 بارکوڈز میں رکھتا ہے۔ یکجا موڈ میں ان میں سے زیادہ سے زیادہ تین اسکین کریں، اور GAIA Desktop ان کے AI کو اس ایک عنصر سٹرنگ میں جوڑ دیتا ہے جو ایک GS1 DataMatrix میں ہوتی، اور اسے مجموعی طور پر جانچتا ہے۔ ان تینوں کو ترتیب سے اسکین کریں:
