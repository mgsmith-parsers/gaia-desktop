# Zebra اسکینر کا سیٹ اپ — Windows کے لیے GAIA Desktop

Zebra بارکوڈ اسکینر کو انسٹال اور کنفیگر کرنے کا طریقہ، تاکہ GAIA Desktop اس سے براہِ راست GS1 بارکوڈ
پڑھ سکے: ہر اسکین کا تجزیہ ہو کر وہ ہسٹری میں شامل ہو جاتا ہے، اور AIM Code ID سابقہ اور ہر FNC1 فاصل
جوں کا توں رہتا ہے۔ اصل دستاویز:
[GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md)۔

GAIA Desktop کو USB سے جڑے **Zebra DS8108** ہینڈ ہیلڈ امیجر کے ساتھ بنایا اور آزمایا گیا ہے۔ یہ مراحل
ہر اس Zebra 2D اسکینر پر لاگو ہوتے ہیں جسے Zebra کا Scanner SDK سپورٹ کرتا ہے؛ کسی خاص ماڈل کے سیٹ اپ
بارکوڈ اور مینو کے نام اس کی اپنی Quick Reference Guide یا Product Reference Guide میں ملتے ہیں۔

> **صرف Windows۔** Zebra کے اسکینر ڈرائیور صرف Windows کے لیے ہیں، اس لیے macOS یا Linux پر
> GAIA Desktop اسکینر کا کوئی کنٹرول نہیں بناتا۔ ایپ کی باقی ہر چیز ہر پلیٹ فارم پر چلتی ہے۔

## 1. آپ کو کیا چاہیے

| | |
|---|---|
| **اسکینر** | ایک Zebra 2D اسکینر، اس کی USB کیبل کے ساتھ — دیکھیں [معاون Zebra 2D اسکینر](#12-معاون-zebra-2d-اسکینر) |
| **کمپیوٹر** | Windows 10 یا 11، 64 بٹ |
| **Java** | Java 21 یا نیا، **64 بٹ** |
| **Zebra Scanner SDK for Windows** | **64 بٹ**، Zebra کی سپورٹ سائٹ سے — یہ ڈرائیور اور وہ JavaPOS سروسز فراہم کرتا ہے جو GAIA Desktop استعمال کرتا ہے |
| **Zebra 123Scan** | Zebra کی مفت کنفیگریشن یوٹیلیٹی، Zebra کی سپورٹ سائٹ سے — اسکینر کا فرم ویئر اپ ڈیٹ کرنے اور اس کی سیٹنگز جانچنے کے لیے |
| **GAIA Desktop** | `gaia-desktop-1.0.0-win.zip` |
| **اختیاری** | اسکینر کی **Product Reference Guide** (PRG)، جس میں سیٹ اپ بارکوڈ ہوتے ہیں |

حصے آپس میں کیسے جڑتے ہیں:

```
Zebra scanner ──USB──► Zebra CoreScanner driver ──► Zebra JavaPOS services ──► GAIA Desktop
                       (installed by the SDK)        (in the SDK's JPOS\bin)    (run.bat puts them on
                                                                                 the class path)
```

GAIA Desktop خود JavaPOS API اور اسکینر کا نام بتانے والی کنفیگریشن (`jpos.xml`، `gaia-desktop.jar` کے
اندر) ساتھ رکھتا ہے۔ باقی Zebra SDK فراہم کرتا ہے: وہ ڈرائیور جو اسکینر سے بات کرتا ہے، اور Zebra کی وہ
سروس کلاسیں جو JavaPOS اور اس ڈرائیور کے درمیان ہوتی ہیں۔

## 2. Java انسٹال کریں

GAIA Desktop کو **Java 21 یا نیا** چاہیے، اور یہ **64 بٹ** بلڈ ہونا چاہیے تاکہ 64 بٹ Zebra ڈرائیوروں
سے میل کھائے۔

1. Windows x64 کے لیے Java 21 JDK یا JRE انسٹال کریں — مثلاً adoptium.net سے
   Eclipse Temurin۔ اگر انسٹالر `JAVA_HOME` سیٹ کرنے کی پیشکش کرے تو اسے کرنے دیں۔
2. Command Prompt میں اسے جانچیں:

   ```
   java -version
   ```

   پہلی سطر میں ورژن 21 یا اس کے بعد کا ہونا چاہیے؛ 64 بٹ Java `64-Bit Server VM` بھی لکھتا ہے۔

`run.bat` Java کو اس ترتیب سے تلاش کرتا ہے: `run.bat` کے ساتھ رکھا `jdk*` فولڈر، پھر `JAVA_HOME`، پھر
`PATH` پر موجود `java`۔ 21 سے پرانا کچھ بھی ہو تو پیغام کے ساتھ اسے مسترد کر دیتا ہے۔

## 3. Zebra Scanner SDK انسٹال کریں

1. Zebra کی سپورٹ سائٹ سے **Zebra Scanner SDK for Windows (64-bit)** ڈاؤن لوڈ کریں۔
2. انسٹالر چلائیں۔ اگر یہ اجزاء چننے کا اختیار دے تو یقینی بنائیں کہ **JPOS** (JavaPOS) جزو شامل ہے۔
3. انسٹال کی ڈیفالٹ جگہ ہی رہنے دیں۔ GAIA Desktop SDK کا JavaPOS حصہ یہاں تلاش کرتا ہے:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   اور توقع کرتا ہے کہ Zebra کی سروس jar فائلیں (`JposServiceScanner.jar`، `JposServiceJniScanner.jar`، …)
   اور نیٹو لائبریریاں (`CSJPOSScanner64.dll`، …) اس کے `bin\` فولڈر میں ہوں۔ اگر SDK کہیں اور
   انسٹال ہے تو [ZEBRA_HOME](#zebra_home) دیکھیں۔
4. انسٹال کرنے کے بعد **Windows کو ری اسٹارٹ کریں**۔ SDK کا CoreScanner ڈرائیور پس منظر میں چلتا ہے اور
   GAIA Desktop کے اسکینر تک پہنچنے سے پہلے اس کا چلنا ضروری ہے؛ ری اسٹارٹ اس کا یقین کرنے کا سب سے
   آسان طریقہ ہے۔

## 4. 123Scan انسٹال کریں

123Scan، Zebra کی اپنے اسکینروں کو کنفیگر کرنے والی مفت یوٹیلیٹی ہے۔ اگلے مرحلے میں اسی سے اسکینر کا فرم
ویئر اپ ڈیٹ کیا جاتا ہے، اور بعد میں اسکینر کی سیٹنگز جانچنے اور بدلنے کا سب سے آسان طریقہ بھی یہی ہے۔

1. Zebra کی سپورٹ سائٹ سے **123Scan** ڈاؤن لوڈ کریں اور انسٹالر چلائیں۔
2. Zebra اسکینر لگائیں اور 123Scan شروع کریں۔ اسے اسکینر مل جانا چاہیے اور اس کا ماڈل، سیریل نمبر اور
   موجودہ فرم ویئر ورژن دکھانا چاہیے۔ اگر ایسا نہ ہو تو آگے بڑھنے سے پہلے کوئی دوسرا USB پورٹ یا کیبل
   آزمائیں — جو اسکینر 123Scan کو نظر نہیں آتا، وہ GAIA Desktop کو بھی نظر نہیں آئے گا۔

---

## 5. Zebra اسکینر کا فرم ویئر اپ ڈیٹ کریں

کنفیگر کرنے سے پہلے اسکینر کا فرم ویئر تازہ ترین ورژن پر لے آئیں۔ فرم ویئر اپ ڈیٹ ڈی کوڈنگ کے مسائل
ٹھیک کرتے ہیں اور اسکینر کو SDK کے انسٹال کردہ Zebra ڈرائیور کے ساتھ ہم آہنگ رکھتے ہیں۔

1. **GAIA Desktop** اور کوئی بھی دوسرا پروگرام جو اسکینر استعمال کر رہا ہو، بند کریں: اپ ڈیٹ کے دوران
   123Scan کو اسکینر صرف اپنے پاس چاہیے۔
2. اسکینر منسلک ہونے کی حالت میں 123Scan میں اس کا فرم ویئر اپ ڈیٹ کا اختیار چنیں۔ 123Scan اسکینر کے فرم
   ویئر کا موازنہ Zebra کے جاری کردہ تازہ ترین فرم ویئر سے کرتا ہے اور اسے ڈاؤن لوڈ اور انسٹال کرنے کی
   پیشکش کرتا ہے۔ اگر کمپیوٹر پر انٹرنیٹ نہیں ہے تو Zebra کی سائٹ پر اسکینر کے سپورٹ صفحے سے اس کا فرم
   ویئر ڈاؤن لوڈ کریں اور فائل 123Scan میں لوڈ کریں۔
3. اپ ڈیٹ شروع کریں اور **جب تک 123Scan یہ نہ بتائے کہ کام مکمل ہو گیا، اسکینر لگا رہنے دیں**۔ اس میں
   کئی منٹ لگتے ہیں؛ آخر میں اسکینر ری اسٹارٹ ہوتا ہے۔ بیچ میں نکالنے سے یہ ناکارہ ہو سکتا ہے۔
4. جانچیں کہ 123Scan اب نیا فرم ویئر ورژن دکھا رہا ہے۔

اپ ڈیٹ کچھ سیٹنگز کو ڈیفالٹ پر لوٹا سکتا ہے، اسی لیے اسکینر کو اگلے دو مراحل میں، فرم ویئر کے بعد،
کنفیگر کیا جاتا ہے۔

## 6. Zebra اسکینر کا USB موڈ سیٹ کریں

یہی مرحلہ سب سے زیادہ چھوٹ جاتا ہے۔ **ڈبے سے نکلا Zebra اسکینر ایک USB کی بورڈ ہوتا ہے** (USB HID
Keyboard موڈ): یہ ہر بارکوڈ وہاں "ٹائپ" کر دیتا ہے جہاں فوکس ہو۔ اس موڈ میں GAIA Desktop کا
*اسکینر منسلک کریں* اسے تلاش نہیں کر پاتا، اور ٹیکسٹ فیلڈ میں ٹائپ ہونے والی ہر چیز اپنے FNC1 فاصل کھو
دیتی ہے، جس سے GS1 عنصر سٹرنگ کا مطلب بدل جاتا ہے۔

اسکینر کو ایسے موڈ میں بدلیں جس سے Zebra ڈرائیور براہِ راست بات کرتا ہے:

| اسکینر کا USB موڈ | GAIA Desktop میں ڈیوائس کا نام | نوٹ |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld`، یا `ZebraAllScanners` | تجویز کردہ |
| SNAPI (امیجنگ کے ساتھ یا بغیر) | `ZebraScannerSNAPI`، یا `ZebraAllScanners` | Zebra کا اپنا USB پروٹوکول؛ یہ بھی چلتا ہے |
| IBM Table-top USB | `ZebraUSBTableTop`، یا `ZebraAllScanners` | میز پر رکھے اسکینروں کے لیے |
| USB OPOS (Hand-held) | `ZebraUSBOPOS`، یا `ZebraAllScanners` | |
| USB HID Keyboard (فیکٹری ڈیفالٹ) | — | **منسلک نہیں ہوگا** |

`ZebraAllScanners`، GAIA Desktop کا ڈیفالٹ ڈیوائس نام، کسی بھی معاون موڈ میں اسکینر قبول کرتا ہے، اس
لیے موڈ سیٹ ہوتے ہی ڈیفالٹ عموماً خود ہی کام کر جاتا ہے۔

موڈ بدلنے کے لیے، یا تو:

- اسکینر کی Quick Reference Guide یا Product Reference Guide (USB Host Types / USB Device Type حصہ)
  میں اس موڈ کا — مثلاً *IBM Hand-held USB* — **سیٹ اپ بارکوڈ اسکین کریں**؛ اسکینر بیپ کر کے تصدیق
  کرتا ہے۔ یا
- **123Scan استعمال کریں** ([مرحلہ 4](#4-123scan-انسٹال-کریں)): اسکینر منسلک کریں، اس کی کنفیگریشن
  کھولیں، اور USB ہوسٹ کی قسم سیٹ کریں۔

موڈ بدلنے کے بعد Windows اسکینر کو ایک مختلف قسم کی ڈیوائس کے طور پر دوبارہ پہچانتا ہے؛ منسلک کرنے سے
پہلے چند سیکنڈ رکیں۔

بعد میں اسکینر کو کی بورڈ موڈ میں واپس لانے کے لیے — دوسرے سافٹ ویئر کے ساتھ استعمال کی خاطر —
*USB Keyboard (HID)* سیٹ اپ بارکوڈ اسکین کریں، یا اس کی فیکٹری ڈیفالٹ سیٹنگز بحال کریں۔

## 7. GS1 کے لیے Zebra اسکینر کنفیگر کریں

جب اسکینر بتائے کہ اس نے کس قسم کا بارکوڈ پڑھا ہے تو GAIA Desktop سب سے بہتر تجزیہ کرتا ہے۔

### AIM Code ID بھیجیں

Product Reference Guide (User Preferences) کے سیٹ اپ بارکوڈ سے یا 123Scan میں **Transmit Code ID
Character** کو **AIM Code ID Character** پر سیٹ کریں۔ پھر ہر اسکین اپنی سمبالوجی شناخت سے شروع ہوتا ہے —
GS1-128 کے لیے `]C1`، GS1 DataMatrix کے لیے `]d2`، GS1 QR Code کے لیے `]Q3`، GS1 DataBar کے لیے
`]e0` — جسے GAIA Desktop ڈیٹا کیریئر کا نام بتانے اور اس کے قواعد لاگو کرنے کے لیے استعمال کرتا ہے۔

اس کے بغیر بھی GAIA Desktop عنصر سٹرنگ کا تجزیہ کرتا ہے اور سمبالوجی خود اسکین سے لیتا ہے، لیکن رپورٹ
کے پاس دکھانے کو کوئی AIM Code ID نہیں ہوتا، اور EAN-13 جیسے سادہ بارکوڈ کو GS1 عنصر سٹرنگ سے الگ
پہچاننا مشکل ہو جاتا ہے۔

### سمبالوجیز جانچیں

یقینی بنائیں کہ جن بارکوڈ اقسام کے ساتھ آپ کام کرتے ہیں وہ **فعال** ہیں: عموماً GS1-128، GS1 DataMatrix،
GS1 DataBar، GS1 QR Code اور EAN/UPC۔ Zebra کے 2D اسکینروں پر ان میں سے زیادہ تر ڈیفالٹ طور پر چالو
ہوتی ہیں؛ 123Scan موجودہ سیٹنگز دکھاتا ہے، اور Product Reference Guide میں ہر ایک کو فعال کرنے کا بارکوڈ
موجود ہے۔

### Zebra کی GS1 تجزیہ کی سہولیات بند رکھیں

نئے فرم ویئر میں ایسی GS1 سہولیات شامل ہیں جو خود اسکینر پر کام کرتی ہیں — **Label Parse+**، **GS1
Digital Link** اور **GS1 Retail POS parsing**۔ انہیں **بند** رکھیں، جیسے اسکینر آتا ہے: یہ اسکینر کے
بھیجے گئے ڈیٹا کی شکل بدلتی یا اسے مختصر کرتی ہیں، جبکہ GAIA Desktop کو تجزیے اور توثیق کے لیے خام ڈیٹا
چاہیے۔ ہر ایک کیا کرتی ہے، یہ [معاون Zebra 2D اسکینر](#12-معاون-zebra-2d-اسکینر) میں دیکھیں۔

### سابقے اور لاحقے بند رکھیں

اسکینر کے آؤٹ پٹ میں کوئی سابقہ، لاحقہ یا Enter کی شامل نہ کریں۔ GAIA Desktop ہر اسکین JavaPOS کے
ذریعے ایک مکمل پیغام کے طور پر وصول کرتا ہے اور اسے ان میں سے کسی کی ضرورت نہیں؛ اضافی حروف عنصر سٹرنگ
میں جا پہنچیں گے۔

## 8. GAIA Desktop انسٹال کریں اور چلائیں

1. `gaia-desktop-1.0.0-win.zip` کو ان زِپ کریں، مثلاً `C:\Tools\` میں۔ اس میں ایک فولڈر ہوتا ہے:

   ```
   gaia-desktop-1.0.0-win\
   ├── docs\
   │   └── GaiaDesktop-Zebra-Scanner-Windows.md      this guide
   ├── gaia-desktop.jar
   ├── lib\
   ├── readme.html                                   index of every guide
   └── run.bat
   ```

2. اسکینر لگائیں۔
3. **`run.bat`** پر ڈبل کلک کریں۔ ایپ کے ساتھ ایک کنسول ونڈو کھلتی ہے اور کھلی رہتی ہے: اسکینر کی
   حالت اور JavaPOS کی خرابیاں وہیں بتائی جاتی ہیں۔
4. کنسول کی پہلی سطر پڑھیں۔ اس میں لکھا ہوتا ہے کہ `run.bat` کو کیا ملا:

   ```
   run.bat: Java 21.0.8 from JAVA_HOME; JavaFX from lib\; JavaPOS from lib\; Zebra services from C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   اگر یہ **`Zebra services from none (Zebra Scanner SDK not installed)`** پر ختم ہو تو SDK اپنی ڈیفالٹ
   جگہ پر نہیں ملا — اسے انسٹال کریں ([مرحلہ 3](#3-zebra-scanner-sdk-انسٹال-کریں)) یا
   [ZEBRA_HOME](#zebra_home) سیٹ کریں۔ ایپ پھر بھی چلتی ہے، لیکن اسکینر منسلک نہیں ہو سکتا۔

## 9. اسکینر منسلک کریں

1. ٹول بار میں **ڈیوائس چُننے والا** ان اسکینر ناموں کی فہرست دکھاتا ہے جو GAIA Desktop جانتا ہے۔ اسے
   **`ZebraAllScanners`** پر رہنے دیں، یا [مرحلہ 6](#6-zebra-اسکینر-کا-usb-موڈ-سیٹ-کریں) کے جدول سے
   اسکینر کے USB موڈ کا نام چنیں۔
2. **اسکینر منسلک کریں** پر کلک کریں، یا **Ctrl+K** دبائیں (یہ **اسکینر** مینو میں بھی ہے)۔
3. اسٹیٹس بار بدل کر **`اسکینر: ZebraAllScanners`** (یا آپ کا چنا ہوا نام) ہو جاتا ہے، اور اسٹیٹس لائن
   *اسکینر منسلک ہوا — ZebraAllScanners* بتاتی ہے۔ بٹن پر اب **اسکینر منقطع کریں** لکھا ہوتا ہے۔
4. کوئی GS1 بارکوڈ اسکین کریں۔ یہ کیپچر ہسٹری میں سب سے اوپر نظر آتا ہے اور اس کی رپورٹ کھل جاتی ہے۔
   AIM Code ID چالو ہو تو رپورٹ ڈیٹا کیریئر کا نام بتاتی ہے — *GS1-128*، *GS1 DataMatrix* — اور عنصر
   سٹرنگ ہر FNC1 فاصل برقرار رکھتی ہے۔

ڈیوائس چُننے والا ہر بار چلانے کے درمیان آپ کا انتخاب یاد رکھتا ہے۔ اسکینر اس وقت تک منسلک رہتا ہے جب
تک آپ اسے منقطع نہ کریں یا ایپ بند نہ کریں۔ اسکین **تشکیل** اور **یکجا** موڈ میں بھی کام کرتے ہیں: یکجا
میں ہر اسکین یکجا کیے جانے والے بارکوڈوں میں سے ایک بن جاتا ہے۔

جب تک GAIA Desktop اسکینر کو تھامے رکھتا ہے، دوسرے پروگرام اسے استعمال نہیں کر سکتے، اور اس کے برعکس
بھی: منسلک کرنے سے پہلے 123Scan اور کوئی بھی دوسرا پوائنٹ آف سیل یا اسکینر سافٹ ویئر بند کریں۔

## 10. کنفیگریشن کا حوالہ

### ڈیوائس کے نام

ڈیوائس چُننے والا `gaia-desktop.jar` میں شامل `jpos.xml` سے بھرا جاتا ہے۔ اس کے اسکینر اندراجات:

| ڈیوائس کا نام | اسکینر کی قسم | کس کے ساتھ استعمال کریں |
|---|---|---|
| `ZebraAllScanners` | کوئی بھی | **ڈیفالٹ۔** کوئی بھی معاون USB موڈ |
| `ZebraAllScanners114` | کوئی بھی | اسی سروس کا JavaPOS 1.14 ورژن |
| `ZebraUSBHandHeld` | IBM Hand-held USB | IBM Hand-held USB موڈ میں اسکینر |
| `ZebraUSBTableTop` | IBM Table-top USB | ٹیبل ٹاپ موڈ |
| `ZebraUSBOPOS` | USB OPOS | USB OPOS موڈ |
| `ZebraScannerSNAPI` | SNAPI | SNAPI موڈ |
| `ZebraScannerUSB` | کوئی بھی USB | کوئی بھی USB موڈ |
| `ZebraScannerSerialSSI` | سیریل SSI | سیریل کیبل والے اسکینر (USB نہیں) |
| `ZebraScannerSerialNIXMODB` | سیریل NIXMODB | سیریل کیبل والے اسکینر |
| `ZebraVDI` | VDI | ورچوئل ڈیسک ٹاپ تک پہنچائے گئے اسکینر |

### ZEBRA_HOME

اگر Zebra SDK ڈیفالٹ کے علاوہ کہیں اور انسٹال ہے تو `run.bat` چلانے سے پہلے `ZEBRA_HOME` کو اس کے `JPOS`
فولڈر پر سیٹ کریں — مثلاً اس کے ساتھ رکھی ایک چھوٹی بیچ فائل میں:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

پھر `run.bat` Zebra کی سروس jar فائلیں `%ZEBRA_HOME%bin` سے لیتا ہے اور Zebra DLL کے لیے اس فولڈر کو
`PATH` میں شامل کرتا ہے۔

### آپ کا اپنا jpos.xml

کوئی ڈیوائس نام شامل کرنے یا کسی اندراج کی سیٹنگز بدلنے کے لیے `gaia-desktop.jar` سے `jpos.xml` کی کاپی
نکالیں (یہ ایک zip ہے؛ کوئی بھی ان زِپ ٹول اسے کھول لیتا ہے)، کاپی میں ترمیم کریں، اور GAIA Desktop کو
اس کی طرف اشارہ کریں:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

پھر ڈیوائس چُننے والا اس فائل کے اسکینر دکھاتا ہے۔ ایک سے زیادہ Zebra اسکینر منسلک ہوں تو کسی اندراج کو
اس کی `ScannerModel` یا `SerialNumber` خاصیت کے ذریعے ان میں سے کسی ایک سے باندھا جا سکتا ہے، جیسا کہ
`ZebraAllScanners` اندراج میں ہے۔

### دیگر اختیارات

| سیٹنگ | کیسے |
|---|---|
| ایپ کی زبان | `run.bat --language=FR` (صرف اس بار کے لیے)، یا اختیارات کا پینل |
| اضافی Java اختیارات | `run.bat` سے پہلے `set GAIA_DESKTOP_OPTS=…` |
| ساتھ رکھا Java | `run.bat` کے ساتھ ایک `jdk-21…` فولڈر رکھیں؛ یہ `JAVA_HOME` سے پہلے استعمال ہوتا ہے |

## 11. مسائل کا حل

خرابیاں منسلک کرتے وقت ایک ڈائیلاگ میں، کنسول ونڈو میں، اور لاگ فائل `logs\gaia-desktop.log` میں نظر آتی
ہیں، جو اس فولڈر میں ہوتی ہے جہاں سے `run.bat` چلایا گیا (`run.bat` پر ڈبل کلک کرنے پر یہ GAIA Desktop
فولڈر ہوتا ہے)۔ لاگ میں چوکور قوسین کے اندر کا عدد JavaPOS خرابی کا کوڈ ہے۔

| آپ کو کیا نظر آتا ہے | ممکنہ وجہ | کیا کریں |
|---|---|---|
| کوئی *اسکینر منسلک کریں* بٹن نہیں | Windows پر نہیں چل رہا | اسکیننگ صرف Windows پر ہے |
| 123Scan کو اسکینر نہیں ملتا | کیبل، USB پورٹ، یا اسکینر کسی دوسرے پروگرام نے تھام رکھا ہے | دوسری کیبل یا پورٹ آزمائیں؛ GAIA Desktop اور دوسرا اسکینر سافٹ ویئر بند کریں۔ جو اسکینر 123Scan کو نظر نہیں آتا وہ GAIA Desktop کو بھی نظر نہیں آئے گا |
| کنسول: `Zebra services from none (Zebra Scanner SDK not installed)` | SDK اپنی ڈیفالٹ جگہ پر نہیں ہے | 64 بٹ SDK انسٹال کریں ([مرحلہ 3](#3-zebra-scanner-sdk-انسٹال-کریں))، یا [ZEBRA_HOME](#zebra_home) سیٹ کریں |
| خرابی **104**: *Could not connect to service with logicalName = …: …SymScannerSvc112Factory* | Zebra کی سروس jar فائلیں نہیں ملیں | اوپر کی طرح — کنسول کی `Zebra services from` سطر جانچیں |
| خرابی **109**: *Service does not exist in loaded JCL registry* | ڈیوائس کا نام اسکینر کنفیگریشن میں نہیں، یا SDK کی `javaPOS114.jar` class path میں آ گئی | ڈیوائس چُننے والے سے کوئی نام چنیں؛ `javaPOS114.jar` شامل نہ کریں؛ اپنا `jpos.xml` استعمال کرتے ہوں تو جانچیں کہ نام اس میں ہے |
| خرابی **107** (ہارڈ ویئر نہیں)، یا اسکینر لگا ہونے کے باوجود منسلک کرنا ناکام | اسکینر اب بھی USB کی بورڈ موڈ میں ہے، یا CoreScanner ڈرائیور نہیں چل رہا | USB موڈ سیٹ کریں ([مرحلہ 6](#6-zebra-اسکینر-کا-usb-موڈ-سیٹ-کریں))؛ SDK انسٹال کرنے کے بعد Windows ری اسٹارٹ کریں؛ دوسرا USB پورٹ آزمائیں |
| منسلک کرتے وقت خرابی **112** (ٹائم آؤٹ) یا **102** (قبضے میں) | کوئی دوسرا پروگرام اسکینر تھامے ہوئے ہے | 123Scan اور کوئی بھی دوسرا اسکینر یا پوائنٹ آف سیل سافٹ ویئر بند کریں، پھر دوبارہ منسلک کریں |
| کنسول میں `UnsatisfiedLinkError` … `CSJPOSScanner64` | Zebra DLL لوڈ نہیں ہو پاتے — اکثر 64 بٹ Java کے ساتھ 32 بٹ SDK | 64 بٹ SDK انسٹال کریں؛ جانچیں کہ `java -version` 64 بٹ VM بتاتا ہے |
| اسکین کیپچر بن کر آنے کے بجائے ان پٹ بار میں ٹائپ ہو جاتے ہیں | اسکینر USB کی بورڈ موڈ میں ہے | USB موڈ سیٹ کریں ([مرحلہ 6](#6-zebra-اسکینر-کا-usb-موڈ-سیٹ-کریں)) |
| منسلک ہے، لیکن اسکین نہیں آتے | اسکینر کے موڈ کے لیے غلط ڈیوائس نام، یا منسلک ہوتے ہوئے اسکینر دوبارہ لگایا گیا | منقطع کریں، `ZebraAllScanners` چنیں، دوبارہ منسلک کریں |
| رپورٹ میں AIM Code ID / ڈیٹا کیریئر نظر نہیں آتا | AIM Code ID بھیجنا بند ہے | *Transmit Code ID Character → AIM Code ID* چالو کریں ([مرحلہ 7](#7-gs1-کے-لیے-zebra-اسکینر-کنفیگر-کریں)) |
| عنصر سٹرنگ سے فاصل غائب ہیں، یا AI آپس میں مل گئے ہیں | کی بورڈ موڈ میں اسکین کیا، یا `{GS}` کے بغیر ہاتھ سے ٹائپ کیا | JavaPOS والا USB موڈ استعمال کریں؛ ٹائپ کرتے وقت فاصل `{GS}` بٹن سے ڈالیں |
| کوئی بارکوڈ قسم کبھی نہیں پڑھی جاتی | وہ سمبالوجی اسکینر پر غیر فعال ہے | اسے فعال کریں ([مرحلہ 7](#7-gs1-کے-لیے-zebra-اسکینر-کنفیگر-کریں)) |

اگر مسئلہ برقرار رہے تو کنسول کی `run.bat:` سطر، خرابی کے ڈائیلاگ کا متن اور `logs\gaia-desktop.log`
اکٹھے محفوظ رکھیں: مل کر یہ دکھاتے ہیں کہ کون سا Java، کون سی Zebra سروسز اور کون سا ڈیوائس نام استعمال
ہوا، اور منسلک ہونا ٹھیک کہاں ناکام ہوا۔

## 12. معاون Zebra 2D اسکینر

GAIA Desktop کو ایسا اسکینر چاہیے جو وہ بارکوڈ پڑھ سکے جن میں GS1 ڈیٹا چھپتا ہے — GS1-128،
GS1 DataBar، EAN/UPC، اور زیادہ تر استعمالات کے لیے 2D کوڈ: **GS1 DataMatrix** اور **GS1 QR Code**،
جس میں عموماً **GS1 Digital Link** URI بھی چھپتا ہے۔ یعنی ایک Zebra **2D امیجر**: لکیری (1D) اسکینر
DataMatrix یا QR کوڈ بالکل نہیں پڑھ سکتا۔

اسکینر کو خود GS1 Application Identifiers یا Digital Link سمجھنے کی ضرورت نہیں۔
**GAIA Desktop دونوں کا تجزیہ کرتا ہے**: یہ اسکین کو ویسا ہی لیتا ہے جیسا اسکینر نے پڑھا — AIM Code ID،
FNC1 فاصل، سب کچھ — اور خود اسے AI میں تقسیم کرتا ہے، یا Digital Link URI کو اس کے AI میں بدلتا ہے۔

### آزمایا گیا

| اسکینر | قسم | حالت |
|---|---|---|
| **DS8108** | تار والا ہینڈ ہیلڈ 2D امیجر | GAIA Desktop کے ساتھ **بنایا اور آزمایا گیا** |

### چلنے کی توقع

یہ Zebra کے 2D امیجر ہیں جو DS8108 کی طرح Zebra کے Scanner SDK اور JavaPOS سروسز کے ذریعے چلتے ہیں۔
انہیں GAIA Desktop کے ساتھ **آزمایا نہیں گیا**؛ ہر ایک کو اس گائیڈ کے مطابق سیٹ کریں، اور سیٹ اپ بارکوڈ اس
کی اپنی Quick Reference Guide یا Product Reference Guide سے لیں۔

| خاندان | ماڈل (مثالیں) |
|---|---|
| DS81x8 | DS8108 (تار والا)، DS8178 (بے تار) |
| DS22x8 | DS2208 (تار والا)، DS2278 (بے تار) — عام استعمال |
| DS36x8 | DS3608 (تار والا)، DS3678 (بے تار) — مضبوط، KD اور XR اقسام سمیت |
| DS46x8 | DS4608 (تار والا)، DS4678 (بے تار) |
| DS9308 / DS9908 | پریزنٹیشن اور ہینڈز فری اسکینر |
| MP7000 / MP7200 | کثیر سطحی بایوپٹک اسکینر اور اسکینر ترازو |
| CS6080 | بے تار معاون اسکینر |

بے تار اسکینر اپنے کریڈل سے بات کرتا ہے، اور کمپیوٹر میں کریڈل ہی لگتا ہے: کریڈل کو USB سے منسلک کریں
اور جوڑے کو ایک اسکینر سمجھیں۔ دوسرے Zebra خاندانوں کے اسکینر بھی چل سکتے ہیں، اگر Zebra کا Scanner SDK
انہیں [مرحلہ 6](#6-zebra-اسکینر-کا-usb-موڈ-سیٹ-کریں) کے کسی USB موڈ میں سپورٹ کرتا ہو۔

### Zebra اسکینر پر چلنے والی GS1 سہولیات

بارکوڈ پڑھنے سے ہٹ کر، کچھ Zebra 2D امیجر خود اسکینر پر GS1 ڈیٹا پر کارروائی کر سکتے ہیں، جسے 123Scan
کے ذریعے کنفیگر کیا جاتا ہے:

| سہولت | یہ کیا کرتی ہے | GAIA Desktop کے لیے |
|---|---|---|
| **Label Parse+** | اسکینر پر ہی GS1 لیبل کے AI کا تجزیہ کر کے نئی شکل میں فیلڈز بھیجتی ہے | **بند رکھیں** — تب GAIA Desktop کو AI، FNC1 فاصل اور AIM Code ID نظر نہیں آئیں گے |
| **GS1 Digital Link** | ان ریٹیل مصنوعات کے لیے جن پر 1D EAN/UPC اور 2D Digital Link کوڈ دونوں ہوں: چنتی ہے کہ کیا بھیجا جائے | **بند رکھیں** (ڈیفالٹ) |
| **GS1 Retail POS parsing** | Digital Link URI یا عنصر سٹرنگ سنٹیکس میں 2D ریٹیل بارکوڈ پڑھتی ہے | **بند رکھیں** |

**GS1 Digital Link** سیٹنگ کے تین موڈ ہیں۔ **Mode 1 — GTIN only**، فعال کرنے پر جس موڈ میں یہ شروع
ہوتی ہے، صرف GTIN بھیجتا ہے، خواہ وہ کسی بھی بارکوڈ سے آئے، اس لیے Digital Link کا بیچ، میعاد ختم ہونے کی
تاریخ یا سیریل نمبر کبھی GAIA Desktop تک نہیں پہنچتا۔ **Mode 2 — Prioritize 2D** ترجیحی ٹائم آؤٹ
(ڈیفالٹ 200 ms) کے اندر نظر آنے پر 2D کوڈ بھیجتا ہے، ورنہ 1D۔ **Mode 3 — Corroborate 1D and 2D GTINs
Match** 1D بھیجتا ہے، اور GTIN مل جائے تو 2D بھی۔ اگر کسی دوسرے سافٹ ویئر کے لیے سیٹنگ کو چالو رکھنا
ضروری ہو تو Mode 1 نہیں، Mode 2 استعمال کریں۔ DS8108 پر یہ پیرامیٹر 2373 (چالو/بند)، 2374 (موڈ) اور
2491 (ٹائم آؤٹ) ہیں۔

ان سہولیات کے لیے **123Scan ورژن 6 یا نیا** اور انہیں شامل کرنے والا فرم ویئر درکار ہے۔ Zebra اپریل 2025

سے لی گئی ہیں، اس لیے ہر ماڈل کے فرم ویئر ریلیز نوٹس جانچیں:
