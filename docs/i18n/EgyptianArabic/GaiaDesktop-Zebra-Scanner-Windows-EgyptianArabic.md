# إعداد ماسح Zebra — GAIA Desktop على Windows

إزاي تسطّب ماسح باركود من Zebra وتظبطه علشان GAIA Desktop يقرا منه باركود GS1 على طول: كل مسحة
بتتحلل وتتضاف للسجل، والبادئة بتاعة AIM Code ID وكل فاصل FNC1 بيفضلوا زي ما هم. المستند الأصلي:
[GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md).

GAIA Desktop اتعمل واتجرّب مع ماسح التصوير اللي بيتمسك في الإيد **Zebra DS8108** متوصل بـ USB.
الخطوات دي تنفع مع أي ماسح ثنائي الأبعاد من Zebra بيدعمه Scanner SDK بتاع Zebra؛ وباركودات الإعداد
وأسامي القوايم لأي موديل بعينه موجودة في الـ Quick Reference Guide أو الـ Product Reference Guide
بتاعه.

> **Windows بس.** مشغّلات ماسحات Zebra موجودة لـ Windows بس، فـ GAIA Desktop مش بيعمل أي تحكم
> في الماسح على macOS أو Linux. أي حاجة تانية في البرنامج شغالة على كل الأنظمة.

## 1. هتحتاج إيه

| | |
|---|---|
| **الماسح** | ماسح ثنائي الأبعاد من Zebra، بالكابل الـ USB بتاعه — شوف [ماسحات Zebra ثنائية الأبعاد المدعومة](#12-ماسحات-zebra-ثنائية-الأبعاد-المدعومة) |
| **الكمبيوتر** | Windows 10 أو 11، 64 بت |
| **Java** | Java 21 أو أحدث، **64 بت** |
| **Zebra Scanner SDK for Windows** | **64 بت**، من موقع دعم Zebra — هو اللي بيدّي المشغّل وخدمات JavaPOS اللي GAIA Desktop بيستخدمها |
| **Zebra 123Scan** | أداة الإعداد المجانية بتاعة Zebra، من موقع دعم Zebra — بتستخدمها تحدّث السوفتوير الداخلي للماسح وتراجع إعداداته |
| **GAIA Desktop** | `gaia-desktop-1.0.0-win.zip` |
| **اختياري** | الـ **Product Reference Guide** (PRG) بتاع الماسح، وفيه باركودات الإعداد |

الحاجات دي بتتركّب على بعض إزاي:

```
Zebra scanner ──USB──► Zebra CoreScanner driver ──► Zebra JavaPOS services ──► GAIA Desktop
                       (installed by the SDK)        (in the SDK's JPOS\bin)    (run.bat puts them on
                                                                                 the class path)
```

GAIA Desktop شايل جواه واجهة JavaPOS والإعداد اللي بيسمّي الماسح (`jpos.xml`، جوه
`gaia-desktop.jar`). والباقي بييجي من Zebra SDK: المشغّل اللي بيكلّم الماسح، وكلاسات خدمات Zebra اللي
قاعدة بين JavaPOS والمشغّل ده.

## 2. سطّب Java

GAIA Desktop محتاج **Java 21 أو أحدث**، ولازم تكون نسخة **64 بت**، علشان تمشي مع مشغّلات Zebra اللي
هي 64 بت.

1. سطّب Java 21 JDK أو JRE لـ Windows x64 — زي Eclipse Temurin من
   adoptium.net. ولو المسطّب عرض يظبط `JAVA_HOME` سيبه يعملها.
2. اتأكد منها في Command Prompt:

   ```
   java -version
   ```

   أول سطر لازم يبيّن نسخة 21 أو أحدث؛ والـ Java اللي 64 بت بتطبع كمان `64-Bit Server VM`.

`run.bat` بيدوّر على Java بالترتيب ده: فولدر `jdk*` جنب `run.bat`، وبعدين `JAVA_HOME`، وبعدين `java`
اللي على `PATH`. وأي نسخة أقدم من 21 بيرفضها برسالة بتقول كده.

## 3. سطّب Zebra Scanner SDK

1. نزّل **Zebra Scanner SDK for Windows (64-bit)** من موقع دعم Zebra.
2. شغّل المسطّب. ولو اداك تختار المكوّنات، اتأكد إن مكوّن **JPOS** (JavaPOS) متعلّم عليه.
3. سيب مكان التسطيب الافتراضي زي ما هو. GAIA Desktop بيدوّر على جزء JavaPOS من الـ SDK في:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   ومستني يلاقي ملفات jar بتاعة خدمات Zebra (`JposServiceScanner.jar`، `JposServiceJniScanner.jar`، …)
   والمكتبات الأصلية (`CSJPOSScanner64.dll`، …) في فولدر `bin\` بتاعه. لو الـ SDK متسطّب في حتة
   تانية، شوف [ZEBRA_HOME](#zebra_home).
4. **اعمل ريستارت لـ Windows** بعد التسطيب. مشغّل CoreScanner بتاع الـ SDK بيشتغل في الخلفية، ولازم
   يكون شغال قبل ما GAIA Desktop يقدر يوصل للماسح؛ والريستارت أسهل طريقة تضمن بيها ده.

## 4. سطّب 123Scan

‏123Scan هي أداة Zebra المجانية لإعداد ماسحاتها. هتستخدمها في الخطوة الجاية تحدّث السوفتوير الداخلي
للماسح، وهي أسهل طريقة تراجع وتغيّر بيها إعدادات الماسح بعد كده.

1. نزّل **123Scan** من موقع دعم Zebra وشغّل المسطّب.
2. ركّب ماسح Zebra وشغّل 123Scan. المفروض يلاقي الماسح ويعرض الموديل والرقم التسلسلي ونسخة السوفتوير
   الداخلي الحالية. لو ملقاهوش، جرّب منفذ USB أو كابل تاني قبل ما تكمّل — GAIA Desktop مش هيشوف ماسح
   123Scan مش شايفه.

## 5. حدّث السوفتوير الداخلي لماسح Zebra

طلّع السوفتوير الداخلي (الفيرموير) بتاع الماسح لآخر نسخة قبل ما تظبطه. التحديثات دي بتصلّح مشاكل فك
الترميز وبتخلّي الماسح ماشي مع مشغّل Zebra اللي الـ SDK سطّبه.

1. اقفل **GAIA Desktop** وأي برنامج تاني ممكن يكون بيستخدم الماسح: 123Scan محتاج الماسح لوحده طول
   التحديث.
2. في 123Scan، والماسح متوصل، اختار تحديث الفيرموير بتاعه. 123Scan بيقارن فيرموير الماسح بآخر واحد
   Zebra نزّلته ويعرض ينزّله ويسطّبه. لو الكمبيوتر مفيهوش إنترنت، نزّل فيرموير الماسح من صفحة الدعم
   بتاعته على موقع Zebra وحمّل الملف في 123Scan.
3. ابدأ التحديث و**سيب الماسح متركّب لحد ما 123Scan يقول إنه خلص**. بياخد كذا دقيقة؛ والماسح بيعمل
   ريستارت في الآخر. لو شلته في النص ممكن يبوظ ومايشتغلش.
4. اتأكد إن 123Scan بقى بيعرض نسخة الفيرموير الجديدة.

التحديث ممكن يرجّع شوية إعدادات للافتراضي بتاعها، وعلشان كده بنظبط الماسح في الخطوتين الجايين، بعد
الفيرموير.

## 6. ظبط وضع USB لماسح Zebra

دي أكتر خطوة الناس بتنساها. **ماسح Zebra وهو طالع من الكرتونة بيبقى كيبورد USB** (وضع USB HID
Keyboard): بـ"يكتب" كل باركود في أي حتة عليها الفوكس. وفي الوضع ده *توصيل الماسح* في GAIA Desktop
مايقدرش يلاقيه، وأي حاجة بتتكتب في خانة نص بتضيع منها فواصل FNC1، وده بيغيّر معنى سلسلة عناصر GS1.

حوّل الماسح لوضع مشغّل Zebra بيكلّمه على طول:

| وضع USB للماسح | اسم الجهاز في GAIA Desktop | ملاحظات |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld`، أو `ZebraAllScanners` | ده اللي ننصح بيه |
| SNAPI (بالتصوير أو من غيره) | `ZebraScannerSNAPI`، أو `ZebraAllScanners` | بروتوكول USB بتاع Zebra نفسها؛ شغال برضه |
| IBM Table-top USB | `ZebraUSBTableTop`، أو `ZebraAllScanners` | معمول للماسحات اللي على الترابيزة |
| USB OPOS (Hand-held) | `ZebraUSBOPOS`، أو `ZebraAllScanners` | |
| USB HID Keyboard (إعداد المصنع) | — | **مش هيتوصل** |

`ZebraAllScanners`، اسم الجهاز الافتراضي في GAIA Desktop، بيقبل الماسح في أي وضع من الأوضاع المدعومة،
فأول ما تظبط الوضع، الافتراضي غالبًا بيشتغل على طول.

علشان تغيّر الوضع، يا إما:

- **امسح باركود الإعداد** بتاع الوضع — *IBM Hand-held USB* مثلًا — من الـ Quick Reference Guide أو الـ
  Product Reference Guide بتاع الماسح (جزء USB Host Types / USB Device Type)؛ والماسح بيصفّر يأكّد.
  يا إما
- **استخدم 123Scan** ([الخطوة 4](#4-سطّب-123scan)): وصّل الماسح، وافتح إعداداته، وظبط نوع الـ USB host.

بعد ما تغيّر الوضع، Windows بيتعرّف على الماسح تاني كأنه جهاز من نوع تاني؛ استنى كام ثانية قبل ما
توصّل.

ولو عايز ترجّع الماسح لوضع الكيبورد بعدين — علشان تستخدمه مع برامج تانية — امسح باركود الإعداد
*USB Keyboard (HID)*، أو رجّع إعدادات المصنع.

## 7. ظبط ماسح Zebra علشان GS1

GAIA Desktop بيحلل أحسن لما الماسح يقوله قرا أنهي نوع باركود.

### ابعت الـ AIM Code ID

خلّي **Transmit Code ID Character** على **AIM Code ID Character**، بباركود الإعداد اللي في الـ Product
Reference Guide (جزء User Preferences) أو من 123Scan. ساعتها كل مسحة بتبدأ بمعرّف الترميز بتاعها —
`]C1` لـ GS1-128، و`]d2` لـ GS1 DataMatrix، و`]Q3` لـ GS1 QR Code، و`]e0` لـ GS1 DataBar — واللي
GAIA Desktop بيستخدمه يسمّي ناقل البيانات ويطبّق القواعد بتاعته.

من غيره GAIA Desktop برضه بيحلل سلسلة العناصر وبياخد نوع الترميز من المسحة نفسها، بس التقرير مش هيلاقي
AIM Code ID يعرضه، وهيبقى أصعب تفرّق باركود عادي زي EAN-13 عن سلسلة عناصر GS1.

### راجع أنواع الباركود

اتأكد إن أنواع الباركود اللي بتشتغل بيها **مفعّلة**: عادةً GS1-128 وGS1 DataMatrix وGS1 DataBar
وGS1 QR Code وEAN/UPC. أغلبها شغال من الأول في ماسحات Zebra ثنائية الأبعاد؛ و123Scan بيعرض الإعدادات
الحالية، والـ Product Reference Guide فيه باركود يفعّل كل واحد منهم.

### سيب مميزات تحليل GS1 بتاعة Zebra مقفولة

الفيرموير الجديد زوّد مميزات GS1 بتشتغل على الماسح نفسه — **Label Parse+** و**GS1 Digital Link**
و**GS1 Retail POS parsing**. سيبهم **مقفولين**، زي ما الماسح بييجي: دول بيغيّروا شكل اللي الماسح بيبعته
أو بيختصروه، وGAIA Desktop محتاج البيانات الخام علشان يحللها ويتأكد منها. شوف
[ماسحات Zebra ثنائية الأبعاد المدعومة](#12-ماسحات-zebra-ثنائية-الأبعاد-المدعومة) علشان تعرف كل واحدة
بتعمل إيه.

### من غير بادئات ولا لواحق

ماتزوّدش بادئة أو لاحقة أو زرار Enter على اللي الماسح بيطلّعه. GAIA Desktop بيستلم كل مسحة رسالة كاملة
عن طريق JavaPOS ومش محتاج أي حاجة من دول؛ والحروف الزيادة هتدخل في سلسلة العناصر.

## 8. سطّب GAIA Desktop وشغّله

1. فك ضغط `gaia-desktop-1.0.0-win.zip`، مثلًا في `C:\Tools\`. جواه فولدر واحد:

   ```
   gaia-desktop-1.0.0-win\
   ├── docs\
   │   └── GaiaDesktop-Zebra-Scanner-Windows.md      this guide
   ├── gaia-desktop.jar
   ├── lib\
   ├── readme.html                                   index of every guide
   └── run.bat
   ```

2. ركّب الماسح.
3. دوس دبل كليك على **`run.bat`**. هتفتح شاشة كونسول جنب البرنامج وتفضل مفتوحة: حالة الماسح وأخطاء
   JavaPOS بتظهر فيها.
4. اقرا أول سطر في الكونسول. بيقول `run.bat` لقى إيه:

   ```
   run.bat: Java 21.0.8 from JAVA_HOME; JavaFX from lib\; JavaPOS from lib\; Zebra services from C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   لو خلص بـ **`Zebra services from none (Zebra Scanner SDK not installed)`**، يبقى الـ SDK ملقاهوش في
   مكانه الافتراضي — سطّبه ([الخطوة 3](#3-سطّب-zebra-scanner-sdk)) أو ظبط [ZEBRA_HOME](#zebra_home).
   البرنامج هيفتح برضه، بس الماسح مش هيقدر يتوصل.

## 9. وصّل الماسح

1. في شريط الأدوات، **قايمة الأجهزة** فيها أسامي الماسحات اللي GAIA Desktop يعرفها. سيبها على
   **`ZebraAllScanners`**، أو اختار الاسم اللي يناسب وضع USB بتاع الماسح من الجدول في
   [الخطوة 6](#6-ظبط-وضع-usb-لماسح-zebra).
2. دوس **توصيل الماسح**، أو اضغط **Ctrl+K** (موجودة كمان في قايمة **الماسح**).
3. شريط الحالة هيتغيّر لـ **`الماسح: ZebraAllScanners`** (أو الاسم اللي اخترته)، وسطر الحالة هيقول
   *الماسح اتوصل — ZebraAllScanners*. والزرار هيبقى مكتوب عليه **فصل الماسح**.
4. امسح باركود GS1. هيظهر فوق خالص في سجل الالتقاطات والتقرير بتاعه هيفتح. ولو الـ AIM Code ID شغال،
   التقرير بيسمّي ناقل البيانات — *GS1-128*، *GS1 DataMatrix* — وسلسلة العناصر بتحتفظ بكل فاصل FNC1.

قايمة الأجهزة بتفتكر اختيارك من مرة للتانية. والماسح بيفضل متوصل لحد ما تفصله أو تقفل البرنامج.
والمسح شغال كمان في وضعي **إنشاء** و**دمج**: في الدمج كل مسحة بتبقى واحد من الباركودات اللي بتتدمج.

طول ما GAIA Desktop ماسك الماسح، البرامج التانية مش هتقدر تستخدمه، والعكس صحيح: اقفل 123Scan وأي
برنامج كاشير أو ماسحات تاني قبل ما توصّل.

## 10. مرجع الإعدادات

### أسامي الأجهزة

قايمة الأجهزة بتتملي من `jpos.xml` اللي جوه `gaia-desktop.jar`. ودي بنود الماسحات اللي فيه:

| اسم الجهاز | نوع الماسح | يتستخدم مع |
|---|---|---|
| `ZebraAllScanners` | أي نوع | **الافتراضي.** أي وضع USB مدعوم |
| `ZebraAllScanners114` | أي نوع | نسخة JavaPOS 1.14 من نفس الخدمة |
| `ZebraUSBHandHeld` | IBM Hand-held USB | ماسح في وضع IBM Hand-held USB |
| `ZebraUSBTableTop` | IBM Table-top USB | وضع Table-top |
| `ZebraUSBOPOS` | USB OPOS | وضع USB OPOS |
| `ZebraScannerSNAPI` | SNAPI | وضع SNAPI |
| `ZebraScannerUSB` | أي USB | أي وضع USB |
| `ZebraScannerSerialSSI` | سيريال SSI | ماسحات بكابل سيريال (مش USB) |
| `ZebraScannerSerialNIXMODB` | سيريال NIXMODB | ماسحات بكابل سيريال |
| `ZebraVDI` | VDI | ماسحات متحوّلة لديسكتوب افتراضي |

### ZEBRA_HOME

لو Zebra SDK متسطّب في حتة غير الافتراضية، ظبط `ZEBRA_HOME` على فولدر `JPOS` بتاعه قبل ما تشغّل
`run.bat` — مثلًا في ملف batch صغير جنبه:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

ساعتها `run.bat` بياخد ملفات jar بتاعة خدمات Zebra من `%ZEBRA_HOME%bin` ويزوّد الفولدر ده على `PATH`
علشان ملفات DLL بتاعة Zebra.

### ملف jpos.xml بتاعك

علشان تزوّد اسم جهاز أو تغيّر إعدادات بند، اعمل نسخة من `jpos.xml` وطلّعها من `gaia-desktop.jar` (هو
zip؛ أي برنامج فك ضغط يفتحه)، وعدّل النسخة، وخلّي GAIA Desktop يشاور عليها:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

ساعتها قايمة الأجهزة هتعرض الماسحات اللي في الملف ده. ولو فيه أكتر من ماسح Zebra متوصل، تقدر تربط بند
بواحد منهم عن طريق الخاصية `ScannerModel` أو `SerialNumber` بتاعته، زي ما في بند `ZebraAllScanners`.

### اختيارات تانية

| الإعداد | إزاي |
|---|---|
| لغة البرنامج | `run.bat --language=FR` (للمرة دي بس)، أو لوحة الخيارات |
| اختيارات Java زيادة | `set GAIA_DESKTOP_OPTS=…` قبل `run.bat` |
| Java جاية مع البرنامج | حط فولدر `jdk-21…` جنب `run.bat`؛ بيتستخدم قبل `JAVA_HOME` |

## 11. حل المشاكل

الأخطاء بتظهر في رسالة وانت بتوصّل، وفي شاشة الكونسول، وفي ملف السجل `logs\gaia-desktop.log`، في
الفولدر اللي `run.bat` اتشغّل منه (فولدر GAIA Desktop، لو دوست دبل كليك على `run.bat`). والرقم اللي
بين القوسين المربعين في السجل هو كود خطأ JavaPOS.

| انت شايف إيه | السبب المحتمل | تعمل إيه |
|---|---|---|
| مفيش زرار *توصيل الماسح* | البرنامج مش شغال على Windows | المسح على Windows بس |
| 123Scan مش لاقي الماسح | الكابل، أو منفذ USB، أو برنامج تاني ماسك الماسح | جرّب كابل أو منفذ تاني؛ اقفل GAIA Desktop وبرامج الماسحات التانية. GAIA Desktop مش هيشوف ماسح 123Scan مش شايفه |
| الكونسول: `Zebra services from none (Zebra Scanner SDK not installed)` | الـ SDK مش في مكانه الافتراضي | سطّب الـ SDK الـ 64 بت ([الخطوة 3](#3-سطّب-zebra-scanner-sdk))، أو ظبط [ZEBRA_HOME](#zebra_home) |
| خطأ **104**: *Could not connect to service with logicalName = …: …SymScannerSvc112Factory* | ملفات jar بتاعة خدمات Zebra مش موجودة | زي اللي فوق — بص على سطر `Zebra services from` في الكونسول |
| خطأ **109**: *Service does not exist in loaded JCL registry* | اسم الجهاز مش موجود في إعداد الماسح، أو `javaPOS114.jar` بتاع الـ SDK دخل في الـ class path | اختار اسم من قايمة الأجهزة؛ ماتزوّدش `javaPOS114.jar`؛ ولو بتستخدم `jpos.xml` بتاعك، اتأكد إن الاسم فيه |
| خطأ **107** (مفيش هاردوير)، أو التوصيل بيفشل والماسح متركّب | الماسح لسه في وضع كيبورد USB، أو مشغّل CoreScanner مش شغال | ظبط وضع USB ([الخطوة 6](#6-ظبط-وضع-usb-لماسح-zebra))؛ اعمل ريستارت لـ Windows بعد تسطيب الـ SDK؛ جرّب منفذ USB تاني |
| خطأ **112** (المهلة خلصت) أو **102** (محجوز) وانت بتوصّل | برنامج تاني ماسك الماسح | اقفل 123Scan وأي برنامج ماسحات أو كاشير تاني، ووصّل تاني |
| `UnsatisfiedLinkError` … `CSJPOSScanner64` في الكونسول | ملفات DLL بتاعة Zebra مش راضية تتحمّل — غالبًا SDK 32 بت مع Java 64 بت | سطّب الـ SDK الـ 64 بت؛ واتأكد إن `java -version` بيقول VM 64 بت |
| المسحات بتتكتب في شريط الإدخال بدل ما توصل التقاطات | الماسح في وضع كيبورد USB | ظبط وضع USB ([الخطوة 6](#6-ظبط-وضع-usb-لماسح-zebra)) |
| متوصل، بس المسحات مش واصلة | اسم جهاز غلط لوضع الماسح، أو الماسح اتشال واترّكب وهو متوصل | افصل، واختار `ZebraAllScanners`، ووصّل تاني |
| التقرير مش بيعرض AIM Code ID / ناقل البيانات | إرسال الـ AIM Code ID مقفول | شغّل *Transmit Code ID Character → AIM Code ID* ([الخطوة 7](#7-ظبط-ماسح-zebra-علشان-gs1)) |
| سلسلة عناصر ناقصها الفواصل، أو الـ AI لازقة في بعض | اتمسحت في وضع الكيبورد، أو اتكتبت بالإيد من غير `{GS}` | استخدم وضع USB بتاع JavaPOS؛ ولما تكتب، حط الفواصل بزرار `{GS}` |
| نوع باركود عمره ما بيتقري | الترميز ده مقفول على الماسح | فعّله ([الخطوة 7](#7-ظبط-ماسح-zebra-علشان-gs1)) |

لو المشكلة فضلت، احتفظ بسطر `run.bat:` من الكونسول ونص رسالة الخطأ و`logs\gaia-desktop.log` مع بعض:
مع بعض بيوضّحوا أنهي Java وأنهي خدمات Zebra وأنهي اسم جهاز اتستخدموا، والتوصيل فشل فين بالظبط.

## 12. ماسحات Zebra ثنائية الأبعاد المدعومة

GAIA Desktop محتاج ماسح يقدر يقرا الباركودات اللي بيتطبع بيها بيانات GS1 — GS1-128 وGS1 DataBar
وEAN/UPC، ولأغلب الاستخدامات الأكواد ثنائية الأبعاد: **GS1 DataMatrix** و**GS1 QR Code**، وده كمان
الشكل اللي غالبًا بيتطبع بيه URI من نوع **GS1 Digital Link**. يعني محتاج **ماسح تصوير ثنائي الأبعاد**
من Zebra: الماسح الخطي (1D) مايقدرش يقرا أكواد DataMatrix أو QR خالص.

الماسح نفسه مش محتاج يفهم GS1 Application Identifiers أو Digital Link.
**GAIA Desktop بيحلل الاتنين**: بياخد المسحة زي ما الماسح قراها — بالـ AIM Code ID وفواصل FNC1 وكل
حاجة — ويقسّمها لـ AI، أو يحوّل URI الـ Digital Link لـ AI بتاعته، بنفسه.

### اتجرّب

| الماسح | النوع | الحالة |
|---|---|---|
| **DS8108** | ماسح تصوير ثنائي الأبعاد بسلك بيتمسك في الإيد | **اتعمل واتجرّب** مع GAIA Desktop |

### المفروض يشتغل

دي ماسحات تصوير ثنائية الأبعاد من Zebra بتشتغل، زي DS8108، عن طريق Scanner SDK وخدمات JavaPOS بتاعة
Zebra. **ماتجرّبتش** مع GAIA Desktop؛ ظبط كل واحد زي الدليل ده، واستخدم الـ Quick Reference Guide أو
الـ Product Reference Guide بتاعه علشان باركودات الإعداد.

|---|---|
| DS81x8 | DS8108 (بسلك)، DS8178 (لاسلكي) |

| DS36x8 | DS3608 (بسلك)، DS3678 (لاسلكي) — تقيلة ومتينة، ومعاها نسخ KD وXR |

الماسح اللاسلكي بيكلّم القاعدة بتاعته، والقاعدة هي اللي بتتركّب في الكمبيوتر: وصّل القاعدة بـ USB
واعتبر الاتنين ماسح واحد. وماسحات من عيلات Zebra التانية ممكن تشتغل برضه، لو Scanner SDK بتاع Zebra

### مميزات GS1 اللي على ماسح Zebra نفسه

بعيد عن قراية الباركود، فيه ماسحات تصوير ثنائية الأبعاد من Zebra تقدر تعالج بيانات GS1 على الماسح نفسه،
وبتتظبط من 123Scan:

| الميزة | بتعمل إيه | بالنسبة لـ GAIA Desktop |
|---|---|---|
| **Label Parse+** | بتحلل الـ AI بتاعة ملصق GS1 على الماسح وتبعت حقول متغيّر شكلها | **سيبها مقفولة** — GAIA Desktop مش هيشوف تاني الـ AI ولا فواصل FNC1 ولا الـ AIM Code ID |
| **GS1 Digital Link** | لمنتجات التجزئة اللي عليها EAN/UPC أحادي البعد وكود Digital Link ثنائي الأبعاد مع بعض: بتختار تبعت أنهي واحد | **سيبها مقفولة** (الافتراضي) |
| **GS1 Retail POS parsing** | بتقرا باركودات التجزئة ثنائية الأبعاد بصيغة URI الـ Digital Link أو صيغة سلسلة العناصر | **سيبها مقفولة** |

إعداد **GS1 Digital Link** ليه تلات أوضاع. **Mode 1 — GTIN only**، الوضع اللي بيبدأ بيه أول ما تفعّله،
بيبعت الـ GTIN بس، من أي باركود كان، فالتشغيلة أو تاريخ الانتهاء أو الرقم التسلسلي اللي في الـ Digital
Link عمرهم ما هيوصلوا لـ GAIA Desktop. **Mode 2 — Prioritize 2D** بيبعت الكود ثنائي الأبعاد لو شافه جوه
مهلة الأولوية (200 مللي ثانية افتراضيًا)، وإلا بيبعت الأحادي. **Mode 3 — Corroborate 1D and 2D GTINs
Match** بيبعت الأحادي، والثنائي كمان لو الـ GTIN بتاعه مطابق. ولو لازم الإعداد يفضل شغال علشان برنامج
تاني، استخدم Mode 2 مش Mode 1. وفي DS8108 دي البارامترات 2373 (تشغيل/قفل) و2374 (الوضع) و2491 (المهلة).

علشان تستخدم المميزات دي محتاج **123Scan نسخة 6 أو أحدث** وفيرموير فيه المميزات دي. Zebra بتزوّد دعم
GS1 Digital Link بتحديثات فيرموير من أبريل 2025؛ والتواريخ اللي تحت جاية من موزّع Zebra، فراجع ملاحظات
إصدار الفيرموير لكل موديل:

| عيلة الموديل | نزول فيرموير GS1 Digital Link |
|---|---|
| DS81x8 | 16 أبريل 2025 |
| MP7000 | 21 أبريل 2025 |
| DS9908 | 6 يونيو 2025 |
| SP72 / SM72 | 11 يوليو 2025 |
| DS46x8 | 28 يوليو 2025 |
| MP7200 (Rev-C)، DS5502 | 30 يوليو 2025 |
| DS9308 | 29 أغسطس 2025 |
| DS22x8، DS1000 | 5 سبتمبر 2025 (آسيا والمحيط الهادئ بس) |
