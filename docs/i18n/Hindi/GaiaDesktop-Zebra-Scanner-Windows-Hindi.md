# Zebra स्कैनर सेटअप — Windows के लिए GAIA Desktop

Zebra बारकोड स्कैनर को इंस्टॉल और कॉन्फ़िगर करने का तरीका, ताकि GAIA Desktop उससे सीधे GS1
बारकोड पढ़ सके: हर स्कैन का विश्लेषण होकर वह इतिहास में जुड़ जाता है, और AIM Code ID उपसर्ग
तथा हर FNC1 विभाजक जस का तस रहता है। मूल दस्तावेज़:
[GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md)।

GAIA Desktop को USB से जुड़े **Zebra DS8108** हैंडहेल्ड इमेजर के साथ बनाया और परखा गया है। ये
चरण किसी भी ऐसे Zebra 2D स्कैनर पर लागू होते हैं जिसे Zebra का Scanner SDK समर्थित करता है; किसी
विशेष मॉडल के सेटअप बारकोड और मेनू नाम उसकी अपनी Quick Reference Guide या Product Reference
Guide में मिलते हैं।

> **केवल Windows।** Zebra के स्कैनर ड्राइवर केवल Windows के लिए हैं, इसलिए macOS या Linux पर
> GAIA Desktop कोई स्कैनर नियंत्रण नहीं बनाता। ऐप की बाकी हर चीज़ हर प्लेटफ़ॉर्म पर चलती है।

## 1. आपको क्या चाहिए

| | |
|---|---|
| **स्कैनर** | एक Zebra 2D स्कैनर, उसकी USB केबल के साथ — देखें [समर्थित Zebra 2D स्कैनर](#12-समर्थित-zebra-2d-स्कैनर) |
| **कंप्यूटर** | Windows 10 या 11, 64-बिट |
| **Java** | Java 21 या नया, **64-बिट** |
| **Zebra Scanner SDK for Windows** | **64-बिट**, Zebra की सहायता साइट से — यह ड्राइवर और वे JavaPOS सेवाएँ देता है जिनका GAIA Desktop उपयोग करता है |
| **Zebra 123Scan** | Zebra की मुफ़्त कॉन्फ़िगरेशन यूटिलिटी, Zebra की सहायता साइट से — स्कैनर का फ़र्मवेयर अपडेट करने और उसकी सेटिंग जाँचने के लिए |
| **GAIA Desktop** | `gaia-desktop-1.0.0-win.zip` |
| **वैकल्पिक** | स्कैनर की **Product Reference Guide** (PRG), जिसमें सेटअप बारकोड होते हैं |

हिस्से आपस में कैसे जुड़ते हैं:

```
Zebra scanner ──USB──► Zebra CoreScanner driver ──► Zebra JavaPOS services ──► GAIA Desktop
                       (installed by the SDK)        (in the SDK's JPOS\bin)    (run.bat puts them on
                                                                                 the class path)
```

GAIA Desktop JavaPOS API और स्कैनर का नाम बताने वाला कॉन्फ़िगरेशन (`jpos.xml`, `gaia-desktop.jar`
के अंदर) ख़ुद साथ लाता है। बाकी Zebra SDK देता है: स्कैनर से बात करने वाला ड्राइवर, और Zebra की वे
सेवा क्लासें जो JavaPOS और उस ड्राइवर के बीच बैठती हैं।

## 2. Java इंस्टॉल करें

GAIA Desktop को **Java 21 या नया** चाहिए, और वह **64-बिट** बिल्ड होना चाहिए, ताकि 64-बिट Zebra
ड्राइवरों से मेल खाए।

1. Windows x64 के लिए Java 21 JDK या JRE इंस्टॉल करें — उदाहरण के लिए adoptium.net से
   Eclipse Temurin। इंस्टॉलर `JAVA_HOME` सेट करने की पेशकश करे तो उसे करने दें।
2. Command Prompt में इसे जाँचें:

   ```
   java -version
   ```

   पहली पंक्ति में संस्करण 21 या बाद का दिखना चाहिए; 64-बिट Java `64-Bit Server VM` भी छापता है।

`run.bat` Java को इस क्रम में ढूँढता है: `run.bat` के पास रखा `jdk*` फ़ोल्डर, फिर `JAVA_HOME`,
फिर `PATH` पर `java`। 21 से पुराना कुछ भी हो तो वह संदेश देकर उसे अस्वीकार कर देता है।

## 3. Zebra Scanner SDK इंस्टॉल करें

1. Zebra की सहायता साइट से **Zebra Scanner SDK for Windows (64-bit)** डाउनलोड करें।
2. इंस्टॉलर चलाएँ। अगर वह घटक चुनने का विकल्प दे, तो पक्का करें कि **JPOS** (JavaPOS) घटक
   शामिल है।
3. डिफ़ॉल्ट इंस्टॉल स्थान ही रहने दें। GAIA Desktop SDK का JavaPOS हिस्सा यहाँ ढूँढता है:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   और Zebra की सेवा jar फ़ाइलें (`JposServiceScanner.jar`, `JposServiceJniScanner.jar`, …)
   तथा नेटिव लाइब्रेरी (`CSJPOSScanner64.dll`, …) उसके `bin\` फ़ोल्डर में होने की अपेक्षा करता है।
   अगर SDK कहीं और इंस्टॉल है, तो [ZEBRA_HOME](#zebra_home) देखें।
4. इंस्टॉल करने के बाद **Windows को रीस्टार्ट करें**। SDK का CoreScanner ड्राइवर बैकग्राउंड में
   चलता है और GAIA Desktop के स्कैनर तक पहुँचने से पहले उसका चलना ज़रूरी है; रीस्टार्ट इसे पक्का
   करने का सबसे आसान तरीका है।

## 4. 123Scan इंस्टॉल करें

123Scan, Zebra की अपने स्कैनरों को कॉन्फ़िगर करने वाली मुफ़्त यूटिलिटी है। अगले चरण में इससे
स्कैनर का फ़र्मवेयर अपडेट किया जाता है, और बाद में स्कैनर की सेटिंग जाँचने और बदलने का यही सबसे
आसान तरीका है।

1. Zebra की सहायता साइट से **123Scan** डाउनलोड करें और इंस्टॉलर चलाएँ।
2. Zebra स्कैनर लगाएँ और 123Scan शुरू करें। उसे स्कैनर मिल जाना चाहिए और उसका मॉडल, सीरियल नंबर
   और वर्तमान फ़र्मवेयर संस्करण दिखना चाहिए। अगर ऐसा न हो, तो आगे बढ़ने से पहले कोई दूसरा USB पोर्ट
   या केबल आज़माएँ — जो स्कैनर 123Scan को नहीं दिखता, वह GAIA Desktop को भी नहीं दिखेगा।

## 5. Zebra स्कैनर का फ़र्मवेयर अपडेट करें

स्कैनर को कॉन्फ़िगर करने से पहले उसका फ़र्मवेयर नवीनतम संस्करण पर ले आएँ। फ़र्मवेयर अपडेट डिकोडिंग
की समस्याएँ ठीक करते हैं और स्कैनर को SDK द्वारा इंस्टॉल किए गए Zebra ड्राइवर के साथ तालमेल में
रखते हैं।

1. **GAIA Desktop** और कोई भी दूसरा प्रोग्राम जो स्कैनर का उपयोग कर रहा हो, बंद करें: अपडेट के
   दौरान 123Scan को स्कैनर पूरी तरह अपने पास चाहिए।
2. स्कैनर जुड़ा रहते हुए 123Scan में उसका फ़र्मवेयर अपडेट विकल्प चुनें। 123Scan स्कैनर के फ़र्मवेयर
   की तुलना Zebra द्वारा प्रकाशित नवीनतम फ़र्मवेयर से करता है और उसे डाउनलोड करके इंस्टॉल करने की
   पेशकश करता है। अगर कंप्यूटर पर इंटरनेट नहीं है, तो Zebra की साइट पर स्कैनर के सहायता पेज से
   उसका फ़र्मवेयर डाउनलोड करें और फ़ाइल को 123Scan में लोड करें।
3. अपडेट शुरू करें और **जब तक 123Scan यह न बताए कि अपडेट पूरा हो गया, स्कैनर लगा रहने दें**।
   इसमें कई मिनट लगते हैं; अंत में स्कैनर रीस्टार्ट होता है। बीच में निकालने से वह बेकार हो सकता है।
4. जाँचें कि 123Scan अब नया फ़र्मवेयर संस्करण दिखाता है।

अपडेट कुछ सेटिंग को उनके डिफ़ॉल्ट पर लौटा सकता है, इसीलिए स्कैनर को अगले दो चरणों में, फ़र्मवेयर
के बाद, कॉन्फ़िगर किया जाता है।

## 6. Zebra स्कैनर का USB मोड सेट करें

यही चरण सबसे ज़्यादा छूटता है। **बॉक्स से निकला Zebra स्कैनर एक USB कीबोर्ड होता है** (USB HID
Keyboard मोड): वह हर बारकोड को वहाँ "टाइप" कर देता है जहाँ फ़ोकस हो। उस मोड में GAIA Desktop का
*स्कैनर जोड़ें* उसे ढूँढ नहीं पाता, और टेक्स्ट फ़ील्ड में टाइप हुई हर चीज़ अपने FNC1 विभाजक खो देती
है, जिससे GS1 तत्व स्ट्रिंग का अर्थ बदल जाता है।

स्कैनर को ऐसे मोड में बदलें जिससे Zebra ड्राइवर सीधे बात करता है:

| स्कैनर का USB मोड | GAIA Desktop में डिवाइस नाम | टिप्पणी |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld`, या `ZebraAllScanners` | अनुशंसित |
| SNAPI (इमेजिंग के साथ या बिना) | `ZebraScannerSNAPI`, या `ZebraAllScanners` | Zebra का अपना USB प्रोटोकॉल; यह भी चलता है |
| IBM Table-top USB | `ZebraUSBTableTop`, या `ZebraAllScanners` | टेबल-टॉप स्कैनरों के लिए |
| USB OPOS (Hand-held) | `ZebraUSBOPOS`, या `ZebraAllScanners` | |
| USB HID Keyboard (फ़ैक्टरी डिफ़ॉल्ट) | — | **नहीं जुड़ेगा** |

`ZebraAllScanners`, GAIA Desktop का डिफ़ॉल्ट डिवाइस नाम, किसी भी समर्थित मोड में स्कैनर स्वीकार
करता है, इसलिए मोड सेट होते ही डिफ़ॉल्ट आमतौर पर अपने आप काम कर जाता है।

मोड बदलने के लिए, या तो:

- स्कैनर की Quick Reference Guide या Product Reference Guide (USB Host Types / USB Device Type
  खंड) में उस मोड का — जैसे *IBM Hand-held USB* — **सेटअप बारकोड स्कैन करें**; स्कैनर बीप करके
  पुष्टि करता है। या
- **123Scan का उपयोग करें** ([चरण 4](#4-123scan-इंस्टॉल-करें)): स्कैनर जोड़ें, उसका कॉन्फ़िगरेशन
  खोलें, और USB होस्ट प्रकार सेट करें।

मोड बदलने के बाद Windows स्कैनर को एक अलग प्रकार के डिवाइस के रूप में फिर से पहचानता है; जोड़ने से
पहले कुछ सेकंड रुकें।

बाद में स्कैनर को कीबोर्ड मोड में लौटाने के लिए — दूसरे सॉफ़्टवेयर के साथ उपयोग हेतु — *USB
Keyboard (HID)* सेटअप बारकोड स्कैन करें, या उसकी फ़ैक्टरी डिफ़ॉल्ट सेटिंग बहाल करें।

## 7. GS1 के लिए Zebra स्कैनर कॉन्फ़िगर करें

GAIA Desktop सबसे अच्छा विश्लेषण तब करता है जब स्कैनर बताए कि उसने किस प्रकार का बारकोड पढ़ा।

### AIM Code ID भेजें

Product Reference Guide (User Preferences) के सेटअप बारकोड से या 123Scan में **Transmit Code ID
Character** को **AIM Code ID Character** पर सेट करें। तब हर स्कैन अपने सिम्बॉलॉजी पहचानकर्ता से
शुरू होता है — GS1-128 के लिए `]C1`, GS1 DataMatrix के लिए `]d2`, GS1 QR Code के लिए `]Q3`,
GS1 DataBar के लिए `]e0` — जिसका उपयोग GAIA Desktop डेटा वाहक का नाम बताने और उस पर लागू नियम
लगाने के लिए करता है।

इसके बिना भी GAIA Desktop तत्व स्ट्रिंग का विश्लेषण करता है और सिम्बॉलॉजी स्कैन से ही लेता है,
लेकिन रिपोर्ट के पास दिखाने को कोई AIM Code ID नहीं होता, और EAN-13 जैसे साधारण बारकोड को GS1
तत्व स्ट्रिंग से अलग पहचानना कठिन हो जाता है।

### सिम्बॉलॉजी जाँचें

पक्का करें कि जिन बारकोड प्रकारों के साथ आप काम करते हैं वे **सक्षम** हैं: आमतौर पर GS1-128,
GS1 DataMatrix, GS1 DataBar, GS1 QR Code और EAN/UPC। Zebra के 2D स्कैनरों पर इनमें से ज़्यादातर
डिफ़ॉल्ट रूप से चालू होते हैं; 123Scan वर्तमान सेटिंग दिखाता है, और Product Reference Guide में हर
एक को सक्षम करने का बारकोड होता है।

### Zebra की GS1 विश्लेषण सुविधाएँ बंद रखें

नए फ़र्मवेयर में ऐसी GS1 सुविधाएँ जुड़ी हैं जो स्कैनर पर ही काम करती हैं — **Label Parse+**,
**GS1 Digital Link** और **GS1 Retail POS parsing**। इन्हें **बंद** रखें, जैसे स्कैनर आता है: ये
स्कैनर के भेजे डेटा का स्वरूप बदल देती हैं या उसे छोटा कर देती हैं, जबकि GAIA Desktop को विश्लेषण
और सत्यापन के लिए कच्चा डेटा चाहिए। हर सुविधा क्या करती है, यह
[समर्थित Zebra 2D स्कैनर](#12-समर्थित-zebra-2d-स्कैनर) में देखें।

### उपसर्ग और प्रत्यय बंद रखें

स्कैनर के आउटपुट में कोई उपसर्ग, प्रत्यय या Enter कुंजी न जोड़ें। GAIA Desktop हर स्कैन को JavaPOS
के ज़रिए एक पूरे संदेश के रूप में पाता है और उसे इनमें से किसी की ज़रूरत नहीं; अतिरिक्त वर्ण तत्व
स्ट्रिंग में जा पहुँचेंगे।

## 8. GAIA Desktop इंस्टॉल करें और शुरू करें

1. `gaia-desktop-1.0.0-win.zip` को अनज़िप करें, उदाहरण के लिए `C:\Tools\` में। इसमें एक फ़ोल्डर
   होता है:

   ```
   gaia-desktop-1.0.0-win\
   ├── docs\
   │   └── GaiaDesktop-Zebra-Scanner-Windows.md      this guide
   ├── gaia-desktop.jar
   ├── lib\
   ├── readme.html                                   index of every guide
   └── run.bat
   ```

2. स्कैनर लगाएँ।
3. **`run.bat`** पर डबल-क्लिक करें। ऐप के पास एक कंसोल विंडो खुलती है और खुली रहती है: स्कैनर की
   स्थिति और JavaPOS त्रुटियाँ वहीं दिखती हैं।
4. कंसोल की पहली पंक्ति पढ़ें। उसमें लिखा होता है कि `run.bat` को क्या मिला:

   ```
   run.bat: Java 21.0.8 from JAVA_HOME; JavaFX from lib\; JavaPOS from lib\; Zebra services from C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   अगर वह **`Zebra services from none (Zebra Scanner SDK not installed)`** पर ख़त्म हो, तो SDK अपने
   डिफ़ॉल्ट स्थान पर नहीं मिला — उसे इंस्टॉल करें ([चरण 3](#3-zebra-scanner-sdk-इंस्टॉल-करें)) या
   [ZEBRA_HOME](#zebra_home) सेट करें। ऐप फिर भी शुरू होता है, लेकिन स्कैनर नहीं जुड़ सकता।

## 9. स्कैनर जोड़ें

1. टूलबार में **डिवाइस चयनकर्ता** उन स्कैनर नामों की सूची दिखाता है जिन्हें GAIA Desktop जानता है।
   उसे **`ZebraAllScanners`** पर रहने दें, या [चरण 6](#6-zebra-स्कैनर-का-usb-मोड-सेट-करें) की तालिका
   से स्कैनर के USB मोड का नाम चुनें।
2. **स्कैनर जोड़ें** पर क्लिक करें, या **Ctrl+K** दबाएँ (यह **स्कैनर** मेनू में भी है)।
3. स्टेटस बार बदलकर **`स्कैनर: ZebraAllScanners`** (या आपका चुना नाम) हो जाता है, और स्थिति पंक्ति
   *स्कैनर जुड़ा — ZebraAllScanners* बताती है। बटन पर अब **स्कैनर हटाएँ** लिखा होता है।
4. कोई GS1 बारकोड स्कैन करें। वह कैप्चर इतिहास में सबसे ऊपर दिखता है और उसकी रिपोर्ट खुल जाती है।
   AIM Code ID चालू होने पर रिपोर्ट डेटा वाहक का नाम बताती है — *GS1-128*, *GS1 DataMatrix* — और
   तत्व स्ट्रिंग हर FNC1 विभाजक बनाए रखती है।

डिवाइस चयनकर्ता हर बार चलाने के बीच आपकी पसंद याद रखता है। स्कैनर तब तक जुड़ा रहता है जब तक आप
उसे हटा न दें या ऐप बंद न कर दें। स्कैन **निर्माण** और **संयोजन** मोड में भी काम करते हैं: संयोजन
में हर स्कैन जोड़े जा रहे बारकोडों में से एक बन जाता है।

जब तक GAIA Desktop स्कैनर को थामे रहता है, दूसरे प्रोग्राम उसका उपयोग नहीं कर सकते, और उलटा भी:
जोड़ने से पहले 123Scan और कोई भी दूसरा पॉइंट-ऑफ़-सेल या स्कैनर सॉफ़्टवेयर बंद करें।

## 10. कॉन्फ़िगरेशन संदर्भ

### डिवाइस नाम

डिवाइस चयनकर्ता `gaia-desktop.jar` में शामिल `jpos.xml` से भरा जाता है। उसकी स्कैनर प्रविष्टियाँ:

| डिवाइस नाम | स्कैनर प्रकार | किसके साथ उपयोग करें |
|---|---|---|
| `ZebraAllScanners` | कोई भी | **डिफ़ॉल्ट।** कोई भी समर्थित USB मोड |
| `ZebraAllScanners114` | कोई भी | उसी सेवा का JavaPOS 1.14 संस्करण |
| `ZebraUSBHandHeld` | IBM Hand-held USB | IBM Hand-held USB मोड में स्कैनर |
| `ZebraUSBTableTop` | IBM Table-top USB | टेबल-टॉप मोड |
| `ZebraUSBOPOS` | USB OPOS | USB OPOS मोड |
| `ZebraScannerSNAPI` | SNAPI | SNAPI मोड |
| `ZebraScannerUSB` | कोई भी USB | कोई भी USB मोड |
| `ZebraScannerSerialSSI` | सीरियल SSI | सीरियल केबल वाले स्कैनर (USB नहीं) |
| `ZebraScannerSerialNIXMODB` | सीरियल NIXMODB | सीरियल केबल वाले स्कैनर |
| `ZebraVDI` | VDI | वर्चुअल डेस्कटॉप तक पहुँचाए गए स्कैनर |

### ZEBRA_HOME

अगर Zebra SDK डिफ़ॉल्ट के अलावा कहीं और इंस्टॉल है, तो `run.bat` शुरू करने से पहले `ZEBRA_HOME` को
उसके `JPOS` फ़ोल्डर पर सेट करें — उदाहरण के लिए उसके पास रखी एक छोटी बैच फ़ाइल में:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

तब `run.bat` Zebra की सेवा jar फ़ाइलें `%ZEBRA_HOME%bin` से लेता है और Zebra DLL के लिए उस फ़ोल्डर
को `PATH` में जोड़ता है।

### आपका अपना jpos.xml

कोई डिवाइस नाम जोड़ने या किसी प्रविष्टि की सेटिंग बदलने के लिए, `gaia-desktop.jar` से `jpos.xml`
की कॉपी निकालें (यह एक zip है; कोई भी अनज़िप टूल इसे खोल लेता है), कॉपी संपादित करें, और GAIA
Desktop को उसकी ओर इंगित करें:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

तब डिवाइस चयनकर्ता उस फ़ाइल के स्कैनर दिखाता है। एक से अधिक Zebra स्कैनर जुड़े हों, तो किसी
प्रविष्टि को उसकी `ScannerModel` या `SerialNumber` प्रॉपर्टी से उनमें से एक के साथ बाँधा जा सकता
है, जैसा `ZebraAllScanners` प्रविष्टि में है।

### अन्य विकल्प

| सेटिंग | कैसे |
|---|---|
| ऐप की भाषा | `run.bat --language=FR` (केवल इस बार के लिए), या विकल्प पैनल |
| अतिरिक्त Java विकल्प | `run.bat` से पहले `set GAIA_DESKTOP_OPTS=…` |
| साथ रखा Java | `run.bat` के पास `jdk-21…` फ़ोल्डर रखें; उसे `JAVA_HOME` से पहले उपयोग किया जाता है |

## 11. समस्या निवारण

त्रुटियाँ जोड़ते समय एक डायलॉग में, कंसोल विंडो में, और लॉग फ़ाइल `logs\gaia-desktop.log` में
दिखती हैं, जो उस फ़ोल्डर में होती है जहाँ से `run.bat` शुरू किया गया (`run.bat` पर डबल-क्लिक करने
पर यह GAIA Desktop फ़ोल्डर होता है)। लॉग में वर्गाकार कोष्ठकों के बीच की संख्या JavaPOS त्रुटि
कोड है।

| आपको क्या दिखता है | संभावित कारण | क्या करें |
|---|---|---|
| कोई *स्कैनर जोड़ें* बटन नहीं है | Windows पर नहीं चल रहा | स्कैनिंग केवल Windows पर है |
| 123Scan को स्कैनर नहीं मिलता | केबल, USB पोर्ट, या स्कैनर किसी दूसरे प्रोग्राम ने थाम रखा है | दूसरी केबल या पोर्ट आज़माएँ; GAIA Desktop और दूसरा स्कैनर सॉफ़्टवेयर बंद करें। जो स्कैनर 123Scan को नहीं दिखता, वह GAIA Desktop को भी नहीं दिखेगा |
| कंसोल: `Zebra services from none (Zebra Scanner SDK not installed)` | SDK अपने डिफ़ॉल्ट स्थान पर नहीं है | 64-बिट SDK इंस्टॉल करें ([चरण 3](#3-zebra-scanner-sdk-इंस्टॉल-करें)), या [ZEBRA_HOME](#zebra_home) सेट करें |
| त्रुटि **104**: *Could not connect to service with logicalName = …: …SymScannerSvc112Factory* | Zebra की सेवा jar फ़ाइलें नहीं मिलीं | ऊपर की तरह — कंसोल की `Zebra services from` पंक्ति जाँचें |
| त्रुटि **109**: *Service does not exist in loaded JCL registry* | डिवाइस नाम स्कैनर कॉन्फ़िगरेशन में नहीं है, या SDK की `javaPOS114.jar` class path में आ गई | डिवाइस चयनकर्ता से कोई नाम चुनें; `javaPOS114.jar` न जोड़ें; अपना `jpos.xml` उपयोग करते हों, तो जाँचें कि नाम उसमें है |
| त्रुटि **107** (हार्डवेयर नहीं), या स्कैनर लगा होने पर भी जोड़ना विफल | स्कैनर अब भी USB कीबोर्ड मोड में है, या CoreScanner ड्राइवर नहीं चल रहा | USB मोड सेट करें ([चरण 6](#6-zebra-स्कैनर-का-usb-मोड-सेट-करें)); SDK इंस्टॉल करने के बाद Windows रीस्टार्ट करें; दूसरा USB पोर्ट आज़माएँ |
| जोड़ते समय त्रुटि **112** (टाइमआउट) या **102** (कब्ज़े में) | कोई दूसरा प्रोग्राम स्कैनर थामे है | 123Scan और कोई भी दूसरा स्कैनर या पॉइंट-ऑफ़-सेल सॉफ़्टवेयर बंद करें, फिर दोबारा जोड़ें |
| कंसोल में `UnsatisfiedLinkError` … `CSJPOSScanner64` | Zebra DLL लोड नहीं हो पाते — अक्सर 64-बिट Java के साथ 32-बिट SDK | 64-बिट SDK इंस्टॉल करें; जाँचें कि `java -version` 64-बिट VM बताता है |
| स्कैन कैप्चर के रूप में आने के बजाय इनपुट बार में टाइप हो जाते हैं | स्कैनर USB कीबोर्ड मोड में है | USB मोड सेट करें ([चरण 6](#6-zebra-स्कैनर-का-usb-मोड-सेट-करें)) |
| जुड़ा है, पर स्कैन नहीं आते | स्कैनर के मोड के लिए गलत डिवाइस नाम, या जुड़े रहते स्कैनर दोबारा लगाया गया | हटाएँ, `ZebraAllScanners` चुनें, फिर से जोड़ें |
| रिपोर्ट में AIM Code ID / डेटा वाहक नहीं दिखता | AIM Code ID भेजना बंद है | *Transmit Code ID Character → AIM Code ID* चालू करें ([चरण 7](#7-gs1-के-लिए-zebra-स्कैनर-कॉन्फ़िगर-करें)) |
| तत्व स्ट्रिंग से विभाजक गायब हैं, या AI आपस में मिल गए हैं | कीबोर्ड मोड में स्कैन किया, या `{GS}` के बिना हाथ से टाइप किया | JavaPOS वाला USB मोड उपयोग करें; टाइप करते समय विभाजक `{GS}` बटन से डालें |
| कोई बारकोड प्रकार कभी नहीं पढ़ा जाता | वह सिम्बॉलॉजी स्कैनर पर अक्षम है | उसे सक्षम करें ([चरण 7](#7-gs1-के-लिए-zebra-स्कैनर-कॉन्फ़िगर-करें)) |

अगर समस्या बनी रहे, तो कंसोल की `run.bat:` पंक्ति, त्रुटि डायलॉग का पाठ और
`logs\gaia-desktop.log` एक साथ सँभालकर रखें: मिलकर ये दिखाते हैं कि कौन-सा Java, कौन-सी Zebra
सेवाएँ और कौन-सा डिवाइस नाम उपयोग हुआ, और जुड़ाव ठीक कहाँ विफल हुआ।

## 12. समर्थित Zebra 2D स्कैनर

GAIA Desktop को ऐसा स्कैनर चाहिए जो उन बारकोडों को पढ़ सके जिनमें GS1 डेटा छपता है — GS1-128,
GS1 DataBar, EAN/UPC, और ज़्यादातर उपयोगों के लिए 2D कोड: **GS1 DataMatrix** और **GS1 QR Code**,
जिसमें आमतौर पर **GS1 Digital Link** URI भी छपता है। इसका अर्थ है एक Zebra **2D इमेजर**: एक
रैखिक (1D) स्कैनर DataMatrix या QR कोड बिल्कुल नहीं पढ़ सकता।

स्कैनर को ख़ुद GS1 Application Identifiers या Digital Link समझने की ज़रूरत नहीं है।
**GAIA Desktop दोनों का विश्लेषण करता है**: वह स्कैन को वैसा ही लेता है जैसा स्कैनर ने पढ़ा — AIM
Code ID, FNC1 विभाजक, सब कुछ — और ख़ुद उसे AI में बाँटता है, या Digital Link URI को उसके AI में
बदलता है।

### परखा गया

| स्कैनर | प्रकार | स्थिति |
|---|---|---|
| **DS8108** | तार वाला हैंडहेल्ड 2D इमेजर | GAIA Desktop के साथ **बनाया और परखा गया** |

### चलने की अपेक्षा

ये Zebra 2D इमेजर हैं जो DS8108 की तरह Zebra के Scanner SDK और JavaPOS सेवाओं से चलते हैं। इन्हें
GAIA Desktop के साथ **परखा नहीं गया** है; हर एक को इस गाइड के अनुसार सेट करें, और सेटअप बारकोड
उसकी अपनी Quick Reference Guide या Product Reference Guide से लें।

| परिवार | मॉडल (उदाहरण) |
|---|---|
| DS81x8 | DS8108 (तार वाला), DS8178 (ताररहित) |
| DS22x8 | DS2208 (तार वाला), DS2278 (ताररहित) — सामान्य उपयोग |
| DS36x8 | DS3608 (तार वाला), DS3678 (ताररहित) — मज़बूत, KD और XR रूपों सहित |
| DS46x8 | DS4608 (तार वाला), DS4678 (ताररहित) |
| DS9308 / DS9908 | प्रेज़ेंटेशन और हैंड्स-फ़्री स्कैनर |
| MP7000 / MP7200 | बहु-तल बायोप्टिक स्कैनर और स्कैनर-तराज़ू |
| CS6080 | ताररहित सहायक स्कैनर |

ताररहित स्कैनर अपने क्रेडल से बात करता है, और कंप्यूटर में क्रेडल ही लगता है: क्रेडल को USB से
जोड़ें और जोड़ी को एक स्कैनर मानें। दूसरे Zebra परिवारों के स्कैनर भी चल सकते हैं, अगर Zebra का
Scanner SDK उन्हें [चरण 6](#6-zebra-स्कैनर-का-usb-मोड-सेट-करें) के किसी USB मोड में समर्थित करता हो।

### Zebra स्कैनर पर ही चलने वाली GS1 सुविधाएँ

बारकोड पढ़ने से अलग, कुछ Zebra 2D इमेजर स्कैनर पर ही GS1 डेटा संसाधित कर सकते हैं, जिसे 123Scan
से कॉन्फ़िगर किया जाता है:

| सुविधा | यह क्या करती है | GAIA Desktop के लिए |
|---|---|---|
| **Label Parse+** | स्कैनर पर ही GS1 लेबल के AI का विश्लेषण करके नए स्वरूप में फ़ील्ड भेजती है | **बंद रखें** — तब GAIA Desktop को AI, FNC1 विभाजक और AIM Code ID नहीं दिखेंगे |
| **GS1 Digital Link** | 1D EAN/UPC और 2D Digital Link कोड दोनों वाले खुदरा उत्पादों के लिए: चुनती है कि क्या भेजना है | **बंद रखें** (डिफ़ॉल्ट) |
| **GS1 Retail POS parsing** | Digital Link URI या तत्व स्ट्रिंग सिंटैक्स में 2D खुदरा बारकोड पढ़ती है | **बंद रखें** |

**GS1 Digital Link** सेटिंग के तीन मोड हैं। **Mode 1 — GTIN only**, सक्षम करने पर जिस मोड में यह
शुरू होती है, केवल GTIN भेजता है, चाहे वह किसी भी बारकोड से आए, इसलिए Digital Link का बैच,
समाप्ति तिथि या सीरियल नंबर कभी GAIA Desktop तक नहीं पहुँचता। **Mode 2 — Prioritize 2D** प्राथमिकता
टाइमआउट (डिफ़ॉल्ट रूप से 200 ms) के भीतर दिखने पर 2D कोड भेजता है, नहीं तो 1D। **Mode 3 —
Corroborate 1D and 2D GTINs Match** 1D भेजता है, और GTIN मेल खाने पर 2D भी। अगर किसी दूसरे सॉफ़्टवेयर
के लिए सेटिंग चालू रखनी ही हो, तो Mode 1 नहीं, Mode 2 उपयोग करें। DS8108 पर ये पैरामीटर 2373
(चालू/बंद), 2374 (मोड) और 2491 (टाइमआउट) हैं।

अप्रैल 2025 से फ़र्मवेयर अपडेट के ज़रिए GS1 Digital Link समर्थन जोड़ रहा है; नीचे की तिथियाँ एक Zebra
