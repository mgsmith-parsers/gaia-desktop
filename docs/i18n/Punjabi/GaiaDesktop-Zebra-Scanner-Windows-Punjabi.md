# Zebra ਸਕੈਨਰ ਸੈੱਟਅੱਪ — Windows ਲਈ GAIA Desktop

Zebra ਬਾਰਕੋਡ ਸਕੈਨਰ ਨੂੰ ਕਿਵੇਂ ਇੰਸਟਾਲ ਅਤੇ ਕੌਂਫਿਗਰ ਕਰਨਾ ਹੈ ਤਾਂ ਜੋ GAIA Desktop ਉਸ ਤੋਂ ਸਿੱਧੇ GS1 ਬਾਰਕੋਡ
ਪੜ੍ਹ ਸਕੇ: ਹਰ ਸਕੈਨ ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ ਹੋ ਕੇ ਉਹ ਇਤਿਹਾਸ ਵਿੱਚ ਜੁੜ ਜਾਂਦਾ ਹੈ, ਅਤੇ AIM Code ID ਅਗੇਤਰ ਤੇ ਹਰ FNC1
ਵਿਭਾਜਕ ਜਿਉਂ ਦਾ ਤਿਉਂ ਰਹਿੰਦਾ ਹੈ। ਮੂਲ ਦਸਤਾਵੇਜ਼:
[GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md)।

GAIA Desktop ਨੂੰ USB ਨਾਲ ਜੁੜੇ **Zebra DS8108** ਹੱਥ ਵਿੱਚ ਫੜਨ ਵਾਲੇ ਇਮੇਜਰ ਨਾਲ ਬਣਾਇਆ ਅਤੇ ਪਰਖਿਆ ਗਿਆ
ਹੈ। ਇਹ ਕਦਮ ਹਰ ਉਸ Zebra 2D ਸਕੈਨਰ ਉੱਤੇ ਲਾਗੂ ਹੁੰਦੇ ਹਨ ਜਿਸ ਨੂੰ Zebra ਦਾ Scanner SDK ਸਮਰਥਨ ਦਿੰਦਾ ਹੈ; ਕਿਸੇ
ਖ਼ਾਸ ਮਾਡਲ ਦੇ ਸੈੱਟਅੱਪ ਬਾਰਕੋਡ ਅਤੇ ਮੀਨੂ ਦੇ ਨਾਮ ਉਸ ਦੀ ਆਪਣੀ Quick Reference Guide ਜਾਂ Product Reference
Guide ਵਿੱਚ ਹੁੰਦੇ ਹਨ।

> **ਸਿਰਫ਼ Windows।** Zebra ਦੇ ਸਕੈਨਰ ਡਰਾਈਵਰ ਸਿਰਫ਼ Windows ਲਈ ਹਨ, ਇਸ ਲਈ macOS ਜਾਂ Linux ਉੱਤੇ
> GAIA Desktop ਕੋਈ ਸਕੈਨਰ ਨਿਯੰਤਰਣ ਨਹੀਂ ਬਣਾਉਂਦਾ। ਐਪ ਦੀ ਬਾਕੀ ਹਰ ਚੀਜ਼ ਹਰ ਪਲੈਟਫਾਰਮ ਉੱਤੇ ਚੱਲਦੀ ਹੈ।


ਸੇਵਾ ਕਲਾਸਾਂ ਜੋ JavaPOS ਅਤੇ ਉਸ ਡਰਾਈਵਰ ਦੇ ਵਿਚਕਾਰ ਹੁੰਦੀਆਂ ਹਨ।

## 2. Java ਇੰਸਟਾਲ ਕਰੋ

GAIA Desktop ਨੂੰ **Java 21 ਜਾਂ ਨਵਾਂ** ਚਾਹੀਦਾ ਹੈ, ਅਤੇ ਇਹ **64-ਬਿੱਟ** ਬਿਲਡ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ, ਤਾਂ ਜੋ
64-ਬਿੱਟ Zebra ਡਰਾਈਵਰਾਂ ਨਾਲ ਮੇਲ ਖਾਵੇ।

1. Windows x64 ਲਈ Java 21 JDK ਜਾਂ JRE ਇੰਸਟਾਲ ਕਰੋ — ਉਦਾਹਰਨ ਲਈ adoptium.net ਤੋਂ
   Eclipse Temurin। ਜੇ ਇੰਸਟਾਲਰ `JAVA_HOME` ਸੈੱਟ ਕਰਨ ਦੀ ਪੇਸ਼ਕਸ਼ ਕਰੇ ਤਾਂ ਉਸ ਨੂੰ ਕਰਨ ਦਿਓ।
2. Command Prompt ਵਿੱਚ ਇਸ ਨੂੰ ਜਾਂਚੋ:

   ```
   java -version
   ```

   ਪਹਿਲੀ ਲਾਈਨ ਵਿੱਚ ਵਰਜਨ 21 ਜਾਂ ਬਾਅਦ ਦਾ ਦਿਸਣਾ ਚਾਹੀਦਾ ਹੈ; 64-ਬਿੱਟ Java `64-Bit Server VM` ਵੀ ਛਾਪਦਾ ਹੈ।

`run.bat` Java ਨੂੰ ਇਸ ਕ੍ਰਮ ਵਿੱਚ ਲੱਭਦਾ ਹੈ: `run.bat` ਦੇ ਨਾਲ ਪਿਆ `jdk*` ਫੋਲਡਰ, ਫਿਰ `JAVA_HOME`, ਫਿਰ
`PATH` ਉੱਤੇ `java`। 21 ਤੋਂ ਪੁਰਾਣਾ ਕੁਝ ਵੀ ਹੋਵੇ ਤਾਂ ਉਹ ਸੁਨੇਹਾ ਦੇ ਕੇ ਉਸ ਨੂੰ ਰੱਦ ਕਰ ਦਿੰਦਾ ਹੈ।

## 3. Zebra Scanner SDK ਇੰਸਟਾਲ ਕਰੋ

1. Zebra ਦੀ ਸਹਾਇਤਾ ਸਾਈਟ ਤੋਂ **Zebra Scanner SDK for Windows (64-bit)** ਡਾਊਨਲੋਡ ਕਰੋ।
2. ਇੰਸਟਾਲਰ ਚਲਾਓ। ਜੇ ਇਹ ਹਿੱਸੇ ਚੁਣਨ ਦਾ ਵਿਕਲਪ ਦੇਵੇ, ਤਾਂ ਪੱਕਾ ਕਰੋ ਕਿ **JPOS** (JavaPOS) ਹਿੱਸਾ ਸ਼ਾਮਲ ਹੈ।
3. ਮੂਲ ਇੰਸਟਾਲ ਟਿਕਾਣਾ ਹੀ ਰਹਿਣ ਦਿਓ। GAIA Desktop SDK ਦਾ JavaPOS ਹਿੱਸਾ ਇੱਥੇ ਲੱਭਦਾ ਹੈ:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   ਅਤੇ Zebra ਦੀਆਂ ਸੇਵਾ jar ਫ਼ਾਈਲਾਂ (`JposServiceScanner.jar`, `JposServiceJniScanner.jar`, …) ਅਤੇ ਨੇਟਿਵ
   ਲਾਇਬ੍ਰੇਰੀਆਂ (`CSJPOSScanner64.dll`, …) ਉਸ ਦੇ `bin\` ਫੋਲਡਰ ਵਿੱਚ ਹੋਣ ਦੀ ਉਮੀਦ ਕਰਦਾ ਹੈ। ਜੇ SDK ਕਿਤੇ ਹੋਰ
   ਇੰਸਟਾਲ ਹੈ, ਤਾਂ [ZEBRA_HOME](#zebra_home) ਵੇਖੋ।
4. ਇੰਸਟਾਲ ਕਰਨ ਤੋਂ ਬਾਅਦ **Windows ਰੀਸਟਾਰਟ ਕਰੋ**। SDK ਦਾ CoreScanner ਡਰਾਈਵਰ ਪਿਛੋਕੜ ਵਿੱਚ ਚੱਲਦਾ ਹੈ ਅਤੇ
   GAIA Desktop ਦੇ ਸਕੈਨਰ ਤੱਕ ਪਹੁੰਚਣ ਤੋਂ ਪਹਿਲਾਂ ਉਸ ਦਾ ਚੱਲਣਾ ਲਾਜ਼ਮੀ ਹੈ; ਰੀਸਟਾਰਟ ਇਸ ਨੂੰ ਪੱਕਾ ਕਰਨ ਦਾ ਸਭ ਤੋਂ
   ਸੌਖਾ ਤਰੀਕਾ ਹੈ।

## 4. 123Scan ਇੰਸਟਾਲ ਕਰੋ

123Scan, Zebra ਦੀ ਆਪਣੇ ਸਕੈਨਰ ਕੌਂਫਿਗਰ ਕਰਨ ਵਾਲੀ ਮੁਫ਼ਤ ਯੂਟਿਲਿਟੀ ਹੈ। ਅਗਲੇ ਕਦਮ ਵਿੱਚ ਇਸ ਨਾਲ ਸਕੈਨਰ ਦਾ
ਫਰਮਵੇਅਰ ਅੱਪਡੇਟ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਅਤੇ ਬਾਅਦ ਵਿੱਚ ਸਕੈਨਰ ਦੀਆਂ ਸੈਟਿੰਗਾਂ ਜਾਂਚਣ ਤੇ ਬਦਲਣ ਦਾ ਸਭ ਤੋਂ ਸੌਖਾ ਤਰੀਕਾ ਵੀ
ਇਹੀ ਹੈ।

1. Zebra ਦੀ ਸਹਾਇਤਾ ਸਾਈਟ ਤੋਂ **123Scan** ਡਾਊਨਲੋਡ ਕਰੋ ਅਤੇ ਇੰਸਟਾਲਰ ਚਲਾਓ।
2. Zebra ਸਕੈਨਰ ਲਾਓ ਅਤੇ 123Scan ਸ਼ੁਰੂ ਕਰੋ। ਇਸ ਨੂੰ ਸਕੈਨਰ ਲੱਭ ਜਾਣਾ ਚਾਹੀਦਾ ਹੈ ਅਤੇ ਉਸ ਦਾ ਮਾਡਲ, ਸੀਰੀਅਲ
   ਨੰਬਰ ਅਤੇ ਮੌਜੂਦਾ ਫਰਮਵੇਅਰ ਵਰਜਨ ਦਿਖਾਉਣਾ ਚਾਹੀਦਾ ਹੈ। ਜੇ ਅਜਿਹਾ ਨਾ ਹੋਵੇ, ਤਾਂ ਅੱਗੇ ਵਧਣ ਤੋਂ ਪਹਿਲਾਂ ਕੋਈ
   ਹੋਰ USB ਪੋਰਟ ਜਾਂ ਕੇਬਲ ਅਜ਼ਮਾਓ — ਜੋ ਸਕੈਨਰ 123Scan ਨੂੰ ਨਹੀਂ ਦਿਸਦਾ, ਉਹ GAIA Desktop ਨੂੰ ਵੀ ਨਹੀਂ ਦਿਸੇਗਾ।

## 5. Zebra ਸਕੈਨਰ ਦਾ ਫਰਮਵੇਅਰ ਅੱਪਡੇਟ ਕਰੋ

ਕੌਂਫਿਗਰ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਸਕੈਨਰ ਦਾ ਫਰਮਵੇਅਰ ਨਵੀਨਤਮ ਵਰਜਨ ਉੱਤੇ ਲਿਆਓ। ਫਰਮਵੇਅਰ ਅੱਪਡੇਟ ਡੀਕੋਡਿੰਗ ਦੀਆਂ
ਸਮੱਸਿਆਵਾਂ ਠੀਕ ਕਰਦੇ ਹਨ ਅਤੇ ਸਕੈਨਰ ਨੂੰ SDK ਵੱਲੋਂ ਇੰਸਟਾਲ ਕੀਤੇ Zebra ਡਰਾਈਵਰ ਨਾਲ ਮੇਲ ਵਿੱਚ ਰੱਖਦੇ ਹਨ।

1. **GAIA Desktop** ਅਤੇ ਕੋਈ ਵੀ ਹੋਰ ਪ੍ਰੋਗਰਾਮ ਜੋ ਸਕੈਨਰ ਵਰਤ ਰਿਹਾ ਹੋ ਸਕਦਾ ਹੈ, ਬੰਦ ਕਰੋ: ਅੱਪਡੇਟ ਦੌਰਾਨ
   123Scan ਨੂੰ ਸਕੈਨਰ ਸਿਰਫ਼ ਆਪਣੇ ਕੋਲ ਚਾਹੀਦਾ ਹੈ।
2. ਸਕੈਨਰ ਜੁੜਿਆ ਹੋਣ ਸਮੇਂ 123Scan ਵਿੱਚ ਉਸ ਦਾ ਫਰਮਵੇਅਰ ਅੱਪਡੇਟ ਵਿਕਲਪ ਚੁਣੋ। 123Scan ਸਕੈਨਰ ਦੇ ਫਰਮਵੇਅਰ ਦੀ
   Zebra ਵੱਲੋਂ ਜਾਰੀ ਨਵੀਨਤਮ ਫਰਮਵੇਅਰ ਨਾਲ ਤੁਲਨਾ ਕਰਦਾ ਹੈ ਅਤੇ ਉਸ ਨੂੰ ਡਾਊਨਲੋਡ ਤੇ ਇੰਸਟਾਲ ਕਰਨ ਦੀ ਪੇਸ਼ਕਸ਼ ਕਰਦਾ
   ਹੈ। ਜੇ ਕੰਪਿਊਟਰ ਉੱਤੇ ਇੰਟਰਨੈੱਟ ਨਹੀਂ ਹੈ, ਤਾਂ Zebra ਦੀ ਸਾਈਟ ਉੱਤੇ ਸਕੈਨਰ ਦੇ ਸਹਾਇਤਾ ਪੰਨੇ ਤੋਂ ਉਸ ਦਾ
   ਫਰਮਵੇਅਰ ਡਾਊਨਲੋਡ ਕਰੋ ਅਤੇ ਫ਼ਾਈਲ 123Scan ਵਿੱਚ ਲੋਡ ਕਰੋ।
3. ਅੱਪਡੇਟ ਸ਼ੁਰੂ ਕਰੋ ਅਤੇ **ਜਦੋਂ ਤੱਕ 123Scan ਇਹ ਨਾ ਦੱਸੇ ਕਿ ਕੰਮ ਪੂਰਾ ਹੋ ਗਿਆ, ਸਕੈਨਰ ਲੱਗਿਆ ਰਹਿਣ ਦਿਓ**।
   ਇਸ ਨੂੰ ਕਈ ਮਿੰਟ ਲੱਗਦੇ ਹਨ; ਅਖ਼ੀਰ ਵਿੱਚ ਸਕੈਨਰ ਰੀਸਟਾਰਟ ਹੁੰਦਾ ਹੈ। ਵਿਚਕਾਰ ਕੱਢਣ ਨਾਲ ਇਹ ਬੇਕਾਰ ਹੋ ਸਕਦਾ ਹੈ।
4. ਜਾਂਚੋ ਕਿ 123Scan ਹੁਣ ਨਵਾਂ ਫਰਮਵੇਅਰ ਵਰਜਨ ਦਿਖਾ ਰਿਹਾ ਹੈ।

ਅੱਪਡੇਟ ਕੁਝ ਸੈਟਿੰਗਾਂ ਨੂੰ ਮੂਲ ਉੱਤੇ ਵਾਪਸ ਲਿਆ ਸਕਦਾ ਹੈ, ਇਸੇ ਲਈ ਸਕੈਨਰ ਨੂੰ ਅਗਲੇ ਦੋ ਕਦਮਾਂ ਵਿੱਚ, ਫਰਮਵੇਅਰ ਤੋਂ
ਬਾਅਦ, ਕੌਂਫਿਗਰ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।

## 6. Zebra ਸਕੈਨਰ ਦਾ USB ਮੋਡ ਸੈੱਟ ਕਰੋ

ਇਹੀ ਕਦਮ ਸਭ ਤੋਂ ਵੱਧ ਛੁੱਟਦਾ ਹੈ। **ਡੱਬੇ ਵਿੱਚੋਂ ਨਿਕਲਿਆ Zebra ਸਕੈਨਰ ਇੱਕ USB ਕੀਬੋਰਡ ਹੁੰਦਾ ਹੈ** (USB HID
Keyboard ਮੋਡ): ਇਹ ਹਰ ਬਾਰਕੋਡ ਨੂੰ ਉੱਥੇ "ਟਾਈਪ" ਕਰ ਦਿੰਦਾ ਹੈ ਜਿੱਥੇ ਫੋਕਸ ਹੋਵੇ। ਉਸ ਮੋਡ ਵਿੱਚ GAIA Desktop
ਦਾ *ਸਕੈਨਰ ਜੋੜੋ* ਉਸ ਨੂੰ ਲੱਭ ਨਹੀਂ ਸਕਦਾ, ਅਤੇ ਟੈਕਸਟ ਖੇਤਰ ਵਿੱਚ ਟਾਈਪ ਹੋਈ ਹਰ ਚੀਜ਼ ਆਪਣੇ FNC1 ਵਿਭਾਜਕ ਗੁਆ
ਦਿੰਦੀ ਹੈ, ਜਿਸ ਨਾਲ GS1 ਤੱਤ ਸਟ੍ਰਿੰਗ ਦਾ ਅਰਥ ਬਦਲ ਜਾਂਦਾ ਹੈ।

ਸਕੈਨਰ ਨੂੰ ਅਜਿਹੇ ਮੋਡ ਵਿੱਚ ਬਦਲੋ ਜਿਸ ਨਾਲ Zebra ਡਰਾਈਵਰ ਸਿੱਧੀ ਗੱਲ ਕਰਦਾ ਹੈ:

| ਸਕੈਨਰ ਦਾ USB ਮੋਡ | GAIA Desktop ਵਿੱਚ ਡਿਵਾਈਸ ਦਾ ਨਾਮ | ਟਿੱਪਣੀ |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld`, ਜਾਂ `ZebraAllScanners` | ਸਿਫ਼ਾਰਸ਼ੀ |
| SNAPI (ਇਮੇਜਿੰਗ ਸਮੇਤ ਜਾਂ ਬਿਨਾਂ) | `ZebraScannerSNAPI`, ਜਾਂ `ZebraAllScanners` | Zebra ਦਾ ਆਪਣਾ USB ਪ੍ਰੋਟੋਕੋਲ; ਇਹ ਵੀ ਚੱਲਦਾ ਹੈ |
| IBM Table-top USB | `ZebraUSBTableTop`, ਜਾਂ `ZebraAllScanners` | ਮੇਜ਼ ਉੱਤੇ ਰੱਖੇ ਸਕੈਨਰਾਂ ਲਈ |
| USB OPOS (Hand-held) | `ZebraUSBOPOS`, ਜਾਂ `ZebraAllScanners` | |
| USB HID Keyboard (ਫੈਕਟਰੀ ਮੂਲ) | — | **ਨਹੀਂ ਜੁੜੇਗਾ** |

`ZebraAllScanners`, GAIA Desktop ਦਾ ਮੂਲ ਡਿਵਾਈਸ ਨਾਮ, ਕਿਸੇ ਵੀ ਸਮਰਥਿਤ ਮੋਡ ਵਿੱਚ ਸਕੈਨਰ ਸਵੀਕਾਰ ਕਰਦਾ ਹੈ, ਇਸ
ਲਈ ਮੋਡ ਸੈੱਟ ਹੁੰਦੇ ਹੀ ਮੂਲ ਆਮ ਤੌਰ ਉੱਤੇ ਆਪਣੇ ਆਪ ਕੰਮ ਕਰ ਜਾਂਦਾ ਹੈ।

ਮੋਡ ਬਦਲਣ ਲਈ, ਜਾਂ ਤਾਂ:

- ਸਕੈਨਰ ਦੀ Quick Reference Guide ਜਾਂ Product Reference Guide (USB Host Types / USB Device Type ਭਾਗ)
  ਵਿੱਚ ਉਸ ਮੋਡ ਦਾ — ਜਿਵੇਂ *IBM Hand-held USB* — **ਸੈੱਟਅੱਪ ਬਾਰਕੋਡ ਸਕੈਨ ਕਰੋ**; ਸਕੈਨਰ ਬੀਪ ਕਰਕੇ ਪੁਸ਼ਟੀ
  ਕਰਦਾ ਹੈ। ਜਾਂ
- **123Scan ਵਰਤੋ** ([ਕਦਮ 4](#4-123scan-ਇੰਸਟਾਲ-ਕਰੋ)): ਸਕੈਨਰ ਜੋੜੋ, ਉਸ ਦੀ ਕੌਂਫਿਗਰੇਸ਼ਨ ਖੋਲ੍ਹੋ, ਅਤੇ USB
  ਹੋਸਟ ਦੀ ਕਿਸਮ ਸੈੱਟ ਕਰੋ।

ਮੋਡ ਬਦਲਣ ਤੋਂ ਬਾਅਦ Windows ਸਕੈਨਰ ਨੂੰ ਵੱਖਰੀ ਕਿਸਮ ਦੀ ਡਿਵਾਈਸ ਵਜੋਂ ਮੁੜ ਪਛਾਣਦਾ ਹੈ; ਜੋੜਨ ਤੋਂ ਪਹਿਲਾਂ ਕੁਝ
ਸਕਿੰਟ ਰੁਕੋ।

ਬਾਅਦ ਵਿੱਚ ਸਕੈਨਰ ਨੂੰ ਕੀਬੋਰਡ ਮੋਡ ਵਿੱਚ ਵਾਪਸ ਲਿਆਉਣ ਲਈ — ਹੋਰ ਸਾਫ਼ਟਵੇਅਰ ਨਾਲ ਵਰਤਣ ਲਈ — *USB Keyboard (HID)*
ਸੈੱਟਅੱਪ ਬਾਰਕੋਡ ਸਕੈਨ ਕਰੋ, ਜਾਂ ਉਸ ਦੀਆਂ ਫੈਕਟਰੀ ਮੂਲ ਸੈਟਿੰਗਾਂ ਬਹਾਲ ਕਰੋ।

## 7. GS1 ਲਈ Zebra ਸਕੈਨਰ ਕੌਂਫਿਗਰ ਕਰੋ

ਜਦੋਂ ਸਕੈਨਰ ਦੱਸੇ ਕਿ ਉਸ ਨੇ ਕਿਸ ਕਿਸਮ ਦਾ ਬਾਰਕੋਡ ਪੜ੍ਹਿਆ ਹੈ, ਤਾਂ GAIA Desktop ਸਭ ਤੋਂ ਵਧੀਆ ਵਿਸ਼ਲੇਸ਼ਣ ਕਰਦਾ ਹੈ।

### AIM Code ID ਭੇਜੋ

Product Reference Guide (User Preferences) ਦੇ ਸੈੱਟਅੱਪ ਬਾਰਕੋਡ ਨਾਲ ਜਾਂ 123Scan ਵਿੱਚ **Transmit Code ID
Character** ਨੂੰ **AIM Code ID Character** ਉੱਤੇ ਸੈੱਟ ਕਰੋ। ਫਿਰ ਹਰ ਸਕੈਨ ਆਪਣੇ ਸਿੰਬੋਲੋਜੀ ਪਛਾਣਕਰਤਾ ਨਾਲ ਸ਼ੁਰੂ
ਹੁੰਦਾ ਹੈ — GS1-128 ਲਈ `]C1`, GS1 DataMatrix ਲਈ `]d2`, GS1 QR Code ਲਈ `]Q3`, GS1 DataBar ਲਈ `]e0` —
ਜਿਸ ਨੂੰ GAIA Desktop ਡਾਟਾ ਵਾਹਕ ਦਾ ਨਾਮ ਦੱਸਣ ਅਤੇ ਉਸ ਦੇ ਨਿਯਮ ਲਾਗੂ ਕਰਨ ਲਈ ਵਰਤਦਾ ਹੈ।

ਇਸ ਤੋਂ ਬਿਨਾਂ ਵੀ GAIA Desktop ਤੱਤ ਸਟ੍ਰਿੰਗ ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ ਕਰਦਾ ਹੈ ਅਤੇ ਸਿੰਬੋਲੋਜੀ ਸਕੈਨ ਤੋਂ ਹੀ ਲੈਂਦਾ ਹੈ, ਪਰ
ਰਿਪੋਰਟ ਕੋਲ ਦਿਖਾਉਣ ਲਈ ਕੋਈ AIM Code ID ਨਹੀਂ ਹੁੰਦਾ, ਅਤੇ EAN-13 ਵਰਗੇ ਸਾਧਾਰਨ ਬਾਰਕੋਡ ਨੂੰ GS1 ਤੱਤ ਸਟ੍ਰਿੰਗ ਤੋਂ
ਵੱਖ ਪਛਾਣਨਾ ਔਖਾ ਹੋ ਜਾਂਦਾ ਹੈ।

### ਸਿੰਬੋਲੋਜੀਆਂ ਜਾਂਚੋ

ਪੱਕਾ ਕਰੋ ਕਿ ਜਿਨ੍ਹਾਂ ਬਾਰਕੋਡ ਕਿਸਮਾਂ ਨਾਲ ਤੁਸੀਂ ਕੰਮ ਕਰਦੇ ਹੋ ਉਹ **ਸਮਰੱਥ** ਹਨ: ਆਮ ਤੌਰ ਉੱਤੇ GS1-128,
GS1 DataMatrix, GS1 DataBar, GS1 QR Code ਅਤੇ EAN/UPC। Zebra ਦੇ 2D ਸਕੈਨਰਾਂ ਉੱਤੇ ਇਨ੍ਹਾਂ ਵਿੱਚੋਂ ਜ਼ਿਆਦਾਤਰ
ਮੂਲ ਰੂਪ ਵਿੱਚ ਚਾਲੂ ਹੁੰਦੀਆਂ ਹਨ; 123Scan ਮੌਜੂਦਾ ਸੈਟਿੰਗਾਂ ਦਿਖਾਉਂਦਾ ਹੈ, ਅਤੇ Product Reference Guide ਵਿੱਚ ਹਰ
ਇੱਕ ਨੂੰ ਸਮਰੱਥ ਕਰਨ ਦਾ ਬਾਰਕੋਡ ਹੁੰਦਾ ਹੈ।

### Zebra ਦੀਆਂ GS1 ਵਿਸ਼ਲੇਸ਼ਣ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਬੰਦ ਰੱਖੋ

ਨਵਾਂ ਫਰਮਵੇਅਰ ਅਜਿਹੀਆਂ GS1 ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਜੋੜਦਾ ਹੈ ਜੋ ਸਕੈਨਰ ਉੱਤੇ ਹੀ ਕੰਮ ਕਰਦੀਆਂ ਹਨ — **Label Parse+**,
**GS1 Digital Link** ਅਤੇ **GS1 Retail POS parsing**। ਇਨ੍ਹਾਂ ਨੂੰ **ਬੰਦ** ਰੱਖੋ, ਜਿਵੇਂ ਸਕੈਨਰ ਆਉਂਦਾ ਹੈ: ਇਹ
ਸਕੈਨਰ ਵੱਲੋਂ ਭੇਜੇ ਡਾਟੇ ਦਾ ਰੂਪ ਬਦਲਦੀਆਂ ਜਾਂ ਉਸ ਨੂੰ ਛੋਟਾ ਕਰਦੀਆਂ ਹਨ, ਜਦਕਿ GAIA Desktop ਨੂੰ ਵਿਸ਼ਲੇਸ਼ਣ ਅਤੇ
ਪ੍ਰਮਾਣਿਕਤਾ ਲਈ ਕੱਚਾ ਡਾਟਾ ਚਾਹੀਦਾ ਹੈ। ਹਰ ਇੱਕ ਕੀ ਕਰਦੀ ਹੈ, ਇਹ
[ਸਮਰਥਿਤ Zebra 2D ਸਕੈਨਰ](#12-ਸਮਰਥਿਤ-zebra-2d-ਸਕੈਨਰ) ਵਿੱਚ ਵੇਖੋ।

### ਅਗੇਤਰ ਅਤੇ ਪਿਛੇਤਰ ਬੰਦ ਰੱਖੋ

ਸਕੈਨਰ ਦੇ ਆਉਟਪੁੱਟ ਵਿੱਚ ਕੋਈ ਅਗੇਤਰ, ਪਿਛੇਤਰ ਜਾਂ Enter ਕੁੰਜੀ ਨਾ ਜੋੜੋ। GAIA Desktop ਹਰ ਸਕੈਨ ਨੂੰ JavaPOS
ਰਾਹੀਂ ਇੱਕ ਪੂਰੇ ਸੁਨੇਹੇ ਵਜੋਂ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ ਅਤੇ ਉਸ ਨੂੰ ਇਨ੍ਹਾਂ ਵਿੱਚੋਂ ਕਿਸੇ ਦੀ ਲੋੜ ਨਹੀਂ; ਵਾਧੂ ਅੱਖਰ ਤੱਤ
ਸਟ੍ਰਿੰਗ ਵਿੱਚ ਜਾ ਵੜਨਗੇ।

## 8. GAIA Desktop ਇੰਸਟਾਲ ਕਰੋ ਅਤੇ ਸ਼ੁਰੂ ਕਰੋ

1. `gaia-desktop-1.0.0-win.zip` ਨੂੰ ਅਨਜ਼ਿੱਪ ਕਰੋ, ਉਦਾਹਰਨ ਲਈ `C:\Tools\` ਵਿੱਚ। ਇਸ ਵਿੱਚ ਇੱਕ ਫੋਲਡਰ ਹੁੰਦਾ ਹੈ:

   ```
   gaia-desktop-1.0.0-win\
   ├── docs\
   │   └── GaiaDesktop-Zebra-Scanner-Windows.md      this guide
   ├── gaia-desktop.jar
   ├── lib\
   ├── readme.html                                   index of every guide
   └── run.bat
   ```

2. ਸਕੈਨਰ ਲਾਓ।
3. **`run.bat`** ਉੱਤੇ ਡਬਲ-ਕਲਿੱਕ ਕਰੋ। ਐਪ ਦੇ ਨਾਲ ਇੱਕ ਕੰਸੋਲ ਵਿੰਡੋ ਖੁੱਲ੍ਹਦੀ ਹੈ ਅਤੇ ਖੁੱਲ੍ਹੀ ਰਹਿੰਦੀ ਹੈ: ਸਕੈਨਰ
   ਦੀ ਸਥਿਤੀ ਅਤੇ JavaPOS ਗਲਤੀਆਂ ਉੱਥੇ ਦੱਸੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।
4. ਕੰਸੋਲ ਦੀ ਪਹਿਲੀ ਲਾਈਨ ਪੜ੍ਹੋ। ਇਹ ਦੱਸਦੀ ਹੈ ਕਿ `run.bat` ਨੂੰ ਕੀ ਲੱਭਿਆ:

   ```
   run.bat: Java 21.0.8 from JAVA_HOME; JavaFX from lib\; JavaPOS from lib\; Zebra services from C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   ਜੇ ਇਹ **`Zebra services from none (Zebra Scanner SDK not installed)`** ਉੱਤੇ ਮੁੱਕੇ, ਤਾਂ SDK ਆਪਣੇ ਮੂਲ
   ਟਿਕਾਣੇ ਉੱਤੇ ਨਹੀਂ ਲੱਭਿਆ — ਉਸ ਨੂੰ ਇੰਸਟਾਲ ਕਰੋ ([ਕਦਮ 3](#3-zebra-scanner-sdk-ਇੰਸਟਾਲ-ਕਰੋ)) ਜਾਂ
   [ZEBRA_HOME](#zebra_home) ਸੈੱਟ ਕਰੋ। ਐਪ ਫਿਰ ਵੀ ਸ਼ੁਰੂ ਹੁੰਦੀ ਹੈ, ਪਰ ਸਕੈਨਰ ਜੁੜ ਨਹੀਂ ਸਕਦਾ।

## 9. ਸਕੈਨਰ ਜੋੜੋ

1. ਟੂਲਬਾਰ ਵਿੱਚ **ਡਿਵਾਈਸ ਚੋਣਕਾਰ** ਉਨ੍ਹਾਂ ਸਕੈਨਰ ਨਾਮਾਂ ਦੀ ਸੂਚੀ ਦਿਖਾਉਂਦਾ ਹੈ ਜਿਨ੍ਹਾਂ ਨੂੰ GAIA Desktop ਜਾਣਦਾ
   ਹੈ। ਇਸ ਨੂੰ **`ZebraAllScanners`** ਉੱਤੇ ਰਹਿਣ ਦਿਓ, ਜਾਂ [ਕਦਮ 6](#6-zebra-ਸਕੈਨਰ-ਦਾ-usb-ਮੋਡ-ਸੈੱਟ-ਕਰੋ) ਦੀ
   ਸਾਰਣੀ ਵਿੱਚੋਂ ਸਕੈਨਰ ਦੇ USB ਮੋਡ ਦਾ ਨਾਮ ਚੁਣੋ।
2. **ਸਕੈਨਰ ਜੋੜੋ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ, ਜਾਂ **Ctrl+K** ਦਬਾਓ (ਇਹ **ਸਕੈਨਰ** ਮੀਨੂ ਵਿੱਚ ਵੀ ਹੈ)।
3. ਸਟੇਟਸ ਬਾਰ ਬਦਲ ਕੇ **`ਸਕੈਨਰ: ZebraAllScanners`** (ਜਾਂ ਤੁਹਾਡਾ ਚੁਣਿਆ ਨਾਮ) ਹੋ ਜਾਂਦੀ ਹੈ, ਅਤੇ ਸਥਿਤੀ ਲਾਈਨ
   *ਸਕੈਨਰ ਜੁੜਿਆ — ZebraAllScanners* ਦੱਸਦੀ ਹੈ। ਬਟਨ ਉੱਤੇ ਹੁਣ **ਸਕੈਨਰ ਵੱਖ ਕਰੋ** ਲਿਖਿਆ ਹੁੰਦਾ ਹੈ।
4. ਕੋਈ GS1 ਬਾਰਕੋਡ ਸਕੈਨ ਕਰੋ। ਇਹ ਕੈਪਚਰ ਇਤਿਹਾਸ ਵਿੱਚ ਸਭ ਤੋਂ ਉੱਪਰ ਦਿਸਦਾ ਹੈ ਅਤੇ ਉਸ ਦੀ ਰਿਪੋਰਟ ਖੁੱਲ੍ਹ ਜਾਂਦੀ
   ਹੈ। AIM Code ID ਚਾਲੂ ਹੋਣ ਉੱਤੇ ਰਿਪੋਰਟ ਡਾਟਾ ਵਾਹਕ ਦਾ ਨਾਮ ਦੱਸਦੀ ਹੈ — *GS1-128*, *GS1 DataMatrix* — ਅਤੇ
   ਤੱਤ ਸਟ੍ਰਿੰਗ ਹਰ FNC1 ਵਿਭਾਜਕ ਬਣਾਈ ਰੱਖਦੀ ਹੈ।

ਡਿਵਾਈਸ ਚੋਣਕਾਰ ਹਰ ਵਾਰ ਚਲਾਉਣ ਵਿਚਕਾਰ ਤੁਹਾਡੀ ਚੋਣ ਯਾਦ ਰੱਖਦਾ ਹੈ। ਸਕੈਨਰ ਉਦੋਂ ਤੱਕ ਜੁੜਿਆ ਰਹਿੰਦਾ ਹੈ ਜਦੋਂ ਤੱਕ
ਤੁਸੀਂ ਉਸ ਨੂੰ ਵੱਖ ਨਾ ਕਰੋ ਜਾਂ ਐਪ ਬੰਦ ਨਾ ਕਰੋ। ਸਕੈਨ **ਬਣਾਓ** ਅਤੇ **ਜੋੜੋ** ਮੋਡਾਂ ਵਿੱਚ ਵੀ ਕੰਮ ਕਰਦੇ ਹਨ: ਜੋੜੋ
ਵਿੱਚ ਹਰ ਸਕੈਨ ਜੋੜੇ ਜਾ ਰਹੇ ਬਾਰਕੋਡਾਂ ਵਿੱਚੋਂ ਇੱਕ ਬਣ ਜਾਂਦਾ ਹੈ।

ਜਦੋਂ ਤੱਕ GAIA Desktop ਸਕੈਨਰ ਨੂੰ ਫੜੀ ਰੱਖਦਾ ਹੈ, ਹੋਰ ਪ੍ਰੋਗਰਾਮ ਉਸ ਨੂੰ ਵਰਤ ਨਹੀਂ ਸਕਦੇ, ਅਤੇ ਉਲਟ ਵੀ: ਜੋੜਨ ਤੋਂ
ਪਹਿਲਾਂ 123Scan ਅਤੇ ਕੋਈ ਵੀ ਹੋਰ ਪੁਆਇੰਟ-ਆਫ਼-ਸੇਲ ਜਾਂ ਸਕੈਨਰ ਸਾਫ਼ਟਵੇਅਰ ਬੰਦ ਕਰੋ।

## 10. ਕੌਂਫਿਗਰੇਸ਼ਨ ਹਵਾਲਾ

### ਡਿਵਾਈਸ ਦੇ ਨਾਮ

ਡਿਵਾਈਸ ਚੋਣਕਾਰ `gaia-desktop.jar` ਵਿੱਚ ਸ਼ਾਮਲ `jpos.xml` ਤੋਂ ਭਰਿਆ ਜਾਂਦਾ ਹੈ। ਉਸ ਦੀਆਂ ਸਕੈਨਰ ਇੰਦਰਾਜ਼ਾਂ:

| ਡਿਵਾਈਸ ਦਾ ਨਾਮ | ਸਕੈਨਰ ਦੀ ਕਿਸਮ | ਕਿਸ ਨਾਲ ਵਰਤੋ |
|---|---|---|

### ZEBRA_HOME

ਜੇ Zebra SDK ਮੂਲ ਤੋਂ ਇਲਾਵਾ ਕਿਤੇ ਹੋਰ ਇੰਸਟਾਲ ਹੈ, ਤਾਂ `run.bat` ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ `ZEBRA_HOME` ਨੂੰ ਉਸ ਦੇ
`JPOS` ਫੋਲਡਰ ਉੱਤੇ ਸੈੱਟ ਕਰੋ — ਉਦਾਹਰਨ ਲਈ ਉਸ ਦੇ ਨਾਲ ਰੱਖੀ ਇੱਕ ਛੋਟੀ ਬੈਚ ਫ਼ਾਈਲ ਵਿੱਚ:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

ਫਿਰ `run.bat` Zebra ਦੀਆਂ ਸੇਵਾ jar ਫ਼ਾਈਲਾਂ `%ZEBRA_HOME%bin` ਤੋਂ ਲੈਂਦਾ ਹੈ ਅਤੇ Zebra DLL ਲਈ ਉਸ ਫੋਲਡਰ ਨੂੰ
`PATH` ਵਿੱਚ ਜੋੜਦਾ ਹੈ।

### ਤੁਹਾਡੀ ਆਪਣੀ jpos.xml

ਕੋਈ ਡਿਵਾਈਸ ਨਾਮ ਜੋੜਨ ਜਾਂ ਕਿਸੇ ਇੰਦਰਾਜ਼ ਦੀਆਂ ਸੈਟਿੰਗਾਂ ਬਦਲਣ ਲਈ, `gaia-desktop.jar` ਵਿੱਚੋਂ `jpos.xml` ਦੀ
ਕਾਪੀ ਕੱਢੋ (ਇਹ ਇੱਕ zip ਹੈ; ਕੋਈ ਵੀ ਅਨਜ਼ਿੱਪ ਟੂਲ ਇਸ ਨੂੰ ਖੋਲ੍ਹ ਲੈਂਦਾ ਹੈ), ਕਾਪੀ ਨੂੰ ਸੋਧੋ, ਅਤੇ GAIA Desktop
ਨੂੰ ਉਸ ਵੱਲ ਇਸ਼ਾਰਾ ਕਰੋ:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

ਫਿਰ ਡਿਵਾਈਸ ਚੋਣਕਾਰ ਉਸ ਫ਼ਾਈਲ ਦੇ ਸਕੈਨਰ ਦਿਖਾਉਂਦਾ ਹੈ। ਇੱਕ ਤੋਂ ਵੱਧ Zebra ਸਕੈਨਰ ਜੁੜੇ ਹੋਣ ਤਾਂ ਕਿਸੇ ਇੰਦਰਾਜ਼ ਨੂੰ
ਉਸ ਦੀ `ScannerModel` ਜਾਂ `SerialNumber` ਵਿਸ਼ੇਸ਼ਤਾ ਰਾਹੀਂ ਉਨ੍ਹਾਂ ਵਿੱਚੋਂ ਇੱਕ ਨਾਲ ਬੰਨ੍ਹਿਆ ਜਾ ਸਕਦਾ ਹੈ, ਜਿਵੇਂ
`ZebraAllScanners` ਇੰਦਰਾਜ਼ ਵਿੱਚ ਹੈ।

## 12. ਸਮਰਥਿਤ Zebra 2D ਸਕੈਨਰ

GAIA Desktop ਨੂੰ ਅਜਿਹਾ ਸਕੈਨਰ ਚਾਹੀਦਾ ਹੈ ਜੋ ਉਹ ਬਾਰਕੋਡ ਪੜ੍ਹ ਸਕੇ ਜਿਨ੍ਹਾਂ ਵਿੱਚ GS1 ਡਾਟਾ ਛਪਦਾ ਹੈ — GS1-128,
GS1 DataBar, EAN/UPC, ਅਤੇ ਜ਼ਿਆਦਾਤਰ ਵਰਤੋਂ ਲਈ 2D ਕੋਡ: **GS1 DataMatrix** ਅਤੇ **GS1 QR Code**, ਜਿਸ ਵਿੱਚ ਆਮ
ਤੌਰ ਉੱਤੇ **GS1 Digital Link** URI ਵੀ ਛਪਦਾ ਹੈ। ਭਾਵ ਇੱਕ Zebra **2D ਇਮੇਜਰ**: ਰੇਖਿਕ (1D) ਸਕੈਨਰ DataMatrix
ਜਾਂ QR ਕੋਡ ਬਿਲਕੁਲ ਨਹੀਂ ਪੜ੍ਹ ਸਕਦਾ।

ਸਕੈਨਰ ਨੂੰ ਆਪ GS1 Application Identifiers ਜਾਂ Digital Link ਸਮਝਣ ਦੀ ਲੋੜ ਨਹੀਂ।
**GAIA Desktop ਦੋਵਾਂ ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ ਕਰਦਾ ਹੈ**: ਇਹ ਸਕੈਨ ਨੂੰ ਉਵੇਂ ਹੀ ਲੈਂਦਾ ਹੈ ਜਿਵੇਂ ਸਕੈਨਰ ਨੇ ਪੜ੍ਹਿਆ — AIM Code
ID, FNC1 ਵਿਭਾਜਕ, ਸਭ ਕੁਝ — ਅਤੇ ਆਪ ਉਸ ਨੂੰ AI ਵਿੱਚ ਵੰਡਦਾ ਹੈ, ਜਾਂ Digital Link URI ਨੂੰ ਉਸ ਦੇ AI ਵਿੱਚ ਬਦਲਦਾ ਹੈ।

ਬੇਤਾਰ ਸਕੈਨਰ ਆਪਣੇ ਕ੍ਰੈਡਲ ਨਾਲ ਗੱਲ ਕਰਦਾ ਹੈ, ਅਤੇ ਕੰਪਿਊਟਰ ਵਿੱਚ ਕ੍ਰੈਡਲ ਹੀ ਲੱਗਦਾ ਹੈ: ਕ੍ਰੈਡਲ ਨੂੰ USB ਨਾਲ ਜੋੜੋ
ਅਤੇ ਜੋੜੀ ਨੂੰ ਇੱਕ ਸਕੈਨਰ ਮੰਨੋ। ਹੋਰ Zebra ਪਰਿਵਾਰਾਂ ਦੇ ਸਕੈਨਰ ਵੀ ਚੱਲ ਸਕਦੇ ਹਨ, ਜੇ Zebra ਦਾ Scanner SDK
ਉਨ੍ਹਾਂ ਨੂੰ [ਕਦਮ 6](#6-zebra-ਸਕੈਨਰ-ਦਾ-usb-ਮੋਡ-ਸੈੱਟ-ਕਰੋ) ਦੇ ਕਿਸੇ USB ਮੋਡ ਵਿੱਚ ਸਮਰਥਨ ਦਿੰਦਾ ਹੋਵੇ।

### Zebra ਸਕੈਨਰ ਉੱਤੇ ਹੀ ਚੱਲਣ ਵਾਲੀਆਂ GS1 ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

ਬਾਰਕੋਡ ਪੜ੍ਹਨ ਤੋਂ ਵੱਖ, ਕੁਝ Zebra 2D ਇਮੇਜਰ ਸਕੈਨਰ ਉੱਤੇ ਹੀ GS1 ਡਾਟੇ ਉੱਤੇ ਕਾਰਵਾਈ ਕਰ ਸਕਦੇ ਹਨ, ਜਿਸ ਨੂੰ
123Scan ਰਾਹੀਂ ਕੌਂਫਿਗਰ ਕੀਤਾ ਜਾਂਦਾ ਹੈ:

| ਵਿਸ਼ੇਸ਼ਤਾ | ਇਹ ਕੀ ਕਰਦੀ ਹੈ | GAIA Desktop ਲਈ |
|---|---|---|
| **Label Parse+** | ਸਕੈਨਰ ਉੱਤੇ ਹੀ GS1 ਲੇਬਲ ਦੇ AI ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ ਕਰਕੇ ਨਵੇਂ ਰੂਪ ਵਿੱਚ ਖੇਤਰ ਭੇਜਦੀ ਹੈ | **ਬੰਦ ਰੱਖੋ** — ਫਿਰ GAIA Desktop ਨੂੰ AI, FNC1 ਵਿਭਾਜਕ ਅਤੇ AIM Code ID ਨਹੀਂ ਦਿਸਣਗੇ |
| **GS1 Digital Link** | 1D EAN/UPC ਅਤੇ 2D Digital Link ਕੋਡ ਦੋਵਾਂ ਵਾਲੇ ਪ੍ਰਚੂਨ ਉਤਪਾਦਾਂ ਲਈ: ਚੁਣਦੀ ਹੈ ਕਿ ਕੀ ਭੇਜਣਾ ਹੈ | **ਬੰਦ ਰੱਖੋ** (ਮੂਲ) |
| **GS1 Retail POS parsing** | Digital Link URI ਜਾਂ ਤੱਤ ਸਟ੍ਰਿੰਗ ਸਿੰਟੈਕਸ ਵਿੱਚ 2D ਪ੍ਰਚੂਨ ਬਾਰਕੋਡ ਪੜ੍ਹਦੀ ਹੈ | **ਬੰਦ ਰੱਖੋ** |

**GS1 Digital Link** ਸੈਟਿੰਗ ਦੇ ਤਿੰਨ ਮੋਡ ਹਨ। **Mode 1 — GTIN only**, ਸਮਰੱਥ ਕਰਨ ਉੱਤੇ ਜਿਸ ਮੋਡ ਵਿੱਚ ਇਹ ਸ਼ੁਰੂ
ਹੁੰਦੀ ਹੈ, ਸਿਰਫ਼ GTIN ਭੇਜਦਾ ਹੈ, ਭਾਵੇਂ ਉਹ ਕਿਸੇ ਵੀ ਬਾਰਕੋਡ ਤੋਂ ਆਵੇ, ਇਸ ਲਈ Digital Link ਦਾ ਬੈਚ, ਮਿਆਦ ਪੁੱਗਣ ਦੀ
ਤਾਰੀਖ਼ ਜਾਂ ਸੀਰੀਅਲ ਨੰਬਰ ਕਦੇ GAIA Desktop ਤੱਕ ਨਹੀਂ ਪਹੁੰਚਦਾ। **Mode 2 — Prioritize 2D** ਤਰਜੀਹੀ ਸਮਾਂ-ਸੀਮਾ
(ਮੂਲ ਰੂਪ ਵਿੱਚ 200 ms) ਦੇ ਅੰਦਰ ਦਿਸਣ ਉੱਤੇ 2D ਕੋਡ ਭੇਜਦਾ ਹੈ, ਨਹੀਂ ਤਾਂ 1D। **Mode 3 — Corroborate 1D and 2D
GTINs Match** 1D ਭੇਜਦਾ ਹੈ, ਅਤੇ GTIN ਮੇਲ ਖਾਣ ਉੱਤੇ 2D ਵੀ। ਜੇ ਕਿਸੇ ਹੋਰ ਸਾਫ਼ਟਵੇਅਰ ਲਈ ਸੈਟਿੰਗ ਚਾਲੂ ਰੱਖਣੀ ਹੀ
ਪਵੇ, ਤਾਂ Mode 1 ਨਹੀਂ, Mode 2 ਵਰਤੋ। DS8108 ਉੱਤੇ ਇਹ ਪੈਰਾਮੀਟਰ 2373 (ਚਾਲੂ/ਬੰਦ), 2374 (ਮੋਡ) ਅਤੇ 2491
(ਸਮਾਂ-ਸੀਮਾ) ਹਨ।

ਇਨ੍ਹਾਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਲਈ **123Scan ਵਰਜਨ 6 ਜਾਂ ਨਵਾਂ** ਅਤੇ ਇਨ੍ਹਾਂ ਨੂੰ ਸ਼ਾਮਲ ਕਰਨ ਵਾਲਾ ਫਰਮਵੇਅਰ ਚਾਹੀਦਾ ਹੈ। Zebra
ਅਪ੍ਰੈਲ 2025 ਤੋਂ ਫਰਮਵੇਅਰ ਅੱਪਡੇਟਾਂ ਰਾਹੀਂ GS1 Digital Link ਸਮਰਥਨ ਜੋੜ ਰਹੀ ਹੈ; ਹੇਠਲੀਆਂ ਤਾਰੀਖ਼ਾਂ ਇੱਕ Zebra
ਮੁੜ-ਵਿਕਰੇਤਾ ਤੋਂ ਲਈਆਂ ਗਈਆਂ ਹਨ, ਇਸ ਲਈ ਹਰ ਮਾਡਲ ਦੇ ਫਰਮਵੇਅਰ ਰਿਲੀਜ਼ ਨੋਟ ਜਾਂਚੋ:
