GAIA Desktop மாதிரிகள்

ஒவ்வொரு பொதுவான GS1 தரவு கேரியருக்கும் ஒரு பார்கோடு, GAIA நிராகரிக்கும் இரண்டு, மேலும் இணைப்புக்காக ஒரு பாரம்பரிய லேபிள். Zebra ஸ்கேனர் மூலம் இவற்றை நேரடியாகத் திரையிலிருந்து ஸ்கேன் செய்யுங்கள், அல்லது ஓர் உறுப்பு சரத்தை GAIA Desktop உள்ளீட்டுப் பட்டியில் நகலெடுங்கள்.

ஒவ்வொரு உறுப்பு சரமும் அதன் AIM Code ID உடன் தொடங்குகிறது; ஸ்கேன் எந்தத் தரவு கேரியரிலிருந்து வந்தது என்பதை அது GAIA-க்குத் தெரிவிக்கிறது. {GS} என்பது FNC1 ஐக் குறிக்கிறது, அதாவது மாறுபடும் நீளமுள்ள AI-க்குப் பின் வரும் பிரிப்பான்; உள்ளீட்டுப் பட்டி அதை உண்மையான எழுத்தாக மாற்றுகிறது. பார்கோடு படங்களை TEC-IT இன் ஆன்லைன் பார்கோடு ஜெனரேட்டர் வரைகிறது, எனவே இந்தப் பக்கத்தைத் திறந்தால் மாதிரித் தரவு அதற்கு அனுப்பப்படும். அதிகப் பயன்பாட்டின்போது பார்கோடுக்குப் பதிலாகக் கோரிக்கை வரம்பு அறிவிப்பைக் காட்டலாம்; பின்னர் மீண்டும் ஏற்றுங்கள்.

பகுப்பாய்வு

பகுப்பாய்வு பயன்முறையில், ஒவ்வொரு ஸ்கேனும் ஒட்டப்பட்ட உரையும் அதன் Application Identifiers ஆகப் பிரிக்கப்படுகிறது. கடைசி இரண்டு அட்டைகள் GAIA கண்டுபிடிக்கும் தவறுகள்: ஒவ்வொன்றும் GAIA அறிவிக்கும் பிழைகளைக் குறிப்பிடுகிறது.

இணைப்பு

ஒரு பாரம்பரிய சரக்குப் போக்குவரத்து லேபிள் தன் தரவைப் பல GS1-128 பார்கோடுகளில் கொண்டுள்ளது. இணைப்பு பயன்முறையில் அவற்றில் அதிகபட்சம் மூன்றை ஸ்கேன் செய்யுங்கள்; GAIA Desktop அவற்றின் AI-களை ஒரு GS1 DataMatrix கொண்டிருக்கும் ஒற்றை உறுப்பு சரமாக இணைத்து, முழுமையாகச் சரிபார்க்கிறது. இந்த மூன்றையும் வரிசையாக ஸ்கேன் செய்யுங்கள்:
