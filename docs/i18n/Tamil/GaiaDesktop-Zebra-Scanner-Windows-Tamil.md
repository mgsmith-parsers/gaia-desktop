# Zebra ஸ்கேனர் அமைப்பு — Windows-க்கான GAIA Desktop

GAIA Desktop ஒரு Zebra பார்கோடு ஸ்கேனரிலிருந்து GS1 பார்கோடுகளை நேரடியாகப் படிக்கும்படி அதை
நிறுவி அமைப்பது எப்படி என்பதை இந்த வழிகாட்டி விளக்குகிறது: ஒவ்வொரு ஸ்கேனும் பகுப்பாய்வு
செய்யப்பட்டு வரலாற்றில் சேர்க்கப்படும்; AIM Code ID முன்னொட்டும் ஒவ்வொரு FNC1 பிரிப்பானும்
மாறாமல் இருக்கும். மூல ஆவணம் (ஆங்கிலம்):
[GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md).

GAIA Desktop, USB வழியாக இணைக்கப்பட்ட **Zebra DS8108** கையடக்க இமேஜருடன் உருவாக்கப்பட்டுச்
சோதிக்கப்பட்டது. Zebra-வின் Scanner SDK ஆதரிக்கும் எந்த Zebra 2D ஸ்கேனருக்கும் இந்தப் படிகள்
பொருந்தும்; ஒரு குறிப்பிட்ட மாதிரியின் அமைப்புப் பார்கோடுகளும் மெனுப் பெயர்களும் அதன் சொந்த
Quick Reference Guide அல்லது Product Reference Guide-இல் உள்ளன.

> **Windows-இல் மட்டும்.** Zebra-வின் ஸ்கேனர் இயக்கிகள் Windows-க்கு மட்டுமே உள்ளன; ஆகவே macOS
> அல்லது Linux-இல் GAIA Desktop எந்த ஸ்கேனர் கட்டுப்பாடுகளையும் உருவாக்குவதில்லை. செயலியின்
> மற்ற எல்லாமும் எல்லா இயங்குதளங்களிலும் வேலை செய்யும்.

| **GAIA Desktop** | `gaia-desktop-1.0.0-win.zip` |
| **விருப்பத்தேர்வு** | ஸ்கேனரின் **Product Reference Guide** (PRG) — அமைப்புப் பார்கோடுகள் அதில் உள்ளன |

பகுதிகள் எப்படி இணைகின்றன:

```
Zebra scanner ──USB──► Zebra CoreScanner driver ──► Zebra JavaPOS services ──► GAIA Desktop
                       (installed by the SDK)        (in the SDK's JPOS\bin)    (run.bat puts them on
                                                                                 the class path)
```

JavaPOS API-யையும், ஸ்கேனருக்குப் பெயரிடும் அமைப்பையும் (`gaia-desktop.jar`-க்குள் உள்ள
`jpos.xml`) GAIA Desktop தானே கொண்டுள்ளது. மீதியை Zebra SDK வழங்குகிறது: ஸ்கேனருடன் பேசும்
இயக்கியும், JavaPOS-க்கும் அந்த இயக்கிக்கும் இடையே இருக்கும் Zebra சேவை வகுப்புகளும்.

## 2. Java-வை நிறுவுதல்

GAIA Desktop-க்கு **Java 21 அல்லது புதியது** தேவை; 64-பிட் Zebra இயக்கிகளுடன் பொருந்த, அது
**64-பிட்** பதிப்பாக இருக்க வேண்டும்.

1. Windows x64-க்கான Java 21 JDK அல்லது JRE-ஐ நிறுவுங்கள் — உதாரணமாக adoptium.net-இலிருந்து
   Eclipse Temurin. நிறுவி `JAVA_HOME`-ஐ அமைக்க முன்வந்தால், அமைக்க விடுங்கள்.
2. Command Prompt-இல் சரிபாருங்கள்:

   ```
   java -version
   ```

   முதல் வரி பதிப்பு 21 அல்லது அதற்குப் பிந்தையதைக் காட்ட வேண்டும்; 64-பிட் Java
   `64-Bit Server VM` என்றும் காட்டும்.

`run.bat` இந்த வரிசையில் Java-வைத் தேடுகிறது: `run.bat`-க்கு அருகிலுள்ள `jdk*` கோப்புறை, பிறகு
`JAVA_HOME`, பிறகு `PATH`-இல் உள்ள `java`. 21-ஐ விடப் பழையதை, அதைச் சொல்லும் செய்தியுடன் மறுக்கிறது.

## 3. Zebra Scanner SDK-ஐ நிறுவுதல்

1. Zebra-வின் ஆதரவுத் தளத்திலிருந்து **Windows-க்கான Zebra Scanner SDK (64-பிட்)**-ஐப்
   பதிவிறக்குங்கள்.
2. நிறுவியை இயக்குங்கள். கூறுகளைத் தேர்ந்தெடுக்க வாய்ப்பு இருந்தால், **JPOS** (JavaPOS) கூறு
   சேர்க்கப்பட்டுள்ளதா என்று உறுதிசெய்யுங்கள்.
3. இயல்புநிலை நிறுவல் இடத்தையே வைத்திருங்கள். GAIA Desktop, SDK-யின் JavaPOS பகுதியை இங்கே
   தேடுகிறது:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   அதன் `bin\` கோப்புறையில் Zebra-வின் சேவை jar-களும் (`JposServiceScanner.jar`,
   `JposServiceJniScanner.jar`, …) நேட்டிவ் நூலகங்களும் (`CSJPOSScanner64.dll`, …) இருக்கும் என்று
   எதிர்பார்க்கிறது. SDK வேறு இடத்தில் நிறுவப்பட்டிருந்தால், [ZEBRA_HOME](#zebra_home) பார்க்கவும்.
4. நிறுவிய பிறகு **Windows-ஐ மறுதொடக்கம் செய்யுங்கள்**. SDK-யின் CoreScanner இயக்கி பின்னணியில்
   இயங்குகிறது; GAIA Desktop ஸ்கேனரை அணுகுவதற்கு முன் அது இயங்கிக்கொண்டிருக்க வேண்டும். அதை
   உறுதிசெய்ய எளிய வழி மறுதொடக்கம்தான்.

## 4. 123Scan-ஐ நிறுவுதல்

123Scan என்பது Zebra தன் ஸ்கேனர்களை அமைப்பதற்கான இலவசக் கருவி. அடுத்த படியில் ஸ்கேனரின்
ஃபர்ம்வேரைப் புதுப்பிக்க இது பயன்படுகிறது; அதன் பிறகு ஸ்கேனரின் அமைப்புகளைச் சரிபார்க்கவும்
மாற்றவும் இதுவே எளிய வழி.

1. Zebra-வின் ஆதரவுத் தளத்திலிருந்து **123Scan**-ஐப் பதிவிறக்கி, நிறுவியை இயக்குங்கள்.
2. Zebra ஸ்கேனரை இணைத்து 123Scan-ஐத் தொடங்குங்கள். அது ஸ்கேனரைக் கண்டறிந்து, அதன் மாதிரி,
   வரிசை எண், தற்போதைய ஃபர்ம்வேர் பதிப்பு ஆகியவற்றைக் காட்ட வேண்டும். காட்டவில்லை என்றால்,
   தொடர்வதற்கு முன் வேறு USB போர்ட் அல்லது கேபிளை முயலுங்கள் — 123Scan காணாத ஸ்கேனரை
   GAIA Desktop-உம் காணாது.

## 5. Zebra ஸ்கேனரின் ஃபர்ம்வேரைப் புதுப்பித்தல்

அமைப்பதற்கு முன், ஸ்கேனரின் ஃபர்ம்வேரை அண்மைய பதிப்புக்குக் கொண்டு வாருங்கள். ஃபர்ம்வேர்
புதுப்பிப்புகள் டிகோடிங் சிக்கல்களைச் சரிசெய்கின்றன; SDK நிறுவிய Zebra இயக்கியுடன் ஸ்கேனரை
ஒத்திசைவாக வைத்திருக்கின்றன.

1. **GAIA Desktop**-ஐயும், ஸ்கேனரைப் பயன்படுத்தக்கூடிய வேறு எந்த நிரலையும் மூடுங்கள்:
   புதுப்பிப்பின்போது 123Scan-க்கு ஸ்கேனர் தனக்கு மட்டுமே வேண்டும்.
2. 123Scan-இல், ஸ்கேனர் இணைந்திருக்கும் நிலையில், அதன் ஃபர்ம்வேர் புதுப்பிப்பு விருப்பத்தைத்
   தேர்ந்தெடுங்கள். 123Scan, ஸ்கேனரின் ஃபர்ம்வேரை Zebra வெளியிட்ட அண்மைய பதிப்புடன் ஒப்பிட்டு,
   அதைப் பதிவிறக்கி நிறுவ முன்வருகிறது. கணினிக்கு இணைய அணுகல் இல்லையென்றால், Zebra-வின் தளத்தில்
   அந்த ஸ்கேனரின் ஆதரவுப் பக்கத்திலிருந்து ஃபர்ம்வேரைப் பதிவிறக்கி, அந்தக் கோப்பை 123Scan-இல்
   ஏற்றுங்கள்.
3. புதுப்பிப்பைத் தொடங்கி, **123Scan முடிந்ததாகத் தெரிவிக்கும் வரை ஸ்கேனரை இணைப்பிலேயே
   வைத்திருங்கள்**. இதற்குச் சில நிமிடங்கள் ஆகும்; இறுதியில் ஸ்கேனர் மறுதொடக்கம் ஆகும்.
   இடையில் துண்டித்தால் ஸ்கேனர் பயன்படுத்த முடியாமல் போகலாம்.
4. 123Scan இப்போது புதிய ஃபர்ம்வேர் பதிப்பைக் காட்டுகிறதா என்று சரிபாருங்கள்.

ஒரு புதுப்பிப்பு சில அமைப்புகளை இயல்புநிலைக்குத் திருப்பலாம்; அதனால்தான் ஃபர்ம்வேருக்குப்
பிறகு, அடுத்த இரண்டு படிகளில் ஸ்கேனர் அமைக்கப்படுகிறது.

## 6. Zebra ஸ்கேனரின் USB முறையை அமைத்தல்

பெரும்பாலும் தவறவிடப்படும் படி இதுதான். **பெட்டியிலிருந்து எடுத்தவுடன் Zebra ஸ்கேனர் ஒரு USB
விசைப்பலகையாக நடந்துகொள்கிறது** (USB HID Keyboard முறை): ஒவ்வொரு பார்கோடையும் கவனம் உள்ள
இடத்தில் "தட்டச்சு" செய்கிறது. அந்த முறையில் GAIA Desktop-இன் *ஸ்கேனரை இணை* அதைக் கண்டுபிடிக்க
முடியாது; உரைப் புலத்தில் தட்டச்சு செய்யப்படும் எதுவும் அதன் FNC1 பிரிப்பான்களை இழக்கிறது —
இது ஒரு GS1 எலிமெண்ட் சரத்தின் பொருளையே மாற்றிவிடும்.

Zebra இயக்கி நேரடியாகப் பேசும் ஒரு முறைக்கு ஸ்கேனரை மாற்றுங்கள்:

| ஸ்கேனரின் USB முறை | GAIA Desktop சாதனப் பெயர் | குறிப்புகள் |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld`, அல்லது `ZebraAllScanners` | பரிந்துரைக்கப்படுகிறது |
| SNAPI (இமேஜிங்குடன் அல்லது இல்லாமல்) | `ZebraScannerSNAPI`, அல்லது `ZebraAllScanners` | Zebra-வின் சொந்த USB நெறிமுறை; இதுவும் வேலை செய்யும் |
| IBM Table-top USB | `ZebraUSBTableTop`, அல்லது `ZebraAllScanners` | மேசை வகை ஸ்கேனர்களுக்கானது |
| USB OPOS (Hand-held) | `ZebraUSBOPOS`, அல்லது `ZebraAllScanners` | |
| USB HID Keyboard (தொழிற்சாலை இயல்புநிலை) | — | **இணையாது** |

GAIA Desktop-இன் இயல்புநிலைச் சாதனப் பெயரான `ZebraAllScanners`, ஆதரிக்கப்படும் எந்த முறையில்
உள்ள ஸ்கேனரையும் ஏற்கிறது; ஆகவே முறையை அமைத்த பிறகு பொதுவாக இயல்புநிலையே போதும்.

முறையை மாற்ற, இவற்றில் ஒன்றைச் செய்யுங்கள்:

- ஸ்கேனரின் Quick Reference Guide அல்லது Product Reference Guide-இல் (USB Host Types / USB
  Device Type பகுதி) அந்த முறைக்கான — உதாரணமாக *IBM Hand-held USB* — **அமைப்புப் பார்கோடை
  ஸ்கேன் செய்யுங்கள்**; ஸ்கேனர் பீப் ஒலியால் உறுதிப்படுத்தும். அல்லது
- **123Scan-ஐப் பயன்படுத்துங்கள்** ([படி 4](#4-123scan-ஐ-நிறுவுதல்)): ஸ்கேனரை இணைத்து, அதன் அமைப்பைத்
  திறந்து, USB ஹோஸ்ட் வகையை அமையுங்கள்.

முறையை மாற்றிய பிறகு, Windows ஸ்கேனரை வேறு வகைச் சாதனமாக மீண்டும் கண்டறிகிறது; இணைப்பதற்கு
முன் சில வினாடிகள் கொடுங்கள்.

பின்னர் ஸ்கேனரை விசைப்பலகை முறைக்குத் திருப்ப — வேறு மென்பொருளுடன் பயன்படுத்த —
*USB Keyboard (HID)* அமைப்புப் பார்கோடை ஸ்கேன் செய்யுங்கள், அல்லது தொழிற்சாலை இயல்புநிலைகளை
மீட்டமையுங்கள்.

## 7. GS1-க்காக Zebra ஸ்கேனரை அமைத்தல்

எந்த வகைப் பார்கோடைப் படித்தது என்று ஸ்கேனர் சொல்லும்போது GAIA Desktop சிறப்பாகப் பகுப்பாய்வு
செய்கிறது.

### AIM Code ID-ஐ அனுப்புதல்

Product Reference Guide-இல் (User Preferences) உள்ள அமைப்புப் பார்கோடு மூலமாகவோ 123Scan-இலோ,
**Transmit Code ID Character**-ஐ **AIM Code ID Character** என அமையுங்கள். அப்போது ஒவ்வொரு ஸ்கேனும்
அதன் குறியீட்டு முறை அடையாளத்துடன் தொடங்கும் — GS1-128-க்கு `]C1`, GS1 DataMatrix-க்கு `]d2`,
GS1 QR Code-க்கு `]Q3`, GS1 DataBar-க்கு `]e0` — இதை வைத்து GAIA Desktop தரவு கேரியரை (data
carrier) அடையாளம் கண்டு, அதற்கான விதிகளைப் பயன்படுத்துகிறது.

இது இல்லாமலும் GAIA Desktop எலிமெண்ட் சரத்தைப் பகுப்பாய்வு செய்து, குறியீட்டு முறையை ஸ்கேனிலிருந்தே
எடுக்கும்; ஆனால் அறிக்கையில் காட்ட AIM Code ID இருக்காது, மேலும் EAN-13 போன்ற எளிய பார்கோடை ஒரு
GS1 எலிமெண்ட் சரத்திலிருந்து வேறுபடுத்துவது கடினமாகும்.

### குறியீட்டு முறைகளைச் சரிபார்த்தல்

நீங்கள் பயன்படுத்தும் பார்கோடு வகைகள் **இயக்கப்பட்டுள்ளனவா** என்று உறுதிசெய்யுங்கள்: பொதுவாக
GS1-128, GS1 DataMatrix, GS1 DataBar, GS1 QR Code, EAN/UPC. Zebra 2D ஸ்கேனர்களில் பெரும்பாலானவை
இயல்பாகவே இயக்கத்தில் இருக்கும்; தற்போதைய அமைப்புகளை 123Scan காட்டுகிறது, ஒவ்வொன்றையும் இயக்க
Product Reference Guide-இல் ஒரு பார்கோடு உள்ளது.

### Zebra-வின் GS1 பகுப்பாய்வு அம்சங்களை அணைத்தே வையுங்கள்

அண்மைய ஃபர்ம்வேர், ஸ்கேனருக்குள்ளேயே வேலை செய்யும் GS1 அம்சங்களைச் சேர்க்கிறது —
**Label Parse+**, **GS1 Digital Link**, **GS1 Retail POS parsing**. ஸ்கேனர் வரும் நிலையிலேயே
அவற்றை **அணைத்து** வையுங்கள்: அவை ஸ்கேனர் அனுப்புவதை மறுவடிவமைக்கின்றன அல்லது சுருக்குகின்றன;
பகுப்பாய்வு செய்து சரிபார்க்க GAIA Desktop-க்கு மூலத் தரவு தேவை. ஒவ்வொன்றும் என்ன செய்கிறது என்பதற்கு
[ஆதரிக்கப்படும் Zebra 2D ஸ்கேனர்கள்](#12-ஆதரிக்கப்படும்-zebra-2d-ஸ்கேனர்கள்) பார்க்கவும்.

### முன்னொட்டுகளையும் பின்னொட்டுகளையும் சேர்க்காதீர்கள்

ஸ்கேனரின் வெளியீட்டில் முன்னொட்டு, பின்னொட்டு அல்லது Enter விசையைச் சேர்க்காதீர்கள். GAIA Desktop
ஒவ்வொரு ஸ்கேனையும் JavaPOS வழியாக முழுமையான செய்தியாகப் பெறுகிறது; அவற்றில் எதுவும் தேவையில்லை.
கூடுதல் எழுத்துகள் எலிமெண்ட் சரத்துக்குள் போய்ச் சேரும்.

## 8. GAIA Desktop-ஐ நிறுவித் தொடங்குதல்

1. `gaia-desktop-1.0.0-win.zip`-ஐ, உதாரணமாக `C:\Tools\`-இல், பிரித்தெடுங்கள். அதில் ஒரு கோப்புறை
   உள்ளது:

   ```
   gaia-desktop-1.0.0-win\
   ├── docs\
   │   └── GaiaDesktop-Zebra-Scanner-Windows.md      this guide
   ├── gaia-desktop.jar
   ├── lib\
   ├── readme.html                                   index of every guide
   └── run.bat
   ```

2. ஸ்கேனரை இணையுங்கள்.
3. **`run.bat`**-ஐ இருமுறை கிளிக் செய்யுங்கள். செயலிக்கு அருகில் ஒரு கன்சோல் சாளரம் திறந்து
   திறந்தபடியே இருக்கும்: ஸ்கேனர் நிலையும் JavaPOS பிழைகளும் அங்கே தெரிவிக்கப்படும்.
4. கன்சோலின் முதல் வரியைப் படியுங்கள். `run.bat` எதைக் கண்டது என்று அது சொல்கிறது:

   ```
   run.bat: Java 21.0.8 from JAVA_HOME; JavaFX from lib\; JavaPOS from lib\; Zebra services from C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   அது **`Zebra services from none (Zebra Scanner SDK not installed)`** என்று முடிந்தால், SDK
   அதன் இயல்புநிலை இடத்தில் கண்டறியப்படவில்லை — அதை நிறுவுங்கள்
   ([படி 3](#3-zebra-scanner-sdk-ஐ-நிறுவுதல்)) அல்லது [ZEBRA_HOME](#zebra_home)-ஐ அமையுங்கள்.
   செயலி தொடங்கும், ஆனால் ஸ்கேனர் இணைய முடியாது.

## 9. ஸ்கேனரை இணைத்தல்

1. கருவிப் பட்டையில் உள்ள **சாதனத் தேர்வுப் பட்டியல்**, GAIA Desktop அறிந்த ஸ்கேனர் பெயர்களைக்
   காட்டுகிறது. அதை **`ZebraAllScanners`**-இலேயே விடுங்கள், அல்லது
   [படி 6](#6-zebra-ஸ்கேனரின்-usb-முறையை-அமைத்தல்)-இன் அட்டவணையிலிருந்து ஸ்கேனரின் USB முறைக்கான
   பெயரைத் தேர்ந்தெடுங்கள்.
2. **ஸ்கேனரை இணை**-ஐக் கிளிக் செய்யுங்கள், அல்லது **Ctrl+K**-ஐ அழுத்துங்கள்
   (**ஸ்கேனர்** மெனுவிலும் உள்ளது).
3. நிலைப் பட்டை **`ஸ்கேனர்: ZebraAllScanners`** (அல்லது நீங்கள் தேர்ந்த பெயர்) என
   மாறுகிறது; நிலை வரி *ஸ்கேனர் இணைக்கப்பட்டது — ZebraAllScanners* எனத் தெரிவிக்கிறது. பொத்தான்
   இப்போது **ஸ்கேனரைத் துண்டி** எனக் காட்டுகிறது.
4. ஒரு GS1 பார்கோடை ஸ்கேன் செய்யுங்கள். அது கைப்பற்றல் வரலாற்றின் மேலே தோன்றி, அதன் அறிக்கை
   திறக்கிறது. AIM Code ID இயக்கத்தில் இருந்தால், அறிக்கை தரவு கேரியரைப் பெயரிடுகிறது —
   *GS1-128*, *GS1 DataMatrix* — எலிமெண்ட் சரம் ஒவ்வொரு FNC1 பிரிப்பானையும் வைத்திருக்கிறது.

சாதனத் தேர்வுப் பட்டியல் உங்கள் தேர்வை அடுத்த முறைகளுக்கும் நினைவில் வைக்கிறது. நீங்கள் துண்டிக்கும்
வரை அல்லது செயலியை மூடும் வரை ஸ்கேனர் இணைந்தே இருக்கும். **உருவாக்கம்**, **இணைப்பு**
முறைகளிலும் ஸ்கேன்கள் வேலை செய்யும்: இணைப்பு முறையில், ஒவ்வொரு ஸ்கேனும் இணைக்கப்படும்
பார்கோடுகளில் ஒன்றாகிறது.

GAIA Desktop ஸ்கேனரைப் பிடித்திருக்கும்போது மற்ற நிரல்களால் அதைப் பயன்படுத்த முடியாது; நேர்மாறாகவும்
அப்படியே: இணைப்பதற்கு முன் 123Scan-ஐயும் வேறு எந்த விற்பனை முனைய (POS) அல்லது ஸ்கேனர்
மென்பொருளையும் மூடுங்கள்.

## 10. அமைப்புக் குறிப்பு

### சாதனப் பெயர்கள்

சாதனத் தேர்வுப் பட்டியல், `gaia-desktop.jar`-இல் உள்ள `jpos.xml`-இலிருந்து நிரப்பப்படுகிறது. அதன்
ஸ்கேனர் உள்ளீடுகள்:

| சாதனப் பெயர் | ஸ்கேனர் வகை | எதனுடன் பயன்படுத்துவது |
|---|---|---|
| `ZebraAllScanners` | எதுவும் | **இயல்புநிலை.** ஆதரிக்கப்படும் எந்த USB முறையும் |
| `ZebraAllScanners114` | எதுவும் | அதே சேவையின் JavaPOS 1.14 பதிப்பு |
| `ZebraUSBHandHeld` | IBM Hand-held USB | IBM Hand-held USB முறையில் உள்ள ஸ்கேனர் |
| `ZebraUSBTableTop` | IBM Table-top USB | மேசை வகை முறை |
| `ZebraUSBOPOS` | USB OPOS | USB OPOS முறை |
| `ZebraScannerSNAPI` | SNAPI | SNAPI முறை |
| `ZebraScannerUSB` | எந்த USB-யும் | எந்த USB முறையும் |
| `ZebraScannerSerialSSI` | சீரியல் SSI | சீரியல் கேபிள் ஸ்கேனர்கள் (USB அல்ல) |
| `ZebraScannerSerialNIXMODB` | சீரியல் NIXMODB | சீரியல் கேபிள் ஸ்கேனர்கள் |
| `ZebraVDI` | VDI | மெய்நிகர் டெஸ்க்டாப்புக்கு அனுப்பப்படும் ஸ்கேனர்கள் |

### ZEBRA_HOME

Zebra SDK இயல்புநிலை அல்லாத வேறு இடத்தில் நிறுவப்பட்டிருந்தால், `run.bat`-ஐத் தொடங்குவதற்கு முன்
`ZEBRA_HOME`-ஐ அதன் `JPOS` கோப்புறைக்கு அமையுங்கள் — உதாரணமாக அதன் அருகில் வைக்கும் ஒரு சிறிய
batch கோப்பில்:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

அப்போது `run.bat`, Zebra-வின் சேவை jar-களை `%ZEBRA_HOME%bin`-இலிருந்து எடுத்து, Zebra DLL-களுக்காக
அந்தக் கோப்புறையை `PATH`-இல் சேர்க்கிறது.

### உங்கள் சொந்த jpos.xml

ஒரு சாதனப் பெயரைச் சேர்க்க அல்லது ஒரு உள்ளீட்டின் அமைப்புகளை மாற்ற, `gaia-desktop.jar`-இலிருந்து
`jpos.xml`-ஐ நகலெடுங்கள் (அது ஒரு zip; எந்தப் பிரித்தெடுக்கும் கருவியும் அதைத் திறக்கும்), நகலைத்
திருத்தி, GAIA Desktop-க்கு அதைச் சுட்டுங்கள்:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

அப்போது சாதனத் தேர்வுப் பட்டியல் அந்தக் கோப்பிலுள்ள ஸ்கேனர்களைக் காட்டும். ஒன்றுக்கு மேற்பட்ட Zebra
ஸ்கேனர்கள் இணைந்திருந்தால், `ZebraAllScanners` உள்ளீட்டில் உள்ளதுபோல, ஒரு உள்ளீட்டை அதன்
`ScannerModel` அல்லது `SerialNumber` பண்பின் மூலம் அவற்றில் ஒன்றுடன் இணைக்கலாம்.

## 12. ஆதரிக்கப்படும் Zebra 2D ஸ்கேனர்கள்

GS1 தரவு அச்சிடப்படும் பார்கோடுகளைப் படிக்கக்கூடிய ஸ்கேனர் GAIA Desktop-க்குத் தேவை — GS1-128,
GS1 DataBar, EAN/UPC, மேலும் பெரும்பாலான பயன்பாடுகளுக்கு 2D குறியீடுகளான **GS1 DataMatrix**,
**GS1 QR Code** (ஒரு **GS1 Digital Link** URI பொதுவாக இந்த வடிவில்தான் அச்சிடப்படுகிறது). அதாவது
ஒரு Zebra **2D இமேஜர்**: நேர்கோட்டு (1D) ஸ்கேனரால் DataMatrix அல்லது QR குறியீடுகளைப் படிக்கவே
முடியாது.

GS1 Application Identifier-களையோ Digital Link-ஐயோ ஸ்கேனர் தானே புரிந்துகொள்ள வேண்டியதில்லை.
**இரண்டையும் GAIA Desktop பகுப்பாய்வு செய்கிறது**: ஸ்கேனர் படித்தபடியே ஸ்கேனை — AIM Code ID,
FNC1 பிரிப்பான்கள் உட்பட — எடுத்து, AI-களாகப் பிரிக்கிறது, அல்லது ஒரு Digital Link URI-யை
அதன் AI-களாகத் தானே மாற்றுகிறது.

**GS1 Digital Link** அமைப்புக்கு மூன்று முறைகள் உள்ளன. இயக்கியவுடன் தொடங்கும் முறையான
**Mode 1 — GTIN only**, எந்தப் பார்கோடிலிருந்து வந்தாலும் GTIN-ஐ மட்டுமே அனுப்புகிறது; ஆகவே Digital
Link-இல் உள்ள தொகுதி எண், காலாவதித் தேதி அல்லது வரிசை எண் ஒருபோதும் GAIA Desktop-ஐ அடையாது.
**Mode 2 — Prioritize 2D**, முன்னுரிமை நேர வரம்புக்குள் (இயல்பாக 200 ms) 2D குறியீடு தென்பட்டால்
அதையும், இல்லையெனில் 1D-ஐயும் அனுப்புகிறது. **Mode 3 — Corroborate 1D and 2D GTINs Match**,
1D-ஐ அனுப்புகிறது; அதன் GTIN பொருந்தினால் 2D-ஐயும் அனுப்புகிறது. வேறு மென்பொருளுக்காக இந்த அமைப்பு
இயக்கத்தில் இருக்க வேண்டியிருந்தால், Mode 1 அல்ல, Mode 2-ஐப் பயன்படுத்துங்கள். DS8108-இல் இவை
அளவுருக்கள் 2373 (இயக்கு/அணை), 2374 (முறை), 2491 (நேர வரம்பு).

இந்த அம்சங்களைப் பயன்படுத்த **123Scan பதிப்பு 6 அல்லது புதியது**-ம், அவற்றை உள்ளடக்கிய ஃபர்ம்வேரும்
தேவை. 2025 ஏப்ரல் முதல் Zebra, ஃபர்ம்வேர் புதுப்பிப்பு மூலம் GS1 Digital Link ஆதரவைச் சேர்த்து
வருகிறது; கீழே உள்ள தேதிகள் ஒரு Zebra மறுவிற்பனையாளரிடமிருந்து வந்தவை, ஆகவே ஒவ்வொரு மாதிரியின்
