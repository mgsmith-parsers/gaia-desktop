GAIA Desktop 样例

每种 GS1 数据载体各有一只条码，另外还有一张拨“合并”用个老式标签。侬可以用 Zebra 扫描器直接辣屏幕浪扫，或者拿元素串复制到 GAIA Desktop 个输入栏里。

每只元素串侪是从伊个 AIM Code ID 开始个，告诉 GAIA 搿趟扫描是从啥个数据载体来个。{GS} 代表 FNC1，就是跟辣变长 AI 后头个分隔符；输入栏会拿伊变成真正个字符。条码图片是 TEC-IT 个在线条码生成器画个，所以打开搿只页面，样例数据就会发拨伊。用个人多个辰光，伊可能会显示请求次数限制个提示，勿是条码；晏眼再重新加载。

解析

辣解析模式里，每趟扫描或者粘贴个内容侪会拆成伊个应用标识符（Application Identifier）。

合并
