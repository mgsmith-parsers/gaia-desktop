## 迭个是啥物事

GAIA Desktop 对牢 GS1 数据做三桩事体：

- **解析** — 敲进或者粘一条 GS1 元素字符串或者 Digital Link URI，也好从文件里向打开，也好扫进
  来，接下去把结果当一份完整报告看：每一个应用标识符（AI）是啥意思、啥地方错脱哉、为啥错；
- **构建** — 拿 AI 搭数值一对对拼起来，做出一条元素字符串或者 Digital Link URI；
- **合并** — 拿同一张标签上顶多三个 GS1-128 条码，合并成一个 GS1 DataMatrix 会装个
  单一元素字符串，一道检查，再画出符号来。

迭个程序晓得个关于 GS1 个一切 — 每个 AI 个定义、每条检查规则、每段错误消息、每处本地化细节 —
侪是从底下跑个 GAIA 引擎来个。程序自家呒没添过一条规则：引擎收啥，伊就收啥。

## 运行

```bash
java -jar gaia-desktop.jar
```

迭个 JAR 文件要用跟伊一道发个 `lib/` 目录 — 两样物事要摆勒一淘，否则程序起勿来。（也好构建一个
自包含个 JAR 文件；请看[开发者指南](../../GaiaDesktop-Developer.md#packaging)。）

要装**Java 21 或者更新个**。发行版是为某一个操作系统搭某一种处理器架构做个，所以要用为侬台机器
做个那个 JAR 文件。

若是想用某种语言打开程序，又勿想改脱已经存牢个语言：

```bash
java -jar gaia-desktop.jar --language=FR
```

数值好是目录代码（`FR`、`PCM`、`ARZ`）、全名（`FRENCH`、`WU-CHINESE`），或者语言标签（`fr`；
广东话用 `zh-HK`，埃及阿拉伯文用 `ar-EG`）— 大小写呒没分别。迭条指令只对该趟运行有效：侬存牢个
语言原封勿动，所以侬帮同事做个快捷方式，改勿脱侬自家该份用啥语言打开。勿过勒程序*里向*拣语言就
是真个选择，照常会存牢。至于指勿着任何语言个数值，程序会勒控制台留一句闲话，接下去当伊呒没，仍
旧用存牢个语言打开，勿会拒绝运行。

启动个辰光，控制台会打印一行，里向有程序版本、伊个构建日期搭引擎版本。报告问题个辰光，就是要附
上该一行。

## 解析模式

### 输入栏搭 {GS} 记号

迭条栏收元素字符串、GS1 Digital Link URI，或者连 AIM Code ID 前缀（`]d2…`）个原始扫描数据。
揿 <kbd>Enter</kbd> 就开始解析。

分隔长度勿定个 AI 个那个物事是 **FNC1** — 看勿见个控制字符 `0x1D`。呒没一个文本框揿得牢迭个字
符：伊会悄悄叫消脱，于是 `01…` + FNC1 + `10LOT` 到该面就变做 `01…10LOT` — 就是一条意思已经变
脱个元素字符串。

所以程序拿分隔符显示做看得见个记号 **`{GS}`**，接下去勒送到解析器个辰光再换回原来那个：

- **`{GS}` 按钮**勒光标位置插进记号；
- 侬**粘**真个分隔字符进去个辰光 — 用键盘、用右键菜单或者拖放 — 伊拉会自家变做 `{GS}`，所以
  呒没啥物事会丢脱；
- 记号个写法搭报告个写法一模一样，所以从报告里向复制出来个数值，好直接粘转去。

记录、报告搭存牢个历史 — 三样里向装个侪是**真个**分隔符。记号只是侬看着搭敲个那个。

### 扫描

> **只有 Windows。**Zebra 只为 Windows 出扫描器驱动程序，所以勒 macOS 搭 Linux，程序根本勿会做
> 任何扫描器控件 — 呒没*连接扫描器*按钮、呒没设备列表、呒没*扫描器*菜单、状态栏浪也呒没扫描器
> 状态。也勿会有物事灰脱显出来，因为根本呒没任何设置或者设备好拿伊启用。其余所有物事，包括打开
> 一个装满已存扫描数据个文件，勒啥地方侪用得着。

*连接扫描器*会打开列表里向指定个那台设备；`ZebraAllScanners` 是默认值，大部分型号侪合适。每趟
扫描侪会解析，也会自家添进历史。

扫描器个数据是一个字节一个字节读进来个，所以 AIM Code ID 前缀搭每一个 FNC1 分隔符，到解析器该
面搭扫描器送出来个辰光一模一样。

勒构建模式，扫描器控件会藏脱，勿过连牢个扫描器照旧跑：*扫描器 → 连接 / 断开*（<kbd>⌘K</kbd>）
照样切换得着，状态栏照样会讲，编辑器开牢个辰光扫进来个物事一样会记下来。 勒合并模式，迭眼控件留牢，每趟扫描侪加进合并，勿进历史。

头一趟设置扫描器——Zebra Scanner SDK、扫描器个 USB 模式搭 GS1 设置——勒
[Zebra 扫描器设置指南](GaiaDesktop-Zebra-Scanner-Windows-WuChinese.md)里向一步一步讲清爽，迭份指南勒每个 zip 个 `docs/` 里向侪有。 若是一台设备也连勿着，请看[疑难排解](#疑难排解)。

### 打开文件

*文件 → 打开文本文件…* 会拿**每一行勿是空个字侪当做一条单独记录**去解析 — 人家甩一大堆扫描数
据把侬，噉样处理最快。文件是一个字节一个字节读进来个，所以里向真个分隔符一样完完整整。

### 记录历史

新个勒上头。每一行有个有效 / 无效个圆点、一行摘要，旁边还有记录时间、伊个来源搭里向 AI 个数
目。日期只勒前几日个记录浪出；今朝该些行只有时间。

Digital Link 个摘要是 **Digital Link URI**，其余一律是 **HRI**：元素字符串来讲，看
`(01)09506000134352 (17)261231` 总归比看 `01095060001343521726123110…` 便当。

勒一条记录浪揿右键，好复制伊个输入或者 HRI、送转输入栏、勒编辑器里向打开、删脱伊，或者拿整个历
史清空。

## 构建模式

### AI 编辑器

一张 AI 搭数值成对个表格。敲一个 AI 代码，或者从*添加 AI…* 列表里向勒**引擎认得个所有 AI** 当
中拣；侬一路敲，**标题**、**格式**搭**描述**几列就一路用侬拣个语言填好。构建个辰光肯定要被拒个
AI，列表勿会拿出来把侬拣。

表格最后头永远留一行**空行**：勒里向写点啥，下一行就出来哉，所以要做一条多个 AI 个字符串，侬根
本永远用勿着*添加行*。

编辑个行为就是一张表格应该有个行为：<kbd>Enter</kbd>、<kbd>Tab</kbd>、
<kbd>Shift</kbd>+<kbd>Tab</kbd> 搭揿到别处 — 侪会**留牢**侬敲个物事；<kbd>Esc</kbd> 就丢脱伊。
<kbd>Tab</kbd> 从 AI 走到数值，再走到下一行，跳过改勿了个几列。

### 编辑器勿收啥

| | 会哪能 |
|---|---|
| 引擎勿认得个 AI | 侬一路敲，该行就变红；构建被拒，同时讲清爽为啥 |
| 从列表里向再拣第二趟同一个 AI | 添勿进 — 消息会讲出伊个名字，本来已经有伊该行会被选牢 |
| 用手再敲一趟同一个 AI | 两行侪会标出来；构建以 `GE-S004` 错误被拒 |
| 呒没啥好构建 | 一段消息；勿会产生任何记录 |

一条元素字符串里向，同一个 AI 只好出现一趟 — 所以列表当场就拒脱侬，好过让侬去试一个肯定要败个
构建。

### 元素字符串还是 Digital Link

**构建元素字符串**会拿几行接起来，并且勒标准要求个每一处摆 FNC1 分隔符。**构建 Digital Link**
会做一条 URI 出来；若是想指到侬自家个解析器，勿用标准个 `id.gs1.org`，就打开*Digital Link 目
标*：

| 字段 | 作用 | 空脱就是 |
|---|---|---|
| 域名 | 解析器个主机，比方 `example.com` | `id.gs1.org` |
| 路径前缀 | AI 路径前头该一截，比方 `/products` | 呒没前缀 |

**成功**个闲话，结果个行为搭一趟扫描一模一样：会解析、会进历史、会当报告显出来、也会存牢。构建
是拿自家个结果解析转来检查个，所以伊交出来个物事肯定有效。

**失败**个闲话，啥物事也勿会记下来。原因会留勒构建几只按钮底下 — 每个问题一行，每行侪有错误
码、有关个那个 AI，搭引擎自家个解释：

```
GE-C003  (01)  Check digit validation failed for AI (01) value ''09506000134350''
```

> 该段消息里向个双引号勿是迭个程序加个，是引擎自家个错误目录本来就噉。

### 修改现有记录

勒一条记录浪揿右键 → **构建**，就会拿伊带进 AI 编辑器。改一个数值、再构建一趟，结果就变做一条
新记录出来 — 本来该条记录原封勿动。

## 合并模式

老一点个标签常庄拿数据分勒**几个 GS1-128 条码**上——一个放 GTIN，另一个放到期日脚搭批号——因为
一个线性条码装勿落全部。合并顶多收**三个**迭种条码，拿伊拉合并成一个
**GS1 DataMatrix** 会装个单一元素字符串，再一道检查。结果有效以后，程序就画出 DataMatrix 符号。

迭眼条码呒没一个要自家就齐全。缺脱 GTIN 个批号单独检查会以 `GE-S005` 勿合格，勿过对一套条码里
向个一个来讲迭个蛮正常，所以合并改成勒合并结果上检查伊。

### 合并栏

换到**合并**以后，输入栏会换成窗口底下个一条栏。记录历史让开，因为
合并模式个扫描勿是记录，也从来勿进历史。报告区改成显示合并报告：

```
┌────────────────────────────────────────────────────────────────────┐
│ [Parse|Build|Combine]   (scanner controls, on Windows)   Options   │
├────────────────────────────────────────────────────────────────────┤
│ Combine report                                   │ Options panel   │
├────────────────────────────────────────────────────────────────────┤
│ [Reset] [Remove Last] │ Barcode: [ …………………………………………… ] [Add]       │
├────────────────────────────────────────────────────────────────────┤
│ 2 of 3 GS1-128 barcodes                                   [About]  │
└────────────────────────────────────────────────────────────────────┘
```

条码有两种办法进来：

- **扫伊。** 勒 Windows 上，合并模式里扫描器控件留勒工具栏，每趟扫描直接进合并，
  勿进历史。
- **打或者贴**进 *条码* 栏，再揿 <kbd>Enter</kbd> 或者
  **添加**。FNC1 写成 **`{GS}`**，搭输入栏一样。打个辰光呒没 AIM Code ID 个条码，
  当 GS1-128 来处理。

| 按钮 | 做啥 |
|---|---|
| **添加** | 加进栏里向个条码 |
| **拿脱最后一个** | 拿脱最近加个条码（呒没条码个辰光用勿来） |
| **重置** | 拿脱所有条码，清空栏搭任何拒收，重新开始 |

状态栏一直会讲现在捏牢几个条码（*GS1-128 条码 2/3*），或者上一个为啥拨拒收。

### 合并会拒收啥

拨拒收个条码勿会加进去。报告搭状态栏侪会讲原因：

| 条码 | 拒收原因 |
|---|---|
| 空个栏 | 呒没物事好加 |
| 第四个条码 | 一张标签顶多由三个条码合并。拿脱最后一个，或者重置 |
| 照 AIM Code ID 看是别个符号体系 | 只合并 GS1-128，所以 GS1 DataMatrix（`]d2`）或者 QR Code 会拨拒收，连带伊个名字 |
| 读勿出个 AI | 语法错误；会显示引擎个错误代码搭消息 |
| 一个 AI 也呒没 | 呒没物事好合并 |
| 已经扫过个 | 同一个元素字符串出现两趟，比方讲同一个条码又扫一趟；报告会讲伊重复了前头哪个条码 |

合并只拒收完全用勿来个物事。其他所有物事（错个校验位、勿对个日脚、缺脱个配套 AI）
侪收进来，勒合并结果上判断。

### 重复搭冲突

AI 照扫描个次序合并。两个条码有同一个 AI 个辰光：

- **值一样**：只留一趟，列勒 *重复——保留一趟* 下头，连带读着伊个条码；
- **值勿一样**：就是**冲突**。结论写 *冲突*，对勿上个值一个条码一个条码列出来，
  解决之前**啥也勿合并**。拿脱有问题个条码，或者重置。

### 合并报告

从上到下：

1. **结论**：*呒没扫描*、*冲突*、有效或者无效，搭捏牢几个条码。
2. **扫描**：每个条码原来个样子、伊个符号体系，搭拿脱 AIM Code ID 以后剩下来个元素字符串。只有合并
   结果再好定夺个问题，会标勒该个条码上，注明 *照合并结果判定*。
3. 有个闲话，**重复**搭**冲突**。
4. **合并结果**：元素字符串、伊个 HRI 搭长度，再是用有标注个纸带显示个合并输入，
   搭每个 AI 一张卡，排法搭[解析报告](#报告)一样。后首合并结果个每个错误搭警告侪列勒
   *校验* 下头。
5. **GS1 DataMatrix 符号**，下头有 HRI。只有合并结果有效再会画。勿然报告会讲为啥呒没画，省得
   勿当心印出一个无效个符号来。

比方讲，一张有两个条码个标签：

| 条码 | 装个物事 | 单独检查 |
|---|---|---|
| `]C10109506000134352` | (01) GTIN | 有效 |
| `]C11726123110LOT-ABC` | (17) 到期日脚、(10) 批号 | 两个 AI 侪是 `GE-S005`，照合并结果判断 |

伊拉合并成 `01095060001343521726123110LOT-ABC`，HRI 是
`(01)09506000134352 (17)261231 (10)LOT-ABC`，结果有效，所以会画出符号。AI `17` 是定长个，
所以后头勿要 FNC1。合并会勒标准要求个每个地方插进 FNC1。

只要捏牢一个条码，**保存报告** 就好像导出解析报告一样，拿合并报告导出成 HTML 或者
PDF（看[导出](#导出)）。HTML 文件名以 `gaia-combine-` 开头。

报告跟牢侬拣个语言搭主题。改解析选项或者语言，会重新检查捏牢个条码。换到解析或者
构建再换转来，条码还勒，勿过重新开过就呒没了：合并模式个条码勿保存。

## 报告

拣牢该条记录会当一份完整报告显出来：判定栏、切做一段段有名字个「带」个元素字符串、解析元数据、
每个 AI 一张卡片连伊个意思，还有错误搭警告连哪能修正个指引。

**Digital Link** 个辰光，每张 AI 卡片还会讲伊个结构角色 — **主键**、**键限定词**或者
**数据属性** — 用个颜色跟牢伊拉勒 URI 里向出现个次序。迭些角色只勒 Digital Link 里向看得着：
普通元素字符串里向，AI 勒 URI 浪根本呒没位置好讲。

报告跟牢侬拣个语言搭主题。

### 导出

| | |
|---|---|
| **保存报告 → 存为 HTML…**（<kbd>⌘S</kbd>） | 屏幕浪是哪能就写做哪能：一个自包含个文件，随便啥浏览器侪打得开 |
| **保存报告 → 存为 PDF…**（<kbd>⌘P</kbd>） | 经系统个打印对话框打印该份报告 — 勒该面拣 PDF 目标 |

PDF 要经打印对话框，因为位置搭文件名是勒该面拣个：macOS 拣 **PDF ▾ → Save as PDF**，Windows 拣
**Microsoft Print to PDF**，Linux 拣 **Print to File**。分页分得着，文字也仍旧拣得着。

打印搭 PDF 一律用浅色主题，就算程序眼门前是深色也一样，彩色个 AI 标记搭判定栏照原样留牢。

若是侬台机器根本呒没配置过打印机或者 PDF 目标，程序会照直讲，并且指侬去 HTML 导出 — HTML 报告
勒随便啥浏览器里向侪打印得着。

## 解析选项

右首该块面板拿引擎所有选项摆勒一淘。动一动任何一样，**拣牢该条记录当场就重新解析**，所以迭块面
板勿光影响下一趟扫描 — 伊还是一件工具，让侬问：「迭个输入用迭些设置会变做啥样子？」。

| 选项 | 数值 |
|---|---|
| 解析模式 | `SYNTAX`、`CONTENT`、`DATA_CARRIER`、`INTERPRETATION` — 解析要走到几深 |
| 语言 | 35 个消息目录 |
| 次序 | `LITTLE`（dd/mm/yyyy）、`MIDDLE`（mm/dd/yyyy）、`BIG`（yyyy/mm/dd） |
| 分隔符 | `SLASH`、`HYPHEN`、`PERIOD` |
| 月 | `TWO_DIGIT`（12）、`THREE_LETTER`（DEC） |
| 年 | `FOUR_DIGIT`（2026）、`TWO_DIGIT`（26） |
| 跳过“requires”检查 | 勿再为脱少一个必要个搭档 AI 而拒绝（`GE-S005`） |
| 跳过“excludes”检查 | 勿再拒绝标准禁脱个 AI 组合（`GE-S006`） |

面板底下该个*恢复默认*，会拿引擎自家该套默认值攞转来。

### 第一趟运行

只要还呒没存过任何物事，程序就勿用引擎个默认值，而是从**侬台机器个区域设置**里向攞伊自家该套设
置：

- **语言**从系统区域设置来，呒没目录个就退转做英文；
- **日期选项**从侬区域设置个短日期格式里向读出来：各部分个次序、分隔符，搭月同年写勿写短。

> **要当心。**所以短日期用两位数年份该些区域设置，勒迭面一样会从两位数年份开头：噉样搭侬系统其
> 余部分一致，勿过搭引擎自家四位数个默认值勿一样。勒面板里向改脱伊，该个选择就会留牢。

## 语言

拣语言勿光换脱错误消息，是换脱**整个程序** — 菜单、按钮、编辑器、选项面板、状态行搭报告。从右
到左书写个语言还会拿窗口搭报告翻转过来。

35 种语言侪有，分两层覆盖：

| | 覆盖 |
|---|---|
| 解析报告搭引擎所有错误消息 | **全部 35 种语言** |
| 程序自家个菜单、按钮搭标签 | **全部 35 种语言** |

从右到左书写个语言 — 阿拉伯文、埃及阿拉伯文、波斯文搭乌尔都文 — 从程序一打开该一刻起，就已经拿
窗口搭报告翻转过来哉。

语言会记牢，下趟照用。若是只想用别种语言打开一趟，请看[`--language`](#运行)。

有些物事是特为勒所有语言里向侪勿翻译个：搭原始数值一淘打印出来该些简短字段名（`format`、
`position`、`raw`、`len` …）— 迭些是标识符，勿是字词；样式搭符号体系个名字 — 迭些是 GS1 搭行业
术语；还有标准里向一段长段落 — 翻一半反而越弄越糊涂。

## 会记牢啥

侬个人目录底下 `.gaia-desktop` 里向两个文件：

| 文件 | 里向有啥 |
|---|---|
| `options.properties` | 所有解析选项、主题、选项面板开牢还是关牢、最后用过个扫描器、窗口是勒哪个模式关脱个，搭更新检查个设置——开还是关、上趟啥辰光跑过，搭侬拣了跳脱个版本 |
| `captures.tsv` | 记录历史，新个勒前头，上限 500 条 |

侬每趟改一个选项，就写一趟；历史每趟变，就写一趟。退出个辰光两个侪再写一趟。

删脱其中一个文件，只拿该一部分打转最早个样子，其余啥物事也勿动 — 两个特为分开，就是勿想坏脱个历
史连侬个设置一道拖落水。就算文件被人手改坏脱也勿是死症：每个设置侪是各自退转自家个默认值，所以
一行错个代价，就只有该一行噉多。

历史存个是输入，勿是解析结果。装载个辰光会重新解析一趟，就是讲恢复出来该条记录反映个是**眼门前**
生效该些选项，勿是当初记下来该辰光生效该些。

合并模式捏牢个条码勿保存：重新开过以后，合并从空白开始。

## 疑难排解

| 症状 | 原因搭解决 |
|---|---|
| 程序起勿来，或者出 `NoClassDefFoundError` | `lib/` 目录一定要勒 JAR 文件旁边。两样摆勒一淘，或者用自包含该个发行版 |
| 启动个辰光控制台出 *“Unsupported JavaFX configuration…”* | 早料着个，也呒没害处 — 工具包只是勒讲伊是哪能装载个。程序照常跑 |

| PDF 导出讲呒没目标 | 侬台机器呒没配置过打印机或者 PDF 目标。添一个，或者导出做 HTML 再从浏览器打印 |

## 限制

- **扫描只勒 Windows**，因为驱动程序勒该面。
- **PDF 要经打印对话框**，勿是保存对话框。
- **Digital Link 目标只收域名搭路径前缀**；呒没额外个查询参数，也呒没片段。
- **一个 AI 勒一条元素字符串里向只出现一趟** — 迭个是 GS1 个规则，勿是程序个限制。
- **合并只收 GS1-128 条码，顶多三个**，而且两趟运行之间勿保留。
