GAIA Desktop 範例

每種常用嘅 GS1 數據載體各有一個條碼，兩個 GAIA 會拒絕嘅，另外仲有一張俾「合併」用嘅傳統標籤。你可以用 Zebra 掃描器直接喺螢幕度掃，或者將元素串複製去 GAIA Desktop 嘅輸入欄。

每個元素串都係由佢嘅 AIM Code ID 開始，等 GAIA 知道今次掃描係嚟自邊種數據載體。{GS} 代表 FNC1，即係跟喺可變長度 AI 後面嘅分隔符；輸入欄會將佢轉做真正嘅字元。條碼圖片係由 TEC-IT 網上條碼產生器畫出嚟，所以打開呢一頁就會將範例數據傳俾佢。用嘅人多嗰陣，佢可能會顯示請求次數限制嘅通知，而唔係條碼；遲啲再重新載入就得。

解析

喺解析模式，每次掃描或者貼上嘅內容都會拆做佢嘅應用識別碼（Application Identifier）。最後兩張卡係 GAIA 會捉到嘅錯：每張都寫明 GAIA 報嘅錯誤。
