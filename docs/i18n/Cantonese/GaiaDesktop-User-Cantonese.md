## 呢個係乜嘢

GAIA Desktop 對住 GS1 資料做兩件事：

- **解析** — 打或者貼一條 GS1 元素字串或者 Digital Link URI，又或者由檔案開，又或者掃入嚟，
  跟住睇一份完整報告：每一個應用識別碼（AI）係乜意思、邊度錯咗、點解錯；
- **建立** — 將 AI 同數值一對對砌埋，整出一條元素字串或者 Digital Link URI。

呢個程式對 GS1 所知嘅一切 — 每個 AI 嘅定義、每條檢查規則、每段錯誤訊息、每個在地化細節 —
全部由行喺下面嘅 GAIA 引擎嚟。程式自己冇加過任何規則：引擎收乜嘢，佢就收乜嘢。

## 執行

```bash
java -jar gaia-desktop.jar
```

呢個 JAR 檔要有隨佢一齊派發嘅 `lib/` 目錄 — 兩樣要放埋一齊，唔係程式起唔到。（亦都可以建置一個
自足嘅 JAR 檔；睇[開發者指南](../../GaiaDesktop-Developer.md#packaging)。）

要有 **Java 21 或者更新**。發行版係為某一個作業系統同某一種處理器架構而建，所以要用為你部機建
嗰個 JAR 檔。

如果想用某種語言開程式，但又唔想改咗儲存嗰個語言：

```bash
java -jar gaia-desktop.jar --language=FR
```

數值可以係目錄代碼（`FR`、`PCM`、`ARZ`）、全名（`FRENCH`、`WU-CHINESE`），或者語言標籤
（`fr`；廣東話用 `zh-HK`，埃及阿拉伯文用 `ar-EG`）— 大小寫冇分別。呢個指令淨係對嗰一次執行有
效：你儲存嗰個語言原封不動，所以你幫同事整嗰個捷徑，改唔到你自己嗰份用乜嘢語言開。不過喺程式
*入面*揀語言就係真正嘅選擇，會照舊儲存。至於指唔到任何語言嘅數值，程式會喺主控台留低一句然後
當佢冇到，跟住照樣用儲存嗰個語言開，唔會拒絕行。

啟動嗰陣，主控台會印一行，入面有程式版本、佢嘅建置日期同引擎版本。報告問題嗰陣，就係要附上嗰
一行。

## 解析模式

### 輸入列同 {GS} 記號

呢條列收元素字串、GS1 Digital Link URI，或者連 AIM Code ID 前綴（`]d2…`）嘅原始掃描資料。撳
<kbd>Enter</kbd> 就開始解析。

分隔長度可變嘅 AI 嗰個係 **FNC1** — 睇唔到嘅控制字元 `0x1D`。冇一個文字欄位揸得住呢個字元：佢
會靜靜雞消失，於是 `01…` + FNC1 + `10LOT` 去到嗰邊就變成 `01…10LOT` — 即係一條意思已經變咗嘅元
素字串。

所以程式將分隔符顯示成睇得到嘅記號 **`{GS}`**，然後喺送去解析器嗰陣再轉返做原本嗰個：

- **`{GS}` 掣**會喺游標位置插入記號；
- 當你**貼**真正嘅分隔字元入嚟 — 用鍵盤、用右鍵選單或者拖放 — 佢哋會自動變成 `{GS}`，所以冇
  嘢會唔見咗；
- 記號寫法同報告寫法一模一樣，所以由報告度複製出嚟嘅數值，可以直接貼返入去。

紀錄、報告同儲存低嘅歷史 — 三樣入面裝住嘅都係**真正**嘅分隔符。記號淨係你見到同打嗰個。

### 掃描

> **淨係 Windows。**Zebra 淨係為 Windows 出掃描器驅動程式，所以喺 macOS 同 Linux，程式根本唔會
> 整任何掃描器控制項 — 冇*連接掃描器*掣、冇裝置清單、冇*掃描器*選單、狀態列亦都冇掃描器狀態。
> 亦都唔會有嘢灰色噉顯示出嚟，因為根本就冇任何設定或者裝置可以令佢啟用。其餘所有嘢，包括開一個
> 裝滿已存掃描資料嘅檔案，喺邊度都照用得。

*連接掃描器*會開清單度指定嗰部裝置；`ZebraAllScanners` 係預設值，大部分型號都啱用。每次掃描都
會解析，亦都會自動加入歷史。

掃描器嘅資料係逐個位元組讀入，所以 AIM Code ID 前綴同每一個 FNC1 分隔符，去到解析器嗰陣同掃描
器送出嗰陣一模一樣。

喺建立模式，掃描器控制項會收埋，但係連咗嘅掃描器繼續行：*掃描器 → 連接 / 中斷*
（<kbd>⌘K</kbd>）照樣切換得到，狀態列照樣會講，而編輯器開住嗰陣掃入嚟嘅嘢一樣會記低。

如果連唔到任何裝置，睇[疑難排解](#疑難排解)。

### 開啟檔案

*檔案 → 開啟文字檔…* 會將**每一行唔係空嘅字都當做一筆獨立紀錄**去解析 — 人哋掉一大堆掃描資料
畀你，噉樣處理最快。檔案係逐個位元組讀入，所以入面真正嘅分隔符一樣完好無缺。

### 紀錄歷史

新嘅喺上面。每一行有個有效 / 無效嘅圓點、一行摘要，旁邊仲有紀錄時間、佢嘅來源同入面 AI 嘅數
目。日期淨係喺之前幾日嘅紀錄先會出；今日嗰啲行淨係得時間。

Digital Link 嘅摘要係 **Digital Link URI**，其餘一律係 **HRI**：元素字串嚟講，睇
`(01)09506000134352 (17)261231` 梗係易過睇 `01095060001343521726123110…`。

喺一筆紀錄度撳右掣，可以複製佢嘅輸入或者 HRI、送返去輸入列、喺編輯器度打開、移除佢，又或者清晒
成個歷史。

## 建立模式

### AI 編輯器

一個 AI 同數值成對嘅表格。打個 AI 代碼，又或者由*加入 AI…* 清單度喺**引擎識得嘅所有 AI** 入面
揀；你一路打，**標題**、**格式**同**描述**幾欄就一路用你揀嗰種語言填好。清單唔會畀個建立嗰陣
實被拒嘅 AI 你揀。

表格最尾永遠留住**一行吉行**：喺入面寫嘢，下一行就會出，所以要整一條多個 AI 嘅字串，你根本永遠
唔使撳*新增列*。

編輯嘅行為就係一個表格應該有嘅行為：<kbd>Enter</kbd>、<kbd>Tab</kbd>、
<kbd>Shift</kbd>+<kbd>Tab</kbd> 同撳去第二度 — 全部都會**保住**你打咗嘅嘢；<kbd>Esc</kbd> 就會
掉咗佢。<kbd>Tab</kbd> 由 AI 行去數值，再行去下一行，跳過改唔到嗰幾欄。

### 編輯器唔收乜嘢

| | 會點 |
|---|---|
| 引擎唔識嘅 AI | 你一路打，嗰行就變紅；建立會被拒，同時解釋原因 |
| 由清單再揀第二次同一個 AI | 加唔到 — 訊息會講出佢個名，而本身已經有佢嗰行會被選中 |
| 用手再打多次同一個 AI | 兩行都會標記；建立會以 `GE-S004` 錯誤被拒 |
| 冇嘢好建立 | 一段訊息；唔會產生任何紀錄 |

一條元素字串入面，同一個 AI 只可以出現一次 — 所以清單即刻拒你，好過畀你去試一個實敗嘅建立。

### 元素字串定 Digital Link

**建立元素字串**會將啲行駁埋，並且喺標準要求嘅每一個位放 FNC1 分隔符。**建立 Digital Link** 會
整條 URI 出嚟；如果想指去你自己個解析器，唔用標準嘅 `id.gs1.org`，就打開*Digital Link 目標*：

| 欄位 | 作用 | 留空即係 |
|---|---|---|
| 網域 | 解析器嘅主機，好似 `example.com` | `id.gs1.org` |
| 路徑前綴 | AI 路徑之前嗰一截，好似 `/products` | 冇前綴 |

**成功**嘅話，結果嘅行為同一次掃描一模一樣：會解析、會入歷史、會當報告顯示、亦都會儲存。建立會
解析返自己個結果嚟檢查，所以佢交返出嚟嗰樣嘢一定有效。

**失敗**嘅話，乜都唔會記低。原因會留喺建立幾個掣下面 — 每個問題一行，每行都有錯誤碼、有關嗰個
AI，同埋引擎自己嘅解釋：

```
GE-C003  (01)  Check digit validation failed for AI (01) value ''09506000134350''
```

> 嗰段訊息入面嘅雙引號唔係呢個程式加嘅，係引擎自己個錯誤目錄本身就係噉。

### 修改現有紀錄

喺一筆紀錄度撳右掣 → **建立**，就會將佢帶入 AI 編輯器。改個數值、再建立一次，結果就會變成一筆
新紀錄出現 — 原本嗰筆紀錄原封不動。

## 報告

揀咗嗰筆紀錄會以完整報告顯示：判定列、切成一段段有名「帶」嘅元素字串、解析中繼資料、每個 AI 一
張卡連埋佢嘅意思，仲有錯誤同警告連埋點樣修正嘅指引。

**Digital Link** 嗰陣，每張 AI 卡仲會講埋佢嘅結構角色 — **主鍵**、**鍵限定詞**或者
**資料屬性** — 用嘅顏色跟返佢哋喺 URI 出現嘅次序。呢啲角色淨係喺 Digital Link 先見到：普通元素
字串入面，AI 根本喺 URI 度冇位可言，冇嘢好講。

報告會跟你揀嘅語言同佈景。

### 匯出

| | |
|---|---|
| **儲存報告 → 存成 HTML…**（<kbd>⌘S</kbd>） | 畫面上係點就寫成點：一個自足嘅檔案，任何瀏覽器都開得 |
| **儲存報告 → 存成 PDF…**（<kbd>⌘P</kbd>） | 經系統嘅列印對話框印份報告 — 喺嗰度揀 PDF 目的地 |

PDF 要經列印對話框，因為位置同檔案名係喺嗰度揀：macOS 揀 **PDF ▾ → Save as PDF**，Windows 揀
**Microsoft Print to PDF**，Linux 揀 **Print to File**。分頁分得啱，文字亦都仲揀得到。

列印同 PDF 一律用淺色佈景，就算程式而家係深色都好，而彩色嘅 AI 標記同判定列就照原樣保留。

如果你部機根本冇設定過印表機或者 PDF 目的地，程式會照直講，並且指你去 HTML 匯出 — HTML 喺任何
瀏覽器都印得。

## 解析選項

右邊嗰塊面板將引擎所有選項擺埋一齊。改動任何一樣，**揀咗嗰筆紀錄即刻會重新解析**，所以呢塊面板
唔係淨係影響下一次掃描 — 佢仲係一個工具，等你問：「呢個輸入用呢啲設定會變成點？」。

| 選項 | 數值 |
|---|---|
| 解析模式 | `SYNTAX`、`CONTENT`、`DATA_CARRIER`、`INTERPRETATION` — 解析要行到幾深 |
| 語言 | 35 個訊息目錄 |
| 次序 | `LITTLE`（dd/mm/yyyy）、`MIDDLE`（mm/dd/yyyy）、`BIG`（yyyy/mm/dd） |
| 分隔符 | `SLASH`、`HYPHEN`、`PERIOD` |
| 月 | `TWO_DIGIT`（12）、`THREE_LETTER`（DEC） |
| 年 | `FOUR_DIGIT`（2026）、`TWO_DIGIT`（26） |
| 略過「requires」檢查 | 唔再因為欠咗必要嘅拍檔 AI 而拒絕（`GE-S005`） |
| 略過「excludes」檢查 | 唔再拒絕標準禁止嘅 AI 組合（`GE-S006`） |

面板下面嗰個*回復預設值*，會攞返引擎自己嗰套預設值。

### 第一次執行

只要仲未儲存過任何嘢，程式就唔會用引擎嘅預設值，而係由**你部機嘅地區設定**攞佢自己嗰套設定：

- **語言**由系統地區設定嚟，冇目錄嗰啲就退返做英文；
- **日期選項**由你地區設定嘅短日期格式讀出嚟：各部分嘅次序、分隔符，同埋月同年寫唔寫短。

> **要留意。**所以短日期用兩位數年份嗰啲地區設定，喺呢度一樣會由兩位數年份開始：噉樣同你系統其
> 餘部分一致，但係就同引擎自己四位數嘅預設值唔同。喺面板度改咗佢，個選擇就會留低。

## 語言

揀語言唔單止換咗錯誤訊息，係換咗**成個程式** — 選單、掣、編輯器、選項面板、狀態行同報告。由右
至左書寫嘅語言仲會將視窗同報告反轉。

35 種語言全部有，分兩層覆蓋：

| | 覆蓋 |
|---|---|
| 解析報告同引擎所有錯誤訊息 | **全部 35 種語言** |
| 程式自己嘅選單、掣同標籤 | **全部 35 種語言** |

由右至左書寫嘅語言 — 阿拉伯文、埃及阿拉伯文、波斯文同烏爾都文 — 由程式一開嗰刻起，就已經將視窗
同報告反轉。

語言會記住，下次照用。若果淨係想用第二種語言開一次，睇[`--language`](#執行)。

有啲嘢係特登喺所有語言都唔譯嘅：同原始數值一齊印出嚟嗰啲簡短欄位名（`format`、`position`、
`raw`、`len` …）— 呢啲係識別碼，唔係字詞；樣式同符號體系嘅名 — 呢啲係 GS1 同業界術語；仲有標準
入面一段長段落 — 譯一半反而會愈搞愈亂。

## 會記住啲乜

你個人目錄下面 `.gaia-desktop` 入面兩個檔案：

| 檔案 | 入面有乜 |
|---|---|
| `options.properties` | 所有解析選項、佈景、選項面板開唔開住、最後用過嗰部掃描器，同埋視窗係喺邊個模式關低 |
| `captures.tsv` | 紀錄歷史，新嘅行先，上限 500 筆 |

你每次改一個選項，就寫一次；歷史每次變，就寫一次。結束嗰陣兩個都會再寫一次。

刪咗其中一個檔案，淨係將嗰一部分打返做最初嘅樣，其餘乜都唔會郁 — 兩個特登分開，就係唔想爛咗嘅
歷史連你啲設定都拖埋落水。就算個檔案畀人手改到爛咗都唔係死症：每個設定都係各自退返做自己嘅預設
值，所以一行錯嘅代價，就淨係嗰一行咁多。

歷史存嘅係輸入，唔係解析結果。載入嗰陣會重新解析一次，即係還原返嗰筆紀錄反映嘅係**而家**生效嗰
啲選項，唔係當初記低嗰陣生效嗰啲。

## 疑難排解

| 徵狀 | 原因同解決 |
|---|---|
| 程式起唔到，或者出 `NoClassDefFoundError` | `lib/` 目錄一定要喺 JAR 檔隔籬。兩樣放埋一齊，又或者用自足嗰個發行版 |
| 啟動嗰陣主控台出 *“Unsupported JavaFX configuration…”* | 預咗嘅，亦都無害 — 工具套件淨係講緊佢係點載入。程式照常行 |
| 貼咗入去嘅分隔符好似唔見咗 | 本來就係噉：佢會變成睇得到嘅 `{GS}` 記號，而解析器收到嘅係真正嗰個字元。睇[{GS} 記號](#輸入列同-gs-記號) |
| 根本冇*連接掃描器*個掣 | 你而家喺 macOS 或者 Linux，嗰度根本冇掃描器驅動程式。睇[掃描](#掃描) |
| 掃描器連唔到 | 睇下清單入面嗰個邏輯名稱同你部機型號啱唔啱、掃描器插咗未、有冇第二個程式霸住咗佢 |
| PDF 匯出話冇目的地 | 你部機冇設定過印表機或者 PDF 目的地。加一個，又或者匯出做 HTML 再由瀏覽器印 |
| 某個選單項目度見到好似 `act.hri` 噉嘅嘢 | 有個標籤漏咗 — 麻煩報告返；呢個唔係設定問題，係建置嗰陣嘅缺陷 |

## 限制

- **掃描淨係喺 Windows**，因為驅動程式喺嗰度。
- **PDF 要經列印對話框**，唔係儲存對話框。
- **Digital Link 目標淨係收網域同路徑前綴**；冇額外嘅查詢參數，亦都冇片段。
- **一個 AI 喺一條元素字串入面淨係出現一次** — 呢個係 GS1 嘅規則，唔係程式嘅限制。
