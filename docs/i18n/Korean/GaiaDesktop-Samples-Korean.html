GAIA Desktop 샘플

GS1 데이터 캐리어마다 바코드 하나씩, 그리고 결합용 기존 방식 라벨이 있습니다. Zebra 스캐너로 화면에서 바로 스캔하거나 요소 문자열을 GAIA Desktop 입력 표시줄에 복사하세요.

각 요소 문자열은 AIM Code ID로 시작하며, 이 값은 스캔이 어떤 데이터 캐리어에서 왔는지 GAIA에 알려 줍니다. {GS}는 가변 길이 AI 뒤에 오는 구분자인 FNC1을 나타내며, 입력 표시줄이 이를 실제 문자로 변환합니다. 바코드 이미지는 TEC-IT의 온라인 바코드 생성기가 그리므로, 이 페이지를 열면 샘플 데이터가 그곳으로 전송됩니다. 사용량이 많을 때는 바코드 대신 요청 한도 알림이 표시될 수 있으니 나중에 다시 불러오세요.

파싱

파싱 모드에서는 스캔하거나 붙여 넣은 모든 내용이 Application Identifier로 분해됩니다.

결합

기존 방식의 물류 라벨은 데이터를 여러 개의 GS1-128 바코드에 나누어 담습니다. 결합 모드에서 그중 최대 세 개를 스캔하면 GAIA Desktop이 그 AI들을 GS1 DataMatrix가 담을 하나의 요소 문자열로 합치고 전체를 검증합니다. 다음 세 개를 순서대로 스캔하세요.
