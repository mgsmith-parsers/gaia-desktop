# إعداد ماسح Zebra — GAIA Desktop لنظام Windows

كيفية تثبيت ماسح رموز شريطية من Zebra وإعداده حتى يقرأ GAIA Desktop رموز GS1 الشريطية منه
مباشرةً: يُحلَّل كل مسح ويُضاف إلى السجل، مع بقاء بادئة AIM Code ID وكل فاصل FNC1 كما هي.
المستند الأصلي: [GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md).

بُني GAIA Desktop واختُبر مع ماسح التصوير المحمول باليد **Zebra DS8108** الموصول عبر USB. وتنطبق
الخطوات على أي ماسح ثنائي الأبعاد من Zebra يدعمه Scanner SDK من Zebra؛ أما رموز الإعداد الشريطية
وأسماء القوائم لطراز معيّن فتأتي من دليله الخاص Quick Reference Guide أو Product Reference Guide.

> **Windows فقط.** لا توجد مشغّلات ماسحات Zebra إلا لنظام Windows، ولذلك لا ينشئ GAIA Desktop
> أي أدوات تحكم بالماسح على macOS أو Linux. أما كل ما عدا ذلك في التطبيق فيعمل على كل الأنظمة.

## 1. ما تحتاج إليه

| | |
|---|---|
| **الماسح** | ماسح ثنائي الأبعاد من Zebra مع كبل USB الخاص به — انظر [ماسحات Zebra ثنائية الأبعاد المدعومة](#12-ماسحات-zebra-ثنائية-الأبعاد-المدعومة) |
| **الحاسوب** | Windows 10 أو 11، إصدار 64 بت |
| **Java** | Java 21 أو أحدث، **64 بت** |
| **Zebra Scanner SDK for Windows** | **64 بت**، من موقع دعم Zebra — يوفّر المشغّل وخدمات JavaPOS التي يستخدمها GAIA Desktop |
| **Zebra 123Scan** | أداة الإعداد المجانية من Zebra، من موقع دعم Zebra — تُستخدم لتحديث البرنامج الثابت للماسح والتحقق من إعداداته |
| **GAIA Desktop** | `gaia-desktop-1.0.0-win.zip` |
| **اختياري** | دليل **Product Reference Guide** (PRG) الخاص بالماسح، وفيه رموز الإعداد الشريطية |

كيف تترابط الأجزاء:

```
Zebra scanner ──USB──► Zebra CoreScanner driver ──► Zebra JavaPOS services ──► GAIA Desktop
                       (installed by the SDK)        (in the SDK's JPOS\bin)    (run.bat puts them on
                                                                                 the class path)
```

يحمل GAIA Desktop بنفسه واجهة JavaPOS البرمجية والإعداد الذي يسمّي الماسح (`jpos.xml`، داخل
`gaia-desktop.jar`). ويوفّر Zebra SDK الباقي: المشغّل الذي يتخاطب مع الماسح، وفئات خدمات Zebra
التي تقع بين JavaPOS وذلك المشغّل.

## 2. تثبيت Java

يحتاج GAIA Desktop إلى **Java 21 أو أحدث**، ويجب أن يكون الإصدار **64 بت** ليتوافق مع مشغّلات
Zebra ذات الـ 64 بت.

1. ثبّت Java 21 JDK أو JRE لنظام Windows x64 — مثل Eclipse Temurin من
   adoptium.net. ودع المثبّت يضبط `JAVA_HOME` إن عرض ذلك.
2. تحقّق منه في موجّه الأوامر:

   ```
   java -version
   ```

   يجب أن يُظهر السطر الأول الإصدار 21 أو أحدث؛ وتطبع Java ذات الـ 64 بت أيضًا `64-Bit Server VM`.

يبحث `run.bat` عن Java بهذا الترتيب: مجلد `jdk*` بجوار `run.bat`، ثم `JAVA_HOME`، ثم
`java` في `PATH`. ويرفض أي إصدار أقدم من 21 برسالة توضّح ذلك.

---

## 3. تثبيت Zebra Scanner SDK

1. نزّل **Zebra Scanner SDK for Windows (64-bit)** من موقع دعم Zebra.
2. شغّل المثبّت. وإن عرض اختيار المكوّنات، فتأكد من تضمين مكوّن **JPOS** (JavaPOS).
3. أبقِ موقع التثبيت الافتراضي. يبحث GAIA Desktop عن جزء JavaPOS من الـ SDK في:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   ويتوقع ملفات jar لخدمات Zebra (`JposServiceScanner.jar`، `JposServiceJniScanner.jar`، …)
   والمكتبات الأصلية (`CSJPOSScanner64.dll`، …) في مجلده `bin\`. وإن ثُبّت الـ SDK في مكان
   آخر، فانظر [ZEBRA_HOME](#zebra_home).
4. **أعد تشغيل Windows** بعد التثبيت. يعمل مشغّل CoreScanner التابع للـ SDK في الخلفية، ويجب أن
   يكون قيد التشغيل قبل أن يتمكن GAIA Desktop من الوصول إلى الماسح؛ وإعادة التشغيل أبسط طريقة
   للتأكد من ذلك.

## 4. تثبيت 123Scan

‏123Scan أداة Zebra المجانية لإعداد ماسحاتها. تُستخدم في الخطوة التالية لتحديث البرنامج الثابت
للماسح، وهي أسهل طريقة للتحقق من إعدادات الماسح وتغييرها بعد ذلك.

1. نزّل **123Scan** من موقع دعم Zebra وشغّل المثبّت.
2. صِل ماسح Zebra وشغّل 123Scan. يُفترض أن يعثر على الماسح ويعرض طرازه ورقمه التسلسلي وإصدار
   برنامجه الثابت الحالي. وإن لم يفعل، فجرّب منفذ USB أو كبلًا آخر قبل المتابعة — فلن يرى
   GAIA Desktop ماسحًا لا يراه 123Scan.

## 5. تحديث البرنامج الثابت لماسح Zebra

حدّث البرنامج الثابت للماسح إلى أحدث إصدار قبل إعداده. فتحديثات البرنامج الثابت تصلح مشكلات فك
الترميز وتُبقي الماسح متوافقًا مع مشغّل Zebra الذي ثبّته الـ SDK.

1. أغلق **GAIA Desktop** وأي برنامج آخر قد يستخدم الماسح: يحتاج 123Scan إلى الماسح وحده طوال
   التحديث.
2. في 123Scan، والماسح موصول، اختر خيار تحديث البرنامج الثابت الخاص به. يقارن 123Scan البرنامج
   الثابت للماسح بأحدث ما تنشره Zebra ويعرض تنزيله وتثبيته. وإن لم يكن الحاسوب متصلًا بالإنترنت،
   فنزّل البرنامج الثابت للماسح من صفحة دعمه على موقع Zebra وحمّل الملف في 123Scan.
3. ابدأ التحديث و**أبقِ الماسح موصولًا حتى يُبلغ 123Scan بانتهائه**. يستغرق ذلك عدة دقائق؛
   ويُعاد تشغيل الماسح في النهاية. وفصله في منتصف العملية قد يجعله غير صالح للاستخدام.
4. تحقّق من أن 123Scan يعرض الآن إصدار البرنامج الثابت الجديد.

قد يعيد التحديث بعض الإعدادات إلى قيمها الافتراضية، ولهذا يُعدّ الماسح في الخطوتين التاليتين،
بعد البرنامج الثابت.

## 6. ضبط وضع USB لماسح Zebra

هذه أكثر خطوة يُغفل عنها. **ماسح Zebra في حالته الأصلية لوحة مفاتيح USB** (وضع USB HID
Keyboard): «يكتب» كل رمز شريطي في أي مكان عليه التركيز. وفي هذا الوضع لا يستطيع
*توصيل الماسح* في GAIA Desktop العثور عليه، وكل ما يُكتب في حقل نصي يفقد فواصل FNC1، وهذا يغيّر
معنى سلسلة عناصر GS1.

بدّل الماسح إلى وضع يتخاطب معه مشغّل Zebra مباشرةً:

| وضع USB للماسح | اسم الجهاز في GAIA Desktop | ملاحظات |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld` أو `ZebraAllScanners` | مُوصى به |
| SNAPI (مع التصوير أو بدونه) | `ZebraScannerSNAPI` أو `ZebraAllScanners` | بروتوكول USB الخاص بـ Zebra؛ يعمل أيضًا |
| IBM Table-top USB | `ZebraUSBTableTop` أو `ZebraAllScanners` | مخصص للماسحات المكتبية |
| USB OPOS (Hand-held) | `ZebraUSBOPOS` أو `ZebraAllScanners` | |
| USB HID Keyboard (إعداد المصنع) | — | **لن يتصل** |

يقبل `ZebraAllScanners`، اسم الجهاز الافتراضي في GAIA Desktop، الماسحَ في أي من الأوضاع
المدعومة، فما إن يُضبط الوضع حتى تعمل القيمة الافتراضية عادةً دون أي تغيير.

لتغيير الوضع، إما:

- **امسح رمز الإعداد الشريطي** الخاص بالوضع — *IBM Hand-held USB* مثلًا — في دليل Quick
  Reference Guide أو Product Reference Guide الخاص بالماسح (قسم USB Host Types / USB Device Type)؛
  فيصدر الماسح صوتًا للتأكيد. أو
- **استخدم 123Scan** ([الخطوة 4](#4-تثبيت-123scan)): صِل الماسح، وافتح إعداداته، واضبط نوع مضيف
  USB.

بعد تغيير الوضع يكتشف Windows الماسح من جديد بوصفه جهازًا من نوع آخر؛ فانتظر بضع ثوانٍ قبل
التوصيل.

ولإعادة الماسح لاحقًا إلى وضع لوحة المفاتيح — لاستخدامه مع برامج أخرى — امسح رمز الإعداد الشريطي
*USB Keyboard (HID)*، أو استعد إعدادات المصنع.

## 7. إعداد ماسح Zebra لمعايير GS1

يحلّل GAIA Desktop على أفضل وجه حين يخبره الماسح بنوع الرمز الشريطي الذي قرأه.

### إرسال AIM Code ID

اضبط **Transmit Code ID Character** على **AIM Code ID Character**، باستخدام رمز الإعداد الشريطي
في Product Reference Guide (قسم User Preferences) أو في 123Scan. عندها يبدأ كل مسح بمعرّف
الترميز — `]C1` لـ GS1-128، و`]d2` لـ GS1 DataMatrix، و`]Q3` لـ GS1 QR Code، و`]e0` لـ GS1
DataBar — الذي يستخدمه GAIA Desktop لتسمية ناقل البيانات وتطبيق القواعد الخاصة به.

ومن دونه يظل GAIA Desktop يحلّل سلسلة العناصر ويأخذ نوع الترميز من المسح نفسه، لكن التقرير لا يجد
AIM Code ID ليعرضه، ويصعب تمييز رمز شريطي عادي مثل EAN-13 من سلسلة عناصر GS1.

### التحقق من أنواع الرموز الشريطية

تأكد من **تفعيل** أنواع الرموز الشريطية التي تعمل بها: عادةً GS1-128 وGS1 DataMatrix
وGS1 DataBar وGS1 QR Code وEAN/UPC. معظمها مفعّل افتراضيًا في ماسحات Zebra ثنائية الأبعاد؛ ويعرض
123Scan الإعدادات الحالية، وفي Product Reference Guide رمز شريطي لتفعيل كل نوع منها.

### أبق ميزات تحليل GS1 من Zebra معطلة

تضيف البرامج الثابتة الحديثة ميزات GS1 تعمل على الماسح نفسه — **Label Parse+** و**GS1
Digital Link** و**GS1 Retail POS parsing**. أبقِها **معطّلة**، وهي الحال التي يُشحن بها الماسح:
فهي تعيد تنسيق ما يرسله الماسح أو تختصره، بينما يحتاج GAIA Desktop إلى البيانات الخام ليحلّلها
ويتحقق من صحتها. انظر [ماسحات Zebra ثنائية الأبعاد المدعومة](#12-ماسحات-zebra-ثنائية-الأبعاد-المدعومة)
لمعرفة ما تفعله كل ميزة.

### بلا بادئات ولا لواحق

لا تضف بادئة أو لاحقة أو مفتاح Enter إلى مخرجات الماسح. يتلقى GAIA Desktop كل مسح رسالةً كاملة
عبر JavaPOS ولا يحتاج إلى أي منها؛ وأي محارف إضافية ستنتهي في سلسلة العناصر.

## 8. تثبيت GAIA Desktop وتشغيله

1. فكّ ضغط `gaia-desktop-1.0.0-win.zip`، مثلًا إلى `C:\Tools\`. يحتوي على مجلد واحد:

   ```
   gaia-desktop-1.0.0-win\
   ├── docs\
   │   └── GaiaDesktop-Zebra-Scanner-Windows.md      this guide
   ├── gaia-desktop.jar
   ├── lib\
   ├── readme.html                                   index of every guide
   └── run.bat
   ```

2. صِل الماسح.
3. انقر نقرًا مزدوجًا على **`run.bat`**. تُفتح نافذة وحدة تحكم بجوار التطبيق وتبقى مفتوحة: تُعرض
   فيها حالة الماسح وأخطاء JavaPOS.
4. اقرأ السطر الأول في وحدة التحكم. إنه يذكر ما عثر عليه `run.bat`:

   ```
   run.bat: Java 21.0.8 from JAVA_HOME; JavaFX from lib\; JavaPOS from lib\; Zebra services from C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   إن انتهى بـ **`Zebra services from none (Zebra Scanner SDK not installed)`**، فهذا يعني أن الـ
   SDK لم يُعثر عليه في موقعه الافتراضي — ثبّته ([الخطوة 3](#3-تثبيت-zebra-scanner-sdk)) أو اضبط
   [ZEBRA_HOME](#zebra_home). يبدأ التطبيق مع ذلك، لكن الماسح لا يستطيع الاتصال.

## 9. توصيل الماسح

1. في شريط الأدوات، تعرض **قائمة الأجهزة** أسماء الماسحات التي يعرفها GAIA Desktop. أبقها على
   **`ZebraAllScanners`**، أو اختر الاسم المناسب لوضع USB الخاص بالماسح من الجدول في
   [الخطوة 6](#6-ضبط-وضع-usb-لماسح-zebra).
2. انقر **توصيل الماسح**، أو اضغط **Ctrl+K** (وهو أيضًا في قائمة **الماسح**).
3. يتغير شريط الحالة إلى **`الماسح: ZebraAllScanners`** (أو الاسم الذي اخترته)، ويُبلغ سطر الحالة
   *تم توصيل الماسح — ZebraAllScanners*. ويصبح الزر الآن **فصل الماسح**.
4. امسح رمزًا شريطيًا من GS1. يظهر في أعلى سجل الالتقاطات ويُفتح تقريره. ومع تفعيل AIM Code ID
   يسمّي التقرير ناقل البيانات — *GS1-128*، *GS1 DataMatrix* — وتحتفظ سلسلة العناصر بكل فاصل FNC1.

تتذكر قائمة الأجهزة اختيارك بين مرات التشغيل. ويبقى الماسح موصولًا حتى تفصله أو تغلق التطبيق.
ويعمل المسح أيضًا في وضعي **إنشاء** و**دمج**: في الدمج يصبح كل مسح أحد الرموز الشريطية التي
تُدمج.

ما دام GAIA Desktop ممسكًا بالماسح فلا تستطيع البرامج الأخرى استخدامه، والعكس صحيح: أغلق 123Scan
وأي برنامج آخر لنقاط البيع أو للماسحات قبل التوصيل.

## 10. مرجع الإعدادات

### أسماء الأجهزة

تُملأ قائمة الأجهزة من ملف `jpos.xml` المضمّن في `gaia-desktop.jar`. وهذه مُدخلات الماسحات فيه:

| اسم الجهاز | نوع الماسح | يُستخدم مع |
|---|---|---|
| `ZebraAllScanners` | أي نوع | **الافتراضي.** أي وضع USB مدعوم |
| `ZebraAllScanners114` | أي نوع | إصدار JavaPOS 1.14 من الخدمة نفسها |
| `ZebraUSBHandHeld` | IBM Hand-held USB | ماسح في وضع IBM Hand-held USB |
| `ZebraUSBTableTop` | IBM Table-top USB | وضع Table-top |
| `ZebraUSBOPOS` | USB OPOS | وضع USB OPOS |
| `ZebraScannerSNAPI` | SNAPI | وضع SNAPI |
| `ZebraScannerUSB` | أي USB | أي وضع USB |
| `ZebraScannerSerialSSI` | تسلسلي SSI | ماسحات بكبل تسلسلي (ليس USB) |
| `ZebraScannerSerialNIXMODB` | تسلسلي NIXMODB | ماسحات بكبل تسلسلي |
| `ZebraVDI` | VDI | ماسحات مُمرَّرة إلى سطح مكتب افتراضي |

### ZEBRA_HOME

إن كان Zebra SDK مثبّتًا في غير موقعه الافتراضي، فاضبط `ZEBRA_HOME` على مجلد `JPOS` الخاص به قبل
تشغيل `run.bat` — مثلًا في ملف دفعي صغير بجواره:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

عندها يأخذ `run.bat` ملفات jar لخدمات Zebra من `%ZEBRA_HOME%bin` ويضيف ذلك المجلد إلى `PATH`
من أجل ملفات DLL الخاصة بـ Zebra.

### ملف jpos.xml خاص بك

لإضافة اسم جهاز أو تغيير إعدادات أحد المُدخلات، انسخ `jpos.xml` من داخل `gaia-desktop.jar`
(إنه ملف zip؛ تفتحه أي أداة فك ضغط)، وعدّل النسخة، ثم وجّه GAIA Desktop إليها:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

عندها تعرض قائمة الأجهزة الماسحات الموجودة في ذلك الملف. وإن كان أكثر من ماسح Zebra موصولًا، فيمكن
ربط أحد المُدخلات بواحد منها عبر خاصيته `ScannerModel` أو `SerialNumber`، كما في مُدخل
`ZebraAllScanners`.

### خيارات أخرى

| الإعداد | الطريقة |
|---|---|
| لغة التطبيق | `run.bat --language=FR` (لهذا التشغيل فقط)، أو لوحة الخيارات |
| خيارات Java إضافية | `set GAIA_DESKTOP_OPTS=…` قبل `run.bat` |
| Java مضمّنة | ضع مجلد `jdk-21…` بجوار `run.bat`؛ ويُستخدم قبل `JAVA_HOME` |

## 11. استكشاف الأخطاء وإصلاحها

تظهر الأخطاء في مربع حوار عند التوصيل، وفي نافذة وحدة التحكم، وفي ملف السجل
`logs\gaia-desktop.log` داخل المجلد الذي شُغّل منه `run.bat` (مجلد GAIA Desktop، عند النقر المزدوج
على `run.bat`). والرقم بين القوسين المعقوفين في السجل هو رمز خطأ JavaPOS.

| ما تراه | السبب المحتمل | ما العمل |
|---|---|---|
| لا يوجد زر *توصيل الماسح* | التطبيق لا يعمل على Windows | المسح متاح على Windows فقط |
| لا يعثر 123Scan على الماسح | الكبل، أو منفذ USB، أو أن برنامجًا آخر يمسك بالماسح | جرّب كبلًا أو منفذًا آخر؛ أغلق GAIA Desktop وبرامج الماسحات الأخرى. لن يرى GAIA Desktop ماسحًا لا يراه 123Scan |
| وحدة التحكم: `Zebra services from none (Zebra Scanner SDK not installed)` | الـ SDK ليس في موقعه الافتراضي | ثبّت الـ SDK ذا الـ 64 بت ([الخطوة 3](#3-تثبيت-zebra-scanner-sdk))، أو اضبط [ZEBRA_HOME](#zebra_home) |
| الخطأ **104**: *Could not connect to service with logicalName = …: …SymScannerSvc112Factory* | لم يُعثر على ملفات jar لخدمات Zebra | كما سبق — تحقق من سطر `Zebra services from` في وحدة التحكم |
| الخطأ **109**: *Service does not exist in loaded JCL registry* | اسم الجهاز غير موجود في إعداد الماسح، أو دخل `javaPOS114.jar` التابع للـ SDK إلى class path | اختر اسمًا من قائمة الأجهزة؛ لا تضف `javaPOS114.jar`؛ وإن كنت تستخدم `jpos.xml` خاصًا بك، فتحقق من وجود الاسم فيه |
| الخطأ **107** (لا عتاد)، أو يفشل التوصيل والماسح موصول | الماسح ما زال في وضع لوحة مفاتيح USB، أو مشغّل CoreScanner لا يعمل | اضبط وضع USB ([الخطوة 6](#6-ضبط-وضع-usb-لماسح-zebra))؛ أعد تشغيل Windows بعد تثبيت الـ SDK؛ جرّب منفذ USB آخر |
| الخطأ **112** (انتهاء المهلة) أو **102** (محجوز) عند التوصيل | برنامج آخر يمسك بالماسح | أغلق 123Scan وأي برنامج آخر للماسحات أو لنقاط البيع، ثم صِل من جديد |
| `UnsatisfiedLinkError` … `CSJPOSScanner64` في وحدة التحكم | تعذّر تحميل ملفات DLL الخاصة بـ Zebra — غالبًا SDK بـ 32 بت مع Java بـ 64 بت | ثبّت الـ SDK ذا الـ 64 بت؛ وتحقق من أن `java -version` يذكر VM بـ 64 بت |
| تُكتب المسوح في شريط الإدخال بدلًا من وصولها التقاطات | الماسح في وضع لوحة مفاتيح USB | اضبط وضع USB ([الخطوة 6](#6-ضبط-وضع-usb-لماسح-zebra)) |
| الماسح موصول لكن المسوح لا تصل | اسم جهاز خاطئ لوضع الماسح، أو أعيد وصل الماسح وهو متصل | افصل، واختر `ZebraAllScanners`، ثم صِل من جديد |
| لا يعرض التقرير AIM Code ID / ناقل البيانات | إرسال AIM Code ID معطّل | فعّل *Transmit Code ID Character → AIM Code ID* ([الخطوة 7](#7-إعداد-ماسح-zebra-لمعايير-gs1)) |
| سلسلة عناصر تنقصها الفواصل، أو تتلاصق فيها معرّفات AI | مُسحت في وضع لوحة المفاتيح، أو كُتبت يدويًا دون `{GS}` | استخدم وضع USB يعمل مع JavaPOS؛ وعند الكتابة أدرج الفواصل بزر `{GS}` |
| نوع من الرموز الشريطية لا يُقرأ أبدًا | ذلك الترميز معطّل على الماسح | فعّله ([الخطوة 7](#7-إعداد-ماسح-zebra-لمعايير-gs1)) |

إن استمرت المشكلة، فاحتفظ معًا بسطر `run.bat:` من وحدة التحكم ونص مربع حوار الخطأ و
`logs\gaia-desktop.log`: فهي مجتمعةً تبيّن أي Java وأي خدمات Zebra وأي اسم جهاز استُخدمت، وأين
فشل الاتصال تحديدًا.

## 12. ماسحات Zebra ثنائية الأبعاد المدعومة

يحتاج GAIA Desktop إلى ماسح يقرأ الرموز الشريطية التي تُطبع بها بيانات GS1 — GS1-128 وGS1 DataBar
وEAN/UPC، ولمعظم الاستخدامات الرموز ثنائية الأبعاد: **GS1 DataMatrix** و**GS1 QR Code**، وهو
أيضًا الشكل الذي يُطبع به عادةً URI من نوع **GS1 Digital Link**. وهذا يعني **ماسح تصوير ثنائي
الأبعاد** من Zebra: فالماسح الخطي (أحادي البعد) لا يستطيع قراءة رموز DataMatrix أو QR إطلاقًا.

ولا يحتاج الماسح نفسه إلى فهم GS1 Application Identifiers أو Digital Link.
**فـ GAIA Desktop يحلّل كليهما**: يأخذ المسح كما قرأه الماسح — بـ AIM Code ID وفواصل FNC1 وكل
شيء — ويقسمه إلى معرّفات AI، أو يحوّل URI الـ Digital Link إلى معرّفات AI، بنفسه.

### تم اختباره

| الماسح | النوع | الحالة |
|---|---|---|
| **DS8108** | ماسح تصوير ثنائي الأبعاد محمول باليد بسلك | **بُني واختُبر** مع GAIA Desktop |

### يتوقع أن يعمل

هذه ماسحات تصوير ثنائية الأبعاد من Zebra تُشغَّل، مثل DS8108، عبر Scanner SDK وخدمات JavaPOS من
Zebra. **لم تُختبر** مع GAIA Desktop؛ أعدّ كلًّا منها كما في هذا الدليل، مستخدمًا دليله الخاص
Quick Reference Guide أو Product Reference Guide للحصول على رموز الإعداد الشريطية.

| العائلة | الطُّرز (أمثلة) |
|---|---|
| DS81x8 | DS8108 (سلكي)، DS8178 (لاسلكي) |
| DS22x8 | DS2208 (سلكي)، DS2278 (لاسلكي) — للاستخدام العام |
| DS36x8 | DS3608 (سلكي)، DS3678 (لاسلكي) — متينة، بما فيها الطرازان KD وXR |
| DS46x8 | DS4608 (سلكي)، DS4678 (لاسلكي) |
| DS9308 / DS9908 | ماسحات عرض وماسحات تعمل دون استخدام اليدين |
| MP7000 / MP7200 | ماسحات ثنائية النوافذ متعددة المستويات وماسحات مع موازين |
| CS6080 | ماسح مرافق لاسلكي |

يتخاطب الماسح اللاسلكي مع قاعدته، والقاعدة هي التي توصل بالحاسوب: صِل القاعدة عبر USB وتعامل مع
الاثنين على أنهما ماسح واحد. وقد تعمل أيضًا ماسحات من عائلات Zebra الأخرى، إن كان Scanner SDK من
Zebra يدعمها في أحد أوضاع USB الواردة في [الخطوة 6](#6-ضبط-وضع-usb-لماسح-zebra).

### ميزات GS1 على ماسح Zebra نفسه

بمعزل عن قراءة الرموز الشريطية، تستطيع بعض ماسحات التصوير ثنائية الأبعاد من Zebra معالجة بيانات
GS1 على الماسح نفسه، ويُضبط ذلك عبر 123Scan:

| الميزة | ما تفعله | بالنسبة إلى GAIA Desktop |
|---|---|---|
| **Label Parse+** | تحلّل معرّفات AI في ملصق GS1 على الماسح وترسل حقولًا معاد تنسيقها | **أبقها معطّلة** — لن يرى GAIA Desktop بعدها معرّفات AI ولا فواصل FNC1 ولا AIM Code ID |
| **GS1 Digital Link** | لمنتجات التجزئة الموسومة برمز EAN/UPC أحادي البعد ورمز Digital Link ثنائي الأبعاد معًا: تختار أيهما يُرسل | **أبقها معطّلة** (الافتراضي) |
| **GS1 Retail POS parsing** | تقرأ رموز التجزئة ثنائية الأبعاد بصيغة URI الـ Digital Link أو صيغة سلسلة العناصر | **أبقها معطّلة** |

لإعداد **GS1 Digital Link** ثلاثة أوضاع. **Mode 1 — GTIN only**، وهو الوضع الذي يبدأ به بعد
تفعيله، يرسل رقم GTIN وحده أيًّا كان الرمز الشريطي الذي جاء منه، فلا تصل أبدًا إلى GAIA Desktop
الدفعة أو تاريخ الانتهاء أو الرقم التسلسلي الموجودة في Digital Link. **Mode 2 — Prioritize 2D**
يرسل الرمز ثنائي الأبعاد إن رُئي خلال مهلة الأولوية (200 مللي ثانية افتراضيًا)، وإلا فالرمز أحادي
البعد. **Mode 3 — Corroborate 1D and 2D GTINs Match** يرسل الرمز أحادي البعد، والرمز ثنائي الأبعاد
أيضًا إن طابق رقم GTIN الخاص به. وإن كان لا بد من تفعيل الإعداد لبرنامج آخر، فاستخدم Mode 2 لا
Mode 1. وفي DS8108 هذه هي المعاملات 2373 (تشغيل/إيقاف) و2374 (الوضع) و2491 (المهلة).

يتطلب استخدام هذه الميزات **123Scan الإصدار 6 أو أحدث** وبرنامجًا ثابتًا يتضمنها. وتضيف Zebra
دعم GS1 Digital Link عبر تحديثات البرنامج الثابت منذ أبريل 2025؛ والتواريخ أدناه مأخوذة من أحد
موزّعي Zebra، فتحقّق من ملاحظات إصدار البرنامج الثابت لكل طراز:

| عائلة الطراز | تاريخ صدور البرنامج الثابت الداعم لـ GS1 Digital Link |
|---|---|
| DS81x8 | 16 أبريل 2025 |
| MP7000 | 21 أبريل 2025 |
| DS9908 | 6 يونيو 2025 |
| SP72 / SM72 | 11 يوليو 2025 |
| DS46x8 | 28 يوليو 2025 |
| MP7200 (Rev-C)، DS5502 | 30 يوليو 2025 |
| DS9308 | 29 أغسطس 2025 |
