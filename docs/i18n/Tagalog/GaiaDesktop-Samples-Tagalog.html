Mga Sample ng GAIA Desktop

Isang barcode para sa bawat karaniwang GS1 na tagadala ng datos, dalawang tinatanggihan ng GAIA, at isang lumang uri ng label para sa Pagsamahin. I-scan ang mga ito nang direkta mula sa screen gamit ang Zebra scanner, o kopyahin ang isang element string sa input bar ng GAIA Desktop.

Nagsisimula ang bawat element string sa AIM Code ID nito, na nagsasabi sa GAIA kung saang tagadala ng datos galing ang scan. Ang {GS} ay kumakatawan sa FNC1, ang separator pagkatapos ng AI na pabago-bago ang haba; kino-convert ito ng input bar sa tunay na character. Ang mga larawan ng barcode ay iginuguhit ng online barcode generator ng TEC-IT, kaya ang pagbubukas ng pahinang ito ay nagpapadala ng sample data roon. Kapag mabigat ang paggamit, maaari itong magpakita ng abiso ng rate limit sa halip na barcode; i-reload ito mamaya.

Suriin

Sa mode na Suriin, hinahati ang bawat scan o paste sa mga Application Identifier nito. Ang huling dalawang card ay mga pagkakamaling nahuhuli ng GAIA: bawat isa ay nagsasabi ng mga error na iniuulat ng GAIA.

Pagsamahin

Ang isang lumang uri ng logistics label ay naglalaman ng datos nito sa ilang GS1-128 barcode. Sa mode na Pagsamahin, mag-scan ng hanggang tatlo sa mga ito at pagsasamahin ng GAIA Desktop ang kanilang mga AI sa iisang element string na dadalhin ng isang GS1 DataMatrix, na sinusuri nang buo.
