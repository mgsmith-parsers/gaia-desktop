# Zebra स्कॅनर सेटअप — Windows साठी GAIA Desktop

Zebra बारकोड स्कॅनर कसा इन्स्टॉल आणि कॉन्फिगर करायचा, जेणेकरून GAIA Desktop त्यातून थेट GS1
बारकोड वाचू शकेल: प्रत्येक स्कॅनचे विश्लेषण होऊन तो इतिहासात जोडला जातो, आणि AIM Code ID उपसर्ग व
प्रत्येक FNC1 विभाजक जसाच्या तसा राहतो. मूळ दस्तऐवज:
[GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md).

GAIA Desktop हे USB ने जोडलेल्या **Zebra DS8108** हातात धरायच्या इमेजरसोबत तयार आणि तपासले गेले
आहे. या पायऱ्या Zebra चा Scanner SDK ज्याला समर्थन देतो अशा कोणत्याही Zebra 2D स्कॅनरला लागू होतात;
एखाद्या विशिष्ट मॉडेलचे सेटअप बारकोड आणि मेनूची नावे त्याच्या स्वतःच्या Quick Reference Guide किंवा
Product Reference Guide मध्ये असतात.

> **फक्त Windows.** Zebra चे स्कॅनर ड्रायव्हर फक्त Windows साठीच आहेत, म्हणून macOS किंवा Linux वर
> GAIA Desktop कोणतेही स्कॅनर नियंत्रण तयार करत नाही. ॲपमधील बाकी सर्व काही प्रत्येक प्लॅटफॉर्मवर
> चालते.

## 1. तुम्हाला काय लागेल

| | |
|---|---|
| **स्कॅनर** | एक Zebra 2D स्कॅनर, त्याच्या USB केबलसह — पाहा [समर्थित Zebra 2D स्कॅनर](#12-समर्थित-zebra-2d-स्कॅनर) |
| **संगणक** | Windows 10 किंवा 11, 64-बिट |
| **Java** | Java 21 किंवा नवीन, **64-बिट** |
| **Zebra Scanner SDK for Windows** | **64-बिट**, Zebra च्या सहाय्य साइटवरून — हा ड्रायव्हर आणि GAIA Desktop वापरत असलेल्या JavaPOS सेवा पुरवतो |
| **Zebra 123Scan** | Zebra ची मोफत कॉन्फिगरेशन युटिलिटी, Zebra च्या सहाय्य साइटवरून — स्कॅनरचे फर्मवेअर अपडेट करण्यासाठी आणि त्याची सेटिंग्ज तपासण्यासाठी |
| **GAIA Desktop** | `gaia-desktop-1.0.0-win.zip` |
| **ऐच्छिक** | स्कॅनरची **Product Reference Guide** (PRG), ज्यात सेटअप बारकोड असतात |

भाग एकमेकांना कसे जोडले जातात:

```
Zebra scanner ──USB──► Zebra CoreScanner driver ──► Zebra JavaPOS services ──► GAIA Desktop
                       (installed by the SDK)        (in the SDK's JPOS\bin)    (run.bat puts them on
                                                                                 the class path)
```

GAIA Desktop स्वतः JavaPOS API आणि स्कॅनरचे नाव सांगणारे कॉन्फिगरेशन (`jpos.xml`, `gaia-desktop.jar`
च्या आत) सोबत आणते. उरलेले Zebra SDK पुरवतो: स्कॅनरशी बोलणारा ड्रायव्हर, आणि JavaPOS व त्या
ड्रायव्हरच्या मध्ये असणारे Zebra चे सेवा क्लास.

## 2. Java इन्स्टॉल करा

GAIA Desktop ला **Java 21 किंवा नवीन** लागते, आणि ते **64-बिट** बिल्ड असले पाहिजे, म्हणजे ते 64-बिट
Zebra ड्रायव्हरशी जुळेल.

1. Windows x64 साठी Java 21 JDK किंवा JRE इन्स्टॉल करा — उदाहरणार्थ adoptium.net वरून
   Eclipse Temurin. इन्स्टॉलरने `JAVA_HOME` सेट करण्याचा पर्याय दिल्यास त्याला ते करू द्या.
2. Command Prompt मध्ये तपासा:

   ```
   java -version
   ```

   पहिल्या ओळीत आवृत्ती 21 किंवा नंतरची दिसली पाहिजे; 64-बिट Java `64-Bit Server VM` देखील छापते.

`run.bat` Java या क्रमाने शोधतो: `run.bat` शेजारी असलेले `jdk*` फोल्डर, मग `JAVA_HOME`, मग
`PATH` वरील `java`. 21 पेक्षा जुने काहीही असल्यास संदेश देऊन ते नाकारतो.

---

## 3. Zebra Scanner SDK इन्स्टॉल करा

1. Zebra च्या सहाय्य साइटवरून **Zebra Scanner SDK for Windows (64-bit)** डाउनलोड करा.
2. इन्स्टॉलर चालवा. घटक निवडण्याचा पर्याय दिल्यास **JPOS** (JavaPOS) घटक समाविष्ट असल्याची खात्री
   करा.
3. डीफॉल्ट इन्स्टॉल स्थान तसेच ठेवा. GAIA Desktop SDK चा JavaPOS भाग येथे शोधते:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   आणि Zebra च्या सेवा jar फाइल्स (`JposServiceScanner.jar`, `JposServiceJniScanner.jar`, …) व नेटिव्ह
   लायब्ररी (`CSJPOSScanner64.dll`, …) त्याच्या `bin\` फोल्डरमध्ये असण्याची अपेक्षा करते. SDK दुसरीकडे
   इन्स्टॉल असल्यास [ZEBRA_HOME](#zebra_home) पाहा.
4. इन्स्टॉलनंतर **Windows रीस्टार्ट करा**. SDK चा CoreScanner ड्रायव्हर पार्श्वभूमीत चालतो आणि
   GAIA Desktop स्कॅनरपर्यंत पोहोचण्यापूर्वी तो चालू असणे आवश्यक आहे; रीस्टार्ट हा याची खात्री करण्याचा
   सर्वात सोपा मार्ग आहे.

## 4. 123Scan इन्स्टॉल करा

123Scan ही Zebra ची स्वतःचे स्कॅनर कॉन्फिगर करण्याची मोफत युटिलिटी आहे. पुढच्या पायरीत तिच्याने
स्कॅनरचे फर्मवेअर अपडेट केले जाते, आणि नंतर स्कॅनरची सेटिंग्ज तपासण्याचा व बदलण्याचा हाच सर्वात सोपा
मार्ग आहे.

1. Zebra च्या सहाय्य साइटवरून **123Scan** डाउनलोड करा आणि इन्स्टॉलर चालवा.
2. Zebra स्कॅनर जोडा आणि 123Scan सुरू करा. तिला स्कॅनर सापडला पाहिजे आणि त्याचे मॉडेल, अनुक्रमांक व
   सध्याची फर्मवेअर आवृत्ती दिसली पाहिजे. तसे न झाल्यास, पुढे जाण्यापूर्वी दुसरा USB पोर्ट किंवा केबल
   वापरून पाहा — जो स्कॅनर 123Scan ला दिसत नाही, तो GAIA Desktop लाही दिसणार नाही.

---

## 5. Zebra स्कॅनरचे फर्मवेअर अपडेट करा

कॉन्फिगर करण्यापूर्वी स्कॅनरचे फर्मवेअर नवीनतम आवृत्तीवर आणा. फर्मवेअर अपडेट डिकोडिंगच्या समस्या
दूर करतात आणि स्कॅनरला SDK ने इन्स्टॉल केलेल्या Zebra ड्रायव्हरशी सुसंगत ठेवतात.

1. **GAIA Desktop** आणि स्कॅनर वापरत असू शकणारा इतर कोणताही प्रोग्राम बंद करा: अपडेटदरम्यान
   123Scan ला स्कॅनर पूर्णपणे स्वतःकडे हवा असतो.
2. स्कॅनर जोडलेला असताना 123Scan मध्ये त्याचा फर्मवेअर अपडेटचा पर्याय निवडा. 123Scan स्कॅनरच्या
   फर्मवेअरची तुलना Zebra ने प्रकाशित केलेल्या नवीनतम फर्मवेअरशी करते आणि ते डाउनलोड करून इन्स्टॉल
   करण्याचा पर्याय देते. संगणकावर इंटरनेट नसल्यास, Zebra च्या साइटवरील स्कॅनरच्या सहाय्य पानावरून
   त्याचे फर्मवेअर डाउनलोड करा आणि फाइल 123Scan मध्ये लोड करा.
3. अपडेट सुरू करा आणि **123Scan अपडेट पूर्ण झाल्याचे सांगेपर्यंत स्कॅनर जोडलेलाच ठेवा**. याला काही
   मिनिटे लागतात; शेवटी स्कॅनर रीस्टार्ट होतो. मध्येच काढल्यास तो निरुपयोगी होऊ शकतो.
4. 123Scan आता नवीन फर्मवेअर आवृत्ती दाखवत असल्याची खात्री करा.

अपडेटमुळे काही सेटिंग्ज डीफॉल्टवर परत जाऊ शकतात, म्हणूनच स्कॅनर पुढच्या दोन पायऱ्यांमध्ये, फर्मवेअरनंतर,
कॉन्फिगर केला जातो.

## 6. Zebra स्कॅनरचा USB मोड सेट करा

हीच पायरी सर्वाधिक वेळा सुटते. **खोक्यातून काढलेला Zebra स्कॅनर एक USB कीबोर्ड असतो** (USB HID
Keyboard मोड): जिथे फोकस असेल तिथे तो प्रत्येक बारकोड "टाइप" करतो. त्या मोडमध्ये GAIA Desktop चे
*स्कॅनर जोडा* त्याला शोधू शकत नाही, आणि टेक्स्ट फील्डमध्ये टाइप होणारी प्रत्येक गोष्ट आपले FNC1
विभाजक गमावते, ज्यामुळे GS1 घटक स्ट्रिंगचा अर्थ बदलतो.

स्कॅनरला अशा मोडमध्ये बदला ज्याच्याशी Zebra ड्रायव्हर थेट बोलतो:

| स्कॅनरचा USB मोड | GAIA Desktop मधील डिव्हाइसचे नाव | टीप |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld`, किंवा `ZebraAllScanners` | शिफारस केलेला |
| SNAPI (इमेजिंगसह किंवा शिवाय) | `ZebraScannerSNAPI`, किंवा `ZebraAllScanners` | Zebra चा स्वतःचा USB प्रोटोकॉल; हाही चालतो |
| IBM Table-top USB | `ZebraUSBTableTop`, किंवा `ZebraAllScanners` | टेबल-टॉप स्कॅनरसाठी |
| USB OPOS (Hand-held) | `ZebraUSBOPOS`, किंवा `ZebraAllScanners` | |
| USB HID Keyboard (फॅक्टरी डीफॉल्ट) | — | **जोडला जाणार नाही** |

`ZebraAllScanners`, GAIA Desktop मधील डीफॉल्ट डिव्हाइस नाव, कोणत्याही समर्थित मोडमधील स्कॅनर स्वीकारते,
म्हणून मोड सेट होताच डीफॉल्ट सहसा आपोआप काम करते.

मोड बदलण्यासाठी, एकतर:

- स्कॅनरच्या Quick Reference Guide किंवा Product Reference Guide मधील (USB Host Types / USB Device
  Type विभाग) त्या मोडचा — उदा. *IBM Hand-held USB* — **सेटअप बारकोड स्कॅन करा**; स्कॅनर बीप करून
  खात्री देतो. किंवा
- **123Scan वापरा** ([पायरी 4](#4-123scan-इन्स्टॉल-करा)): स्कॅनर जोडा, त्याचे कॉन्फिगरेशन उघडा, आणि USB
  होस्टचा प्रकार सेट करा.

मोड बदलल्यानंतर Windows स्कॅनरला वेगळ्या प्रकारचे डिव्हाइस म्हणून पुन्हा ओळखते; जोडण्यापूर्वी काही
सेकंद थांबा.

नंतर स्कॅनर पुन्हा कीबोर्ड मोडमध्ये आणण्यासाठी — इतर सॉफ्टवेअरसोबत वापरण्यासाठी — *USB Keyboard
(HID)* सेटअप बारकोड स्कॅन करा, किंवा त्याची फॅक्टरी डीफॉल्ट सेटिंग्ज पुनर्संचयित करा.

## 7. GS1 साठी Zebra स्कॅनर कॉन्फिगर करा

स्कॅनरने कोणत्या प्रकारचा बारकोड वाचला हे सांगितल्यास GAIA Desktop सर्वोत्तम विश्लेषण करते.

### AIM Code ID पाठवा

Product Reference Guide (User Preferences) मधील सेटअप बारकोडने किंवा 123Scan मध्ये **Transmit Code ID
Character** हे **AIM Code ID Character** वर सेट करा. मग प्रत्येक स्कॅन त्याच्या सिम्बॉलॉजी ओळखकर्त्याने
सुरू होतो — GS1-128 साठी `]C1`, GS1 DataMatrix साठी `]d2`, GS1 QR Code साठी `]Q3`, GS1 DataBar
साठी `]e0` — ज्याचा वापर GAIA Desktop डेटा वाहकाचे नाव सांगण्यासाठी आणि त्याचे नियम लागू करण्यासाठी
करते.

याशिवायही GAIA Desktop घटक स्ट्रिंगचे विश्लेषण करते आणि सिम्बॉलॉजी स्कॅनमधूनच घेते, पण अहवालाकडे
दाखवण्यासाठी AIM Code ID नसतो, आणि EAN-13 सारखा साधा बारकोड GS1 घटक स्ट्रिंगपासून वेगळा ओळखणे कठीण
होते.

### सिम्बॉलॉजी तपासा

तुम्ही ज्या बारकोड प्रकारांसोबत काम करता ते **सक्षम** असल्याची खात्री करा: सहसा GS1-128,
GS1 DataMatrix, GS1 DataBar, GS1 QR Code आणि EAN/UPC. Zebra च्या 2D स्कॅनरवर यातील बहुतेक डीफॉल्टने
चालू असतात; 123Scan सध्याची सेटिंग्ज दाखवते, आणि Product Reference Guide मध्ये प्रत्येक सक्षम करण्याचा
बारकोड असतो.

### Zebra ची GS1 विश्लेषण वैशिष्ट्ये बंद ठेवा

नवीन फर्मवेअर स्कॅनरवरच काम करणारी GS1 वैशिष्ट्ये जोडते — **Label Parse+**, **GS1 Digital Link**
आणि **GS1 Retail POS parsing**. ती **बंद** ठेवा, जसा स्कॅनर येतो तसे: ती स्कॅनर पाठवत असलेल्या माहितीचे
स्वरूप बदलतात किंवा ती लहान करतात, तर GAIA Desktop ला विश्लेषण आणि पडताळणीसाठी कच्चा डेटा हवा असतो.
प्रत्येक वैशिष्ट्य काय करते ते [समर्थित Zebra 2D स्कॅनर](#12-समर्थित-zebra-2d-स्कॅनर) मध्ये पाहा.

### उपसर्ग आणि प्रत्यय बंद ठेवा

स्कॅनरच्या आउटपुटमध्ये कोणताही उपसर्ग, प्रत्यय किंवा Enter की जोडू नका. GAIA Desktop प्रत्येक स्कॅन
JavaPOS मार्फत एक संपूर्ण संदेश म्हणून घेते आणि त्याला यापैकी कशाचीही गरज नसते; जादा अक्षरे घटक
स्ट्रिंगमध्ये जातील.

## 8. GAIA Desktop इन्स्टॉल करा आणि सुरू करा

   ```
   ├── lib\
   ```

2. स्कॅनर जोडा.
3. **`run.bat`** वर डबल-क्लिक करा. ॲपशेजारी एक कन्सोल विंडो उघडते आणि उघडीच राहते: स्कॅनरची स्थिती
   आणि JavaPOS त्रुटी तिथे दिसतात.


   ती **`Zebra services from none (Zebra Scanner SDK not installed)`** ने संपत असल्यास SDK त्याच्या

   [ZEBRA_HOME](#zebra_home) सेट करा. ॲप तरीही सुरू होते, पण स्कॅनर जोडला जाऊ शकत नाही.

## 9. स्कॅनर जोडा

1. टूलबारमध्ये **डिव्हाइस निवडक** GAIA Desktop ला माहीत असलेल्या स्कॅनरची नावे दाखवतो. तो
   **`ZebraAllScanners`** वर राहू द्या, किंवा [पायरी 6](#6-zebra-स्कॅनरचा-usb-मोड-सेट-करा) मधील तक्त्यातून
   स्कॅनरच्या USB मोडचे नाव निवडा.
2. **स्कॅनर जोडा** वर क्लिक करा, किंवा **Ctrl+K** दाबा (हे **स्कॅनर** मेनूमध्येही आहे).
3. स्टेटस बार बदलून **`स्कॅनर: ZebraAllScanners`** (किंवा तुम्ही निवडलेले नाव) होतो, आणि स्थिती ओळ
   *स्कॅनर जोडला — ZebraAllScanners* सांगते. बटणावर आता **स्कॅनर तोडा** असे लिहिलेले असते.
4. एखादा GS1 बारकोड स्कॅन करा. तो कॅप्चर इतिहासात सर्वात वर दिसतो आणि त्याचा अहवाल उघडतो. AIM Code ID
   चालू असल्यास अहवाल डेटा वाहकाचे नाव सांगतो — *GS1-128*, *GS1 DataMatrix* — आणि घटक स्ट्रिंग प्रत्येक
   FNC1 विभाजक राखते.

डिव्हाइस निवडक प्रत्येक वेळी चालवताना तुमची निवड लक्षात ठेवतो. तुम्ही तोडेपर्यंत किंवा ॲप बंद करेपर्यंत
स्कॅनर जोडलेला राहतो. स्कॅन **निर्मिती** आणि **संयोजन** मोडमध्येही काम करतात: संयोजनमध्ये प्रत्येक
स्कॅन एकत्र केल्या जाणाऱ्या बारकोडपैकी एक बनतो.

GAIA Desktop स्कॅनर धरून ठेवत असताना इतर प्रोग्राम तो वापरू शकत नाहीत, आणि उलटही: जोडण्यापूर्वी
123Scan आणि इतर कोणतेही पॉइंट-ऑफ-सेल किंवा स्कॅनर सॉफ्टवेअर बंद करा.

### ZEBRA_HOME

Zebra SDK डीफॉल्टव्यतिरिक्त इतरत्र इन्स्टॉल असल्यास `run.bat` सुरू करण्यापूर्वी `ZEBRA_HOME` त्याच्या
`JPOS` फोल्डरवर सेट करा — उदाहरणार्थ त्याच्या शेजारी ठेवलेल्या एका छोट्या बॅच फाइलमध्ये:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

मग `run.bat` Zebra च्या सेवा jar फाइल्स `%ZEBRA_HOME%bin` मधून घेतो आणि Zebra DLL साठी ते फोल्डर
`PATH` मध्ये जोडतो.

### तुमचे स्वतःचे jpos.xml

डिव्हाइसचे नाव जोडण्यासाठी किंवा एखाद्या नोंदीची सेटिंग्ज बदलण्यासाठी `gaia-desktop.jar` मधून
`jpos.xml` ची प्रत काढा (ते zip आहे; कोणतेही अनझिप साधन ते उघडते), प्रत संपादित करा, आणि
GAIA Desktop ला तिच्याकडे निर्देशित करा:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

मग डिव्हाइस निवडक त्या फाइलमधील स्कॅनर दाखवतो. एकापेक्षा जास्त Zebra स्कॅनर जोडलेले असल्यास, एखादी
नोंद तिच्या `ScannerModel` किंवा `SerialNumber` गुणधर्माद्वारे त्यापैकी एकाशी बांधता येते, जसे
`ZebraAllScanners` नोंदीत आहे.

### इतर पर्याय

| सेटिंग | कसे |
|---|---|
| ॲपची भाषा | `run.bat --language=FR` (फक्त या वेळेसाठी), किंवा पर्याय पॅनेल |
| अतिरिक्त Java पर्याय | `run.bat` आधी `set GAIA_DESKTOP_OPTS=…` |
| सोबत ठेवलेले Java | `run.bat` शेजारी `jdk-21…` फोल्डर ठेवा; ते `JAVA_HOME` च्या आधी वापरले जाते |

## 12. समर्थित Zebra 2D स्कॅनर

GAIA Desktop ला असा स्कॅनर लागतो जो GS1 डेटा ज्या बारकोडमध्ये छापला जातो ते वाचू शकेल — GS1-128,
GS1 DataBar, EAN/UPC, आणि बहुतेक वापरांसाठी 2D कोड: **GS1 DataMatrix** आणि **GS1 QR Code**, ज्यात सहसा
**GS1 Digital Link** URI देखील छापला जातो. म्हणजेच Zebra **2D इमेजर**: रेषीय (1D) स्कॅनर DataMatrix
किंवा QR कोड अजिबात वाचू शकत नाही.

स्कॅनरला स्वतः GS1 Application Identifiers किंवा Digital Link समजण्याची गरज नाही.
**GAIA Desktop दोन्हींचे विश्लेषण करते**: स्कॅनरने वाचला तसाच स्कॅन ते घेते — AIM Code ID, FNC1
विभाजक, सर्व काही — आणि स्वतःच त्याचे AI मध्ये विभाजन करते, किंवा Digital Link URI चे त्याच्या AI मध्ये
रूपांतर करते.

### तपासलेले

| स्कॅनर | प्रकार | स्थिती |
|---|---|---|
| **DS8108** | वायर असलेला हातात धरायचा 2D इमेजर | GAIA Desktop सोबत **तयार आणि तपासलेला** |

### चालणे अपेक्षित

हे Zebra चे 2D इमेजर आहेत जे DS8108 प्रमाणेच Zebra च्या Scanner SDK आणि JavaPOS सेवांद्वारे चालतात. ते
GAIA Desktop सोबत **तपासलेले नाहीत**; प्रत्येक या मार्गदर्शकाप्रमाणे सेट करा, आणि सेटअप बारकोडसाठी
त्याची स्वतःची Quick Reference Guide किंवा Product Reference Guide वापरा.

| कुटुंब | मॉडेल (उदाहरणे) |
|---|---|
| DS81x8 | DS8108 (वायरसह), DS8178 (बिनतारी) |
| DS22x8 | DS2208 (वायरसह), DS2278 (बिनतारी) — सर्वसाधारण वापर |
| DS36x8 | DS3608 (वायरसह), DS3678 (बिनतारी) — मजबूत, KD आणि XR प्रकारांसह |
| DS46x8 | DS4608 (वायरसह), DS4678 (बिनतारी) |
| DS9308 / DS9908 | प्रेझेंटेशन आणि हँड्स-फ्री स्कॅनर |
| MP7000 / MP7200 | बहु-प्रतल बायोप्टिक स्कॅनर आणि स्कॅनर-वजनकाटे |
| CS6080 | बिनतारी सहचर स्कॅनर |

बिनतारी स्कॅनर त्याच्या क्रेडलशी बोलतो, आणि संगणकाला क्रेडलच जोडला जातो: क्रेडल USB ने जोडा आणि
जोडीला एक स्कॅनर समजा. इतर Zebra कुटुंबांतील स्कॅनरही चालू शकतात, जर Zebra चा Scanner SDK त्यांना
[पायरी 6](#6-zebra-स्कॅनरचा-usb-मोड-सेट-करा) मधील एखाद्या USB मोडमध्ये समर्थन देत असेल.

### Zebra स्कॅनरवरच चालणारी GS1 वैशिष्ट्ये

बारकोड वाचण्याव्यतिरिक्त, काही Zebra 2D इमेजर स्कॅनरवरच GS1 डेटावर प्रक्रिया करू शकतात, जे 123Scan
मधून कॉन्फिगर केले जाते:

| वैशिष्ट्य | ते काय करते | GAIA Desktop साठी |
|---|---|---|
| **Label Parse+** | स्कॅनरवरच GS1 लेबलच्या AI चे विश्लेषण करून नव्या स्वरूपातील फील्ड पाठवते | **बंद ठेवा** — मग GAIA Desktop ला AI, FNC1 विभाजक आणि AIM Code ID दिसणार नाहीत |
| **GS1 Digital Link** | 1D EAN/UPC आणि 2D Digital Link कोड दोन्ही असलेल्या किरकोळ उत्पादनांसाठी: काय पाठवायचे ते निवडते | **बंद ठेवा** (डीफॉल्ट) |

**GS1 Digital Link** सेटिंगचे तीन मोड आहेत. **Mode 1 — GTIN only**, सक्षम केल्यावर ज्या मोडमध्ये ते
सुरू होते, फक्त GTIN पाठवतो, तो कोणत्याही बारकोडमधून आला तरी, म्हणून Digital Link मधील बॅच, कालबाह्यता
तारीख किंवा अनुक्रमांक कधीच GAIA Desktop पर्यंत पोहोचत नाही. **Mode 2 — Prioritize 2D** प्राधान्य
कालमर्यादेत (डीफॉल्ट 200 ms) 2D कोड दिसल्यास तो पाठवतो, नाहीतर 1D. **Mode 3 — Corroborate 1D and 2D
GTINs Match** 1D पाठवतो, आणि GTIN जुळल्यास 2D देखील. दुसऱ्या सॉफ्टवेअरसाठी सेटिंग चालू ठेवणे भागच असल्यास
Mode 1 नव्हे, Mode 2 वापरा. DS8108 वर हे पॅरामीटर 2373 (चालू/बंद), 2374 (मोड) आणि 2491 (कालमर्यादा)
आहेत.
