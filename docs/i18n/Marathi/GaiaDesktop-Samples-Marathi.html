GAIA Desktop नमुने

प्रत्येक GS1 डेटा वाहकासाठी एक बारकोड, आणि संयोजनासाठी एक पारंपरिक लेबल. Zebra स्कॅनरने ते थेट स्क्रीनवरून स्कॅन करा, किंवा एखादी घटक स्ट्रिंग GAIA Desktop च्या इनपुट बारमध्ये कॉपी करा.

प्रत्येक घटक स्ट्रिंग तिच्या AIM Code ID ने सुरू होते, जो GAIA ला सांगतो की स्कॅन कोणत्या डेटा वाहकावरून आला. {GS} म्हणजे FNC1, बदलत्या लांबीच्या AI नंतर येणारा विभाजक; इनपुट बार त्याचे खऱ्या वर्णात रूपांतर करतो. बारकोडच्या प्रतिमा TEC-IT चा ऑनलाइन बारकोड जनरेटर काढतो, त्यामुळे हे पेज उघडल्यावर नमुना डेटा त्याला पाठवला जातो. जास्त वापराच्या वेळी तो बारकोडऐवजी विनंती-मर्यादेची सूचना दाखवू शकतो; नंतर पुन्हा लोड करा.

विश्लेषण

विश्लेषण मोडमध्ये प्रत्येक स्कॅन किंवा पेस्ट त्याच्या Application Identifiers मध्ये विभागला जातो.
