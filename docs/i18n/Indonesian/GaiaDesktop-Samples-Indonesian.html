Contoh GAIA Desktop

Satu kode batang untuk setiap pembawa data GS1, dan satu label lama untuk Gabung. Pindai langsung dari layar dengan pemindai Zebra, atau salin untai elemen ke bilah input GAIA Desktop.

Setiap untai elemen diawali dengan AIM Code ID-nya, yang memberi tahu GAIA dari pembawa data mana pindaian berasal. {GS} mewakili FNC1, pemisah setelah AI dengan panjang variabel; bilah input mengubahnya menjadi karakter yang sebenarnya. Gambar kode batang dibuat oleh pembuat kode batang online TEC-IT, jadi membuka halaman ini mengirimkan data contoh ke sana. Saat penggunaan tinggi, layanan itu mungkin menampilkan pemberitahuan batas permintaan sebagai ganti kode batang; muat ulang nanti.

Urai

Dalam mode Urai, setiap pindaian atau tempelan diurai menjadi Application Identifier-nya.

Gabung

Label logistik lama membawa datanya dalam beberapa kode batang GS1-128. Dalam mode Gabung, pindai hingga tiga di antaranya dan GAIA Desktop menggabungkan AI-nya menjadi satu untai elemen yang akan dibawa oleh GS1 DataMatrix, divalidasi secara keseluruhan. Pindai ketiganya secara berurutan:
