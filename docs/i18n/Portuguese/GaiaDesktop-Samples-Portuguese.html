Exemplos do GAIA Desktop

Um código de barras para cada portador de dados GS1 comum, dois que o GAIA rejeita e uma etiqueta tradicional para Combinar. Leia-os diretamente no ecrã com um leitor Zebra ou copie uma cadeia de elementos para a barra de entrada do GAIA Desktop.

Cada cadeia de elementos começa pelo seu AIM Code ID, que indica ao GAIA de que portador de dados veio a leitura. {GS} representa o FNC1, o separador a seguir a um AI de comprimento variável; a barra de entrada converte-o no carácter real. As imagens dos códigos de barras são geradas pelo gerador de códigos de barras online da TEC-IT, pelo que abrir esta página envia-lhe os dados de exemplo. Com uso intenso, pode mostrar um aviso de limite de pedidos em vez de um código de barras; volte a carregar mais tarde.

Analisar

No modo Analisar, cada leitura ou texto colado é decomposto nos seus Application Identifiers. Os dois últimos cartões são erros que o GAIA deteta: cada um indica os erros que o GAIA comunica.
