## これは何か

GAIA Desktop は GS1 データに対して次の 2 つを行います。

- **解析** — GS1 の要素ストリングまたは Digital Link URI を入力・貼り付け・ファイルから読み込み・
  スキャンし、その結果を完全なレポートとして読み取ります。各アプリケーション識別子 (AI) が何を
  意味するのか、どこが誤っているのか、そしてその理由が分かります。
- **作成** — AI と値の組み合わせを、要素ストリングまたは Digital Link URI に組み立てます。

このアプリが GS1 について知っていることは、AI の定義、検証ルール、エラーメッセージ、ローカライズ
された説明にいたるまで、すべて土台にある GAIA エンジンから来ています。アプリ自身は規則を一切
足しません。つまり、アプリが受け付けるものはエンジンが受け付けるものとまったく同じです。

## 起動する

```bash
java -jar gaia-desktop.jar
```

この JAR は、隣に配置される `lib/` ディレクトリを必要とします。2 つを一緒に置いてください。
離すと起動しません。（単体で完結する JAR をビルドすることもできます。
[開発者ガイド](../../GaiaDesktop-Developer.md#packaging) を参照。）

**Java 21 以降**が必要です。配布物は OS と CPU アーキテクチャごとに異なるため、お使いのマシン用に
ビルドされた JAR を使用してください。

保存済みの言語を変えずに、特定の言語で開くには次のようにします。

```bash
java -jar gaia-desktop.jar --language=FR
```

値にはカタログコード (`FR`、`PCM`、`ARZ`)、正式名 (`FRENCH`、`WU-CHINESE`)、または言語タグ
(`fr`、広東語なら `zh-HK`、エジプト・アラビア語なら `ar-EG`) を指定できます。大文字と小文字は
区別しません。この指定はその実行にのみ適用されます。保存済みの言語はそのまま残るので、同僚のために
作ったショートカットが自分の環境で開く言語を変えてしまうことはありません。アプリの*中で*言語を
選んだ場合は本人の選択とみなされ、通常どおり保存されます。どの言語も指さない値はコンソールに
メモを残して無視され、起動を拒否するのではなく保存済みの言語で開きます。

起動時、コンソールにはアプリのバージョン、ビルド日、エンジンのバージョンを示す 1 行が出力されます。
不具合を報告するときは、この行を引用してください。

> この図はこのドキュメントの他のコードブロックと同じく英語のままです。画面では
> *解析* / *作成*、*キャプチャ*、*レポートを保存*、*オプション*、*スキャナー: オフ*、

単にもう 1 件のキャプチャになるからです。

オプションパネルは**初回起動時は閉じています**。モード、パネルの表示状態、テーマ、最後に使った
スキャナーは、次回の起動時にも引き継がれます。

## 解析モード

### 入力バーと {GS} トークン

このバーは、要素ストリング、GS1 Digital Link URI、または AIM Code ID 接頭辞 (`]d2…`) を含む生の
スキャンデータを受け付けます。<kbd>Enter</kbd> で解析します。

可変長の AI は **FNC1** — 目に見えない制御文字 `0x1D` — で区切られます。テキストフィールドはこの
文字を保持できません。黙って取り除かれてしまうため、`01…` + FNC1 + `10LOT` は `01…10LOT` として
届き、意味の違う要素ストリングになってしまいます。

そこでアプリは、区切り文字を目に見えるトークン **`{GS}`** として表示し、解析器に渡す途中で元に
戻します。

- **`{GS}` ボタン**はカーソル位置にトークンを挿入します。
- 本物の区切り文字を**貼り付ける**と — キーボード、コンテキストメニュー、ドラッグ＆ドロップの
  いずれでも — 自動的に `{GS}` に変換され、何も失われません。
- トークンの書き方はレポートでの書き方と同じなので、レポートからコピーした値をそのまま貼り戻せます。

キャプチャ、レポート、保存された履歴は、いずれも**本物の**区切り文字を保持しています。トークンは
表示と入力のためだけのものです。

### スキャン

> **Windows 専用。** Zebra はスキャナードライバを Windows 向けにのみ提供しているため、macOS と
> Linux ではスキャナー関連のコントロールを一切構築しません。*スキャナーを接続* トグルも、デバイス
> 選択も、*スキャナー* メニューも、ステータスバーのスキャナー表示もありません。グレーアウトでは
> なく最初から存在しません。有効にできる設定も機器も存在しないからです。保存されたスキャンの
> ファイルを開くことを含め、それ以外の機能はどの環境でも動作します。

*スキャナーを接続* は、選択欄で指定したデバイスを開きます。既定値は `ZebraAllScanners` で、
ほとんどの機種に対応します。スキャンのたびに解析され、自動的に履歴へ追加されます。

スキャナーからのデータはバイト単位で読み取られるため、AIM Code ID 接頭辞とすべての FNC1 区切り文字
が、スキャナーが送ったとおりに解析器へ届きます。

作成モードではスキャナーのコントロールは隠れますが、接続済みのスキャナーはそのまま動作します。
*スキャナー → 接続 / 切断*（<kbd>⌘K</kbd>）は引き続き切り替えられ、ステータスバーにも表示され、
エディタを開いている間に届いたスキャンもきちんとキャプチャされます。

接続できない場合は[トラブルシューティング](#トラブルシューティング)を参照してください。

### ファイルを開く

*ファイル → テキストファイルを開く…* は、**空でない各行をそれぞれ 1 件のキャプチャとして**解析
します。誰かから送られてきたスキャンの束を処理するのに便利です。ファイルはバイト単位で読まれるため、
中にある生の区切り文字も失われません。

### キャプチャ履歴

新しいものが上に並びます。各行には有効 / 無効を示す点、1 行の要約、キャプチャ時刻、取得元、AI の
個数が表示されます。日付は前日以前のキャプチャにのみ付き、当日の行は時刻だけを表示します。

要約は、Digital Link の場合は **Digital Link URI**、それ以外は **HRI** です。要素ストリングでは
`(01)09506000134352 (17)261231` のほうが `01095060001343521726123110…` より読みやすいからです。

キャプチャを右クリックすると、入力または HRI のコピー、入力バーへ戻す、エディタで開く、削除、
履歴の消去ができます。

## 作成モード

### AI エディタ

AI と値の組を並べた表です。AI コードを直接入力するか、*AI を追加…* の一覧から**エンジンが知って
いるすべての AI** を選びます。入力するそばから **タイトル**、**形式**、**説明** の各列が、選択中の
言語で埋まります。この一覧には、作成側が拒否するような AI は現れません。

表の末尾には常に**空の行が 1 つ**あります。そこに入力すると次の行が現れるので、複数の AI を持つ
ストリングでも *行を追加* を使う必要はありません。

編集操作は表として自然に振る舞います。<kbd>Enter</kbd>、<kbd>Tab</kbd>、
<kbd>Shift</kbd>+<kbd>Tab</kbd>、そして他の場所のクリックは、いずれも入力内容を**確定**します。
<kbd>Esc</kbd> は破棄します。<kbd>Tab</kbd> は AI → 値 → 次の行と進み、編集できない列は飛ばします。

### エディタが拒否するもの

| | どうなるか |
|---|---|
| エンジンが認識しない AI | 入力中に行が赤くなり、作成は説明付きで拒否されます |
| 同じ AI を一覧から 2 回 | 追加されません。メッセージがその AI を示し、すでに持っている行が選択されます |
| 同じ AI を手入力で 2 回 | 両方の行に印が付き、作成はエラー `GE-S004` で拒否されます |
| 作成するものがない | メッセージが出て、キャプチャは作られません |

1 つの要素ストリングに同じ AI は 1 度しか現れません。だからこそ一覧は、失敗が確定した作成を試させる
のではなく、その場で拒否します。

### 要素ストリングか Digital Link か

**要素ストリングを作成** は、規格が求める箇所に FNC1 区切り文字を挿入しながら各行を組み立てます。
**Digital Link を作成** は URI を生成します。標準の `id.gs1.org` ではなく自前のリゾルバへ向けたい
場合は、*Digital Link の宛先* を展開してください。

| 項目 | 効果 | 空欄の意味 |
|---|---|---|
| ドメイン | リゾルバのホスト。例: `example.com` | `id.gs1.org` |
| パスのプレフィックス | AI パスの前に置く区切り。例: `/products` | プレフィックスなし |

**成功**した結果は、スキャンとまったく同じように扱われます。解析され、履歴に追加され、レポートとして
描画され、保存されます。作成側は自らの出力を解析して検証しているため、返ってきたものは必ず妥当です。

**失敗**した場合、キャプチャは作られません。理由は作成ボタンの下に残り、問題 1 件につき 1 行で、
エラー、対象の AI、そしてエンジン自身の説明が示されます。

```
GE-C003  (01)  Check digit validation failed for AI (01) value ''09506000134350''
```

> このメッセージ中の二重になった引用符は、このアプリではなくエンジンのエラーカタログに由来します。

### 既存のキャプチャを編集する

キャプチャを右クリック → **作成** で、その AI がエディタに読み込まれます。値を変えて作り直すと、
結果は新しいキャプチャとして追加され、元のキャプチャはそのまま残ります。

## レポート

選択したキャプチャは、完全なレポートとして描画されます。判定バナー、ラベル付きの「テープ」に分解
された要素ストリング、解析メタデータ、AI ごとの解釈カード、そして修正の手掛かりを添えたエラーと
警告です。

**Digital Link** の場合、各 AI のカードには構造上の役割 — **主キー**、**キー修飾子**、
**データ属性** — も色分けで示され、URI での出現順に並びます。役割が表示されるのは Digital Link の
ときだけです。単なる要素ストリングでは、AI に URI 上の位置がないためです。

レポートは、選択した言語とテーマに従います。

### 書き出し

| | |
|---|---|
| **レポートを保存 → HTML で…**（<kbd>⌘S</kbd>） | 画面に表示されているものをそのまま書き出します。どのブラウザーでも開ける単体のファイルです |
| **レポートを保存 → PDF で…**（<kbd>⌘P</kbd>） | システムの印刷ダイアログ経由で印刷します。そこで PDF の出力先を選んでください |

PDF が印刷ダイアログを経由するのは、出力先とファイル名をそこで選ぶからです。macOS では
**PDF ▾ → PDF として保存**、Windows では **Microsoft Print to PDF**、Linux では
**ファイルへ出力** を選びます。ページは適切に分割され、文字は選択可能なまま残ります。

印刷と PDF の出力は、アプリがダークテーマであっても常に明るいパレットを使い、色付きの AI チップと
判定バナーはそのまま保たれます。

プリンターも PDF の出力先も設定されていない場合、アプリはその旨を伝え、HTML の書き出しを案内します。
HTML はどのブラウザーからでも印刷できます。

## 解析オプション

右側のパネルには、エンジンのオプションがすべて並びます。どれかを変更すると**選択中のキャプチャが
その場で再解析される**ため、次のスキャンに備えるだけでなく、「この設定ならこの入力はどう見えるか」
を確かめる道具にもなります。

| オプション | 値 |
|---|---|
| 解析モード | `SYNTAX`、`CONTENT`、`DATA_CARRIER`、`INTERPRETATION` — どこまで踏み込んで解析するか |
| 言語 | 35 のメッセージカタログ |
| 順序 | `LITTLE` (dd/mm/yyyy)、`MIDDLE` (mm/dd/yyyy)、`BIG` (yyyy/mm/dd) |
| 区切り文字 | `SLASH`、`HYPHEN`、`PERIOD` |
| 月 | `TWO_DIGIT` (12)、`THREE_LETTER` (DEC) |
| 年 | `FOUR_DIGIT` (2026)、`TWO_DIGIT` (26) |
| 「requires」チェックをスキップ | 必須の相手 AI が欠けていても拒否しなくなります (`GE-S005`) |
| 「excludes」チェックをスキップ | 規格が禁じる AI の組み合わせでも拒否しなくなります (`GE-S006`) |

パネル下部の *既定値に戻す* は、エンジン本来の既定値を復元します。

### 初回起動

まだ何も保存されていないとき、アプリはエンジンの既定値ではなく**お使いのマシンの地域設定**から
設定を取り込みます。

- **言語**はシステムのロケールから取られ、対応するカタログがない場合は英語に戻ります。
- **日付のオプション**はロケールの短い日付形式から読み取られます。要素の並び順、区切り文字、
  そして月と年を省略形にするかどうかです。

> **注記。** したがって、短い日付を 2 桁の年で書くロケールでは、ここでも 2 桁の年から始まります。
> システムの他の表示とは揃いますが、エンジン本来の既定値である 4 桁とは異なります。パネルで変更
> すれば、その選択が保持されます。

## 言語

言語を選ぶと、エラーメッセージだけでなく**アプリケーション全体** — メニュー、ボタン、エディタ、
オプションパネル、ステータス行、レポート — が切り替わります。右から左に書く言語では、ウィンドウと
レポートが反転します。

35 の言語すべてを利用でき、カバー範囲は 2 層あります。

| | カバー範囲 |
|---|---|
| 解析レポートとエンジンのエラーメッセージ | **35 言語すべて** |
| アプリ自身のメニュー、ボタン、ラベル | **35 言語すべて** |

右から左に書く言語 — アラビア語、エジプト・アラビア語、ペルシア語、ウルドゥー語 — では、
アプリを開いた時点からウィンドウとレポートが反転します。

言語は次回以降も記憶されます。一度だけ別の言語で開きたい場合は
[`--language`](#起動する) を参照してください。

意図的にどの言語でも翻訳しないものがいくつかあります。生の値の横に表示される短い項目名
（`format`、`position`、`raw`、`len` など）は語ではなく識別子だからです。サンプル入力名と
シンボル体系名は GS1 と業界の用語であり、規格の長い一節は中途半端な翻訳がかえって誤解を招くためです。

## 保存される内容

ホームディレクトリの中の `.gaia-desktop` にある 2 つのファイルです。

| ファイル | 内容 |
|---|---|
| `options.properties` | すべての解析オプション、テーマ、オプションパネルの開閉、最後に使ったスキャナー、終了時のモード |
| `captures.tsv` | キャプチャ履歴。新しいものが先頭で、最大 500 件 |

オプションは変更のたびに、履歴は変化のたびに書き込まれます。どちらも終了時に改めて書き込まれます。

どちらかのファイルを削除すると、その部分だけが初期化されます。2 つを分けてあるのは、履歴が壊れても
設定を失わないようにするためです。手で編集して壊してしまっても致命的ではありません。設定は 1 つ
ずつ既定値に戻るため、おかしな行があってもその行の分だけで済みます。

履歴が保存しているのは入力であって、解析結果ではありません。読み込み時に解析し直されるので、
復元されたキャプチャは、キャプチャした当時ではなく**現在**のオプションを反映します。

## トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| 起動しない、または `NoClassDefFoundError` が出る | `lib/` ディレクトリが JAR の隣にある必要があります。一緒に置くか、単体で完結するビルドを使ってください |
| 起動時にコンソールへ *「Unsupported JavaFX configuration…」* | 想定内で無害です。ツールキットが読み込まれ方を報告しているだけで、アプリは正常に動作します |
| 貼り付けた区切り文字が消えたように見える | 想定どおりです。目に見える `{GS}` トークンに書き換えられており、解析器には本物の文字が渡ります。[{GS} トークン](#入力バーと-gs-トークン)を参照 |
| *スキャナーを接続* ボタンがない | macOS か Linux をお使いです。これらの環境にはスキャナードライバがありません。[スキャン](#スキャン)を参照 |
| スキャナーが接続できない | 選択欄の論理名が機種と合っているか、スキャナーが接続されているか、他のアプリが占有していないかを確認してください |
| PDF 書き出しで出力先がないと表示される | プリンターも PDF の出力先も設定されていません。追加するか、HTML で書き出してブラウザーから印刷してください |
| メニュー項目に `act.hri` のような文字列が出る | ラベルの欠落です。ご報告ください。設定ではなくビルド時の不具合です |

## 制限

- **スキャンは Windows 専用**です。ドライバがそうだからです。
- **PDF は保存ダイアログではなく印刷ダイアログ**を経由します。
- **Digital Link の宛先はドメインとパスのプレフィックスのみ**を受け付けます。追加のクエリ
  パラメータやフラグメントには対応していません。
- **1 つの要素ストリングに同じ AI は 1 度だけ** — これはアプリの制限ではなく GS1 の規則です。
