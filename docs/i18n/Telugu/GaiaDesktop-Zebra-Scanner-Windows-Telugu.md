# Zebra స్కానర్ సెటప్ — Windows కోసం GAIA Desktop

GAIA Desktop నేరుగా GS1 బార్‌కోడ్‌లను చదవగలిగేలా Zebra బార్‌కోడ్ స్కానర్‌ను ఎలా ఇన్‌స్టాల్ చేసి
కాన్ఫిగర్ చేయాలి: ప్రతి స్కాన్ విశ్లేషించబడి చరిత్రకు జోడించబడుతుంది, AIM Code ID ఉపసర్గ మరియు
ప్రతి FNC1 విభాజకం యథాతథంగా ఉంటాయి. మూల పత్రం:
[GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md).

GAIA Desktop‌ను USB ద్వారా అనుసంధానించిన **Zebra DS8108** చేతిలో పట్టుకునే ఇమేజర్‌తో నిర్మించి
పరీక్షించారు. Zebra యొక్క Scanner SDK మద్దతిచ్చే ఏ Zebra 2D స్కానర్‌కైనా ఈ దశలు వర్తిస్తాయి; ఒక
నిర్దిష్ట మోడల్ యొక్క సెటప్ బార్‌కోడ్‌లు మరియు మెనూ పేర్లు దాని స్వంత Quick Reference Guide లేదా
Product Reference Guide‌లో ఉంటాయి.

> **Windows మాత్రమే.** Zebra స్కానర్ డ్రైవర్లు Windows కోసం మాత్రమే ఉన్నాయి, కాబట్టి macOS లేదా
> Linux‌లో GAIA Desktop ఎలాంటి స్కానర్ నియంత్రణలనూ సృష్టించదు. యాప్‌లోని మిగతావన్నీ ప్రతి
> ప్లాట్‌ఫారమ్‌లో పనిచేస్తాయి.

## 1. మీకు కావలసినవి

| | |
|---|---|
| **స్కానర్** | ఒక Zebra 2D స్కానర్, దాని USB కేబుల్‌తో — చూడండి [మద్దతు ఉన్న Zebra 2D స్కానర్లు](#12-మద్దతు-ఉన్న-zebra-2d-స్కానర్లు) |
| **కంప్యూటర్** | Windows 10 లేదా 11, 64-బిట్ |
| **Java** | Java 21 లేదా కొత్తది, **64-బిట్** |
| **Zebra Scanner SDK for Windows** | **64-బిట్**, Zebra సహాయ సైట్ నుండి — ఇది డ్రైవర్‌ను మరియు GAIA Desktop ఉపయోగించే JavaPOS సేవలను అందిస్తుంది |
| **Zebra 123Scan** | Zebra ఉచిత కాన్ఫిగరేషన్ యుటిలిటీ, Zebra సహాయ సైట్ నుండి — స్కానర్ ఫర్మ్‌వేర్‌ను నవీకరించడానికి మరియు దాని సెట్టింగ్‌లను తనిఖీ చేయడానికి |
| **GAIA Desktop** | `gaia-desktop-1.0.0-win.zip` |
| **ఐచ్ఛికం** | స్కానర్ **Product Reference Guide** (PRG), ఇందులో సెటప్ బార్‌కోడ్‌లు ఉంటాయి |

భాగాలు ఎలా కలుస్తాయి:

```
Zebra scanner ──USB──► Zebra CoreScanner driver ──► Zebra JavaPOS services ──► GAIA Desktop
                       (installed by the SDK)        (in the SDK's JPOS\bin)    (run.bat puts them on
                                                                                 the class path)
```

GAIA Desktop స్వయంగా JavaPOS API‌ను మరియు స్కానర్‌కు పేరు పెట్టే కాన్ఫిగరేషన్‌ను (`jpos.xml`,
`gaia-desktop.jar` లోపల) తనతో తెస్తుంది. మిగిలినది Zebra SDK అందిస్తుంది: స్కానర్‌తో మాట్లాడే
డ్రైవర్, మరియు JavaPOS కు ఆ డ్రైవర్‌కు మధ్య ఉండే Zebra సేవా క్లాసులు.

## 2. Java ఇన్‌స్టాల్ చేయండి

GAIA Desktop‌కు **Java 21 లేదా కొత్తది** కావాలి, మరియు అది 64-బిట్ Zebra డ్రైవర్లకు సరిపోయేలా
**64-బిట్** బిల్డ్ అయి ఉండాలి.

1. Windows x64 కోసం Java 21 JDK లేదా JRE ఇన్‌స్టాల్ చేయండి — ఉదాహరణకు adoptium.net నుండి
   Eclipse Temurin. ఇన్‌స్టాలర్ `JAVA_HOME` సెట్ చేస్తానంటే దాన్ని చేయనివ్వండి.
2. Command Prompt‌లో తనిఖీ చేయండి:

   ```
   java -version
   ```

   మొదటి పంక్తి వెర్షన్ 21 లేదా తర్వాతిది చూపాలి; 64-బిట్ Java `64-Bit Server VM` అని కూడా ముద్రిస్తుంది.

`run.bat` Java‌ను ఈ క్రమంలో వెతుకుతుంది: `run.bat` పక్కనున్న `jdk*` ఫోల్డర్, తర్వాత `JAVA_HOME`,
తర్వాత `PATH` పై ఉన్న `java`. 21 కంటే పాతది ఏదైనా ఉంటే, ఆ విషయం చెప్పే సందేశంతో దాన్ని తిరస్కరిస్తుంది.

## 3. Zebra Scanner SDK ఇన్‌స్టాల్ చేయండి

1. Zebra సహాయ సైట్ నుండి **Zebra Scanner SDK for Windows (64-bit)** డౌన్‌లోడ్ చేయండి.
2. ఇన్‌స్టాలర్‌ను నడపండి. భాగాలను ఎంచుకునే అవకాశం ఇస్తే, **JPOS** (JavaPOS) భాగం చేర్చబడిందని
   నిర్ధారించుకోండి.
3. డిఫాల్ట్ ఇన్‌స్టాల్ స్థానాన్నే ఉంచండి. GAIA Desktop SDK యొక్క JavaPOS భాగాన్ని ఇక్కడ వెతుకుతుంది:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   మరియు Zebra సేవా jar‌లు (`JposServiceScanner.jar`, `JposServiceJniScanner.jar`, …) మరియు నేటివ్
   లైబ్రరీలు (`CSJPOSScanner64.dll`, …) దాని `bin\` ఫోల్డర్‌లో ఉంటాయని ఆశిస్తుంది. SDK వేరే చోట
   ఇన్‌స్టాల్ అయి ఉంటే, [ZEBRA_HOME](#zebra_home) చూడండి.
4. ఇన్‌స్టాల్ చేసిన తర్వాత **Windows‌ను రీస్టార్ట్ చేయండి**. SDK యొక్క CoreScanner డ్రైవర్ నేపథ్యంలో
   నడుస్తుంది, GAIA Desktop స్కానర్‌ను చేరుకోవడానికి ముందే అది నడుస్తూ ఉండాలి; దీనిని
   నిర్ధారించుకోవడానికి రీస్టార్ట్ సులభమైన మార్గం.

## 4. 123Scan ఇన్‌స్టాల్ చేయండి

123Scan అనేది Zebra తన స్కానర్‌లను కాన్ఫిగర్ చేయడానికి అందించే ఉచిత యుటిలిటీ. తదుపరి దశలో స్కానర్
ఫర్మ్‌వేర్‌ను నవీకరించడానికి దీన్ని ఉపయోగిస్తారు, తర్వాత స్కానర్ సెట్టింగ్‌లను తనిఖీ చేయడానికి
మరియు మార్చడానికి కూడా ఇదే సులభమైన మార్గం.

1. Zebra సహాయ సైట్ నుండి **123Scan** డౌన్‌లోడ్ చేసి ఇన్‌స్టాలర్‌ను నడపండి.
2. Zebra స్కానర్‌ను ప్లగ్ చేసి 123Scan ప్రారంభించండి. అది స్కానర్‌ను కనుగొని దాని మోడల్, సీరియల్
   నంబర్ మరియు ప్రస్తుత ఫర్మ్‌వేర్ వెర్షన్‌ను చూపాలి. చూపకపోతే, ముందుకు వెళ్లే ముందు వేరే USB పోర్ట్
   లేదా కేబుల్ ప్రయత్నించండి — 123Scan చూడలేని స్కానర్‌ను GAIA Desktop కూడా చూడదు.

## 5. Zebra స్కానర్ ఫర్మ్‌వేర్‌ను నవీకరించండి

కాన్ఫిగర్ చేసే ముందు స్కానర్ ఫర్మ్‌వేర్‌ను తాజా వెర్షన్‌కు తీసుకురండి. ఫర్మ్‌వేర్ నవీకరణలు డీకోడింగ్
సమస్యలను సరిచేస్తాయి మరియు SDK ఇన్‌స్టాల్ చేసిన Zebra డ్రైవర్‌తో స్కానర్‌ను పొందికగా ఉంచుతాయి.

1. **GAIA Desktop** మరియు స్కానర్‌ను ఉపయోగిస్తూ ఉండగల ఇతర ఏ ప్రోగ్రామ్‌నైనా మూసివేయండి: నవీకరణ
   సమయంలో 123Scan‌కు స్కానర్ పూర్తిగా తనకే కావాలి.
2. స్కానర్ అనుసంధానమై ఉండగా, 123Scan‌లో దాని ఫర్మ్‌వేర్ నవీకరణ ఎంపికను ఎంచుకోండి. 123Scan స్కానర్
   ఫర్మ్‌వేర్‌ను Zebra ప్రచురించిన తాజాదానితో పోల్చి, దాన్ని డౌన్‌లోడ్ చేసి ఇన్‌స్టాల్ చేయడానికి
   ముందుకొస్తుంది. కంప్యూటర్‌కు ఇంటర్నెట్ లేకపోతే, Zebra సైట్‌లోని స్కానర్ సహాయ పేజీ నుండి దాని
   ఫర్మ్‌వేర్‌ను డౌన్‌లోడ్ చేసి ఫైల్‌ను 123Scan‌లోకి లోడ్ చేయండి.
3. నవీకరణ ప్రారంభించి, **123Scan పూర్తయిందని చెప్పే వరకు స్కానర్‌ను ప్లగ్ చేసే ఉంచండి**. దీనికి
   కొన్ని నిమిషాలు పడుతుంది; చివరలో స్కానర్ రీస్టార్ట్ అవుతుంది. మధ్యలో తీసేస్తే అది పనికిరాకుండా
   పోవచ్చు.
4. 123Scan ఇప్పుడు కొత్త ఫర్మ్‌వేర్ వెర్షన్ చూపుతోందని తనిఖీ చేయండి.

నవీకరణ కొన్ని సెట్టింగ్‌లను డిఫాల్ట్‌కు తిరిగి తీసుకురావచ్చు, అందుకే స్కానర్‌ను ఫర్మ్‌వేర్ తర్వాత, తదుపరి
రెండు దశల్లో కాన్ఫిగర్ చేస్తారు.

## 6. Zebra స్కానర్ USB మోడ్‌ను సెట్ చేయండి

ఎక్కువగా తప్పిపోయే దశ ఇదే. **పెట్టె నుండి తీసిన Zebra స్కానర్ ఒక USB కీబోర్డ్** (USB HID Keyboard
మోడ్): ఫోకస్ ఎక్కడ ఉంటే అక్కడ అది ప్రతి బార్‌కోడ్‌ను "టైప్" చేస్తుంది. ఆ మోడ్‌లో GAIA Desktop యొక్క
*స్కానర్‌ను కలుపు* దాన్ని కనుగొనలేదు, మరియు టెక్స్ట్ ఫీల్డ్‌లో టైప్ అయ్యే ప్రతిదీ దాని FNC1 విభాజకాలను
కోల్పోతుంది, దీనివల్ల GS1 మూలకం స్ట్రింగ్ అర్థం మారిపోతుంది.

Zebra డ్రైవర్ నేరుగా మాట్లాడే మోడ్‌కు స్కానర్‌ను మార్చండి:

| స్కానర్ USB మోడ్ | GAIA Desktop‌లో పరికరం పేరు | గమనికలు |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld`, లేదా `ZebraAllScanners` | సిఫార్సు చేయబడింది |
| SNAPI (ఇమేజింగ్‌తో లేదా లేకుండా) | `ZebraScannerSNAPI`, లేదా `ZebraAllScanners` | Zebra సొంత USB ప్రోటోకాల్; ఇదీ పనిచేస్తుంది |
| IBM Table-top USB | `ZebraUSBTableTop`, లేదా `ZebraAllScanners` | టేబుల్-టాప్ స్కానర్ల కోసం |
| USB OPOS (Hand-held) | `ZebraUSBOPOS`, లేదా `ZebraAllScanners` | |
| USB HID Keyboard (ఫ్యాక్టరీ డిఫాల్ట్) | — | **కలవదు** |

`ZebraAllScanners`, GAIA Desktop‌లోని డిఫాల్ట్ పరికరం పేరు, మద్దతు ఉన్న ఏ మోడ్‌లో ఉన్న స్కానర్‌నైనా
అంగీకరిస్తుంది, కాబట్టి మోడ్ సెట్ అయిన వెంటనే డిఫాల్ట్ సాధారణంగా అలాగే పనిచేస్తుంది.

మోడ్ మార్చడానికి, ఒకటి:

- స్కానర్ Quick Reference Guide లేదా Product Reference Guide (USB Host Types / USB Device Type విభాగం)
  లో ఆ మోడ్ — ఉదాహరణకు *IBM Hand-held USB* — యొక్క **సెటప్ బార్‌కోడ్‌ను స్కాన్ చేయండి**; స్కానర్
  బీప్ చేసి నిర్ధారిస్తుంది. లేదా
- **123Scan ఉపయోగించండి** ([దశ 4](#4-123scan-ఇన్స్టాల్-చేయండి)): స్కానర్‌ను కలిపి, దాని
  కాన్ఫిగరేషన్ తెరిచి, USB హోస్ట్ రకాన్ని సెట్ చేయండి.

మోడ్ మార్చిన తర్వాత Windows స్కానర్‌ను వేరే రకమైన పరికరంగా మళ్లీ గుర్తిస్తుంది; కలిపే ముందు కొన్ని
సెకన్లు ఆగండి.

తర్వాత స్కానర్‌ను కీబోర్డ్ మోడ్‌కు తిరిగి తీసుకురావడానికి — ఇతర సాఫ్ట్‌వేర్‌తో ఉపయోగించడానికి —
*USB Keyboard (HID)* సెటప్ బార్‌కోడ్‌ను స్కాన్ చేయండి, లేదా దాని ఫ్యాక్టరీ డిఫాల్ట్‌లను పునరుద్ధరించండి.

## 7. GS1 కోసం Zebra స్కానర్‌ను కాన్ఫిగర్ చేయండి

స్కానర్ తాను ఏ రకం బార్‌కోడ్ చదివిందో చెప్పినప్పుడు GAIA Desktop ఉత్తమంగా విశ్లేషిస్తుంది.

### AIM Code ID పంపండి

Product Reference Guide (User Preferences) లోని సెటప్ బార్‌కోడ్‌తో లేదా 123Scan‌లో **Transmit Code ID
Character**‌ను **AIM Code ID Character**‌కు సెట్ చేయండి. అప్పుడు ప్రతి స్కాన్ దాని సింబాలజీ
గుర్తింపుతో మొదలవుతుంది — GS1-128 కోసం `]C1`, GS1 DataMatrix కోసం `]d2`, GS1 QR Code కోసం `]Q3`,
GS1 DataBar కోసం `]e0` — దీనిని GAIA Desktop డేటా వాహకం పేరు చెప్పడానికి మరియు దాని నియమాలను
వర్తింపజేయడానికి ఉపయోగిస్తుంది.

అది లేకపోయినా GAIA Desktop మూలకం స్ట్రింగ్‌ను విశ్లేషించి సింబాలజీని స్కాన్ నుండే తీసుకుంటుంది,
కానీ నివేదికకు చూపించడానికి AIM Code ID ఉండదు, మరియు EAN-13 వంటి సాధారణ బార్‌కోడ్‌ను GS1 మూలకం
స్ట్రింగ్ నుండి వేరుగా గుర్తించడం కష్టమవుతుంది.

### సింబాలజీలను తనిఖీ చేయండి

మీరు పనిచేసే బార్‌కోడ్ రకాలు **ప్రారంభించబడి** ఉన్నాయని నిర్ధారించుకోండి: సాధారణంగా GS1-128,
GS1 DataMatrix, GS1 DataBar, GS1 QR Code మరియు EAN/UPC. Zebra 2D స్కానర్లలో వీటిలో చాలావరకు
డిఫాల్ట్‌గా ఆన్‌లో ఉంటాయి; 123Scan ప్రస్తుత సెట్టింగ్‌లను చూపుతుంది, మరియు Product Reference Guide‌లో
ప్రతిదాన్ని ప్రారంభించడానికి బార్‌కోడ్ ఉంటుంది.

### Zebra యొక్క GS1 విశ్లేషణ లక్షణాలను ఆఫ్‌లో ఉంచండి

కొత్త ఫర్మ్‌వేర్ స్కానర్‌పైనే పనిచేసే GS1 లక్షణాలను జోడిస్తుంది — **Label Parse+**, **GS1
Digital Link** మరియు **GS1 Retail POS parsing**. వాటిని **ఆఫ్‌**లో ఉంచండి, స్కానర్ వచ్చినట్లే: అవి
స్కానర్ పంపే దాన్ని పునఃఫార్మాట్ చేస్తాయి లేదా కుదిస్తాయి, కానీ GAIA Desktop విశ్లేషించడానికి మరియు
ధృవీకరించడానికి ముడి డేటా కావాలి. ఒక్కొక్కటి ఏమి చేస్తుందో
[మద్దతు ఉన్న Zebra 2D స్కానర్లు](#12-మద్దతు-ఉన్న-zebra-2d-స్కానర్లు) లో చూడండి.

### ఉపసర్గలు మరియు ప్రత్యయాలు వద్దు

స్కానర్ అవుట్‌పుట్‌కు ఉపసర్గ, ప్రత్యయం లేదా Enter కీని జోడించవద్దు. GAIA Desktop ప్రతి స్కాన్‌ను
JavaPOS ద్వారా పూర్తి సందేశంగా అందుకుంటుంది, వీటిలో దేని అవసరమూ లేదు; అదనపు అక్షరాలు మూలకం
స్ట్రింగ్‌లో చేరిపోతాయి.

## 8. GAIA Desktop‌ను ఇన్‌స్టాల్ చేసి ప్రారంభించండి

1. `gaia-desktop-1.0.0-win.zip`‌ను అన్‌జిప్ చేయండి, ఉదాహరణకు `C:\Tools\`‌కు. అందులో ఒక ఫోల్డర్
   ఉంటుంది:

   ```
   gaia-desktop-1.0.0-win\
   ├── docs\
   │   └── GaiaDesktop-Zebra-Scanner-Windows.md      this guide
   ├── gaia-desktop.jar
   ├── lib\
   ├── readme.html                                   index of every guide
   └── run.bat
   ```

2. స్కానర్‌ను ప్లగ్ చేయండి.
3. **`run.bat`**‌పై డబుల్-క్లిక్ చేయండి. యాప్ పక్కన ఒక కన్సోల్ విండో తెరుచుకుని తెరిచే ఉంటుంది:
   స్కానర్ స్థితి మరియు JavaPOS లోపాలు అక్కడ నివేదించబడతాయి.
4. కన్సోల్‌లోని మొదటి పంక్తిని చదవండి. `run.bat` ఏమి కనుగొందో అది చెబుతుంది:

   ```
   run.bat: Java 21.0.8 from JAVA_HOME; JavaFX from lib\; JavaPOS from lib\; Zebra services from C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   అది **`Zebra services from none (Zebra Scanner SDK not installed)`** తో ముగిస్తే, SDK దాని డిఫాల్ట్
   స్థానంలో కనిపించలేదు — దాన్ని ఇన్‌స్టాల్ చేయండి ([దశ 3](#3-zebra-scanner-sdk-ఇన్స్టాల్-చేయండి))
   లేదా [ZEBRA_HOME](#zebra_home) సెట్ చేయండి. యాప్ అయినా ప్రారంభమవుతుంది, కానీ స్కానర్ కలవదు.

## 9. స్కానర్‌ను కలపండి

1. టూల్‌బార్‌లో, **పరికర ఎంపిక** GAIA Desktop‌కు తెలిసిన స్కానర్ పేర్లను జాబితా చేస్తుంది. దాన్ని
   **`ZebraAllScanners`** వద్దే ఉంచండి, లేదా [దశ 6](#6-zebra-స్కానర్-usb-మోడ్ను-సెట్-చేయండి) లోని
   పట్టిక నుండి స్కానర్ USB మోడ్ పేరును ఎంచుకోండి.
2. **స్కానర్‌ను కలుపు** క్లిక్ చేయండి, లేదా **Ctrl+K** నొక్కండి (**స్కానర్** మెనూలో కూడా ఉంది).
3. స్థితి పట్టీ **`స్కానర్: ZebraAllScanners`** (లేదా మీరు ఎంచుకున్న పేరు)గా మారుతుంది, మరియు స్థితి
   పంక్తి *స్కానర్ కలిసింది — ZebraAllScanners* అని నివేదిస్తుంది. బటన్ ఇప్పుడు **స్కానర్‌ను
   వేరుచేయి** అని చూపుతుంది.
4. ఒక GS1 బార్‌కోడ్‌ను స్కాన్ చేయండి. అది క్యాప్చర్ చరిత్ర పైభాగంలో కనిపించి దాని నివేదిక తెరుచుకుంటుంది.
   AIM Code ID ఆన్‌లో ఉంటే, నివేదిక డేటా వాహకం పేరు చెబుతుంది — *GS1-128*, *GS1 DataMatrix* — మరియు
   మూలకం స్ట్రింగ్ ప్రతి FNC1 విభాజకాన్ని ఉంచుకుంటుంది.

పరికర ఎంపిక ప్రతి రన్ మధ్య మీ ఎంపికను గుర్తుంచుకుంటుంది. మీరు వేరుచేసే వరకు లేదా యాప్ మూసే వరకు స్కానర్
కలిసే ఉంటుంది. **నిర్మాణం** మరియు **కలపడం** మోడ్‌లలో కూడా స్కాన్‌లు పనిచేస్తాయి: కలపడంలో, ప్రతి స్కాన్
కలుపుతున్న బార్‌కోడ్‌లలో ఒకటి అవుతుంది.

GAIA Desktop స్కానర్‌ను పట్టుకుని ఉన్నంతసేపు ఇతర ప్రోగ్రామ్‌లు దాన్ని ఉపయోగించలేవు, అలాగే వ్యతిరేకంగా
కూడా: కలిపే ముందు 123Scan మరియు ఇతర పాయింట్-ఆఫ్-సేల్ లేదా స్కానర్ సాఫ్ట్‌వేర్‌ను మూసివేయండి.

## 10. కాన్ఫిగరేషన్ సూచిక

### పరికరాల పేర్లు

పరికర ఎంపిక `gaia-desktop.jar`‌లో చేర్చిన `jpos.xml` నుండి నింపబడుతుంది. దానిలోని స్కానర్ ఎంట్రీలు:

| పరికరం పేరు | స్కానర్ రకం | దేనితో ఉపయోగించాలి |
|---|---|---|
| `ZebraAllScanners` | ఏదైనా | **డిఫాల్ట్.** మద్దతు ఉన్న ఏ USB మోడ్ అయినా |
| `ZebraAllScanners114` | ఏదైనా | అదే సేవ యొక్క JavaPOS 1.14 వెర్షన్ |
| `ZebraUSBHandHeld` | IBM Hand-held USB | IBM Hand-held USB మోడ్‌లోని స్కానర్ |
| `ZebraUSBTableTop` | IBM Table-top USB | టేబుల్-టాప్ మోడ్ |
| `ZebraUSBOPOS` | USB OPOS | USB OPOS మోడ్ |
| `ZebraScannerSNAPI` | SNAPI | SNAPI మోడ్ |
| `ZebraScannerUSB` | ఏదైనా USB | ఏ USB మోడ్ అయినా |
| `ZebraScannerSerialSSI` | సీరియల్ SSI | సీరియల్ కేబుల్ స్కానర్లు (USB కాదు) |
| `ZebraScannerSerialNIXMODB` | సీరియల్ NIXMODB | సీరియల్ కేబుల్ స్కానర్లు |
| `ZebraVDI` | VDI | వర్చువల్ డెస్క్‌టాప్‌కు పంపిన స్కానర్లు |

### ZEBRA_HOME

Zebra SDK డిఫాల్ట్ కాకుండా వేరే చోట ఇన్‌స్టాల్ అయి ఉంటే, `run.bat` ప్రారంభించే ముందు `ZEBRA_HOME`‌ను
దాని `JPOS` ఫోల్డర్‌కు సెట్ చేయండి — ఉదాహరణకు దాని పక్కన ఉంచిన ఒక చిన్న బ్యాచ్ ఫైల్‌లో:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

అప్పుడు `run.bat` Zebra సేవా jar‌లను `%ZEBRA_HOME%bin` నుండి తీసుకుని, Zebra DLL‌ల కోసం ఆ ఫోల్డర్‌ను
`PATH`‌కు జోడిస్తుంది.

### మీ సొంత jpos.xml

పరికరం పేరును జోడించడానికి లేదా ఒక ఎంట్రీ సెట్టింగ్‌లను మార్చడానికి, `gaia-desktop.jar` నుండి
`jpos.xml` ప్రతిని బయటకు తీయండి (అది ఒక zip; ఏ అన్‌జిప్ సాధనమైనా దాన్ని తెరుస్తుంది), ప్రతిని
సవరించి, GAIA Desktop‌ను దాని వైపు చూపండి:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

అప్పుడు పరికర ఎంపిక ఆ ఫైల్‌లోని స్కానర్‌లను జాబితా చేస్తుంది. ఒకటి కంటే ఎక్కువ Zebra స్కానర్లు
అనుసంధానమై ఉంటే, ఒక ఎంట్రీని దాని `ScannerModel` లేదా `SerialNumber` లక్షణం ద్వారా వాటిలో ఒకదానితో
బంధించవచ్చు, `ZebraAllScanners` ఎంట్రీలో ఉన్నట్లే.

### ఇతర ఎంపికలు

సరిగ్గా ఎక్కడ విఫలమైందో చూపుతాయి.

## 12. మద్దతు ఉన్న Zebra 2D స్కానర్లు

GS1 డేటా ముద్రించబడే బార్‌కోడ్‌లను చదవగలిగే స్కానర్ GAIA Desktop‌కు కావాలి — GS1-128, GS1 DataBar,
EAN/UPC, మరియు చాలా ఉపయోగాలకు 2D కోడ్‌లు: **GS1 DataMatrix** మరియు **GS1 QR Code**, సాధారణంగా
**GS1 Digital Link** URI కూడా ఇలాగే ముద్రించబడుతుంది. అంటే Zebra **2D ఇమేజర్** కావాలి: రేఖీయ (1D)
స్కానర్ DataMatrix లేదా QR కోడ్‌లను అసలు చదవలేదు.

స్కానర్‌కు స్వయంగా GS1 Application Identifiers లేదా Digital Link అర్థం కావలసిన అవసరం లేదు.
**GAIA Desktop రెండింటినీ విశ్లేషిస్తుంది**: స్కానర్ చదివినట్లే స్కాన్‌ను తీసుకుంటుంది — AIM Code ID,
FNC1 విభాజకాలు, అన్నీ — మరియు దాన్ని AI‌లుగా విభజిస్తుంది, లేదా Digital Link URI‌ను దాని AI‌లుగా
మారుస్తుంది, స్వయంగా.

### Zebra స్కానర్‌పైనే పనిచేసే GS1 లక్షణాలు

బార్‌కోడ్‌లను చదవడం కాకుండా, కొన్ని Zebra 2D ఇమేజర్లు స్కానర్‌పైనే GS1 డేటాను ప్రాసెస్ చేయగలవు, దీన్ని
123Scan ద్వారా కాన్ఫిగర్ చేస్తారు:

| లక్షణం | అది ఏమి చేస్తుంది | GAIA Desktop కోసం |
|---|---|---|
| **Label Parse+** | స్కానర్‌పైనే GS1 లేబుల్ AI‌లను విశ్లేషించి, పునఃఫార్మాట్ చేసిన ఫీల్డ్‌లను పంపుతుంది | **ఆఫ్‌లో ఉంచండి** — అప్పుడు GAIA Desktop AI‌లను, FNC1 విభాజకాలను మరియు AIM Code ID‌ను చూడలేదు |
| **GS1 Digital Link** | 1D EAN/UPC మరియు 2D Digital Link కోడ్ రెండూ ఉన్న రిటైల్ ఉత్పత్తుల కోసం: దేన్ని పంపాలో ఎంచుకుంటుంది | **ఆఫ్‌లో ఉంచండి** (డిఫాల్ట్) |
| **GS1 Retail POS parsing** | Digital Link URI లేదా మూలకం స్ట్రింగ్ సింటాక్స్‌లోని 2D రిటైల్ బార్‌కోడ్‌లను చదువుతుంది | **ఆఫ్‌లో ఉంచండి** |

**GS1 Digital Link** సెట్టింగ్‌కు మూడు మోడ్‌లు ఉన్నాయి. **Mode 1 — GTIN only**, ప్రారంభించిన తర్వాత అది
మొదలయ్యే మోడ్, ఏ బార్‌కోడ్ నుండి వచ్చినా GTIN‌ను మాత్రమే పంపుతుంది, కాబట్టి Digital Link‌లోని బ్యాచ్,
గడువు తేదీ లేదా సీరియల్ నంబర్ ఎప్పటికీ GAIA Desktop‌ను చేరదు. **Mode 2 — Prioritize 2D** ప్రాధాన్య
సమయపరిమితి (డిఫాల్ట్‌గా 200 ms) లోపల 2D కోడ్ కనిపిస్తే దాన్ని పంపుతుంది, లేకపోతే 1D. **Mode 3 —
Corroborate 1D and 2D GTINs Match** 1D పంపుతుంది, మరియు దాని GTIN సరిపోలితే 2D‌ను కూడా. ఇతర
సాఫ్ట్‌వేర్ కోసం సెట్టింగ్ ఆన్‌లో ఉండి తీరాల్సి వస్తే, Mode 1 కాదు, Mode 2 ఉపయోగించండి. DS8108‌లో
