GAIA Desktop 示例

每种常用 GS1 数据载体各一个条码，两个 GAIA 会拒绝的示例，另有一张用于“合并”的传统标签。可用 Zebra 扫描器直接扫描屏幕上的条码，或将元素串复制到 GAIA Desktop 的输入栏中。

每个元素串都以其 AIM Code ID 开头，它告诉 GAIA 扫描来自哪种数据载体。{GS} 代表 FNC1，即变长 AI 之后的分隔符；输入栏会将其转换为真正的字符。条码图片由 TEC-IT 在线条码生成器绘制，因此打开本页面会将示例数据发送给它。使用量较大时，它可能会以请求频率限制提示代替条码；请稍后重新加载。

解析

在解析模式下，每次扫描或粘贴的内容都会被拆分为其应用标识符（Application Identifier）。最后两张卡片是 GAIA 能发现的错误：每张都列出了 GAIA 报告的错误。
