# راه‌اندازی اسکنر Zebra — GAIA Desktop برای Windows

چگونه یک اسکنر بارکد Zebra را نصب و پیکربندی کنید تا GAIA Desktop بتواند بارکدهای GS1 را مستقیماً از آن
بخواند: هر اسکن تجزیه و به تاریخچه افزوده می‌شود و پیشوند AIM Code ID و همهٔ جداکننده‌های FNC1 دست‌نخورده
می‌مانند. سند اصلی:
[GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md).

GAIA Desktop با تصویرگر دستی **Zebra DS8108** که از راه USB وصل شده بود ساخته و آزموده شده است. این
گام‌ها برای هر اسکنر دوبعدی Zebra که Scanner SDK شرکت Zebra از آن پشتیبانی کند به کار می‌آیند؛ بارکدهای
تنظیم و نام منوها برای هر مدل در Quick Reference Guide یا Product Reference Guide همان مدل آمده است.

> **فقط Windows.** درایورهای اسکنر Zebra فقط برای Windows وجود دارند، بنابراین GAIA Desktop روی
> macOS یا Linux هیچ کنترلی برای اسکنر نمی‌سازد. بقیهٔ برنامه روی همهٔ سکوها کار می‌کند.

## 1. آنچه لازم دارید

| | |
|---|---|
| **اسکنر** | یک اسکنر دوبعدی Zebra، همراه با کابل USB آن — ببینید [اسکنرهای دوبعدی Zebra که پشتیبانی می‌شوند](#12-اسکنرهای-دوبعدی-zebra-که-پشتیبانی-میشوند) |
| **رایانه** | Windows 10 یا 11، 64 بیتی |
| **Java** | Java 21 یا جدیدتر، **64 بیتی** |
| **Zebra Scanner SDK for Windows** | **64 بیتی**، از سایت پشتیبانی Zebra — درایور و سرویس‌های JavaPOS را که GAIA Desktop به کار می‌برد فراهم می‌کند |
| **Zebra 123Scan** | ابزار رایگان پیکربندی Zebra، از سایت پشتیبانی Zebra — برای به‌روزرسانی میان‌افزار اسکنر و بررسی تنظیمات آن |
| **GAIA Desktop** | `gaia-desktop-1.0.0-win.zip` |
| **اختیاری** | **Product Reference Guide** (PRG) اسکنر، که بارکدهای تنظیم در آن است |

اجزا چگونه به هم وصل می‌شوند:

```
Zebra scanner ──USB──► Zebra CoreScanner driver ──► Zebra JavaPOS services ──► GAIA Desktop
                       (installed by the SDK)        (in the SDK's JPOS\bin)    (run.bat puts them on
                                                                                 the class path)
```

GAIA Desktop خودش رابط JavaPOS و پیکربندی‌ای را که اسکنر را نام‌گذاری می‌کند (`jpos.xml`، درون
`gaia-desktop.jar`) همراه دارد. بقیه را Zebra SDK فراهم می‌کند: درایوری که با اسکنر گفت‌وگو می‌کند، و
کلاس‌های سرویس Zebra که میان JavaPOS و آن درایور قرار می‌گیرند.

## 2. نصب Java

GAIA Desktop به **Java 21 یا جدیدتر** نیاز دارد، و باید نسخهٔ **64 بیتی** باشد تا با درایورهای 64 بیتی
Zebra جور شود.

1. یک JDK یا JRE نسخهٔ 21 جاوا برای Windows x64 نصب کنید — مثلاً Eclipse Temurin از
   adoptium.net. اگر نصب‌کننده پیشنهاد داد `JAVA_HOME` را تنظیم کند، بگذارید این کار را بکند.
2. آن را در Command Prompt بررسی کنید:

   ```
   java -version
   ```

   سطر نخست باید نسخهٔ 21 یا بالاتر را نشان دهد؛ Java 64 بیتی `64-Bit Server VM` را هم چاپ می‌کند.

`run.bat` به این ترتیب دنبال Java می‌گردد: پوشهٔ `jdk*` کنار `run.bat`، سپس `JAVA_HOME`، سپس `java` در
`PATH`. هر نسخهٔ قدیمی‌تر از 21 را با پیامی که همین را می‌گوید رد می‌کند.

## 3. نصب Zebra Scanner SDK

1. **Zebra Scanner SDK for Windows (64-bit)** را از سایت پشتیبانی Zebra دانلود کنید.
2. نصب‌کننده را اجرا کنید. اگر انتخاب اجزا را پیشنهاد داد، مطمئن شوید که جزء **JPOS** (JavaPOS) انتخاب
   شده است.
3. مسیر پیش‌فرض نصب را نگه دارید. GAIA Desktop بخش JavaPOS از SDK را در این مسیر جست‌وجو می‌کند:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   و انتظار دارد jarهای سرویس Zebra (`JposServiceScanner.jar`، `JposServiceJniScanner.jar`، …) و
   کتابخانه‌های بومی (`CSJPOSScanner64.dll`، …) در پوشهٔ `bin\` آن باشند. اگر SDK جای دیگری نصب شده است،
   [ZEBRA_HOME](#zebra_home) را ببینید.
4. پس از نصب، **Windows را دوباره راه‌اندازی کنید**. درایور CoreScanner از SDK در پس‌زمینه اجرا می‌شود و
   پیش از آنکه GAIA Desktop بتواند به اسکنر دسترسی پیدا کند باید در حال اجرا باشد؛ راه‌اندازی دوباره
   ساده‌ترین راه برای اطمینان از این است.

## 4. نصب 123Scan

‏123Scan ابزار رایگان Zebra برای پیکربندی اسکنرهایش است. در گام بعد از آن برای به‌روزرسانی میان‌افزار
اسکنر استفاده می‌شود، و ساده‌ترین راه برای بررسی و تغییر تنظیمات اسکنر در ادامه هم همین است.

1. **123Scan** را از سایت پشتیبانی Zebra دانلود کنید و نصب‌کننده را اجرا کنید.
2. اسکنر Zebra را وصل کنید و 123Scan را اجرا کنید. باید اسکنر را پیدا کند و مدل، شمارهٔ سریال و نسخهٔ
   فعلی میان‌افزار آن را نشان دهد. اگر نشد، پیش از ادامه درگاه USB یا کابل دیگری را امتحان کنید —
   GAIA Desktop اسکنری را که 123Scan نبیند نمی‌بیند.

## 5. به‌روزرسانی میان‌افزار اسکنر Zebra

پیش از پیکربندی، میان‌افزار اسکنر را به آخرین نسخه برسانید. به‌روزرسانی‌های میان‌افزار مشکلات رمزگشایی را
برطرف می‌کنند و اسکنر را با درایور Zebra که SDK نصب کرده هماهنگ نگه می‌دارند.

1. **GAIA Desktop** و هر برنامهٔ دیگری را که ممکن است از اسکنر استفاده کند ببندید: 123Scan در طول
   به‌روزرسانی اسکنر را به‌تنهایی در اختیار می‌خواهد.
2. در 123Scan، در حالی که اسکنر وصل است، گزینهٔ به‌روزرسانی میان‌افزار آن را انتخاب کنید. 123Scan
   میان‌افزار اسکنر را با آخرین نسخه‌ای که Zebra منتشر کرده مقایسه می‌کند و پیشنهاد می‌دهد آن را دانلود و
   نصب کند. اگر رایانه به اینترنت دسترسی ندارد، میان‌افزار اسکنر را از صفحهٔ پشتیبانی آن در سایت Zebra
   دانلود کنید و پرونده را در 123Scan بارگذاری کنید.
3. به‌روزرسانی را آغاز کنید و **تا وقتی 123Scan اعلام نکرده که کار تمام شده، اسکنر را جدا نکنید**. چند
   دقیقه طول می‌کشد؛ در پایان اسکنر دوباره راه‌اندازی می‌شود. جدا کردن آن در میانهٔ کار ممکن است آن را
   از کار بیندازد.
4. بررسی کنید که 123Scan اکنون نسخهٔ جدید میان‌افزار را نشان می‌دهد.

به‌روزرسانی ممکن است برخی تنظیمات را به پیش‌فرض برگرداند، به همین دلیل اسکنر در دو گام بعدی، پس از
میان‌افزار، پیکربندی می‌شود.

## 6. تنظیم حالت USB اسکنر Zebra

این گامی است که بیش از همه از قلم می‌افتد. **اسکنر Zebra در حالت کارخانه یک صفحه‌کلید USB است** (حالت
USB HID Keyboard): هر بارکد را در هر جایی که فوکوس دارد «تایپ» می‌کند. در این حالت، *اتصال اسکنر* در
GAIA Desktop نمی‌تواند آن را پیدا کند، و هر چه در یک کادر متنی تایپ شود جداکننده‌های FNC1 خود را از دست
می‌دهد، و این معنای رشته عناصر GS1 را تغییر می‌دهد.

اسکنر را به حالتی ببرید که درایور Zebra مستقیماً با آن گفت‌وگو کند:

| حالت USB اسکنر | نام دستگاه در GAIA Desktop | یادداشت |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld`، یا `ZebraAllScanners` | پیشنهادی |
| SNAPI (با تصویربرداری یا بدون آن) | `ZebraScannerSNAPI`، یا `ZebraAllScanners` | پروتکل USB خود Zebra؛ این هم کار می‌کند |
| IBM Table-top USB | `ZebraUSBTableTop`، یا `ZebraAllScanners` | برای اسکنرهای رومیزی |
| USB OPOS (Hand-held) | `ZebraUSBOPOS`، یا `ZebraAllScanners` | |
| USB HID Keyboard (پیش‌فرض کارخانه) | — | **وصل نمی‌شود** |

`ZebraAllScanners`، نام دستگاه پیش‌فرض در GAIA Desktop، اسکنر را در هر یک از حالت‌های پشتیبانی‌شده
می‌پذیرد، بنابراین وقتی حالت تنظیم شد، پیش‌فرض معمولاً بی‌دردسر کار می‌کند.

برای تغییر حالت، یا:

- **بارکد تنظیم** آن حالت — مثلاً *IBM Hand-held USB* — را در Quick Reference Guide یا Product Reference
  Guide اسکنر (بخش USB Host Types / USB Device Type) **اسکن کنید**؛ اسکنر برای تأیید بوق می‌زند. یا
- **از 123Scan استفاده کنید** ([گام 4](#4-نصب-123scan)): اسکنر را وصل کنید، پیکربندی آن را باز کنید و
  نوع میزبان USB را تنظیم کنید.

پس از تغییر حالت، Windows اسکنر را دوباره به عنوان دستگاهی از نوع دیگر شناسایی می‌کند؛ پیش از اتصال چند
ثانیه صبر کنید.

برای برگرداندن اسکنر به حالت صفحه‌کلید در آینده — برای استفاده با نرم‌افزارهای دیگر — بارکد تنظیم
*USB Keyboard (HID)* را اسکن کنید، یا تنظیمات کارخانه را بازگردانید.

## 7. پیکربندی اسکنر Zebra برای GS1

GAIA Desktop وقتی بهترین تجزیه را انجام می‌دهد که اسکنر به آن بگوید چه نوع بارکدی خوانده است.

### ارسال AIM Code ID

**Transmit Code ID Character** را روی **AIM Code ID Character** تنظیم کنید، با بارکد تنظیم در Product
Reference Guide (بخش User Preferences) یا در 123Scan. آنگاه هر اسکن با شناسهٔ نمادشناسی خود آغاز می‌شود —
`]C1` برای GS1-128، `]d2` برای GS1 DataMatrix، `]Q3` برای GS1 QR Code، `]e0` برای GS1 DataBar — که
GAIA Desktop از آن برای نام‌بردن از حامل داده و اعمال قواعد مربوط به آن استفاده می‌کند.

بدون آن، GAIA Desktop همچنان رشته عناصر را تجزیه می‌کند و نمادشناسی را از خود اسکن برمی‌گیرد، اما گزارش
AIM Code IDای برای نمایش ندارد، و تشخیص یک بارکد ساده مانند EAN-13 از رشته عناصر GS1 دشوارتر می‌شود.

### بررسی نمادشناسی‌ها

مطمئن شوید انواع بارکدی که با آن‌ها کار می‌کنید **فعال** هستند: معمولاً GS1-128، GS1 DataMatrix،
GS1 DataBar، GS1 QR Code و EAN/UPC. بیشترشان در اسکنرهای دوبعدی Zebra به‌طور پیش‌فرض روشن‌اند؛ 123Scan
تنظیمات فعلی را نشان می‌دهد، و Product Reference Guide برای فعال‌کردن هر یک بارکدی دارد.

### ویژگی‌های تجزیهٔ GS1 در Zebra را خاموش نگه دارید

میان‌افزارهای جدید ویژگی‌هایی برای GS1 افزوده‌اند که روی خود اسکنر کار می‌کنند — **Label Parse+**،
**GS1 Digital Link** و **GS1 Retail POS parsing**. آن‌ها را **خاموش** نگه دارید، همان‌گونه که اسکنر عرضه
می‌شود: این ویژگی‌ها آنچه را اسکنر می‌فرستد بازقالب‌بندی یا کوتاه می‌کنند، در حالی که GAIA Desktop برای
تجزیه و اعتبارسنجی به دادهٔ خام نیاز دارد. برای اینکه هر یک چه می‌کند،
[اسکنرهای دوبعدی Zebra که پشتیبانی می‌شوند](#12-اسکنرهای-دوبعدی-zebra-که-پشتیبانی-میشوند) را ببینید.

### بدون پیشوند و پسوند

به خروجی اسکنر پیشوند، پسوند یا کلید Enter نیفزایید. GAIA Desktop هر اسکن را به صورت یک پیام کامل از راه
JavaPOS دریافت می‌کند و به هیچ‌یک از این‌ها نیاز ندارد؛ نویسه‌های اضافی سر از رشته عناصر درمی‌آورند.

## 8. نصب و اجرای GAIA Desktop

1. `gaia-desktop-1.0.0-win.zip` را از حالت فشرده خارج کنید، مثلاً در `C:\Tools\`. یک پوشه در آن است:

   ```
   gaia-desktop-1.0.0-win\
   ├── docs\
   │   └── GaiaDesktop-Zebra-Scanner-Windows.md      this guide
   ├── gaia-desktop.jar
   ├── lib\
   ├── readme.html                                   index of every guide
   └── run.bat
   ```

2. اسکنر را وصل کنید.
3. روی **`run.bat`** دوبار کلیک کنید. یک پنجرهٔ کنسول کنار برنامه باز می‌شود و باز می‌ماند: وضعیت اسکنر و
   خطاهای JavaPOS آنجا گزارش می‌شوند.
4. سطر نخست کنسول را بخوانید. می‌گوید `run.bat` چه چیزهایی پیدا کرده است:

   ```
   run.bat: Java 21.0.8 from JAVA_HOME; JavaFX from lib\; JavaPOS from lib\; Zebra services from C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   اگر با **`Zebra services from none (Zebra Scanner SDK not installed)`** تمام شود، SDK در مسیر
   پیش‌فرضش پیدا نشده است — آن را نصب کنید ([گام 3](#3-نصب-zebra-scanner-sdk)) یا
   [ZEBRA_HOME](#zebra_home) را تنظیم کنید. برنامه با این حال باز می‌شود، اما اسکنر نمی‌تواند وصل شود.

## 9. اتصال اسکنر

1. در نوار ابزار، **انتخابگر دستگاه** نام اسکنرهایی را که GAIA Desktop می‌شناسد فهرست می‌کند. آن را روی
   **`ZebraAllScanners`** بگذارید، یا نام مربوط به حالت USB اسکنر را از جدول
   [گام 6](#6-تنظیم-حالت-usb-اسکنر-zebra) برگزینید.
2. روی **اتصال اسکنر** کلیک کنید، یا **Ctrl+K** را بزنید (در منوی **اسکنر** هم هست).
3. نوار وضعیت به **`اسکنر: ZebraAllScanners`** (یا نامی که برگزیدید) تغییر می‌کند و سطر وضعیت
   *اسکنر متصل شد — ZebraAllScanners* را گزارش می‌دهد. اکنون روی دکمه نوشته شده **قطع اتصال اسکنر**.
4. یک بارکد GS1 را اسکن کنید. در بالای تاریخچهٔ دریافت‌ها ظاهر می‌شود و گزارش آن باز می‌شود. با روشن بودن
   AIM Code ID، گزارش حامل داده را نام می‌برد — *GS1-128*، *GS1 DataMatrix* — و رشته عناصر همهٔ
   جداکننده‌های FNC1 را نگه می‌دارد.

انتخابگر دستگاه انتخاب شما را میان اجراها به خاطر می‌سپارد. اسکنر تا وقتی آن را قطع نکنید یا برنامه را
نبندید وصل می‌ماند. اسکن در حالت‌های **ساخت** و **ترکیب** هم کار می‌کند: در ترکیب، هر اسکن یکی از
بارکدهایی می‌شود که ترکیب می‌شوند.

تا وقتی GAIA Desktop اسکنر را در اختیار دارد، برنامه‌های دیگر نمی‌توانند از آن استفاده کنند، و برعکس:
پیش از اتصال، 123Scan و هر نرم‌افزار دیگر صندوق فروش یا اسکنر را ببندید.

## 10. مرجع پیکربندی

### نام دستگاه‌ها

انتخابگر دستگاه از `jpos.xml` گنجانده‌شده در `gaia-desktop.jar` پر می‌شود. مدخل‌های اسکنر آن:

| نام دستگاه | نوع اسکنر | کاربرد |
|---|---|---|
| `ZebraAllScanners` | هر نوع | **پیش‌فرض.** هر حالت USB پشتیبانی‌شده |
| `ZebraAllScanners114` | هر نوع | نسخهٔ JavaPOS 1.14 از همان سرویس |
| `ZebraUSBHandHeld` | IBM Hand-held USB | اسکنر در حالت IBM Hand-held USB |
| `ZebraUSBTableTop` | IBM Table-top USB | حالت رومیزی |
| `ZebraUSBOPOS` | USB OPOS | حالت USB OPOS |
| `ZebraScannerSNAPI` | SNAPI | حالت SNAPI |
| `ZebraScannerUSB` | هر USB | هر حالت USB |
| `ZebraScannerSerialSSI` | سریال SSI | اسکنرهای با کابل سریال (نه USB) |
| `ZebraScannerSerialNIXMODB` | سریال NIXMODB | اسکنرهای با کابل سریال |
| `ZebraVDI` | VDI | اسکنرهایی که به یک دسکتاپ مجازی منتقل می‌شوند |

### ZEBRA_HOME

اگر Zebra SDK جایی غیر از مسیر پیش‌فرض نصب شده است، پیش از اجرای `run.bat` متغیر `ZEBRA_HOME` را روی پوشهٔ
`JPOS` آن تنظیم کنید — مثلاً در یک پروندهٔ دسته‌ای کوچک کنار آن:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

آنگاه `run.bat` jarهای سرویس Zebra را از `%ZEBRA_HOME%bin` برمی‌دارد و آن پوشه را برای DLLهای Zebra به
`PATH` می‌افزاید.

### jpos.xml خودتان

برای افزودن نام دستگاه یا تغییر تنظیمات یک مدخل، `jpos.xml` را از `gaia-desktop.jar` رونوشت بگیرید (یک
پروندهٔ zip است؛ هر ابزار بازکردن فشرده‌ای آن را باز می‌کند)، رونوشت را ویرایش کنید و GAIA Desktop را به
آن ارجاع دهید:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

آنگاه انتخابگر دستگاه اسکنرهای آن پرونده را فهرست می‌کند. اگر بیش از یک اسکنر Zebra وصل باشد، می‌توان
یک مدخل را از راه ویژگی `ScannerModel` یا `SerialNumber` آن به یکی از آن‌ها پیوند داد، همان‌طور که در
مدخل `ZebraAllScanners` آمده است.

### گزینه‌های دیگر

| تنظیم | روش |
|---|---|
| زبان برنامه | `run.bat --language=FR` (فقط برای همین اجرا)، یا پنل گزینه‌ها |
| گزینه‌های اضافی Java | `set GAIA_DESKTOP_OPTS=…` پیش از `run.bat` |
| Java همراه | یک پوشهٔ `jdk-21…` کنار `run.bat` بگذارید؛ پیش از `JAVA_HOME` به کار می‌رود |

## 11. عیب‌یابی

خطاها هنگام اتصال در یک کادر گفت‌وگو، در پنجرهٔ کنسول، و در پروندهٔ گزارش `logs\gaia-desktop.log` ظاهر
می‌شوند، در پوشه‌ای که `run.bat` از آن اجرا شده است (هنگام دوبار کلیک روی `run.bat`، همان پوشهٔ
GAIA Desktop). عدد داخل کروشه در گزارش، کد خطای JavaPOS است.

| آنچه می‌بینید | علت احتمالی | چه باید کرد |
|---|---|---|
| دکمهٔ *اتصال اسکنر* وجود ندارد | روی Windows اجرا نمی‌شود | اسکن فقط در Windows است |
| 123Scan اسکنر را پیدا نمی‌کند | کابل، درگاه USB، یا برنامهٔ دیگری اسکنر را در اختیار دارد | کابل یا درگاه دیگری امتحان کنید؛ GAIA Desktop و نرم‌افزارهای دیگر اسکنر را ببندید. GAIA Desktop اسکنری را که 123Scan نبیند نمی‌بیند |
| کنسول: `Zebra services from none (Zebra Scanner SDK not installed)` | SDK در مسیر پیش‌فرضش نیست | SDK نسخهٔ 64 بیتی را نصب کنید ([گام 3](#3-نصب-zebra-scanner-sdk))، یا [ZEBRA_HOME](#zebra_home) را تنظیم کنید |
| خطای **104**: *Could not connect to service with logicalName = …: …SymScannerSvc112Factory* | jarهای سرویس Zebra پیدا نشدند | مانند بالا — سطر `Zebra services from` کنسول را بررسی کنید |
| خطای **109**: *Service does not exist in loaded JCL registry* | نام دستگاه در پیکربندی اسکنر نیست، یا `javaPOS114.jar` از SDK به class path راه یافته است | نامی از انتخابگر دستگاه برگزینید؛ `javaPOS114.jar` را نیفزایید؛ اگر `jpos.xml` خودتان را به کار می‌برید، بررسی کنید نام در آن باشد |
| خطای **107** (سخت‌افزار نیست)، یا اتصال با وجود وصل‌بودن اسکنر شکست می‌خورد | اسکنر هنوز در حالت صفحه‌کلید USB است، یا درایور CoreScanner اجرا نمی‌شود | حالت USB را تنظیم کنید ([گام 6](#6-تنظیم-حالت-usb-اسکنر-zebra))؛ پس از نصب SDK، Windows را دوباره راه‌اندازی کنید؛ درگاه USB دیگری امتحان کنید |
| خطای **112** (پایان مهلت) یا **102** (اشغال) هنگام اتصال | برنامهٔ دیگری اسکنر را در اختیار دارد | 123Scan و هر نرم‌افزار دیگر اسکنر یا صندوق فروش را ببندید، سپس دوباره وصل شوید |
| `UnsatisfiedLinkError` … `CSJPOSScanner64` در کنسول | DLLهای Zebra بارگذاری نمی‌شوند — اغلب SDK سی‌ودو بیتی با Java شصت‌وچهار بیتی | SDK نسخهٔ 64 بیتی را نصب کنید؛ بررسی کنید `java -version` یک VM شصت‌وچهار بیتی گزارش دهد |
| اسکن‌ها به جای رسیدن به صورت دریافت، در نوار ورودی تایپ می‌شوند | اسکنر در حالت صفحه‌کلید USB است | حالت USB را تنظیم کنید ([گام 6](#6-تنظیم-حالت-usb-اسکنر-zebra)) |
| وصل است، اما اسکن‌ها نمی‌رسند | نام دستگاه برای حالت اسکنر نادرست است، یا اسکنر هنگام اتصال دوباره وصل شده است | قطع کنید، `ZebraAllScanners` را برگزینید، دوباره وصل شوید |
| گزارش AIM Code ID / حامل داده را نشان نمی‌دهد | ارسال AIM Code ID خاموش است | *Transmit Code ID Character → AIM Code ID* را روشن کنید ([گام 7](#7-پیکربندی-اسکنر-zebra-برای-gs1)) |
| رشته عناصر جداکننده‌هایش را ندارد، یا AIها به هم چسبیده‌اند | در حالت صفحه‌کلید اسکن شده، یا بدون `{GS}` دستی تایپ شده است | از حالت USB مخصوص JavaPOS استفاده کنید؛ هنگام تایپ، جداکننده‌ها را با دکمهٔ `{GS}` درج کنید |
| یک نوع بارکد هرگز خوانده نمی‌شود | آن نمادشناسی روی اسکنر غیرفعال است | آن را فعال کنید ([گام 7](#7-پیکربندی-اسکنر-zebra-برای-gs1)) |

اگر مشکل ادامه یافت، سطر `run.bat:` کنسول، متن کادر خطا و `logs\gaia-desktop.log` را با هم نگه دارید: این
سه با هم نشان می‌دهند کدام Java، کدام سرویس‌های Zebra و کدام نام دستگاه به کار رفته و اتصال دقیقاً کجا
شکست خورده است.

## 12. اسکنرهای دوبعدی Zebra که پشتیبانی می‌شوند

GAIA Desktop به اسکنری نیاز دارد که بارکدهایی را که دادهٔ GS1 با آن‌ها چاپ می‌شود بخواند — GS1-128،
GS1 DataBar، EAN/UPC، و برای بیشتر کاربردها، کدهای دوبعدی: **GS1 DataMatrix** و **GS1 QR Code**، که
URI از نوع **GS1 Digital Link** هم معمولاً به همین شکل چاپ می‌شود. یعنی یک **تصویرگر دوبعدی** Zebra:
اسکنر خطی (یک‌بعدی) اصلاً نمی‌تواند کدهای DataMatrix یا QR را بخواند.

خود اسکنر لازم نیست GS1 Application Identifiers یا Digital Link را بفهمد.
**GAIA Desktop هر دو را تجزیه می‌کند**: اسکن را همان‌طور که اسکنر خوانده می‌گیرد — با AIM Code ID و
جداکننده‌های FNC1 و همه‌چیز — و خودش آن را به AIها تقسیم می‌کند، یا URI از نوع Digital Link را به AIهای آن
تبدیل می‌کند.

### آزموده‌شده

| اسکنر | نوع | وضعیت |
|---|---|---|
| **DS8108** | تصویرگر دوبعدی دستی سیم‌دار | با GAIA Desktop **ساخته و آزموده شده** |

### انتظار می‌رود کار کنند

این‌ها تصویرگرهای دوبعدی Zebra هستند که مانند DS8108 از راه Scanner SDK و سرویس‌های JavaPOS شرکت Zebra
راه‌اندازی می‌شوند. با GAIA Desktop **آزموده نشده‌اند**؛ هر یک را طبق همین راهنما تنظیم کنید و برای
بارکدهای تنظیم از Quick Reference Guide یا Product Reference Guide خود آن استفاده کنید.

| خانواده | مدل‌ها (نمونه) |
|---|---|
| DS81x8 | DS8108 (سیم‌دار)، DS8178 (بی‌سیم) |
| DS22x8 | DS2208 (سیم‌دار)، DS2278 (بی‌سیم) — همه‌منظوره |
| DS36x8 | DS3608 (سیم‌دار)، DS3678 (بی‌سیم) — مقاوم، از جمله گونه‌های KD و XR |
| DS46x8 | DS4608 (سیم‌دار)، DS4678 (بی‌سیم) |
| DS9308 / DS9908 | اسکنرهای ارائه و بدون‌دست |
| MP7000 / MP7200 | اسکنرهای بیوپتیک چندصفحه‌ای و اسکنر-ترازو |
| CS6080 | اسکنر همراه بی‌سیم |

اسکنر بی‌سیم با پایهٔ خود گفت‌وگو می‌کند، و آنچه به رایانه وصل می‌شود همان پایه است: پایه را با USB وصل کنید
و این دو را یک اسکنر به حساب آورید. اسکنرهای خانواده‌های دیگر Zebra هم ممکن است کار کنند، اگر Scanner SDK
شرکت Zebra در یکی از حالت‌های USB در [گام 6](#6-تنظیم-حالت-usb-اسکنر-zebra) از آن‌ها پشتیبانی کند.

### ویژگی‌های GS1 روی خود اسکنر Zebra

جدا از خواندن بارکدها، برخی تصویرگرهای دوبعدی Zebra می‌توانند دادهٔ GS1 را روی خود اسکنر پردازش کنند، که از
راه 123Scan پیکربندی می‌شود:

| ویژگی | چه می‌کند | برای GAIA Desktop |
|---|---|---|
| **Label Parse+** | AIهای برچسب GS1 را روی اسکنر تجزیه می‌کند و فیلدهای بازقالب‌بندی‌شده می‌فرستد | **خاموش بماند** — GAIA Desktop دیگر AIها، جداکننده‌های FNC1 و AIM Code ID را نمی‌بیند |
| **GS1 Digital Link** | برای کالاهای خرده‌فروشی که هم EAN/UPC یک‌بعدی و هم کد Digital Link دوبعدی دارند: انتخاب می‌کند کدام فرستاده شود | **خاموش بماند** (پیش‌فرض) |
| **GS1 Retail POS parsing** | بارکدهای دوبعدی خرده‌فروشی را با نحو URI از نوع Digital Link یا رشته عناصر می‌خواند | **خاموش بماند** |

تنظیم **GS1 Digital Link** سه حالت دارد. **Mode 1 — GTIN only**، حالتی که پس از فعال‌شدن با آن آغاز
می‌کند، فقط GTIN را می‌فرستد، از هر بارکدی که آمده باشد، بنابراین بچ، تاریخ انقضا یا شمارهٔ سریال موجود در
Digital Link هرگز به GAIA Desktop نمی‌رسد. **Mode 2 — Prioritize 2D** اگر کد دوبعدی را در مهلت اولویت
(به‌طور پیش‌فرض 200 ms) ببیند آن را می‌فرستد، وگرنه کد یک‌بعدی را. **Mode 3 — Corroborate 1D and 2D GTINs
Match** کد یک‌بعدی را می‌فرستد، و اگر GTIN کد دوبعدی هم‌خوان باشد آن را هم. اگر این تنظیم برای نرم‌افزار
دیگری باید روشن باشد، از Mode 2 استفاده کنید نه Mode 1. در DS8108 این‌ها پارامترهای 2373 (روشن/خاموش)،
2374 (حالت) و 2491 (مهلت) هستند.

برای استفاده از این ویژگی‌ها **123Scan نسخهٔ 6 یا جدیدتر** و میان‌افزاری که آن‌ها را دارد لازم است. Zebra
از آوریل ۲۰۲۵ پشتیبانی از GS1 Digital Link را با به‌روزرسانی میان‌افزار می‌افزاید؛ تاریخ‌های زیر از یک
فروشندهٔ Zebra گرفته شده‌اند، پس یادداشت‌های انتشار میان‌افزار هر مدل را بررسی کنید:

| خانوادهٔ مدل | انتشار میان‌افزار GS1 Digital Link |
|---|---|
| DS81x8 | ۱۶ آوریل ۲۰۲۵ |
| MP7000 | ۲۱ آوریل ۲۰۲۵ |
| DS9908 | ۶ ژوئن ۲۰۲۵ |
| SP72 / SM72 | ۱۱ ژوئیه ۲۰۲۵ |
| DS46x8 | ۲۸ ژوئیه ۲۰۲۵ |
| MP7200 (Rev-C)، DS5502 | ۳۰ ژوئیه ۲۰۲۵ |
| DS9308 | ۲۹ اوت ۲۰۲۵ |
| DS22x8، DS1000 | ۵ سپتامبر ۲۰۲۵ (فقط آسیا و اقیانوسیه) |
| DS36x8 (از جمله KD و XR)، MS47 | ۳۰ سپتامبر ۲۰۲۵ |
| PL5000، SE4107 | ۱۵ اکتبر ۲۰۲۵ |
| CS6080 | ۳۱ دسامبر ۲۰۲۵ |

برای خواندن کدهای GS1 Digital Link در GAIA Desktop به هیچ‌یک از این ویژگی‌ها نیازی نیست: وقتی خاموش‌اند،
یک اسکنر دوبعدی Zebra با میان‌افزار جاری، کد QR از نوع Digital Link را مانند هر کد دیگری می‌خواند و
GAIA Desktop آن URI را به AIهایش تبدیل می‌کند.
