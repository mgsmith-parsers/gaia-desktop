# Настройка сканера Zebra — GAIA Desktop для Windows

Как установить и настроить сканер штрихкодов Zebra, чтобы GAIA Desktop считывал с него коды GS1
напрямую: каждый скан анализируется и добавляется в историю, а префикс AIM Code ID и каждый
разделитель FNC1 сохраняются без изменений. Оригинал:
[GaiaDesktop-Zebra-Scanner-Windows.md](../../GaiaDesktop-Zebra-Scanner-Windows.md).

GAIA Desktop разработан и протестирован с ручным имиджером **Zebra DS8108**, подключённым по USB.
Шаги подходят для любого 2D-сканера Zebra, который поддерживает Scanner SDK от Zebra; штрихкоды
настройки и названия меню конкретной модели приведены в её собственном Quick Reference Guide или
Product Reference Guide.

> **Только Windows.** Драйверы сканеров Zebra существуют только для Windows, поэтому в macOS и
> Linux GAIA Desktop не создаёт никаких элементов управления сканером. Всё остальное в приложении
> работает на любой платформе.

## 1. Что потребуется

| | |
|---|---|
| **Сканер** | 2D-сканер Zebra с USB-кабелем — см. [Поддерживаемые 2D-сканеры Zebra](#12-поддерживаемые-2d-сканеры-zebra) |
| **Компьютер** | Windows 10 или 11, 64-разрядная |
| **Java** | Java 21 или новее, **64-разрядная** |
| **Zebra Scanner SDK для Windows** | **64-разрядный**, с сайта поддержки Zebra — содержит драйвер и службы JavaPOS, которые использует GAIA Desktop |
| **Zebra 123Scan** | Бесплатная утилита настройки от Zebra, с сайта поддержки — нужна для обновления прошивки сканера и проверки его настроек |
| **GAIA Desktop** | `gaia-desktop-1.0.0-win.zip` |
| **Необязательно** | **Product Reference Guide** (PRG) сканера со штрихкодами настройки |

Как связаны части:

```
Zebra scanner ──USB──► Zebra CoreScanner driver ──► Zebra JavaPOS services ──► GAIA Desktop
                       (installed by the SDK)        (in the SDK's JPOS\bin)    (run.bat puts them on
                                                                                 the class path)
```

GAIA Desktop сам содержит API JavaPOS и конфигурацию, которая даёт сканеру имя (`jpos.xml` внутри
`gaia-desktop.jar`). Остальное предоставляет SDK Zebra: драйвер, который общается со сканером, и
классы служб Zebra, стоящие между JavaPOS и этим драйвером.

## 2. Установка Java

GAIA Desktop требует **Java 21 или новее**, причём **64-разрядную** версию — под стать
64-разрядным драйверам Zebra.

1. Установите JDK или JRE Java 21 для Windows x64 — например, Eclipse Temurin с adoptium.net.
   Если установщик предлагает задать `JAVA_HOME`, разрешите ему.
2. Проверьте в командной строке:

   ```
   java -version
   ```

   В первой строке должна быть версия 21 или новее; 64-разрядная Java также выводит
   `64-Bit Server VM`.

`run.bat` ищет Java в таком порядке: папка `jdk*` рядом с `run.bat`, затем `JAVA_HOME`, затем
`java` в `PATH`. Всё старше 21 он отклоняет с сообщением об этом.

---

## 3. Установка Zebra Scanner SDK

1. Скачайте **Zebra Scanner SDK для Windows (64-разрядный)** с сайта поддержки Zebra.
2. Запустите установщик. Если он предлагает выбор компонентов, убедитесь, что компонент **JPOS**
   (JavaPOS) включён.
3. Оставьте путь установки по умолчанию. GAIA Desktop ищет JavaPOS-часть SDK здесь:

   ```
   C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   и ожидает jar-файлы служб Zebra (`JposServiceScanner.jar`, `JposServiceJniScanner.jar`, …) и
   нативные библиотеки (`CSJPOSScanner64.dll`, …) в её папке `bin\`. Если SDK установлен в другое
   место, см. [ZEBRA_HOME](#zebra_home).
4. После установки **перезагрузите Windows**. Драйвер CoreScanner из SDK работает в фоне и должен
   быть запущен до того, как GAIA Desktop сможет обратиться к сканеру; перезагрузка — самый простой
   способ в этом убедиться.

## 4. Установка 123Scan

123Scan — бесплатная утилита Zebra для настройки её сканеров. На следующем шаге она нужна для
обновления прошивки сканера, а потом это самый простой способ проверять и менять его настройки.

1. Скачайте **123Scan** с сайта поддержки Zebra и запустите установщик.
2. Подключите сканер Zebra и запустите 123Scan. Утилита должна найти сканер и показать его модель,
   серийный номер и текущую версию прошивки. Если этого не происходит, прежде чем продолжать,
   попробуйте другой USB-порт или кабель — сканер, которого не видит 123Scan, не увидит и
   GAIA Desktop.

## 5. Обновление прошивки сканера Zebra

Перед настройкой обновите прошивку сканера до последней версии. Обновления прошивки исправляют
ошибки декодирования и поддерживают совместимость сканера с драйвером Zebra, установленным SDK.

1. Закройте **GAIA Desktop** и любые другие программы, которые могут использовать сканер: на время
   обновления 123Scan нужен монопольный доступ к сканеру.
2. В 123Scan при подключённом сканере выберите обновление прошивки. 123Scan сравнивает прошивку
   сканера с последней версией, опубликованной Zebra, и предлагает скачать и установить её. Если у
   компьютера нет доступа в Интернет, скачайте прошивку сканера со страницы его поддержки на сайте
   Zebra и загрузите файл в 123Scan.
3. Запустите обновление и **не отключайте сканер, пока 123Scan не сообщит о завершении**. Это
   занимает несколько минут; в конце сканер перезагружается. Отключение посреди процесса может
   вывести сканер из строя.
4. Убедитесь, что 123Scan теперь показывает новую версию прошивки.

Обновление может вернуть часть настроек к значениям по умолчанию; поэтому сканер настраивается на
двух следующих шагах, уже после прошивки.

## 6. Выбор режима USB сканера Zebra

Этот шаг пропускают чаще всего. **С завода сканер Zebra работает как USB-клавиатура** (режим
USB HID Keyboard): он «печатает» каждый штрихкод туда, где находится фокус. В этом режиме
*Подключить сканер* в GAIA Desktop не может его найти, а всё, что вводится в текстовое поле, теряет
разделители FNC1 — и это меняет смысл строки элементов GS1.

Переключите сканер в режим, в котором драйвер Zebra общается с ним напрямую:

| Режим USB сканера | Имя устройства в GAIA Desktop | Примечания |
|---|---|---|
| **IBM Hand-held USB** | `ZebraUSBHandHeld` или `ZebraAllScanners` | Рекомендуется |
| SNAPI (с передачей изображений или без) | `ZebraScannerSNAPI` или `ZebraAllScanners` | Собственный USB-протокол Zebra; тоже работает |
| IBM Table-top USB | `ZebraUSBTableTop` или `ZebraAllScanners` | Для настольных сканеров |
| USB OPOS (Hand-held) | `ZebraUSBOPOS` или `ZebraAllScanners` | |
| USB HID Keyboard (заводская настройка) | — | **Не подключится** |

`ZebraAllScanners`, имя устройства по умолчанию в GAIA Desktop, принимает сканер в любом из
поддерживаемых режимов, поэтому после выбора режима обычно достаточно значения по умолчанию.

Сменить режим можно одним из двух способов:

- **отсканируйте штрихкод настройки** нужного режима — например, *IBM Hand-held USB* — из Quick
  Reference Guide или Product Reference Guide сканера (раздел USB Host Types / USB Device Type);
  сканер подтвердит звуковым сигналом. Или
- **воспользуйтесь 123Scan** ([шаг 4](#4-установка-123scan)): подключите сканер, откройте его
  настройки и задайте тип USB-хоста.

После смены режима Windows заново определяет сканер как устройство другого типа; подождите
несколько секунд, прежде чем подключаться.

Чтобы позже вернуть сканер в режим клавиатуры — для другой программы — отсканируйте штрихкод
настройки *USB Keyboard (HID)* или восстановите заводские настройки.

## 7. Настройка сканера Zebra для GS1

GAIA Desktop анализирует лучше всего, когда сканер сообщает, какой тип штрихкода он прочитал.

### Передача AIM Code ID

Установите для **Transmit Code ID Character** значение **AIM Code ID Character** — штрихкодом
настройки из Product Reference Guide (User Preferences) или в 123Scan. Тогда каждый скан начинается
с идентификатора символики — `]C1` для GS1-128, `]d2` для GS1 DataMatrix, `]Q3` для GS1 QR Code,
`]e0` для GS1 DataBar, — по которому GAIA Desktop определяет носитель данных и применяет его
правила.

Без него GAIA Desktop всё равно анализирует строку элементов и берёт символику из самого скана, но
в отчёте не будет AIM Code ID, а простой штрихкод вроде EAN-13 труднее отличить от строки элементов
GS1.

### Проверка символик

Убедитесь, что нужные вам типы штрихкодов **включены**: обычно GS1-128, GS1 DataMatrix,
GS1 DataBar, GS1 QR Code и EAN/UPC. На 2D-сканерах Zebra большинство из них включены по умолчанию;
123Scan показывает текущие настройки, а в Product Reference Guide есть штрихкод для включения
каждой.

### Функции анализа GS1 от Zebra оставьте выключенными

Новые прошивки добавляют функции GS1, работающие в самом сканере, — **Label Parse+**,
**GS1 Digital Link** и **GS1 Retail POS parsing**. Оставьте их **выключенными**, как при поставке:
они переформатируют или сокращают то, что отправляет сканер, а GAIA Desktop для анализа и проверки
нужны исходные данные. Что делает каждая, см. в разделе
[Поддерживаемые 2D-сканеры Zebra](#12-поддерживаемые-2d-сканеры-zebra).

### Без префиксов и суффиксов

Не добавляйте к выводу сканера префикс, суффикс или клавишу Enter. GAIA Desktop получает каждый скан
через JavaPOS как цельное сообщение, и ничего из этого ему не нужно; лишние символы попали бы в
строку элементов.

## 8. Установка и запуск GAIA Desktop

1. Распакуйте `gaia-desktop-1.0.0-win.zip`, например в `C:\Tools\`. В архиве одна папка:

   ```
   gaia-desktop-1.0.0-win\
   ├── docs\
   │   └── GaiaDesktop-Zebra-Scanner-Windows.md      this guide
   ├── gaia-desktop.jar
   ├── lib\
   ├── readme.html                                   index of every guide
   └── run.bat
   ```

2. Подключите сканер.
3. Дважды щёлкните **`run.bat`**. Рядом с приложением откроется окно консоли и останется открытым:
   туда выводятся состояние сканера и ошибки JavaPOS.
4. Прочтите первую строку в консоли. В ней сказано, что нашёл `run.bat`:

   ```
   run.bat: Java 21.0.8 from JAVA_HOME; JavaFX from lib\; JavaPOS from lib\; Zebra services from C:\Program Files\Zebra Technologies\Barcode Scanners\Scanner SDK\JPOS\
   ```

   Если она заканчивается на **`Zebra services from none (Zebra Scanner SDK not installed)`**, SDK
   не найден в расположении по умолчанию — установите его
   ([шаг 3](#3-установка-zebra-scanner-sdk)) или задайте [ZEBRA_HOME](#zebra_home). Приложение
   всё равно запустится, но сканер подключиться не сможет.

---

## 9. Подключение сканера

1. На панели инструментов **список устройств** показывает имена сканеров, известные GAIA Desktop.
   Оставьте в нём **`ZebraAllScanners`** или выберите имя для режима USB сканера из таблицы на
   [шаге 6](#6-выбор-режима-usb-сканера-zebra).
2. Нажмите **Подключить сканер** или клавиши **Ctrl+K** (команда есть и в меню **Сканер**).
3. Строка состояния сменится на **`сканер: ZebraAllScanners`** (или выбранное имя), а
   строка статуса сообщит *Сканер подключён — ZebraAllScanners*. Кнопка теперь называется
   **Отключить сканер**.
4. Отсканируйте штрихкод GS1. Он появится в начале истории захватов, и откроется его отчёт. При
   включённом AIM Code ID отчёт называет носитель данных — *GS1-128*, *GS1 DataMatrix*, — а строка
   элементов сохраняет каждый разделитель FNC1.

Список устройств запоминает выбор между запусками. Сканер остаётся подключённым, пока вы не
отключите его или не закроете приложение. Сканы работают и в режимах **Сборка** и
**Объединение**: в режиме «Объединение» каждый скан становится одним из объединяемых
штрихкодов.

Пока сканер занят GAIA Desktop, другие программы не могут им пользоваться, и наоборот: перед
подключением закройте 123Scan и любые другие кассовые программы или программы для сканеров.

## 10. Справочник по настройке

### Имена устройств

Список устройств заполняется из файла `jpos.xml`, входящего в `gaia-desktop.jar`. Его записи для
сканеров:

| Имя устройства | Тип сканера | Для чего |
|---|---|---|
| `ZebraAllScanners` | любой | **По умолчанию.** Любой поддерживаемый режим USB |
| `ZebraAllScanners114` | любой | Версия той же службы для JavaPOS 1.14 |
| `ZebraUSBHandHeld` | IBM Hand-held USB | Сканер в режиме IBM Hand-held USB |
| `ZebraUSBTableTop` | IBM Table-top USB | Настольный режим |
| `ZebraUSBOPOS` | USB OPOS | Режим USB OPOS |
| `ZebraScannerSNAPI` | SNAPI | Режим SNAPI |
| `ZebraScannerUSB` | любой USB | Любой режим USB |
| `ZebraScannerSerialSSI` | последовательный SSI | Сканеры с последовательным кабелем (не USB) |
| `ZebraScannerSerialNIXMODB` | последовательный NIXMODB | Сканеры с последовательным кабелем |
| `ZebraVDI` | VDI | Сканеры, перенаправленные в виртуальный рабочий стол |

### ZEBRA_HOME

Если SDK Zebra установлен не в расположение по умолчанию, перед запуском `run.bat` задайте
`ZEBRA_HOME` равным его папке `JPOS` — например, в небольшом пакетном файле рядом с ним:

```bat
@echo off
set "ZEBRA_HOME=D:\Zebra\Scanner SDK\JPOS\"
call "%~dp0run.bat" %*
```

Тогда `run.bat` берёт jar-файлы служб Zebra из `%ZEBRA_HOME%bin` и добавляет эту папку в `PATH`
для библиотек DLL Zebra.

### Собственный jpos.xml

Чтобы добавить имя устройства или изменить настройки записи, скопируйте `jpos.xml` из
`gaia-desktop.jar` (это zip-архив; его откроет любая программа распаковки), отредактируйте копию и
укажите её GAIA Desktop:

```bat
set GAIA_DESKTOP_OPTS=-Djpos.config.populatorFileURL=file:///C:/Tools/jpos.xml
run.bat
```

Тогда список устройств покажет сканеры из этого файла. Если подключено несколько сканеров Zebra,
запись можно привязать к одному из них через свойство `ScannerModel` или `SerialNumber`, как в
записи `ZebraAllScanners`.

### Прочие параметры

| Параметр | Как задать |
|---|---|
| Язык приложения | `run.bat --language=FR` (только для этого запуска) или Панель параметров |
| Дополнительные параметры Java | `set GAIA_DESKTOP_OPTS=…` перед `run.bat` |
| Встроенная Java | положите папку `jdk-21…` рядом с `run.bat`; она используется раньше `JAVA_HOME` |

## 11. Устранение неполадок

Ошибки появляются в диалоговом окне при подключении, в окне консоли и в файле журнала
`logs\gaia-desktop.log` в папке, из которой запущен `run.bat` (в папке GAIA Desktop, если `run.bat`
запущен двойным щелчком). Число в квадратных скобках в журнале — код ошибки JavaPOS.

| Что вы видите | Вероятная причина | Что делать |
|---|---|---|
| Нет кнопки *Подключить сканер* | Приложение запущено не в Windows | Сканирование доступно только в Windows |
| 123Scan не находит сканер | Кабель, USB-порт или сканер занят другой программой | Попробуйте другой кабель или порт; закройте GAIA Desktop и другие программы для сканеров. Сканер, которого не видит 123Scan, не увидит и GAIA Desktop |
| Консоль: `Zebra services from none (Zebra Scanner SDK not installed)` | SDK нет в расположении по умолчанию | Установите 64-разрядный SDK ([шаг 3](#3-установка-zebra-scanner-sdk)) или задайте [ZEBRA_HOME](#zebra_home) |
| Ошибка **104**: *Could not connect to service with logicalName = …: …SymScannerSvc112Factory* | Не найдены jar-файлы служб Zebra | Как выше — проверьте строку консоли `Zebra services from` |
| Ошибка **109**: *Service does not exist in loaded JCL registry* | Имени устройства нет в конфигурации сканера, или `javaPOS114.jar` из SDK попал в class path | Выберите имя из списка устройств; не добавляйте `javaPOS114.jar`; если используете собственный `jpos.xml`, проверьте, что имя в нём есть |
| Ошибка **107** (нет оборудования) или подключение не удаётся при подключённом сканере | Сканер всё ещё в режиме USB-клавиатуры, или драйвер CoreScanner не запущен | Выберите режим USB ([шаг 6](#6-выбор-режима-usb-сканера-zebra)); перезагрузите Windows после установки SDK; попробуйте другой USB-порт |
| Ошибка **112** (тайм-аут) или **102** (занят) при подключении | Сканер занят другой программой | Закройте 123Scan и любые другие программы для сканеров или кассовые программы, затем подключитесь снова |
| `UnsatisfiedLinkError` … `CSJPOSScanner64` в консоли | Не удаётся загрузить DLL Zebra — часто 32-разрядный SDK с 64-разрядной Java | Установите 64-разрядный SDK; проверьте, что `java -version` сообщает о 64-разрядной VM |
| Сканы печатаются в строку ввода, а не поступают как захваты | Сканер в режиме USB-клавиатуры | Выберите режим USB ([шаг 6](#6-выбор-режима-usb-сканера-zebra)) |
| Подключено, но сканы не поступают | Неверное имя устройства для режима сканера, или сканер переподключили во время соединения | Отключитесь, выберите `ZebraAllScanners`, подключитесь снова |
| В отчёте нет AIM Code ID или носителя данных | Передача AIM Code ID выключена | Включите *Transmit Code ID Character → AIM Code ID* ([шаг 7](#7-настройка-сканера-zebra-для-gs1)) |
| В строке элементов нет разделителей, или AI сливаются | Сканировали в режиме клавиатуры или вводили вручную без `{GS}` | Используйте режим USB для JavaPOS; при ручном вводе вставляйте разделители кнопкой `{GS}` |
| Какой-то тип штрихкода никогда не считывается | Эта символика выключена в сканере | Включите её ([шаг 7](#7-настройка-сканера-zebra-для-gs1)) |

Если проблема не уходит, сохраните вместе строку консоли `run.bat:`, текст окна ошибки и
`logs\gaia-desktop.log`: вместе они показывают, какая Java, какие службы Zebra и какое имя
устройства использовались и где именно не удалось подключение.

## 12. Поддерживаемые 2D-сканеры Zebra

GAIA Desktop нужен сканер, читающий штрихкоды, в которых печатаются данные GS1, — GS1-128,
GS1 DataBar, EAN/UPC и, для большинства задач, 2D-коды **GS1 DataMatrix** и **GS1 QR Code**, в
котором обычно печатается и URI **GS1 Digital Link**. Значит, нужен **2D-имиджер** Zebra: линейный
(1D) сканер вообще не читает коды DataMatrix и QR.

Самому сканеру не нужно понимать Application Identifiers GS1 или Digital Link.
**GAIA Desktop анализирует и то, и другое**: он берёт скан таким, каким его прочитал сканер, — с
AIM Code ID и разделителями FNC1 — и делит его на AI или сам преобразует URI Digital Link в его AI.

### Протестировано

| Сканер | Тип | Статус |
|---|---|---|
| **DS8108** | Проводной ручной 2D-имиджер | **Разработано и протестировано** с GAIA Desktop |

### Должны работать

Это 2D-имиджеры Zebra, которые, как и DS8108, управляются через Scanner SDK и службы JavaPOS от
Zebra. С GAIA Desktop они **не тестировались**; настраивайте каждый по этому руководству, а штрихкоды
настройки берите из его собственного Quick Reference Guide или Product Reference Guide.

| Семейство | Модели (примеры) |
|---|---|
| DS81x8 | DS8108 (проводной), DS8178 (беспроводной) |
| DS22x8 | DS2208 (проводной), DS2278 (беспроводной) — общего назначения |
| DS36x8 | DS3608 (проводной), DS3678 (беспроводной) — защищённые, включая варианты KD и XR |
| DS46x8 | DS4608 (проводной), DS4678 (беспроводной) |
| DS9308 / DS9908 | Презентационные сканеры и сканеры «свободные руки» |
| MP7000 / MP7200 | Многоплоскостные биоптические сканеры и сканеры-весы |
| CS6080 | Беспроводной сканер-компаньон |

Беспроводной сканер общается со своей базой, а к компьютеру подключается база: подключите базу по
USB и считайте эту пару одним сканером. Сканеры других семейств Zebra тоже могут работать, если
Scanner SDK от Zebra поддерживает их в одном из режимов USB из [шага 6](#6-выбор-режима-usb-сканера-zebra).

### Встроенные функции GS1 сканеров Zebra

Помимо чтения штрихкодов, некоторые 2D-имиджеры Zebra умеют обрабатывать данные GS1 в самом
сканере; настраивается это через 123Scan:

| Функция | Что делает | Для GAIA Desktop |
|---|---|---|
| **Label Parse+** | Разбирает AI этикетки GS1 в сканере и отправляет переформатированные поля | **Оставьте выключенной** — GAIA Desktop перестал бы видеть AI, разделители FNC1 и AIM Code ID |
| **GS1 Digital Link** | Для розничных товаров с 1D-кодом EAN/UPC и 2D-кодом Digital Link: выбирает, какой из них отправить | **Оставьте выключенной** (по умолчанию) |
| **GS1 Retail POS parsing** | Читает розничные 2D-штрихкоды в синтаксисе URI Digital Link или строки элементов | **Оставьте выключенной** |

У настройки **GS1 Digital Link** три режима. **Mode 1 — GTIN only** — режим, с которого она
начинает после включения, — отправляет только GTIN, из какого бы штрихкода он ни был, поэтому
партия, срок годности или серийный номер из Digital Link никогда не дошли бы до GAIA Desktop.
**Mode 2 — Prioritize 2D** отправляет 2D-код, если он замечен в пределах тайм-аута приоритета (по
умолчанию 200 мс), иначе — 1D. **Mode 3 — Corroborate 1D and 2D GTINs Match** отправляет 1D, а также
2D, если его GTIN совпадает. Если настройку нужно оставить включённой ради другой программы,
используйте Mode 2, а не Mode 1. У DS8108 это параметры 2373 (вкл./выкл.), 2374 (режим) и 2491
(тайм-аут).

Для этих функций нужны **123Scan версии 6 или новее** и прошивка, в которой они есть. С апреля 2025
года Zebra добавляет поддержку GS1 Digital Link через обновления прошивки; даты ниже получены от
реселлера Zebra, поэтому сверяйтесь с примечаниями к выпуску прошивки каждой модели:

| Семейство моделей | Прошивка с GS1 Digital Link выпущена |
|---|---|
| DS81x8 | 16 апреля 2025 |
| MP7000 | 21 апреля 2025 |
| DS9908 | 6 июня 2025 |
| SP72 / SM72 | 11 июля 2025 |
| DS46x8 | 28 июля 2025 |
| MP7200 (Rev-C), DS5502 | 30 июля 2025 |
| DS9308 | 29 августа 2025 |
| DS22x8, DS1000 | 5 сентября 2025 (только Азиатско-Тихоокеанский регион) |
| DS36x8 (включая KD и XR), MS47 | 30 сентября 2025 |
| PL5000, SE4107 | 15 октября 2025 |
| CS6080 | 31 декабря 2025 |

Ни одна из этих функций не нужна, чтобы считывать коды GS1 Digital Link в GAIA Desktop: когда они
выключены, 2D-сканер Zebra с актуальной прошивкой читает QR-код Digital Link как любой другой, а
GAIA Desktop преобразует URI в его AI.
