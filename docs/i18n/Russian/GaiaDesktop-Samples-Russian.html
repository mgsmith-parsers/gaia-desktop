Примеры GAIA Desktop

По одному штрихкоду для каждого носителя данных GS1 и традиционная этикетка для режима «Объединение». Сканируйте их прямо с экрана сканером Zebra или скопируйте строку элементов в строку ввода GAIA Desktop.

Каждая строка элементов начинается с AIM Code ID, который сообщает GAIA, с какого носителя данных получено сканирование. {GS} обозначает FNC1 — разделитель после AI переменной длины; строка ввода заменяет его настоящим символом. Изображения штрихкодов рисует онлайн-генератор штрихкодов TEC-IT, поэтому при открытии этой страницы ему отправляются данные примеров. При высокой нагрузке вместо штрихкода может появиться уведомление о превышении лимита запросов; обновите страницу позже.

Анализ

В режиме «Анализ» каждое сканирование или вставленный текст разбирается на Application Identifiers.
