GAIA Desktop Samples

One barcode for each GS1 data carrier, and a legacy label for Combine. Scan them off the screen with a Zebra scanner, or copy an element string into GAIA Desktop's input bar.

Each element string starts with its AIM Code ID, which tells GAIA which data carrier the scan came from. {GS} stands for FNC1, the separator after a variable-length AI; the input bar converts it to the real character. The barcode images are drawn by TEC-IT's online barcode generator, so opening this page sends the sample data to it. Under heavy use it may show a rate-limit notice in place of a barcode; reload later.

Parse

In Parse mode, every scan or paste is read into its Application Identifiers.
