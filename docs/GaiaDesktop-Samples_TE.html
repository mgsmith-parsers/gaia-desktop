GAIA Desktop నమూనాలు

ప్రతి GS1 డేటా వాహకానికి ఒక బార్‌కోడ్, అలాగే కలపడం కోసం ఒక సాంప్రదాయ లేబుల్. వీటిని Zebra స్కానర్‌తో నేరుగా స్క్రీన్ నుండి స్కాన్ చేయండి, లేదా ఒక మూలకం స్ట్రింగ్‌ను GAIA Desktop ఇన్‌పుట్ బార్‌లోకి కాపీ చేయండి.

ప్రతి మూలకం స్ట్రింగ్ దాని AIM Code IDతో మొదలవుతుంది, అది స్కాన్ ఏ డేటా వాహకం నుండి వచ్చిందో GAIAకి చెబుతుంది. {GS} అంటే FNC1, అంటే మారే పొడవు గల AI తర్వాత వచ్చే విభాజకం; ఇన్‌పుట్ బార్ దాన్ని అసలు అక్షరంగా మారుస్తుంది. బార్‌కోడ్ చిత్రాలను TEC-IT ఆన్‌లైన్ బార్‌కోడ్ జనరేటర్ గీస్తుంది, కాబట్టి ఈ పేజీని తెరిస్తే నమూనా డేటా దానికి పంపబడుతుంది. ఎక్కువ వినియోగం ఉన్నప్పుడు అది బార్‌కోడ్‌కు బదులుగా అభ్యర్థన పరిమితి నోటీసును చూపవచ్చు; తర్వాత మళ్లీ లోడ్ చేయండి.

విశ్లేషణ

విశ్లేషణ మోడ్‌లో, ప్రతి స్కాన్ లేదా అతికించిన పాఠ్యం దాని Application Identifiersగా విభజించబడుతుంది.

కలపడం

ఒక సాంప్రదాయ లాజిస్టిక్స్ లేబుల్ తన డేటాను అనేక GS1-128 బార్‌కోడ్‌లలో ఉంచుతుంది. కలపడం మోడ్‌లో వాటిలో గరిష్ఠంగా మూడింటిని స్కాన్ చేయండి, GAIA Desktop వాటి AIలను ఒక GS1 DataMatrix మోసే ఒకే మూలకం స్ట్రింగ్‌గా కలిపి, మొత్తాన్ని ఒకేసారి ధృవీకరిస్తుంది. ఈ మూడింటిని వరుసగా స్కాన్ చేయండి:
